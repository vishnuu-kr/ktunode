# ECONOMICS FOR ENGINEERS - Module 4: Value Analysis and Value Engineering

## Topic: Use Value

---

### 1. Introduction to Use Value

#### 1.1. Definition of Use Value

**Use Value** refers to the intrinsic worth or utility that a product, service, or component provides to its user. It is primarily concerned with **functionality** – what the item *does* and how well it performs its intended purpose.

*   **Key Concept:** Focus on the *performance* and *utility* delivered.
*   **Contrast with Esteem Value:** Use value is distinct from esteem value, which relates to the prestige, brand image, or psychological satisfaction derived from owning an item (e.g., a luxury watch vs. a basic timekeeping device).

#### 1.2. Importance in Value Analysis and Value Engineering (VA/VE)

VA/VE aims to achieve the required **use value** at the **lowest possible cost** without sacrificing quality or performance. Understanding use value is the cornerstone of these methodologies.

*   **Goal of VA/VE:** Maximize the ratio of Use Value to Cost.
*   **Core Question:** "What does this product/service *do*?" and "How can we achieve this function more effectively or economically?"

---

### 2. Dimensions of Use Value

Use Value can be broken down into several contributing factors, which are crucial for analysis.

#### 2.1. Basic Use Value (Primary Function)

This refers to the fundamental reason for the existence of a product or component. It's the core function it must perform.

*   **Example:**
    *   A chair's basic use value is to provide a place to sit.
    *   A screw's basic use value is to fasten two or more components together.
    *   A bridge's basic use value is to facilitate crossing an obstacle (river, valley).

#### 2.2. Secondary Use Value (Ancillary Functions)

These are functions that support or enhance the primary function, or provide additional benefits.

*   **Example:**
    *   For a chair: Ergonomics (comfort), aesthetics (design), stackability (storage efficiency).
    *   For a screw: Ease of installation, corrosion resistance, decorative appearance.
    *   For a bridge: Aesthetic appeal, capacity for pedestrian traffic, integrated lighting.

#### 2.3. Performance Characteristics

These are the quantifiable attributes that define how well a product or component performs its intended function.

*   **Examples:**
    *   **Mechanical:** Strength, durability, weight, speed, accuracy, efficiency.
    *   **Electrical:** Voltage, current, resistance, conductivity.
    *   **Chemical:** Purity, reactivity, viscosity.
    *   **Thermal:** Insulation, conductivity, heat resistance.

#### 2.4. Reliability and Maintainability

The ability of a product or component to perform its function consistently over time and the ease with which it can be repaired or serviced.

*   **Reliability:** Mean Time Between Failures (MTBF), Mean Time To Repair (MTTR).
*   **Maintainability:** Ease of access, availability of spare parts, simplicity of repair procedures.

#### 2.5. Safety and Environmental Impact

Functions related to user safety and the product's impact on the environment.

*   **Safety:** Non-toxicity, fire resistance, protection against hazards.
*   **Environmental:** Recyclability, biodegradability, energy efficiency, reduced pollution.

### 3. Quantifying and Measuring Use Value

While use value is often qualitative, it can be quantified or assessed through various methods to facilitate comparison and decision-making.

#### 3.1. Functional Analysis

The process of identifying and defining all the functions of a product or system. This involves breaking down complex items into their constituent parts and their respective functions.

*   **Techniques:**
    *   **Function Analysis System Technique (FAST):** A structured method for graphically displaying functions and their relationships, identifying primary and secondary functions, and exploring alternative ways to achieve them. (Referenced in Park's "Contemporary Engineering Economics").
    *   **Checklists and Brainstorming:** Systematically listing all functions.

#### 3.2. Function-Cost Analysis

This involves estimating the cost associated with each identified function. The goal is to understand where the costs are incurred for achieving the required use value.

*   **Process:**
    1.  Identify all functions.
    2.  Estimate the cost of performing each function.
    3.  Analyze the function-cost relationships.

#### 3.3. Use Value Index (UVI)

A conceptual measure to compare the use value of different design alternatives or components.

*   **Formula (Conceptual):**
    $UVI = \frac{\text{Use Value}}{\text{Cost}}$

    *   *Note:* "Use Value" itself needs to be defined or quantified. This can be done through subjective scoring or by assigning weights to performance characteristics.

#### 3.4. Performance Metrics and Benchmarking

Using objective performance metrics to compare a product or component against competitors or industry standards.

*   **Example:** Comparing the fuel efficiency (km/liter) of different car engines or the processing speed (GHz) of different microprocessors. (Referenced in Thuesen & Fabrycky's "Engineering Economy" for performance evaluation).

### 4. Strategies to Enhance Use Value (Within VA/VE Context)

The objective is to increase the use value or maintain it while reducing cost, or to achieve better performance for the same cost.

#### 4.1. Improving Performance Characteristics

*   **Upgrade Materials:** Using stronger, lighter, or more durable materials that enhance performance.
*   **Optimize Design:** Redesigning components for better efficiency, strength, or functionality.
*   **Refine Processes:** Improving manufacturing or operational processes to achieve higher precision or reliability.

#### 4.2. Reducing Cost of Existing Functions

*   **Material Substitution:** Finding cheaper materials that perform the same function adequately.
*   **Design Simplification:** Eliminating unnecessary features or consolidating components.
*   **Standardization:** Using standard parts instead of custom-made ones.
*   **Process Improvement:** Streamlining manufacturing or assembly to reduce labor, waste, or energy.

#### 4.3. Eliminating Unnecessary Functions

*   **Function Analysis:** Identifying functions that are not essential for the product's primary purpose and can be removed without significant impact.

#### 4.4. Improving Reliability and Maintainability

*   **Redesign for Reliability:** Incorporating features that reduce failure rates.
*   **Design for Maintainability:** Making components easier to access and replace.

### 5. Examples Illustrating Use Value

#### Example 1: A Simple Screw

*   **Product:** A standard steel screw.
*   **Basic Use Value:** To fasten components.
*   **Secondary Use Value:** Corrosion resistance (if coated), ease of driving (proper thread pitch), aesthetic appeal (polished finish).
*   **Performance Characteristics:** Tensile strength, shear strength, thread grip.
*   **VA/VE Scenario:**
    *   **Problem:** High cost of a specific type of stainless steel screw used in outdoor furniture.
    *   **Analysis:** The basic use value (fastening) is critical. Corrosion resistance is also important due to outdoor exposure. Aesthetic appeal is secondary.
    *   **Alternatives:**
        *   **Material Substitution:** Use a galvanized steel screw with a durable polymer coating. This offers good corrosion resistance at a lower cost than stainless steel.
        *   **Design Simplification:** Could a simpler thread design be used without compromising grip?
    *   **Outcome:** Using the coated galvanized screw maintains the required use value (fastening and corrosion resistance) at a significantly lower cost.

#### Example 2: A Chair

*   **Product:** An office chair.
*   **Basic Use Value:** To provide a comfortable and supportive seating position for extended periods.
*   **Secondary Use Values:** Ergonomic adjustability (height, backrest angle), durability, aesthetic appeal, portability, stackability (if applicable).
*   **Performance Characteristics:** Lumbar support effectiveness, weight capacity, seat height range, upholstery durability.
*   **VA/VE Scenario:**
    *   **Problem:** High manufacturing cost of a popular office chair model.
    *   **Analysis:** The core function is comfortable and supportive seating. The adjustability features (secondary use value) are key selling points.
    *   **Alternatives:**
        *   **Material Substitution:** Replace a complex metal mechanism for backrest adjustment with a simpler, robust plastic component if performance is not compromised.
        *   **Design Simplification:** Can the seat and backrest be molded as a single unit for easier assembly and lower material usage?
        *   **Manufacturing Process:** Explore injection molding for plastic parts instead of machining if volumes are high.
    *   **Outcome:** Re-designing the adjustment mechanism and optimizing the molding process reduces the cost while retaining the essential use value and key features that customers expect.

### 6. Key Concepts and Definitions Summary

*   **Use Value:** The intrinsic worth or utility of a product/service based on its functionality.
*   **Basic Use Value:** The primary function a product must perform.
*   **Secondary Use Value:** Ancillary functions that enhance or support the primary function.
*   **Performance Characteristics:** Quantifiable attributes defining functional effectiveness.
*   **Function Analysis:** Identifying and defining all functions of a product/system.
*   **Function-Cost Analysis:** Estimating costs associated with performing each function.
*   **Use Value Index (UVI):** A conceptual ratio of Use Value to Cost.

### 8. Practice Questions and Exercises

**Question 1:**
Define "Use Value" and differentiate it from "Esteem Value" in the context of engineering products. Provide an example.

**Answer 1:**
**Use Value** refers to the functional worth or utility that a product provides to its user, focusing on what it *does*. **Esteem Value**, conversely, relates to the prestige, brand image, or psychological satisfaction derived from owning an item, irrespective of its core function.
*   **Example:** A smartphone's **use value** lies in its ability to communicate, access information, and run applications. Its **esteem value** might come from its premium brand, sleek design, and the status it confers upon its owner.

**Question 2:**
A company is manufacturing a high-performance fan. List three distinct "Performance Characteristics" that contribute to its use value and explain why they are important.

**Answer 2:**
1.  **Airflow Volume (CFM - Cubic Feet per Minute):** This is a primary performance characteristic. It directly indicates how effectively the fan moves air, which is its core function. Higher CFM generally means better performance for cooling or ventilation.
2.  **Noise Level (Decibels - dB):** While not directly about moving air, the noise level significantly impacts the user's experience and the practicality of using the fan in certain environments (e.g., bedrooms, offices). A lower noise level enhances the fan's acceptable use value.
3.  **Energy Efficiency (Watts per CFM):** This characteristic measures how much power the fan consumes to move a certain amount of air. It's crucial for operating costs and environmental impact, contributing to the overall long-term use value and economic viability for the user.

**Question 3:**
Consider a simple wrench used to tighten bolts. How could a Value Analysis team approach improving its Use Value? Identify at least two strategies.

**Answer 3:**
A Value Analysis team could approach improving the wrench's Use Value through these strategies:

1.  **Material Substitution & Design Improvement:**
    *   **Current State:** A heavy, standard steel wrench.
    *   **Analysis:** Its basic use value is to grip and turn bolts. Is the current material necessary? Is the design optimal for grip and torque application?
    *   **Potential Improvement:**
        *   **Material:** Investigate using a lighter, high-strength alloy (e.g., forged aluminum alloy or advanced steel) to reduce weight, improving portability and reducing user fatigue, thereby enhancing its secondary use value (ease of handling).
        *   **Design:** Experiment with ergonomic handle grips (e.g., rubberized coatings) to improve user comfort and prevent slippage (improving secondary use value). Analyze the jaw design for optimal bolt gripping to enhance the primary use value (effective turning).
2.  **Standardization & Manufacturing Process Optimization:**
    *   **Current State:** A custom-machined wrench with complex finishing.
    *   **Analysis:** Can the required function be achieved with a more standardized component or a simpler manufacturing method?
    *   **Potential Improvement:**
        *   **Standardization:** If specific head sizes are always required, explore using or adapting standard wrench head designs rather than unique ones.
        *   **Manufacturing:** If the current manufacturing process is expensive (e.g., manual filing, intricate machining), explore alternatives like precision forging or casting followed by minimal finishing, provided these methods achieve the necessary functional tolerances and durability. This reduces cost while aiming to maintain the essential use value.

### 9. Important Points to Remember

*   **Function is King:** Always ask "What does it *do*?"
*   **Focus on the User:** Use value is defined by the user's needs and perception of utility.
*   **Cost-Benefit for Function:** VA/VE aims to optimize the function-to-cost ratio.
*   **Holistic View:** Consider all aspects of use value, from basic performance to reliability and ease of maintenance.
*   **Measurement is Key:** While subjective, try to quantify or objectively assess use value for better decision-making.
