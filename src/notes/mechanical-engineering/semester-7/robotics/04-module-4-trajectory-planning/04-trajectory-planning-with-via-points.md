## ROBOTICS: Module 4: Trajectory Planning - Trajectory Planning with Via Points

This module focuses on generating feasible paths for robot end-effectors or joints to follow, ensuring smooth and efficient motion. Trajectory planning with via points is a crucial technique for guiding robots through a sequence of intermediate positions, essential for tasks involving multiple discrete stages.

---

### 1. Introduction to Trajectory Planning with Via Points

**1.1 What are Via Points?**

*   **Definition:** Via points are intermediate positions or configurations that a robot must pass through during its motion from a start point to an end point. They define a discrete sequence of desired locations.
*   **Purpose:**
    *   **Task Decomposition:** Break down complex tasks into manageable segments.
    *   **Obstacle Avoidance:** Guide the robot around known obstacles.
    *   **Path Constraints:** Ensure the robot adheres to specific intermediate locations required by the task.
    *   **Improved Motion:** Contribute to smoother and more predictable robot behavior.

**1.2 Types of Via Point Specification:**

*   **Joint Space Via Points:** The via points are specified as a sequence of desired joint angles or positions. This is often simpler to plan in but may not guarantee a straight-line motion of the end-effector in Cartesian space.
*   **Cartesian Space Via Points:** The via points are specified as desired positions and orientations of the robot's end-effector in Cartesian (world) coordinates. This ensures the end-effector follows a defined path in space.

**1.3 Key Concepts:**

*   **Start Point ($P_{start}$):** The initial configuration of the robot.
*   **End Point ($P_{end}$):** The final desired configuration of the robot.
*   **Via Points ($P_{v1}, P_{v2}, ..., P_{vn}$):** The intermediate configurations.
*   **Trajectory:** A time-parameterized sequence of configurations that the robot follows. It specifies the position, velocity, and acceleration of each joint or the end-effector over time.
*   **Path:** A geometric description of the sequence of points in space to be followed.
*   **Task Space:** The space in which the end-effector operates (e.g., 3D Cartesian space).
*   **Joint Space:** The space defined by the angles or positions of the robot's joints.

**1.4 Why Use Via Points? (Connecting to Course Outcomes)**

*   **CO3 (Plan trajectories in joint space & Cartesian space and avoid obstacles):** Via points are directly used to define desired intermediate positions for trajectory planning, facilitating obstacle avoidance by specifying paths around known obstacles.
*   **CO1 (Familiarise with anatomy, specifications and types of Robots):** Understanding via points is essential for defining tasks for different robot types (e.g., manipulators, mobile robots).

**1.5 Textual References:**

*   **Schilling, R. J. (1996):** Discusses path generation and trajectory planning, often involving sequences of points.
*   **Craig, J. J. (2002):** Covers joint space and Cartesian space path planning, which can be extended to include via points.

### 2. Trajectory Generation in Joint Space with Via Points

**2.1 Concept:**

In joint space trajectory planning, we define a sequence of desired joint angles/positions. The trajectory is generated by creating a time-parameterized function for each joint, transitioning smoothly between these specified joint configurations.

**2.2 Process:**

1.  **Define Joint Space Via Points:** Specify a sequence of joint angle vectors: $\mathbf{q}_{start}, \mathbf{q}_{v1}, \mathbf{q}_{v2}, ..., \mathbf{q}_{vn}, \mathbf{q}_{end}$.
2.  **Segment the Trajectory:** Divide the overall trajectory into segments, where each segment connects two consecutive via points (e.g., from $\mathbf{q}_{start}$ to $\mathbf{q}_{v1}$, then $\mathbf{q}_{v1}$ to $\mathbf{q}_{v2}$, and so on).
3.  **Generate Segment Trajectories:** For each segment, a polynomial function (typically cubic or quintic) is used to define the joint angles as a function of time. This ensures continuity of position, velocity, and potentially acceleration at the via points.

**2.3 Polynomial Trajectory Generation (Cubic and Quintic):**

*   **Cubic Polynomials:**
    *   Used to interpolate between two points with specified start and end velocities.
    *   A cubic polynomial for a single joint $q_i(t)$ over a segment $[t_0, t_f]$:
        $q_i(t) = a_0 + a_1(t-t_0) + a_2(t-t_0)^2 + a_3(t-t_0)^3$
    *   Requires 4 boundary conditions: $q_i(t_0), \dot{q}_i(t_0), q_i(t_f), \dot{q}_i(t_f)$.
    *   **Limitation:** Cannot specify acceleration at endpoints directly.

*   **Quintic Polynomials:**
    *   Used to interpolate between two points with specified start and end velocities and accelerations.
    *   A quintic polynomial for a single joint $q_i(t)$ over a segment $[t_0, t_f]$:
        $q_i(t) = a_0 + a_1(t-t_0) + a_2(t-t_0)^2 + a_3(t-t_0)^3 + a_4(t-t_0)^4 + a_5(t-t_0)^5$
    *   Requires 6 boundary conditions: $q_i(t_0), \dot{q}_i(t_0), \ddot{q}_i(t_0), q_i(t_f), \dot{q}_i(t_f), \ddot{q}_i(t_f)$.
    *   **Advantage:** Allows for smoother transitions by specifying zero acceleration at via points if desired, leading to less jerk.

**2.4 Boundary Conditions for Via Points:**

*   **Position:** The joint angle at each via point is directly specified.
*   **Velocity:** Often, velocities at via points are set to zero to allow for smooth transitions and to avoid overshooting. However, non-zero velocities can be specified if needed for specific task requirements.
*   **Acceleration:** Similar to velocity, acceleration at via points is often set to zero for smoother motion.

**2.5 Example (Conceptual):**

Consider a 2-DOF robot arm with desired joint space via points:
$\mathbf{q}_{start} = [0, 0]$ rad
$\mathbf{q}_{v1} = [\pi/4, \pi/4]$ rad
$\mathbf{q}_{end} = [\pi/2, 0]$ rad

To generate the trajectory from $\mathbf{q}_{start}$ to $\mathbf{q}_{v1}$:
*   Assume we want smooth transitions, so $\dot{q}_{start} = [0, 0]$ and $\dot{q}_{v1} = [0, 0]$.
*   If using quintic polynomials, we might also set $\ddot{q}_{start} = [0, 0]$ and $\ddot{q}_{v1} = [0, 0]$.
*   We would solve the polynomial equations for the coefficients ($a_0$ to $a_5$ for each joint) using these boundary conditions and the time duration for the segment.
*   This process is repeated for the segment from $\mathbf{q}_{v1}$ to $\mathbf{q}_{end}$.

**2.6 Important Points to Remember:**

*   **Continuity:** Polynomial trajectories ensure continuity of position and velocity between segments, preventing jerky movements.
*   **Computational Cost:** Calculating polynomial coefficients for each joint and segment can be computationally intensive, especially for robots with many degrees of freedom.
*   **Joint Limits:** It's crucial to ensure the generated trajectories do not violate the physical joint limits of the robot.
*   **Singularities:** Be mindful of robot singularities when planning in joint space.

### 3. Trajectory Generation in Cartesian Space with Via Points

**3.1 Concept:**

In Cartesian space trajectory planning, the via points are specified as desired positions and orientations of the robot's end-effector. The robot's joint angles are then calculated at these via points using inverse kinematics. Once the joint space configurations for the via points are known, joint space trajectory generation techniques (as described above) are applied.

**3.2 Process:**

1.  **Define Cartesian Space Via Points:** Specify a sequence of end-effector poses (position and orientation) in Cartesian space: $T_{start}, T_{v1}, T_{v2}, ..., T_{vn}, T_{end}$.
2.  **Inverse Kinematics for Via Points:** For each Cartesian via point $T_{vi}$, calculate the corresponding joint configuration $\mathbf{q}_{vi}$ using the robot's inverse kinematics solution.
    *   $\mathbf{q}_{start} = IK(T_{start})$
    *   $\mathbf{q}_{v1} = IK(T_{v1})$
    *   ...
    *   $\mathbf{q}_{end} = IK(T_{end})$
    *   **Challenge:** Inverse kinematics can be non-unique and may involve solving complex equations. Numerical methods are often used.
3.  **Joint Space Trajectory Generation:** With the sequence of joint space configurations ($\mathbf{q}_{start}, \mathbf{q}_{v1}, ..., \mathbf{q}_{end}$) obtained from inverse kinematics, generate a smooth trajectory in joint space using polynomial interpolation (cubic or quintic) as described in Section 2.
4.  **Forward Kinematics (Verification):** Optionally, use forward kinematics to transform the generated joint space trajectory back into Cartesian space to verify that the end-effector indeed passes through the intended Cartesian via points.

**3.3 Challenges:**

*   **Multiple Inverse Kinematics Solutions:** The inverse kinematics for a given end-effector pose might yield multiple valid joint configurations. The choice of which solution to follow is critical for smooth overall motion.
*   **Joint Limit Violations:** The inverse kinematics might result in joint configurations that violate the robot's physical limits.
*   **Singularities:** If a Cartesian via point requires the robot to be at or near a singularity, the inverse kinematics solution might become unstable or impossible to compute.
*   **Workspace Limitations:** The desired Cartesian via points might lie outside the robot's reachable workspace.
*   **Path Distortion:** Simply interpolating joint angles corresponding to Cartesian via points does not guarantee a straight line motion of the end-effector in Cartesian space. The path traced by the end-effector will be influenced by the robot's kinematics.

**3.4 Example (Conceptual):**

Consider a 3-DOF planar manipulator.
*   **Cartesian Via Points:**
    *   $T_{start}$: End-effector at (0.5, 0.2) with orientation 0 degrees.
    *   $T_{v1}$: End-effector at (0.7, 0.3) with orientation 15 degrees.
    *   $T_{end}$: End-effector at (0.6, 0.1) with orientation -5 degrees.
*   **Inverse Kinematics:** Calculate $\mathbf{q}_{start}$, $\mathbf{q}_{v1}$, $\mathbf{q}_{end}$ for each of these poses.
*   **Joint Space Trajectory:** Generate smooth polynomial trajectories for each joint angle from $\mathbf{q}_{start}$ to $\mathbf{q}_{v1}$ and then to $\mathbf{q}_{end}$.

**3.5 Important Points to Remember:**

*   **Kinematic Chain:** The nature of the robot's kinematic chain heavily influences the inverse kinematics solution and the resulting Cartesian path.
*   **Configuration Space:** Planning in joint space is generally more straightforward than directly planning in Cartesian space due to the complexities of inverse kinematics.
*   **Smoothness in Cartesian Space:** To achieve smoother Cartesian paths, sophisticated techniques like Cartesian path interpolation (e.g., linearly interpolating the end-effector pose) followed by inverse kinematics and then joint space trajectory generation are employed. However, this can lead to non-monotonic joint space movements.

### 4. Advanced Techniques and Considerations

**4.1 Handling Multiple Via Points:**

*   **Smooth Transitions:** Ensure continuity of velocity and acceleration at each via point to avoid sudden changes in robot motion, which can cause vibration and strain.
*   **Jerk Minimization:** Quintic polynomials help in minimizing jerk (the rate of change of acceleration), leading to smoother and more controlled motion.
*   **Trajectory Smoothing Algorithms:** Techniques like B-splines or Bezier curves can be used to generate smoother trajectories that pass through or near the via points, especially when direct interpolation might lead to undesirable oscillations.

**4.2 Obstacle Avoidance with Via Points:**

*   **Pre-planned Obstacle Avoidance:** Via points can be strategically placed to guide the robot around known static obstacles.
*   **Dynamic Obstacle Avoidance:** For dynamic obstacles, online trajectory modification or replanning based on sensor feedback becomes necessary. Via points can serve as intermediate goals for replanned paths.

**4.3 Time Optimal Trajectory Planning:**

*   **S-Curve Profiles:** To achieve faster movements while respecting velocity and acceleration limits, S-curve velocity profiles can be used instead of simple polynomial trajectories. This leads to smooth acceleration and deceleration phases.
*   **Time Scaling:** Adjusting the time taken to traverse each segment between via points to optimize for speed or energy consumption, while adhering to kinematic and dynamic constraints.

**4.4 Dynamic Constraints:**

*   **Torque/Force Limits:** Real-world robots have limitations on the torques or forces their actuators can produce. Trajectory planning must consider these dynamic constraints to ensure the robot can actually execute the planned trajectory.
*   **Trajectory Scaling:** Adjusting the amplitude or timing of the trajectory to satisfy dynamic constraints.

**4.5 Path vs. Trajectory:**

*   **Path:** The geometric route in task or joint space.
*   **Trajectory:** The path with a time specification (position, velocity, acceleration over time). Via points define the path, and the polynomial interpolation (or other methods) defines the trajectory by assigning time to each point.

**4.6 Important Points to Remember:**

*   **Real-world Limitations:** Always consider the robot's physical constraints (joint limits, actuator capabilities, singularities) when planning trajectories.
*   **Computational Complexity:** As the number of via points or the robot's DOF increases, computational complexity grows.
*   **Optimization:** Trajectory planning often involves trade-offs between speed, smoothness, energy consumption, and accuracy.

### 6. Practice Questions and Answers

**Question 1:**
What is the primary purpose of using via points in robot trajectory planning?
(a) To define the end goal of the robot's task.
(b) To specify intermediate positions the robot must pass through.
(c) To control the robot's end-effector velocity.
(d) To calculate the robot's dynamic model.

**Answer:** (b) To specify intermediate positions the robot must pass through.

**Question 2:**
When planning a trajectory in joint space with via points, which type of polynomial is generally preferred for smoother motion and why?
(a) Linear polynomial, because it's simple.
(b) Quadratic polynomial, for constant acceleration.
(c) Cubic polynomial, for continuity of position and velocity.
(d) Quintic polynomial, for continuity of position, velocity, and acceleration.

**Answer:** (d) Quintic polynomial, for continuity of position, velocity, and acceleration.

**Question 3:**
If you are given Cartesian space via points for an industrial robot, what is the first crucial step before generating a joint space trajectory?
(a) Perform forward kinematics on the via points.
(b) Solve the inverse kinematics for each Cartesian via point to get joint configurations.
(c) Directly apply polynomial interpolation in Cartesian space.
(d) Check the robot's end-effector velocity at each via point.

**Answer:** (b) Solve the inverse kinematics for each Cartesian via point to get joint configurations.

**Question 4:**
A major challenge when planning trajectories in Cartesian space using via points is:
(a) The number of joints in the robot.
(b) The need for inverse kinematics and its potential for multiple solutions or singularities.
(c) The definition of the start and end points.
(d) The calculation of forward kinematics.

**Answer:** (b) The need for inverse kinematics and its potential for multiple solutions or singularities.

**Question 5 (Conceptual/Application):**
Imagine you are programming a pick-and-place operation for a robot. The robot needs to pick up an object at location A, move to an intermediate staging point B above a conveyor belt, and then place the object at location C. How would you use the concept of via points to plan this trajectory?

**Answer:**
You would define the following points:
*   **Start Point:** The initial position of the robot's end-effector.
*   **Via Point 1:** The position and orientation required to grasp the object at location A.
*   **Via Point 2:** The intermediate staging point B, likely above the conveyor belt and at a safe height. This via point is crucial for transitioning between the pickup and placement phases and may be used for orientation control or to clear an obstacle.
*   **End Point:** The position and orientation required to place the object at location C.

You would then choose to plan this in either joint space or Cartesian space. If planning in Cartesian space, you would first find the joint configurations for each of these points using inverse kinematics. Subsequently, you would generate smooth trajectories (e.g., using quintic polynomials) to connect these joint configurations sequentially, ensuring smooth transitions at each via point.

### 7. Summary of Key Takeaways

*   **Via points** are essential for breaking down complex robot tasks into a series of intermediate goals.
*   Trajectories can be planned in **joint space** (specifying joint angles) or **Cartesian space** (specifying end-effector poses).
*   **Inverse kinematics** is a critical step when planning in Cartesian space with via points.
*   **Polynomial interpolation (cubic and quintic)** is a common method for generating smooth joint-space trajectories between via points.
*   **Quintic polynomials** are preferred for ensuring continuity of position, velocity, and acceleration, minimizing jerk.
*   Challenges include **multiple inverse kinematics solutions, singularities, joint limits, and workspace constraints**.
*   Trajectory planning must consider **dynamic constraints** for real-world robot execution.
*   Via points contribute to **obstacle avoidance** by defining paths around known obstacles.
