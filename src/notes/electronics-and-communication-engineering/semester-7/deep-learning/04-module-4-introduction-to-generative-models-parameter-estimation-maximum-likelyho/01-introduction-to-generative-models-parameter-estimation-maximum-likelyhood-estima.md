# Deep Learning: Module 4 - Introduction to Generative Models: Parameter Estimation, Maximum Likelihood Estimation

## 1. Introduction to Generative Models

Generative models are a class of machine learning models that aim to learn the underlying probability distribution of the data. Once this distribution is learned, the model can be used to generate new data samples that resemble the training data. This is in contrast to discriminative models, which learn to distinguish between different classes of data.

**Key Concepts:**

*   **Probability Distribution:** A function that describes the likelihood of different outcomes for a random variable. In the context of generative models, we aim to learn the joint probability distribution $p(x, y)$ of the data $x$ and its label $y$, or the marginal probability distribution $p(x)$ if we are not concerned with labels.
*   **Generative vs. Discriminative Models:**
    *   **Discriminative Models:** Learn $p(y|x)$ – the probability of a label given the data. They focus on the decision boundary between classes. Examples: Logistic Regression, Support Vector Machines (SVMs), most standard feedforward neural networks for classification.
    *   **Generative Models:** Learn $p(x, y)$ or $p(x)$. They model how the data is generated. This allows them to:
        *   Generate new data samples.
        *   Calculate the probability of a given data point.
        *   Potentially derive $p(y|x)$ using Bayes' theorem: $p(y|x) = \frac{p(x|y)p(y)}{p(x)}$.
*   **Applications of Generative Models:**
    *   **Image Generation:** Creating realistic images (e.g., faces, landscapes).
    *   **Text Generation:** Writing stories, poems, or code.
    *   **Data Augmentation:** Creating synthetic data to improve the performance of discriminative models.
    *   **Anomaly Detection:** Identifying data points that are unlikely to have been generated by the learned distribution.
    *   **Speech Synthesis:** Generating human-like speech.

**Reference:**
*   *Deep Learning* by Goodfellow, Bengio, and Courville (Chapter 20: Generative Adversarial Networks, implicitly covers the underlying principles of learning data distributions)
*   *Generative Deep Learning* by David Foster (Chapter 1: Introduction to Generative Models)

## 2. Parameter Estimation

Once we have chosen a model architecture for our generative model, we need to determine the specific parameters (weights and biases in neural networks) that best represent the underlying data distribution. This process is called parameter estimation.

**Key Concepts:**

*   **Model Parameters ($\theta$):** The values within the model that are learned from the data. For a neural network, these are the weights and biases of the neurons.
*   **Likelihood Function:** A function that measures how well a particular set of model parameters explains the observed data. Given a dataset $D = \{x^{(1)}, x^{(2)}, ..., x^{(n)}\}$, and a parameterized model that defines a probability distribution $p(x; \theta)$, the likelihood of the data given the parameters is:
    $L(\theta; D) = p(D; \theta) = \prod_{i=1}^{n} p(x^{(i)}; \theta)$
    assuming the data points are independent and identically distributed (i.i.d.).
*   **Goal of Parameter Estimation:** To find the set of parameters $\theta$ that maximizes the likelihood of the observed data.

**Connection to Course Outcomes:**
*   This section directly relates to understanding the foundational concepts of how models learn from data, a prerequisite for understanding more complex generative models like GANs (CO4) and general neural network principles (CO1).

## 3. Maximum Likelihood Estimation (MLE)

Maximum Likelihood Estimation (MLE) is a fundamental method for estimating the parameters of a statistical model. It works by finding the parameter values that maximize the likelihood function.

**Key Concepts:**

*   **The Principle of MLE:** Find $\theta$ such that the probability of observing the training data is maximized.
    $\theta_{MLE} = \arg\max_{\theta} L(\theta; D)$

*   **Log-Likelihood:** Maximizing the likelihood function $L(\theta; D)$ is equivalent to maximizing its logarithm, $\log L(\theta; D)$. This is often preferred because:
    *   It converts the product into a sum: $\log L(\theta; D) = \sum_{i=1}^{n} \log p(x^{(i)}; \theta)$. Sums are generally easier to work with mathematically (e.g., derivatives).
    *   It avoids numerical underflow issues when dealing with very small probabilities in the product.

    So, the objective becomes:
    $\theta_{MLE} = \arg\max_{\theta} \log L(\theta; D) = \arg\max_{\theta} \sum_{i=1}^{n} \log p(x^{(i)}; \theta)$

*   **Optimization:** The process of finding the parameters $\theta$ that maximize the log-likelihood often involves optimization algorithms.
    *   **Gradient Ascent:** Since we are maximizing, we use gradient ascent. The update rule for a parameter $\theta_j$ is:
        $\theta_j \leftarrow \theta_j + \eta \frac{\partial}{\partial \theta_j} \sum_{i=1}^{n} \log p(x^{(i)}; \theta)$
        where $\eta$ is the learning rate.
    *   **Stochastic Gradient Ascent (SGA) / Mini-batch Gradient Ascent:** In practice, especially with large datasets, we update the parameters using small subsets of the data (mini-batches) at each step. This is more computationally efficient and can help escape local optima.
        For a mini-batch $B$:
        $\theta \leftarrow \theta + \eta \nabla_{\theta} \sum_{x^{(i)} \in B} \log p(x^{(i)}; \theta)$

*   **Differentiability:** MLE is typically used for models where the probability distribution $p(x; \theta)$ is differentiable with respect to its parameters $\theta$.

**Example: Estimating the mean and variance of a Gaussian Distribution**

Let's assume our data $x^{(i)}$ comes from a univariate Gaussian distribution with unknown mean $\mu$ and variance $\sigma^2$. The probability density function (PDF) of a Gaussian is:
$p(x; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$

The log-likelihood for a dataset $D = \{x^{(1)}, ..., x^{(n)}\}$ is:
$\log L(\mu, \sigma^2; D) = \sum_{i=1}^{n} \log \left( \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x^{(i)}-\mu)^2}{2\sigma^2}\right) \right)$
$\log L(\mu, \sigma^2; D) = \sum_{i=1}^{n} \left( -\frac{1}{2} \log(2\pi) - \frac{1}{2} \log(\sigma^2) - \frac{(x^{(i)}-\mu)^2}{2\sigma^2} \right)$
$\log L(\mu, \sigma^2; D) = -\frac{n}{2} \log(2\pi) - \frac{n}{2} \log(\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2$

To find the MLE for $\mu$ and $\sigma^2$, we take partial derivatives with respect to $\mu$ and $\sigma^2$ and set them to zero.

**1. Estimating $\mu$:**
$\frac{\partial}{\partial \mu} \log L = \frac{\partial}{\partial \mu} \left( -\frac{1}{2\sigma^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2 \right)$
$\frac{\partial}{\partial \mu} \log L = -\frac{1}{2\sigma^2} \sum_{i=1}^{n} 2(x^{(i)}-\mu)(-1)$
$\frac{\partial}{\partial \mu} \log L = \frac{1}{\sigma^2} \sum_{i=1}^{n} (x^{(i)}-\mu)$

Setting the derivative to zero:
$\frac{1}{\sigma^2} \sum_{i=1}^{n} (x^{(i)}-\mu) = 0$
$\sum_{i=1}^{n} x^{(i)} - \sum_{i=1}^{n} \mu = 0$
$\sum_{i=1}^{n} x^{(i)} - n\mu = 0$
$n\mu = \sum_{i=1}^{n} x^{(i)}$
$\mu_{MLE} = \frac{1}{n} \sum_{i=1}^{n} x^{(i)} = \bar{x}$ (the sample mean)

**2. Estimating $\sigma^2$:**
$\frac{\partial}{\partial \sigma^2} \log L = \frac{\partial}{\partial \sigma^2} \left( -\frac{n}{2} \log(\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2 \right)$
$\frac{\partial}{\partial \sigma^2} \log L = -\frac{n}{2} \cdot \frac{1}{\sigma^2} - \frac{1}{2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2 \cdot \left(-\frac{1}{(\sigma^2)^2}\right)$
$\frac{\partial}{\partial \sigma^2} \log L = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2$

Setting the derivative to zero:
$-\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2 = 0$
$\frac{n}{2\sigma^2} = \frac{1}{2(\sigma^2)^2} \sum_{i=1}^{n} (x^{(i)}-\mu)^2$
Multiply both sides by $2(\sigma^2)^2$:
$n\sigma^2 = \sum_{i=1}^{n} (x^{(i)}-\mu)^2$
$\sigma^2_{MLE} = \frac{1}{n} \sum_{i=1}^{n} (x^{(i)}-\mu)^2$

If we substitute $\mu_{MLE} = \bar{x}$:
$\sigma^2_{MLE} = \frac{1}{n} \sum_{i=1}^{n} (x^{(i)}-\bar{x})^2$

**Important Note:** The MLE for variance is the *biased* sample variance (dividing by $n$). The *unbiased* sample variance divides by $n-1$. MLE finds the parameters that best fit the observed data, not necessarily the ones that provide unbiased estimates of population parameters in all cases.

## 4. MLE in Deep Learning Context

While the Gaussian example is simple, MLE is applied to more complex probability distributions defined by deep neural networks.

**Key Concepts:**

*   **Parameterized Probability Distributions:** Deep neural networks can be used to parameterize complex probability distributions. For example:
    *   **Outputting Mean and Variance:** A neural network can output the mean ($\mu$) and variance ($\sigma^2$) of a Gaussian distribution for each input, or even for generating data points.
    *   **Categorical Distributions:** For discrete data (like pixels in one-hot encoding, or words), a network can output probabilities for each class using a softmax function, defining a categorical distribution.
    *   **Autoregressive Models:** Models like PixelRNN or PixelCNN model the joint distribution as a product of conditional distributions: $p(x) = \prod_{i=1}^{N} p(x_i | x_1, ..., x_{i-1})$. MLE is used to train these models by maximizing the sum of log-probabilities of each pixel/element given the previous ones.

*   **Challenges with MLE in Deep Learning:**
    *   **Intractability:** For very complex, high-dimensional data distributions (e.g., images), the direct computation of the likelihood function can be intractable or computationally very expensive.
    *   **Local Optima:** The log-likelihood function can be non-convex, meaning gradient ascent might get stuck in local optima, leading to suboptimal parameter estimates.
    *   **Model Choice:** Choosing the right parameterized distribution $p(x; \theta)$ that can accurately capture the complexity of the data is crucial.

*   **Alternatives/Extensions:** Due to these challenges, other methods like:
    *   **Variational Inference:** Approximating the true posterior distribution with a simpler, tractable distribution.
    *   **Monte Carlo Methods:** Using sampling techniques to approximate expectations or likelihoods.
    *   **Generative Adversarial Networks (GANs):** GANs implicitly learn the data distribution without explicitly defining and maximizing a likelihood function. Instead, they use a minimax game between a generator and a discriminator.

**Textbook References:**

*   *Generative Deep Learning* by David Foster (Chapter 2: Variational Autoencoders, introduces VAEs which use variational inference, a related but different approach to learning distributions).

## 5. Practice Questions and Exercises

**Question 1:**
What is the fundamental difference between generative and discriminative models? Provide an example for each.

**Answer 1:**
*   **Generative Models:** Learn the joint probability distribution $p(x, y)$ or $p(x)$. They model how the data is generated and can create new data samples. Example: Generative Adversarial Networks (GANs) for image generation.
*   **Discriminative Models:** Learn the conditional probability $p(y|x)$. They focus on the decision boundary between classes to classify data. Example: Logistic Regression for binary classification.

**Question 2:**
Why is the log-likelihood function often preferred over the likelihood function in parameter estimation?

**Answer 2:**
The log-likelihood is preferred because:
1.  It converts products into sums, which are mathematically easier to handle (e.g., differentiation).
2.  It helps to avoid numerical underflow issues when dealing with very small probabilities in the likelihood product.

**Question 3:**
Suppose you have a dataset of coin flip outcomes (Heads=1, Tails=0) and you want to estimate the probability of getting Heads, $p$. If your dataset is $[1, 0, 1, 1, 0]$, what is the Maximum Likelihood Estimate for $p$?

**Answer 3:**
Let $x_i$ be the outcome of the $i$-th flip. We assume $x_i \sim \text{Bernoulli}(p)$. The probability mass function is $p(x; p) = p^x (1-p)^{1-x}$.
The likelihood function is $L(p; D) = \prod_{i=1}^{n} p^{x^{(i)}} (1-p)^{1-x^{(i)}}$.
The log-likelihood is $\log L(p; D) = \sum_{i=1}^{n} (x^{(i)} \log p + (1-x^{(i)}) \log (1-p))$.
To find the MLE for $p$, we take the derivative with respect to $p$ and set it to zero:
$\frac{\partial}{\partial p} \log L = \sum_{i=1}^{n} \left(\frac{x^{(i)}}{p} - \frac{1-x^{(i)}}{1-p}\right) = 0$
$\sum_{i=1}^{n} \frac{x^{(i)}}{p} - \sum_{i=1}^{n} \frac{1-x^{(i)}}{1-p} = 0$
$\frac{1}{p} \sum x^{(i)} - \frac{1}{1-p} \sum (1-x^{(i)}) = 0$
$\frac{\sum x^{(i)}}{p} = \frac{\sum (1-x^{(i)})}{1-p}$
$(\sum x^{(i)})(1-p) = p (\sum (1-x^{(i)}))$
$\sum x^{(i)} - p \sum x^{(i)} = p \sum 1 - p \sum x^{(i)}$
$\sum x^{(i)} = pn$
$p_{MLE} = \frac{\sum x^{(i)}}{n}$

For the dataset $[1, 0, 1, 1, 0]$:
$n = 5$
$\sum x^{(i)} = 1 + 0 + 1 + 1 + 0 = 3$
$p_{MLE} = \frac{3}{5} = 0.6$

The MLE for the probability of heads is 0.6.

**Question 4 (Conceptual):**
Would you typically use MLE to train a standard feedforward neural network for image classification or a Generative Adversarial Network (GAN) for image generation? Explain why.

**Answer 4:**
*   **Feedforward Neural Network for Image Classification:** Yes, typically. These models are often trained by minimizing a loss function that is derived from MLE. For example, cross-entropy loss for classification is directly related to maximizing the likelihood of the correct class given the input.
*   **Generative Adversarial Network (GAN) for Image Generation:** No, not directly. GANs are designed to *implicitly* learn the data distribution through a game-theoretic approach. They do not explicitly define a likelihood function $p(x; \theta)$ to maximize. Instead, the generator tries to fool the discriminator, and the discriminator tries to distinguish real from fake data. This adversarial process leads to the generator learning to produce realistic samples that match the training data distribution, without ever calculating the likelihood of a given sample.

**Question 5:**
Consider training a generative model using MLE. If the model is too simple and cannot capture the complexity of the data distribution, what kind of problem might you encounter with the parameter estimates?

**Answer 5:**
If the model is too simple (underfitting), it will not be able to adequately represent the true data distribution. This means the maximum likelihood estimate might result in a model that assigns low probability to many of the observed data points, even though a more complex model could capture them better. The resulting model will likely perform poorly on both generating new data and potentially even on tasks like density estimation. The parameters might converge to a point that "best fits" the limited capacity of the model but doesn't truly reflect the underlying data generating process.

## 6. Important Points to Remember

*   **Generative models learn data distributions.** This is their core purpose, enabling data generation.
*   **Parameter estimation is key to making models work.** We need to find the "best" parameters for our chosen model.
*   **Maximum Likelihood Estimation (MLE)** is a powerful and widely used method for parameter estimation.
*   **MLE aims to maximize the probability of observing the given data.**
*   **The log-likelihood function is preferred** for numerical stability and mathematical convenience.
*   **Optimization algorithms (like gradient ascent)** are used to find the parameters that maximize the log-likelihood.
*   **Deep neural networks can parameterize complex distributions**, but applying MLE directly can be challenging due to intractability and non-convexity.
*   **GANs represent an alternative approach** to learning data distributions that bypasses direct likelihood maximization.
*   Understanding MLE is foundational for many deep learning techniques, including some generative models and the training of discriminative models via cross-entropy loss.
