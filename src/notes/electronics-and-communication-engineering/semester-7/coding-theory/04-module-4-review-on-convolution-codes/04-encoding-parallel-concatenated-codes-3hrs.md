# CODING THEORY: Module 4 - Review on Convolution Codes

## Topic: Encoding Parallel Concatenated Codes (3 Hours)

**Learning Outcomes:**

*   Understand the structure and operation of parallel concatenated codes (PCCs), also known as Turbo Codes.
*   Learn the principles of encoding data using two or more constituent convolutional encoders.
*   Comprehend the role of interleaving in enhancing the performance of PCCs.
*   Analyze the impact of different interleaving patterns on the coding gain.
*   Gain an understanding of the basic structure of a Turbo Encoder.
*   Relate the encoding process to the overall error correction capability of PCCs.

**Course Outcomes Alignment:**

*   **CO1: Explain various algebraic structures used in coding theory (Knowledge Level: K2)** - While PCCs are not purely algebraic in the same sense as linear block codes, the underlying convolutional codes are based on finite state machines and shift registers, which have underlying algebraic properties.
*   **CO2: Explain the error detection and correction capabilities of linear codes (Knowledge Level: K2)** - Understanding linear block codes provides a foundation for appreciating how structured encoding, even with convolutional codes, contributes to error correction.
*   **CO3: Apply linear block codes to detect and correct errors. (Knowledge Level: K3)** - This outcome builds upon CO2 and helps in understanding the general principles of how encoded information is protected.
*   **CO4: Use algebraic techniques to construct efficient codes with reduced structural complexity (Knowledge Level: K3)** - The construction of constituent encoders in PCCs can involve algebraic principles to achieve good performance.
*   **CO5: Apply convolutional code for error detection correction (Knowledge Level: K3)** - This is a prerequisite and foundational concept for understanding PCCs, as they are built using convolutional codes.
