### 1. Definition of the Complex Exponential Function

The complex exponential function is defined for any complex number $z = x + iy$, where $x$ and $y$ are real numbers, as:

$w = e^z = e^{x+iy}$

Using Euler's formula ($e^{i\theta} = \cos\theta + i\sin\theta$), we can express this as:

$w = e^x e^{iy} = e^x (\cos y + i \sin y)$

**Key Concepts & Definitions:**

*   **Real Part of $w$**: $\text{Re}(w) = e^x \cos y$
*   **Imaginary Part of $w$**: $\text{Im}(w) = e^x \sin y$
*   **Modulus of $w$**: $|w| = |e^x (\cos y + i \sin y)| = |e^x| |\cos y + i \sin y| = e^x \sqrt{\cos^2 y + \sin^2 y} = e^x$
*   **Argument of $w$**: $\arg(w) = y + 2n\pi$, where $n$ is an integer. The principal argument is $\text{Arg}(w) = y$ for $-\pi < y \le \pi$.

### 2. Properties of the Complex Exponential Function

The complex exponential function possesses several key properties, many of which are analogous to its real counterpart.

*   **Additivity:** $e^{z_1 + z_2} = e^{z_1} e^{z_2}$ for any complex numbers $z_1$ and $z_2$.
    *   *Proof:* Let $z_1 = x_1 + iy_1$ and $z_2 = x_2 + iy_2$.
        $e^{z_1 + z_2} = e^{(x_1+x_2) + i(y_1+y_2)} = e^{x_1+x_2} e^{i(y_1+y_2)}$
        $= e^{x_1}e^{x_2} (\cos(y_1+y_2) + i\sin(y_1+y_2))$
        Using trigonometric sum formulas:
        $= e^{x_1}e^{x_2} (\cos y_1 \cos y_2 - \sin y_1 \sin y_2 + i(\sin y_1 \cos y_2 + \cos y_1 \sin y_2))$
        Rearranging terms:
        $= (e^{x_1}\cos y_1 + ie^{x_1}\sin y_1)(e^{x_2}\cos y_2 + ie^{x_2}\sin y_2)$
        $= e^{z_1} e^{z_2}$

*   **Periodicity:** $e^z$ is periodic with period $2\pi i$.
    $e^{z + 2\pi i} = e^z e^{2\pi i} = e^z (\cos(2\pi) + i\sin(2\pi)) = e^z (1 + i \cdot 0) = e^z$

*   **$e^z = 1$ if and only if $z = 2n\pi i$ for some integer $n$.**
    If $e^z = 1$, then $|e^z| = |e^x| = 1$, which implies $x=0$.
    Also, $\arg(e^z) = y$. For $e^z=1$, the argument must be $0 + 2n\pi$.
    Thus, $y = 2n\pi$, and $z = x + iy = 0 + i(2n\pi) = 2n\pi i$.

*   **$e^{z_1} = e^{z_2}$ if and only if $z_1 - z_2 = 2n\pi i$ for some integer $n$.**
    If $e^{z_1} = e^{z_2}$, then $e^{z_1}e^{-z_2} = 1$, which means $e^{z_1-z_2} = 1$.
    Therefore, $z_1 - z_2 = 2n\pi i$.

*   **Euler's Formula:** $e^{i\theta} = \cos\theta + i\sin\theta$.
    *   *Proof:* Consider the Taylor series for $e^z$, $\cos z$, and $\sin z$.
        $e^z = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \dots$
        If we substitute $z = i\theta$:
        $e^{i\theta} = 1 + i\theta + \frac{(i\theta)^2}{2!} + \frac{(i\theta)^3}{3!} + \frac{(i\theta)^4}{4!} + \dots$
        $e^{i\theta} = 1 + i\theta - \frac{\theta^2}{2!} - i\frac{\theta^3}{3!} + \frac{\theta^4}{4!} + \dots$
        Group real and imaginary terms:
        $e^{i\theta} = \left(1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \dots\right) + i\left(\theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \dots\right)$
        Recognizing the Taylor series for $\cos\theta$ and $\sin\theta$:
        $e^{i\theta} = \cos\theta + i\sin\theta$.

*   **Relationship with Hyperbolic Functions:**
    $\cosh z = \frac{e^z + e^{-z}}{2}$
    $\sinh z = \frac{e^z - e^{-z}}{2}$

**Important Points to Remember:**

*   The exponential function is never zero. $|e^z| = e^x > 0$ for all $z$.
*   The periodic nature of $e^z$ is crucial for understanding its behavior over different regions.

**References:**

### 3. Analyticity of $w = e^z$

The complex exponential function $w = e^z$ is analytic everywhere in the complex plane. This means it is differentiable at every point.

**Key Concepts & Definitions:**

*   **Analytic Function:** A complex function $f(z)$ is analytic in an open region if it is differentiable at every point in that region.
*   **Cauchy-Riemann Equations:** For a function $f(z) = u(x, y) + iv(x, y)$ to be analytic, the Cauchy-Riemann equations must be satisfied:
    $\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ and $\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$

**Verification for $w = e^z$:**

Let $w = e^z = e^{x+iy} = e^x \cos y + i e^x \sin y$.
So, $u(x, y) = e^x \cos y$ and $v(x, y) = e^x \sin y$.

Let's check the Cauchy-Riemann equations:

1.  $\frac{\partial u}{\partial x} = \frac{\partial}{\partial x}(e^x \cos y) = e^x \cos y$
    $\frac{\partial v}{\partial y} = \frac{\partial}{\partial y}(e^x \sin y) = e^x \cos y$
    So, $\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ is satisfied.

2.  $\frac{\partial u}{\partial y} = \frac{\partial}{\partial y}(e^x \cos y) = -e^x \sin y$
    $\frac{\partial v}{\partial x} = \frac{\partial}{\partial x}(e^x \sin y) = e^x \sin y$
    So, $\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$ is satisfied.

Since both Cauchy-Riemann equations are satisfied and the partial derivatives are continuous everywhere, $w = e^z$ is analytic in the entire complex plane.

**Derivative of $w = e^z$:**

The derivative of $w = e^z$ is also $e^z$.

$f'(z) = \frac{\partial u}{\partial x} + i \frac{\partial v}{\partial x} = e^x \cos y + i e^x \sin y = e^x (\cos y + i \sin y) = e^z$

**Learning Outcome Alignment (CO2):**

The analyticity of $e^z$ is fundamental for its role in conformal mapping. Since $f'(z) = e^z \neq 0$ for all $z$, the mapping $w=e^z$ is conformal everywhere in the complex plane. This means it preserves angles between curves.

**References:**

*   **Kreyszig (10th ed., pp. 225-226):** Demonstrates analyticity using Cauchy-Riemann equations and shows the derivative.
*   **Zill & Shanahan (3rd ed., pp. 60-61):** Explicitly proves analyticity and discusses the derivative.

### 4. Mapping Properties of $w = e^z$

The complex exponential function maps vertical lines to circles and horizontal lines to rays.

**Key Concepts & Definitions:**

*   **Vertical Line:** $x = c$ (constant)
*   **Horizontal Line:** $y = c$ (constant)
*   **Conformal Mapping:** A mapping that preserves angles locally.

**Mapping of Vertical Lines:**

Consider a vertical line $x = c$, where $c$ is a real constant.
For any point on this line, $z = c + iy$.
$w = e^z = e^{c+iy} = e^c (\cos y + i \sin y)$

Let $w = u + iv$. Then:
$u = e^c \cos y$
$v = e^c \sin y$

Squaring and adding these equations:
$u^2 + v^2 = (e^c \cos y)^2 + (e^c \sin y)^2 = (e^c)^2 (\cos^2 y + \sin^2 y) = e^{2c}$

This is the equation of a circle centered at the origin in the $w$-plane with radius $r = e^c$. As $y$ varies from $-\infty$ to $\infty$, the point $w$ traverses this circle infinitely many times. The image of a vertical line $x=c$ is a circle of radius $e^c$.

*   If $c > 0$, the image is a circle of radius $e^c > 1$.
*   If $c = 0$, the image is a circle of radius $e^0 = 1$ (the unit circle).
*   If $c < 0$, the image is a circle of radius $e^c < 1$.

**Mapping of Horizontal Lines:**

Consider a horizontal line $y = c$, where $c$ is a real constant.
For any point on this line, $z = x + ic$.
$w = e^z = e^{x+ic} = e^x (\cos c + i \sin c)$

Let $w = u + iv$. Then:
$u = e^x \cos c$
$v = e^x \sin c$

The modulus of $w$ is $|w| = e^x$. The argument of $w$ is $\arg(w) = c + 2n\pi$.
As $x$ varies from $-\infty$ to $\infty$, $e^x$ varies from $0$ to $\infty$. This means $|w|$ can take any positive value.
The argument of $w$ is fixed at $c$ (modulo $2\pi$).
Therefore, the image of a horizontal line $y = c$ is a ray emanating from the origin with an angle $c$ with respect to the positive real axis.

*   If $c$ is in $(0, \pi)$, the ray is in the upper half-plane.
*   If $c$ is in $(-\pi, 0)$, the ray is in the lower half-plane.
*   If $c = 0$, the image is the positive real axis.
*   If $c = \pi$, the image is the negative real axis.

**Mapping of Rectangles:**

A rectangle in the $z$-plane with vertices $z_1 = x_1 + iy_1$, $z_2 = x_2 + iy_1$, $z_3 = x_2 + iy_2$, $z_4 = x_1 + iy_2$ (where $x_1 < x_2$ and $y_1 < y_2$) is mapped to a region in the $w$-plane bounded by arcs of circles and rays. The image is a sector of an annulus.

**The Strip $0 \le y \le \pi$:**

This strip is mapped to the upper half of the complex plane (excluding the negative real axis).
For $z = x + iy$, $w = e^x (\cos y + i \sin y)$.
Since $0 \le y \le \pi$, $\sin y \ge 0$.
The imaginary part of $w$, $v = e^x \sin y$, is non-negative.
The real part, $u = e^x \cos y$, can be positive or negative.
The argument of $w$ is $y$, which lies in $[0, \pi]$. This corresponds to the upper half-plane.

**The Strip $0 \le y \le 2\pi$:**

This strip covers the entire unit circle $|w|=1$ exactly once.
For $z = x + iy$, $w = e^z$.
If we consider the strip $0 \le y < 2\pi$, it maps to the entire complex plane excluding the origin.
The strip $-\infty < x < \infty$ and $0 \le y < 2\pi$ maps to the entire $w$-plane excluding the origin.

**Learning Outcome Alignment (CO2):**

This section directly addresses understanding analyticity and its application in conformal mapping, as stated in CO2. The mapping properties of $e^z$ are classic examples of conformal transformations used in various physical and engineering problems (e.g., fluid flow, heat distribution).

**References:**

*   **Kreyszig (10th ed., pp. 226-229):** Excellent visual examples and explanations of mapping lines and regions.
*   **Zill & Shanahan (3rd ed., pp. 61-64):** Detailed discussion on mapping properties and examples.
*   **Ramana (39th ed., pp. 7.5-7.7):** Focuses on the geometric interpretation of the mapping.

### 5. Complex Integration and $w = e^z$

The exponential function's analyticity simplifies complex integration.

**Key Concepts & Definitions:**

*   **Cauchy's Integral Theorem:** If $f(z)$ is analytic in a simply connected domain $D$, then for any simple closed contour $C$ in $D$, $\oint_C f(z) dz = 0$.
*   **Cauchy's Integral Formula:** If $f(z)$ is analytic in a simply connected domain $D$, and $C$ is a simple closed contour in $D$ with a point $z_0$ inside $C$, then $f(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{z-z_0} dz$.

**Integration Properties:**

Since $w = e^z$ is analytic everywhere, its integral along any closed contour is zero.

$\oint_C e^z dz = 0$ for any closed contour $C$.

**Example:**

Evaluate $\oint_C e^z dz$ where $C$ is the circle $|z|=1$.
Since $e^z$ is analytic everywhere, and the circle $|z|=1$ is a closed contour, by Cauchy's Integral Theorem, the integral is 0.

**Derivatives of $e^z$ using Cauchy's Integral Formula:**

The $n$-th derivative of $f(z)$ at $z_0$ is given by:
$f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^{n+1}} dz$

For $f(z) = e^z$:
$f'(z_0) = \frac{1!}{2\pi i} \oint_C \frac{e^z}{(z-z_0)^{1+1}} dz = \frac{1}{2\pi i} \oint_C \frac{e^z}{(z-z_0)^2} dz$
This confirms that $f'(z_0) = e^{z_0}$.

**Learning Outcome Alignment (CO3):**

This section directly relates to CO3 by demonstrating how Cauchy's Integral Theorem applies to the exponential function, resulting in a zero integral for closed paths.

**References:**

### 6. Series Expansion of $w = e^z$

The Taylor series expansion of $w = e^z$ around any point $z_0$ is simply the function itself.

**Key Concepts & Definitions:**

*   **Taylor Series:** A representation of a function as an infinite sum of terms, calculated from the values of its derivatives at a single point.
    $f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!} (z-z_0)^n$

**Taylor Series Expansion about $z_0 = 0$ (Maclaurin Series):**

We know that $f(z) = e^z$, $f'(z) = e^z$, $f''(z) = e^z$, and so on.
$f^{(n)}(z) = e^z$ for all $n \ge 0$.
Evaluating at $z_0 = 0$: $f^{(n)}(0) = e^0 = 1$ for all $n$.

Therefore, the Maclaurin series for $e^z$ is:
$e^z = \sum_{n=0}^{\infty} \frac{f^{(n)}(0)}{n!} (z-0)^n = \sum_{n=0}^{\infty} \frac{1}{n!} z^n$
$e^z = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \frac{z^4}{4!} + \dots$

This series converges for all $z \in \mathbb{C}$.

**Taylor Series Expansion about an arbitrary $z_0$:**

$e^z = \sum_{n=0}^{\infty} \frac{e^{z_0}}{n!} (z-z_0)^n = e^{z_0} \sum_{n=0}^{\infty} \frac{(z-z_0)^n}{n!}$

**Laurent Series Expansion:**

If a function has a singularity, its Laurent series is used. However, $e^z$ is entire (analytic everywhere), so its Laurent series is the same as its Taylor series.

### 7. Connection to Fourier Transforms (CO1)

The complex exponential function is the cornerstone of Fourier analysis.

**Key Concepts & Definitions:**

*   **Fourier Series:** Represents a periodic function as a sum of sines and cosines.
*   **Fourier Transform:** Extends Fourier series to non-periodic functions, representing them as an integral of complex exponentials.
*   **Euler's Formula:** $e^{i\omega t} = \cos(\omega t) + i\sin(\omega t)$

**The Role of $e^{i\omega t}$:**

The Fourier transform of a function $f(t)$ is defined as:
$\mathcal{F}\{f(t)\} = F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$

Here, $e^{-i\omega t}$ is the complex exponential, representing sinusoidal components of different frequencies $\omega$. The integral decomposes the function $f(t)$ into its constituent frequencies.

**Example:**

Consider the Dirac delta function $\delta(t)$.
$\mathcal{F}\{\delta(t)\} = \int_{-\infty}^{\infty} \delta(t) e^{-i\omega t} dt$
By the sampling property of the delta function, this integral is equal to $e^{-i\omega (0)} = e^0 = 1$.
So, the Fourier transform of $\delta(t)$ is $1$.

**Inverse Fourier Transform:**

The inverse Fourier transform reconstructs the original function from its frequency components:
$f(t) = \mathcal{F}^{-1}\{F(\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{i\omega t} d\omega$

The presence of $e^{i\omega t}$ in the inverse transform highlights how complex exponentials are used to synthesize signals.

**Learning Outcome Alignment (CO1):**

The complex exponential $e^{i\omega t}$ is directly used in the definition of Fourier transforms. Understanding $w = e^z$ provides the foundational knowledge for comprehending how these sinusoidal components (represented by $e^{i\omega t}$) are used to analyze and represent signals and systems in electrical and physical sciences.

**References:**

*   **Fast Fourier Transform - Algorithms and Applications by K.R. Rao, Do Nyeon Kim, Jae Jeong Hwang (1st ed., Chapter 1):** This book is specifically dedicated to FFT and its applications, heavily relying on the properties of complex exponentials.

### Answers to Practice Questions

**1. (Definition & Properties)**
$z = 2 - 3i$
$e^z = e^{2-3i} = e^2 e^{-3i} = e^2 (\cos(-3) + i\sin(-3)) = e^2 (\cos 3 - i\sin 3)$
Using calculator values: $e^2 \approx 7.389$, $\cos 3 \approx -0.990$, $\sin 3 \approx 0.141$.
$e^z \approx 7.389 (-0.990 - i 0.141) \approx -7.315 - 1.042i$

$|e^z| = |e^{2-3i}| = |e^2| |e^{-3i}| = e^2 \times 1 = e^2 \approx 7.389$

$\text{Arg}(e^z) = \arg(e^2 (\cos 3 - i\sin 3)) = \arg(-0.990 - i 0.141)$
This angle is in the third quadrant.
$\tan \theta = \frac{-0.141}{-0.990} \approx 0.142$
$\theta = \arctan(0.142) \approx 0.141$ radians.
Since it's in the third quadrant, the principal argument is $\theta - \pi \approx 0.141 - \pi \approx -2.999$ radians.
So, $\text{Arg}(e^z) \approx -3$ radians (since $y=-3$).

**2. (Properties)**
If $e^z = 1 + i$.
$|e^z| = |1+i| = \sqrt{1^2 + 1^2} = \sqrt{2}$.
Since $|e^z| = e^x$, we have $e^x = \sqrt{2}$, so $x = \ln(\sqrt{2}) = \frac{1}{2}\ln 2$.

$\arg(e^z) = \arg(1+i) = \frac{\pi}{4} + 2n\pi$.
Since $\arg(e^z) = y$, we have $y = \frac{\pi}{4} + 2n\pi$.

Therefore, $z = x + iy = \frac{1}{2}\ln 2 + i\left(\frac{\pi}{4} + 2n\pi\right)$ for any integer $n$.

**3. (Analyticity)**
$u(x, y) = e^x \cos y$, $v(x, y) = e^x \sin y$.
$\frac{\partial u}{\partial x} = e^x \cos y$, $\frac{\partial v}{\partial y} = e^x \cos y$. (Equal)
$\frac{\partial u}{\partial y} = -e^x \sin y$, $\frac{\partial v}{\partial x} = e^x \sin y$. (Opposite signs)
Cauchy-Riemann equations are satisfied.
$f'(z) = \frac{\partial u}{\partial x} + i \frac{\partial v}{\partial x} = e^x \cos y + i e^x \sin y = e^x (\cos y + i \sin y) = e^z$.
The derivative is $e^z$.

**4. (Mapping)**
*   Image of $x=1$: A circle centered at the origin with radius $e^1 = e$. The equation is $|w|=e$.
*   Image of $y=\pi/2$: A ray emanating from the origin along the positive imaginary axis (since $\cos(\pi/2)=0$ and $\sin(\pi/2)=1$, $w = e^x(0+i) = i e^x$. As $x$ goes from $-\infty$ to $\infty$, $e^x$ goes from $0$ to $\infty$, so $w$ traces the positive imaginary axis.

**5. (Mapping of Regions)**
The region is a rectangle with $x$ from $0$ to $\ln 2$ and $y$ from $0$ to $\pi$.
The left boundary $x=0$ maps to $|w|=e^0=1$.
The right boundary $x=\ln 2$ maps to $|w|=e^{\ln 2}=2$.
The bottom boundary $y=0$ maps to the positive real axis.
The top boundary $y=\pi$ maps to the negative real axis.
The image is a sector of an annulus defined by $1 \le |w| \le 2$ and $0 \le \arg(w) \le \pi$. This is the upper half of the annulus between the circles of radius 1 and 2.

**6. (Complex Integration)**
Since $e^z$ is analytic everywhere, by Cauchy's Integral Theorem, the integral over any closed contour is zero. The ellipse $|z-1|=1$ is a closed contour.
Therefore, $\oint_C e^z dz = 0$.

**7. (Series Expansion)**
The Maclaurin series for $e^z$ is:
$e^z = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \frac{z^4}{4!} + \dots = \sum_{n=0}^{\infty} \frac{z^n}{n!}$

**8. (Fourier Transform Connection)**
The term $e^{-i\omega t}$ in the Fourier transform integral $\int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$ represents the complex exponential basis functions. These functions, due to Euler's formula ($e^{-i\omega t} = \cos(\omega t) - i\sin(\omega t)$), capture both the amplitude and phase information of different sinusoidal frequencies present in the signal $f(t)$. The integral effectively projects $f(t)$ onto these basis functions to determine the contribution of each frequency $\omega$.
