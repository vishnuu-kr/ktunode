# Advanced Communication Theory: Module 3 - Introduction to Wireless Communication

## Topic: Code-Division Multiple Access (CDMA)

---

### **1. Introduction to Multiple Access Techniques**

Before diving into CDMA, it's crucial to understand the necessity of multiple access techniques in wireless communication. These techniques allow multiple users to share a common communication medium (e.g., radio spectrum) simultaneously without interfering with each other significantly.

*   **Why Multiple Access?**
    *   Limited spectrum resources.
    *   Need to support multiple users in a cellular network.

*   **Common Multiple Access Techniques:**
    *   **Frequency Division Multiple Access (FDMA):** Divides the available frequency spectrum into separate channels, with each user assigned a unique channel.
        *   *Analogy:* Assigning different radio stations to different frequencies.
        *   *Reference:* Rappaport, Chapter 3.
    *   **Time Division Multiple Access (TDMA):** Divides the time axis into slots, and each user is allocated specific time slots for transmission.
        *   *Analogy:* Users taking turns to speak on a single channel.
        *   *Reference:* Goldsmith, Chapter 2.
    *   **Code Division Multiple Access (CDMA):** Users are assigned unique spreading codes that differentiate their signals within the same frequency band and time.
        *   *Analogy:* People speaking different languages in the same room; you can focus on the language you understand.
        *   *Reference:* Goldsmith, Chapter 11; Rappaport, Chapter 7.

### **2. Code-Division Multiple Access (CDMA): The Core Concept**

CDMA is a **spread spectrum** technique where users transmit simultaneously over the same frequency band. Each user's signal is spread across a wide bandwidth using a unique **spreading code** (or pseudo-random noise, PN code). At the receiver, a correlator synchronized with the user's spreading code can extract the intended signal while rejecting other users' signals as noise.

*   **Key Principles:**
    *   **Simultaneous Transmission:** All users share the same frequency band at the same time.
    *   **Unique Spreading Codes:** Each user is assigned a unique, pseudo-random code.
    *   **Spread Spectrum:** The data signal is spread over a much wider bandwidth than the original data rate.
    *   **Interference Rejection:** The receiver uses the user's specific code to "despread" the signal, effectively filtering out other users' signals which appear as noise.

*   **How it Works (Simplified):**
    1.  **Spreading (at Transmitter):** The user's data bits are multiplied (or XORed, for binary signals) with the spreading code. This spreads the signal over a wider bandwidth.
    2.  **Transmission:** The spread signal is transmitted.
    3.  **Despreading (at Receiver):** The receiver multiplies the received signal with the *same* spreading code used by the intended transmitter. This "compresses" the intended signal back to its original bandwidth and spreads the other users' signals even further, making them appear as noise.
    4.  **Correlation:** A correlation process is used to extract the original data. The correlation between the received spread signal and the user's unique spreading code will be high for the intended user, and low for others.

*   **Reference:** Goldsmith, Chapter 11; Rappaport, Chapter 7.
*   **Alignment with CO4:** Explains a fundamental wireless communication technique.

### **3. Spreading Codes in CDMA**

The performance of CDMA heavily relies on the properties of the spreading codes.

*   **Types of Spreading Codes:**
    *   **Pseudo-Random Noise (PN) Codes:** These codes appear random but are generated by deterministic algorithms. They are designed to have good correlation properties.
        *   **Gold Codes:** A family of codes with good auto-correlation and cross-correlation properties, commonly used in IS-95 CDMA. They are formed by combining two m-sequences.
        *   **Walsh Codes:** Orthogonal codes that are perfectly uncorrelated when aligned. They are useful for separating users in a single cell where all users share the same base station and can be synchronized. However, their orthogonality is lost in the presence of timing differences or multipath fading (leading to the concept of "near-far problem").
        *   **Pseudo-Noise (PN) Sequences (m-sequences):** These are sequences generated by linear feedback shift registers (LFSRs). They have good autocorrelation properties (sharp peak at zero shift, low sidelobes).

*   **Key Properties of Spreading Codes:**
    *   **High Auto-correlation:** The correlation of a code with itself should be high at zero shift (synchronous) and low (ideally zero) at all other shifts. This helps in accurate synchronization.
    *   **Low Cross-correlation:** The correlation between any two different codes should be low (ideally zero). This minimizes interference between different users.
    *   **Spreading Factor (SF) or Processing Gain (PG):** The ratio of the chip rate ($R_{chip}$) to the data rate ($R_{data}$), $SF = PG = \frac{R_{chip}}{R_{data}}$. A higher processing gain leads to better interference rejection and hence higher capacity.

*   **Example:**
    Let data be `1` and the spreading code be `1011`.
    Spread signal: `1011` (since `1` AND `1011` is `1011`).
    If data is `0`, the code is inverted: `0100`.
    The spreading code effectively spreads the data bit over multiple "chips" (elements of the code).

*   **Reference:** Goldsmith, Chapter 11; Rappaport, Chapter 7; Lin & Costello, Chapter 1.
*   **Alignment with CO3:** Understanding spreading codes is analogous to understanding error correction codes in terms of their mathematical structure and error-inducing properties, though their application is different. Good codes in CDMA minimize "correlation errors."

### **4. CDMA Transmitter and Receiver Structure**

*   **CDMA Transmitter:**
    1.  **Data Modulation:** Convert digital data into a suitable waveform (e.g., BPSK).
    2.  **Spreading:** Multiply the modulated data by the user's unique spreading code.
    3.  **Upconversion:** Shift the signal to the desired radio frequency.
    4.  **Amplification and Transmission:** Boost the signal power and transmit.

*   **CDMA Receiver:**
    1.  **Downconversion:** Shift the received signal to a baseband frequency.
    2.  **Demodulation:** Remove the carrier frequency.
    3.  **Despreading:** Multiply the received signal with the intended user's spreading code. This is the crucial step for separating users.
    4.  **Correlation:** A correlator (or matched filter) is used to detect the presence of the original data signal. The output of the correlator is compared against a threshold to decide the transmitted data bit.
    5.  **Data Recovery:** Convert the demodulated signal back into digital data.

*   **Reference:** Goldsmith, Chapter 11; Rappaport, Chapter 7.

### **5. Performance Analysis of CDMA**

The performance of CDMA is often analyzed in terms of its capacity and its susceptibility to interference.

*   **Capacity:**
    *   The capacity of a CDMA system is limited by the **interference from other users**.
    *   As more users are added, the interference level increases, degrading the performance of each user.
    *   The capacity is inversely proportional to the **processing gain (PG)**. A higher PG allows more users to share the spectrum.
    *   **Fundamental Limit:** The system capacity is limited by the total interference that can be tolerated.

*   **Interference Sources:**
    *   **Other Users:** The primary source of interference in an ideal CDMA system is the "noise" created by other users' despread signals.
    *   **Multipath Fading:** Reflected signals arriving at different times can cause self-interference and de-correlation.
    *   **Near-Far Problem:** If a strong signal from a nearby transmitter arrives at a receiver that is also trying to receive a weak signal from a distant transmitter on the same frequency, the strong signal can overwhelm the receiver's ability to extract the weak signal. Power control is crucial to mitigate this.
    *   **Other Radio Systems:** Interference from systems operating in adjacent frequency bands.

*   **Signal-to-Interference-plus-Noise Ratio (SINR):**
    The performance of a CDMA link is often characterized by the SINR.
    $SINR = \frac{S}{I_{other} + N_0}$
    Where:
    *   $S$ is the desired signal power.
    *   $I_{other}$ is the interference power from other users.
    *   $N_0$ is the power spectral density of the background noise.

    In a CDMA system, the interference from other users ($I_{other}$) can be modeled as a Gaussian noise process if there are a large number of users, thanks to the central limit theorem.

*   **Processing Gain's Role:** A higher processing gain (PG) means the desired signal is spread over a wider bandwidth, and importantly, the interfering signals are also spread over a wider bandwidth at the receiver. When the receiver despreads with the correct code, the desired signal is "recovered" (despread back to the original bandwidth), while the interfering signals are spread even further, effectively reducing their power spectral density.

*   **Reference:** Goldsmith, Chapter 11; Rappaport, Chapter 7; Tse & Viswanath, Chapter 3.
*   **Alignment with CO4:** Demonstrates how multiple access impacts signal quality and system capacity.
*   **Alignment with CO5:** Relates to signal-to-interference ratio, a key metric in analyzing performance.

### **6. CDMA vs. Other Multiple Access Techniques**

*   **Advantages of CDMA:**
    *   **Higher Capacity (potentially):** Can support more users than FDMA or TDMA in certain scenarios due to efficient spectrum utilization and inherent interference rejection.
    *   **Soft Capacity:** The capacity is not hard; adding more users gradually degrades performance rather than causing abrupt failures.
    *   **Graceful Degradation:** Performance degrades gradually as more users are added.
    *   **Robustness to Fading:** Spread spectrum nature makes it more resistant to narrow-band interference and multipath fading compared to non-spread spectrum systems.
    *   **Security:** The spreading codes provide a degree of privacy.
    *   **No Frequency Planning:** Unlike FDMA and TDMA, CDMA systems generally don't require complex frequency planning for cellular networks.

*   **Disadvantages of CDMA:**
    *   **Near-Far Problem:** Requires sophisticated power control to ensure all signals arrive at the base station with similar power levels.
    *   **Complexity:** Requires complex signal processing at both transmitter and receiver (e.g., correlation).
    *   **Bandwidth Requirement:** Requires significantly more bandwidth than the original data rate (due to spreading).
    *   **Synchronization:** Precise synchronization of spreading codes is critical.
    *   **Orthogonality Loss:** Walsh codes lose orthogonality in the presence of multipath or timing differences.

*   **Reference:** Goldsmith, Chapter 11; Rappaport, Chapter 7; Schiller, Chapter 6.
*   **Alignment with CO4:** Contrasts CDMA with other techniques, highlighting its unique characteristics.

### **7. Applications of CDMA**

CDMA has been widely adopted in various wireless communication standards.

*   **Global System for Mobile Communications (GSM) Evolution:** CDMA2000 (IS-2000) is a 3G CDMA standard.
*   **Wideband Code Division Multiple Access (WCDMA):** A 3G UMTS standard.
*   **Satellite Communication Systems:** Used in some satellite navigation and communication systems.
*   **Military Communication:** Due to its inherent security and anti-jamming capabilities.

*   **Reference:** Rappaport, Chapter 7; Schiller, Chapter 6.

### **8. Key Concepts and Definitions Summary**

*   **Multiple Access:** Allowing multiple users to share a communication medium.
*   **Spread Spectrum:** Spreading a signal over a much wider bandwidth than its original bandwidth.
*   **Spreading Code (PN Code):** A pseudo-random sequence used to spread and identify signals in CDMA.
*   **Spreading Factor (SF) / Processing Gain (PG):** The ratio of chip rate to data rate ($SF = PG = R_{chip}/R_{data}$).
*   **Chip:** The smallest unit of a spreading code.
*   **Correlation:** The process of matching a received signal with a known code.
*   **Near-Far Problem:** Interference caused by a strong, nearby signal overwhelming a weak, distant signal.
*   **Power Control:** Essential in CDMA to equalize signal strengths at the receiver.
*   **Orthogonal Codes (e.g., Walsh Codes):** Codes that are perfectly uncorrelated when perfectly aligned.

---

### **9. Important Points to Remember**

*   CDMA's core principle is using **unique codes** to separate users sharing the **same frequency and time**.
*   **Processing Gain** is directly related to the spreading factor and is key to CDMA's performance. Higher PG means better interference rejection and potentially higher capacity.
*   The **near-far problem** is a critical challenge in CDMA, necessitating robust **power control**.
*   CDMA's **graceful degradation** and **soft capacity** are significant advantages.
*   The choice of **spreading codes** (Gold, Walsh, m-sequences) significantly impacts performance due to their auto-correlation and cross-correlation properties.

### **10. Practice Questions and Answers**

**Question 1:** Explain the fundamental difference between FDMA, TDMA, and CDMA.
**Answer:**
*   **FDMA:** Divides the **frequency spectrum**.
*   **TDMA:** Divides the **time axis**.
*   **CDMA:** Uses **unique codes** to separate users within the same frequency and time.

**Question 2:** What is the "spreading factor" in CDMA, and why is it important?
**Answer:** The spreading factor (SF), also known as processing gain (PG), is the ratio of the chip rate ($R_{chip}$) to the data rate ($R_{data}$). It's important because a higher SF means the signal is spread over a wider bandwidth, making it more resistant to interference and allowing for better separation of users. This directly impacts the system's capacity and signal quality.

**Question 3:** Describe the "near-far problem" in CDMA and suggest a solution.
**Answer:** The near-far problem occurs when a strong signal from a nearby transmitter interferes with a weak signal from a distant transmitter being received at the same base station. The strong signal can overwhelm the receiver's ability to extract the weak signal. The primary solution is **power control**, where the base station dynamically adjusts the transmission power of mobile devices to ensure all signals arrive at the base station with roughly equal strength.

**Question 4:** How does CDMA achieve multiple access?
**Answer:** CDMA achieves multiple access by assigning a unique spreading code to each user. All users transmit simultaneously over the same frequency band. At the receiver, the intended user's signal is recovered by despreading it with its specific code, while other users' signals are spread further and appear as background noise due to their different codes.

**Question 5:** If a CDMA system uses a spreading code with a length of 127 chips and a data rate of 9.6 kbps, what is the chip rate?
**Answer:**
The spreading factor (SF) is equal to the length of the spreading code, which is 127.
$SF = \frac{R_{chip}}{R_{data}}$
$127 = \frac{R_{chip}}{9.6 \text{ kbps}}$
$R_{chip} = 127 \times 9.6 \text{ kbps}$
$R_{chip} = 1219.2 \text{ kbps}$
