# WIRELESS & MOBILE COMPUTING - Module 3: Spread Spectrum - Direct Sequence (DS-SS)

## 1. Introduction to Spread Spectrum

*   **Definition:** Spread spectrum is a modulation technique where the bandwidth of a transmitted signal is deliberately spread to be much wider than the minimum bandwidth required to transmit the information being sent.

*   **Why Use Spread Spectrum?**
    *   **Interference Rejection:**  Makes the signal resistant to narrowband interference (e.g., jamming).
    *   **Multipath Mitigation:**  Can improve signal quality in environments with multipath fading.
    *   **Security:** Makes signal interception difficult, enhancing communication security.
    *   **Multiple Access:** Enables multiple users to share the same bandwidth without significant interference (CDMA).
    *   **Hiding and Encrypting Signals:** Concealing the presence of the signal or encrypting the information being transmitted.

*   **Key Characteristics:**
    *   **Wideband:**  The transmitted signal occupies a bandwidth significantly larger than the information bandwidth.
    *   **Pseudorandom Code:** Spreading is accomplished using a pseudorandom (PN) code, which is a deterministic sequence that appears random but is generated by a known algorithm.
    *   **Code Correlation:** Receivers must know the PN code to de-spread the signal and recover the original information.

## 2. Direct Sequence Spread Spectrum (DS-SS) - Core Concepts

*   **Definition:** DS-SS is a spread spectrum technique where the transmitted signal's bandwidth is expanded by multiplying the original data signal by a high-speed pseudorandom code (PN sequence) directly in the time domain.

*   **How it Works:**
    *   **Spreading:**  Each data bit is multiplied by a sequence of PN code bits (chips). This process increases the signal's bandwidth.
    *   **Transmission:** The spread signal is transmitted over the wireless channel.
    *   **De-spreading:**  At the receiver, the received signal is multiplied by an identical and synchronized version of the PN code. This process collapses the signal back to its original bandwidth.
    *   **Data Recovery:**  The data bit is recovered from the de-spread signal.

*   **Key Parameters:**
    *   **Chip Rate (Rc):** The rate at which the PN code bits (chips) are generated. Measured in chips per second (cps).  Rc is much higher than the data bit rate.
    *   **Data Bit Rate (Rb):** The rate at which the data bits are transmitted. Measured in bits per second (bps).
    *   **Processing Gain (Gp):** The ratio of the spread bandwidth to the original data bandwidth.  It's a measure of how much the signal is spread. Gp = Rc / Rb.  Expressed in dB:  Gp(dB) = 10 * log10(Rc/Rb).  Higher processing gain means better interference rejection.
    *   **Spreading Code (PN Code):** A pseudorandom sequence used to spread and de-spread the signal.  Must have good autocorrelation and cross-correlation properties.
    *   **Code Length (N):** The number of chips in a single period of the PN code.

## 3. DS-SS Transmitter and Receiver

*   **DS-SS Transmitter:**
    1.  **Data Source:** Generates the original data signal (e.g., bits).
    2.  **PN Code Generator:** Generates the pseudorandom code (PN sequence).
    3.  **Modulator (Mixer/Multiplier):** Multiplies the data signal by the PN code. This spreads the signal's bandwidth. Common modulation schemes used are Binary Phase Shift Keying (BPSK) or Quadrature Phase Shift Keying (QPSK).
    4.  **RF Transmitter:**  Converts the spread signal to radio frequency for transmission.

*   **DS-SS Receiver:**
    1.  **RF Receiver:** Receives the spread signal.
    2.  **PN Code Generator (synchronized):** Generates an identical and synchronized version of the PN code used at the transmitter.  Synchronization is CRITICAL.
    3.  **De-spreader (Mixer/Multiplier):** Multiplies the received signal by the synchronized PN code. This de-spreads the signal, collapsing it back to its original bandwidth.
    4.  **Demodulator:** Recovers the original data from the de-spread signal.
    5.  **Data Sink:**  Outputs the recovered data.

*   **Importance of Synchronization:**  The receiver's PN code generator must be synchronized with the transmitter's PN code generator.  If synchronization is lost, the de-spreading process will fail, and the data cannot be recovered.  Synchronization techniques involve initial acquisition and tracking to maintain lock.

## 4. Properties of PN Sequences

*   **Pseudorandomness:**  Although deterministic, PN sequences must exhibit properties similar to random sequences.
*   **Balance Property:** Approximately equal numbers of 0s and 1s.
*   **Run Property:** The length distribution of runs (sequences of consecutive 0s or 1s) should be similar to that of a random sequence.
*   **Correlation Properties:**
    *   **Autocorrelation:**  A measure of the similarity of a sequence with a time-shifted version of itself.  Good PN sequences have a sharp peak in their autocorrelation function when the shift is zero (perfect match) and low values for all other shifts.  This allows the receiver to accurately synchronize with the incoming signal.
    *   **Cross-correlation:**  A measure of the similarity between two different PN sequences.  Low cross-correlation is desirable when multiple users are using different PN codes to minimize interference between them (CDMA).

*   **Common PN Code Types:**
    *   **Maximal-Length Sequences (m-sequences):**  Easy to generate using linear feedback shift registers (LFSRs). They have good autocorrelation properties.
    *   **Gold Codes:**  Constructed from a pair of m-sequences and provide a large set of codes with controlled cross-correlation properties, making them suitable for CDMA systems.
    *   **Kasami Codes:**  Another family of codes with good correlation properties used in CDMA.

## 5. Advantages and Disadvantages of DS-SS

*   **Advantages:**
    *   **Interference Rejection:** Can effectively mitigate narrowband interference.
    *   **Multipath Mitigation:** Improves signal quality in environments with multipath fading.
    *   **Security:**  Difficult to intercept and decode without knowing the PN code.
    *   **CDMA Capability:** Supports multiple users sharing the same bandwidth.
    *   **Accurate Ranging:** The precise timing offered by PN sequences can be utilized in distance measurement.

*   **Disadvantages:**
    *   **Increased Bandwidth:** Requires significantly more bandwidth than traditional modulation techniques.
    *   **Complexity:**  Requires more complex hardware and signal processing at both the transmitter and receiver.
    *   **Synchronization Requirements:**  Precise synchronization between transmitter and receiver is crucial for proper operation.  Acquiring and maintaining synchronization can be challenging, especially in mobile environments.
    *   **Near-Far Problem:** In CDMA systems, users closer to the receiver can overpower signals from users farther away.  Power control mechanisms are needed to mitigate this.

## 6. Applications of DS-SS

*   **Wireless Communication:**
    *   **CDMA Cellular Systems (e.g., IS-95, cdma2000):**  Provides multiple access and interference rejection.
    *   **GPS (Global Positioning System):** Uses DS-SS for ranging and navigation.
    *   **Wireless LANs (e.g., older 802.11 standards):** Used in some earlier implementations for improved robustness.
    *   **Satellite Communication:**  Used for robust and secure communication.

*   **Military Communication:**  Used for secure and jam-resistant communication.
*   **Radar Systems:**  Used for improved range resolution and interference rejection.

## 7. Example Scenario: CDMA Cellular Communication

Imagine three users (A, B, and C) communicating with a base station using CDMA DS-SS:

1.  **User A:**  Has data bits to transmit and uses PN code PA.  The data is multiplied by PA and transmitted.
2.  **User B:**  Has data bits to transmit and uses PN code PB.  The data is multiplied by PB and transmitted.
3.  **User C:**  Has data bits to transmit and uses PN code PC.  The data is multiplied by PC and transmitted.

All three signals are transmitted simultaneously over the same frequency band.

At the base station receiver:

1.  **To receive User A's data:** The received signal (a mixture of A, B, and C's spread signals) is multiplied by PA.  Because PA has low cross-correlation with PB and PC, the signals from users B and C are effectively de-spread and appear as noise.  User A's signal is de-spread, and the data is recovered.

2.  **Similarly, to receive User B's or C's data:** The receiver multiplies the received signal by PB or PC, respectively.

This illustrates how CDMA DS-SS allows multiple users to share the same bandwidth by using different PN codes with low cross-correlation.

## 8. Practice Questions and Exercises

1.  **Question:** Define spread spectrum and explain why it is used in wireless communication systems.

    **Answer:** Spread spectrum is a modulation technique where the bandwidth of a signal is deliberately increased to be much wider than the minimum required. It is used for interference rejection, multipath mitigation, security, multiple access (CDMA), and hiding signals.

2.  **Question:** What is the core principle behind Direct Sequence Spread Spectrum (DS-SS)?

    **Answer:** The core principle is to spread the signal's bandwidth by multiplying the data signal with a high-speed pseudorandom noise (PN) code directly in the time domain.

3.  **Question:**  A DS-SS system has a chip rate of 10 Mcps and a data bit rate of 10 Kbps. Calculate the processing gain in dB.

    **Answer:**
    *   Gp = Rc / Rb = 10,000,000 / 10,000 = 1000
    *   Gp(dB) = 10 * log10(1000) = 10 * 3 = 30 dB

4.  **Question:** Explain the importance of synchronization in a DS-SS system. What happens if the receiver is not synchronized with the transmitter?

    **Answer:** Synchronization is critical because the receiver needs an identical and synchronized version of the PN code to de-spread the received signal. If the receiver is not synchronized, the de-spreading process will fail, and the data cannot be recovered. The received signal will appear as noise.

5.  **Question:** What are the key properties that a good PN sequence should possess?

    **Answer:** A good PN sequence should be pseudorandom, balanced (equal numbers of 0s and 1s), have good autocorrelation properties (sharp peak when perfectly aligned, low elsewhere), and, if used in CDMA, have low cross-correlation with other PN sequences.

6.  **Question:** List three applications of DS-SS.

    **Answer:**
    *   CDMA Cellular Systems (e.g., IS-95, cdma2000)
    *   GPS (Global Positioning System)
    *   Satellite Communication

## 9. Important Points to Remember

*   **Spread Spectrum is about bandwidth expansion for benefits like interference immunity.**
*   **DS-SS uses a PN code to directly spread the signal.**
*   **Processing Gain is a key metric for DS-SS performance.**
*   **Synchronization is absolutely critical for DS-SS operation.**
*   **PN codes must have good correlation properties.**
*   **DS-SS enables CDMA (Code Division Multiple Access).**
*   **Be aware of the tradeoffs between bandwidth, complexity, and performance.**
