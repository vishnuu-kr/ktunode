# Object-Oriented Programming: Module 4 - Swing Fundamentals: Swing Controls

This module focuses on the core building blocks of graphical user interfaces (GUIs) in Java using the Swing toolkit. We'll explore various Swing controls, their properties, and how to use them to create interactive applications.

---

## 1. Introduction to Swing Controls

Swing is a GUI toolkit for Java that provides a rich set of components for building platform-independent applications. It's built on top of the Abstract Window Toolkit (AWT) but offers more powerful and flexible components.
