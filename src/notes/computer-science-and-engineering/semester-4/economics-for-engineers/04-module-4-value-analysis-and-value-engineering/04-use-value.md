## Economics for Engineers: Module 4 - Value Analysis and Value Engineering - Use Value

**Learning Outcomes:**

*   Understand the concept of Use Value.
*   Differentiate Use Value from other types of value (e.g., Esteem Value, Exchange Value).
*   Identify factors affecting Use Value.
*   Apply techniques to enhance Use Value in engineering designs and projects.
*   Analyze and evaluate the Use Value of different product or service options.

**1. Introduction to Use Value**

*   **Definition:** Use Value refers to the specific function or performance characteristic that makes a product or service capable of fulfilling a particular need or want. It's the value derived from what a product *does* rather than what it *is* or what it *costs*.  It answers the question:  "What function does this perform?"
*   **Importance in Value Analysis/Value Engineering (VA/VE):**  VA/VE aims to improve the value of a product or service by maximizing its function (Use Value) relative to its cost. It focuses on ensuring that every component and feature directly contributes to the required performance.
*   **Key Concept: Function Analysis:** Understanding Use Value is intrinsically linked to function analysis, a core component of VA/VE.  We analyze *what* the product/service *does* and *how* it does it, which directly impacts its perceived and actual Use Value.

**2. Differentiating Use Value from Other Types of Value**

*   **Types of Value (Brief Overview):**
    *   **Cost Value:** Actual or estimated cost of producing the item.
    *   **Exchange Value:** Price at which the item can be sold or exchanged in the market.
    *   **Esteem Value:**  Subjective value based on perceived reputation, brand image, desirability, or aesthetic appeal.
    *   **Use Value:** Value derived from the function and performance of the item.

*   **Key Differences:**
    *   **Use Value vs. Cost Value:**  A high-cost item doesn't necessarily have high Use Value.  A low-cost item can provide excellent Use Value if it adequately performs the required function. VA/VE strives to achieve *high* Use Value at a *low* Cost Value.
    *   **Use Value vs. Exchange Value:**  A product can have high Exchange Value (market price) due to marketing or brand reputation even if its Use Value is moderate. Conversely, a product with exceptional Use Value might have a lower Exchange Value if it's not well marketed or known.
    *   **Use Value vs. Esteem Value:** Esteem Value is subjective and emotional, whereas Use Value is more objective and functional.  A luxury car might have high Esteem Value but not proportionally higher Use Value compared to a more practical, less expensive vehicle (in terms of transportation function). The same applies to designer clothing versus standard, functional clothing.  Esteem Value can influence perceived Use Value, however.

*   **Relationship:**  These values are interconnected but distinct. Ideal value creation aims for a balance: high Use Value, acceptable Cost Value, reasonable Exchange Value, and potentially some Esteem Value (depending on the target market).

**3. Factors Affecting Use Value**

*   **Performance:** The degree to which the product or service fulfills its intended function. Key aspects include:
    *   **Reliability:** How consistently the product performs over time.
    *   **Durability:**  How long the product lasts under normal operating conditions.
    *   **Efficiency:**  How well the product performs its function with minimal resource consumption (e.g., energy, materials).
    *   **Accuracy:** How precisely the product delivers the intended outcome.
    *   **Capacity:** The maximum load or output the product can handle.
*   **Functionality:**  The range of capabilities offered by the product. More features don't always equate to higher Use Value; unnecessary or poorly implemented features can actually *reduce* it.
*   **Ease of Use (Usability):** How easy it is for the user to operate, maintain, and repair the product.  A product with excellent performance but difficult operation might have lower Use Value than a slightly less powerful but user-friendly alternative.
*   **Safety:** The degree to which the product is free from hazards and risks.  Safety is a crucial factor influencing Use Value, particularly in engineering designs.
*   **Maintainability:** How easily the product can be maintained and repaired.  This directly impacts its lifespan and overall Use Value.
*   **Aesthetics (to a Limited Extent):** While primarily related to Esteem Value, aesthetics can contribute to Use Value if the product is visually appealing and user-friendly. However, aesthetics should never compromise performance or functionality.
*   **Ergonomics:**  How well the product is designed to fit the human body and minimize strain or discomfort. This is particularly relevant for tools, equipment, and workspaces.

**4. Techniques to Enhance Use Value in Engineering Designs and Projects**

*   **Function Analysis System Technique (FAST):** A structured method for identifying, analyzing, and clarifying the functions of a product or service.  This helps to pinpoint areas where Use Value can be improved.
    *   **Basic Function:** The primary reason for the product's existence.
    *   **Secondary Functions:** Functions that support the basic function.
    *   **Unnecessary Functions:**  Functions that don't contribute to the overall value and can be eliminated.
*   **Value Engineering Job Plan:** A systematic process for applying VA/VE principles. This typically involves the following phases:
    *   **Information Phase:** Gather data about the product, its functions, costs, and performance requirements.
    *   **Creative Phase:** Generate alternative solutions for achieving the required functions. Brainstorming, lateral thinking, and checklists are useful techniques.
    *   **Evaluation Phase:** Evaluate the alternative solutions based on their cost, performance, feasibility, and other relevant criteria.
    *   **Development Phase:** Develop the most promising solutions into detailed designs or prototypes.
    *   **Presentation Phase:**  Present the proposed changes to stakeholders and obtain approval for implementation.
    *   **Implementation Phase:**  Put the changes into effect.
    *   **Follow-up Phase:** Monitor the results and make adjustments as needed.
*   **Benchmarking:**  Comparing the product or service to best-in-class alternatives to identify areas for improvement.
*   **Simplification:**  Reducing the number of components or features to streamline the design and improve reliability.
*   **Standardization:** Using standard parts and components to reduce costs and improve maintainability.
*   **Material Substitution:**  Replacing expensive materials with less costly alternatives that provide comparable performance.
*   **Process Improvement:**  Optimizing manufacturing or service delivery processes to reduce costs and improve efficiency.
*   **Design for Manufacturability (DFM) and Design for Assembly (DFA):**  Designing products that are easy to manufacture and assemble, which can reduce costs and improve quality.
*   **Life Cycle Cost Analysis (LCCA):** Considering the total cost of ownership over the product's entire lifespan, including initial cost, operating costs, maintenance costs, and disposal costs. This helps to identify opportunities to reduce costs and improve Use Value over the long term.

**5. Analyzing and Evaluating the Use Value of Different Product/Service Options**

*   **Quantitative Methods:**
    *   **Cost-Benefit Analysis (CBA):**  Comparing the costs and benefits of different options to determine which offers the greatest net benefit.  Benefits should be expressed in terms of improved performance, functionality, reliability, or other aspects of Use Value.
    *   **Value Index (VI):**  A numerical measure of value calculated as: `Value Index = (Performance/Functionality)/(Cost)`. A higher Value Index indicates better Use Value.  Assign weights to different performance/functionality aspects to reflect their relative importance.
    *   **Weighted Scoring Model:** Assign weights to different criteria (e.g., performance, reliability, ease of use, safety) and then score each option based on how well it meets each criterion. The weighted scores are then summed to obtain an overall score for each option.
*   **Qualitative Methods:**
    *   **Expert Opinion:**  Soliciting the opinions of subject matter experts on the Use Value of different options.
    *   **User Feedback:**  Gathering feedback from users through surveys, interviews, or focus groups.  This provides valuable insights into the actual Use Value of the product or service.
    *   **Pairwise Comparison:** Comparing options two at a time to determine which is preferred based on Use Value.
*   **Multi-Criteria Decision Analysis (MCDA):**  A family of techniques that can be used to evaluate multiple options based on multiple criteria, both quantitative and qualitative.

**Example:**

Let's say you are choosing between two types of pumps for a water distribution system:

*   **Pump A:** Lower initial cost, lower efficiency, lower reliability, shorter lifespan.
*   **Pump B:** Higher initial cost, higher efficiency, higher reliability, longer lifespan.

To evaluate the Use Value, you would consider:

1.  **Function:** Both pumps perform the same basic function (pumping water).
2.  **Performance:** Pump B offers superior performance in terms of efficiency and reliability.
3.  **Life Cycle Cost:** Calculate the total cost of ownership for each pump, including initial cost, energy consumption, maintenance, and replacement. Pump B's higher efficiency and longer lifespan might result in lower life cycle costs, even though its initial cost is higher.
4.  **Qualitative Factors:** Consider the reputation of the manufacturers, the availability of spare parts, and the ease of maintenance.

By analyzing these factors, you can determine which pump offers the best Use Value for the specific application.

**Important Points to Remember:**

*   Use Value is about **functionality and performance**.
*   Maximize Use Value while **minimizing cost**.
*   Consider the **life cycle cost** of the product or service.
*   Don't confuse Use Value with **Esteem Value or Exchange Value.**
*   Use **structured techniques** like FAST and the Value Engineering Job Plan.
*   Gather **both quantitative and qualitative data** to support your analysis.
*   Involve **stakeholders** in the decision-making process.

**Practice Questions/Exercises:**

1.  **Define Use Value in your own words and explain why it is important in engineering design.**
    *   **Answer:** Use Value is the benefit derived from the functions and performance characteristics of a product or service, specifically what it *does* to fulfill a need. It's important in engineering design because engineers should strive to create designs that provide the most functionality and performance at the lowest possible cost, thereby maximizing Use Value.

2.  **Give an example of a product where high Esteem Value might not correlate with high Use Value.  Explain your reasoning.**
    *   **Answer:** A high-end designer handbag. While it might have a high price (Exchange Value) and be seen as prestigious (Esteem Value), its Use Value might not be significantly higher than a more affordable, functional bag that adequately carries belongings. The designer bag's value is largely derived from brand image and status, not necessarily superior functionality.

3.  **A company is designing a new type of smartphone. List three factors that would significantly affect the Use Value of the phone and explain why they are important.**
    *   **Answer:**
        *   **Battery Life:**  Long battery life is essential for convenient and uninterrupted use. A phone with poor battery life would frustrate users and limit its functionality.
        *   **Processing Speed:** A fast processor allows the phone to run apps smoothly and efficiently. Slow processing can lead to lag, frustration, and reduced productivity.
        *   **Camera Quality:** A high-quality camera allows users to capture clear and detailed photos and videos. This is important for capturing memories, sharing information, and participating in online communication.

4.  **Describe the difference between a Basic Function and a Secondary Function in FAST. Provide an example.**
    *   **Answer:** The Basic Function is the primary purpose or reason for the product's existence.  Secondary Functions support the Basic Function. Example: For a stapler:
        *   Basic Function: FASTEN PAPERS
        *   Secondary Function: PROTECT FINGERS (the stapler's design protects fingers during use, supporting the main function).

5.  **A company is considering two materials for a component: Material A is cheaper but less durable, while Material B is more expensive but more durable. Explain how Life Cycle Cost Analysis (LCCA) can help them make a decision about which material to use.**
    *   **Answer:** LCCA helps to determine the total cost of each material over the component's lifespan. While Material A has a lower initial cost, its shorter lifespan means it will need to be replaced more frequently. This increases maintenance costs and the overall lifetime expense. Material B, despite the higher upfront cost, may prove cheaper in the long run due to its greater durability, lower maintenance needs, and fewer replacements. LCCA factors in all these costs (initial, maintenance, replacement, disposal) to provide a comprehensive comparison and highlight the option with the lower total cost of ownership, ultimately guiding the decision based on Use Value and cost-effectiveness.
