# THEORY OF COMPUTATION - Module 3: Pushdown Automata (Linz)
## Topic: Closure and Decision Properties of Context-Free Languages (CFLs)

**Description:** This module covers the closure properties and decision problems associated with Context-Free Languages (CFLs), with formal proofs.

**Learning Outcomes:**

*   Understand and explain closure properties of CFLs under various operations (union, concatenation, Kleene star, reversal, homomorphism, inverse homomorphism, intersection with regular languages).
*   Prove closure properties of CFLs using suitable constructions.
*   Understand and explain which decision problems are decidable and undecidable for CFLs.
*   Apply decision algorithms to determine if a given string is in a CFL, or if a CFL is empty.

---

## 1. Key Concepts and Definitions

*   **Context-Free Language (CFL):** A language generated by a Context-Free Grammar (CFG).
*   **Context-Free Grammar (CFG):**  A grammar in which the left-hand side of each production rule consists of only one non-terminal symbol.
*   **Pushdown Automaton (PDA):** A finite automaton with an additional stack. It is a model for recognizing CFLs.
*   **Closure Property:** A property that indicates whether a particular operation on languages (e.g., union, concatenation) will always produce a language of the same type (e.g., if CFLs are closed under union, the union of two CFLs is also a CFL).
*   **Decidable Problem:** A problem for which an algorithm exists that, given any instance of the problem, will always halt and produce a correct "yes" or "no" answer.
*   **Undecidable Problem:** A problem for which no such algorithm exists.

### 2.1 Union

**Theorem:** CFLs are closed under union.

**Proof:**
Let L1 and L2 be two CFLs generated by CFGs G1 = (V1, T1, P1, S1) and G2 = (V2, T2, P2, S2) respectively.  Without loss of generality, assume that V1 and V2 are disjoint (if not, rename the non-terminals).

Construct a new CFG G = (V, T, P, S) where:
*   V = V1 ∪ V2 ∪ {S} (where S is a new start symbol)
*   T = T1 ∪ T2
*   P = P1 ∪ P2 ∪ {S -> S1 | S2}

The grammar G generates L1 ∪ L2. Any string derived from G using the production S -> S1 will be generated by G1 and thus belong to L1.  Similarly, any string derived using S -> S2 will be generated by G2 and thus belong to L2. Therefore, L(G) = L1 ∪ L2.

**Example:**

Let L1 = {a^n b^n | n >= 0} and L2 = {c^m d^m | m >= 0}

G1: S1 -> aS1b | ε
G2: S2 -> cS2d | ε

G:  S -> S1 | S2
    S1 -> aS1b | ε
    S2 -> cS2d | ε

L(G) = {a^n b^n | n >= 0} ∪ {c^m d^m | m >= 0}

### 2.2 Concatenation

**Theorem:** CFLs are closed under concatenation.

**Proof:**
Let L1 and L2 be two CFLs generated by CFGs G1 = (V1, T1, P1, S1) and G2 = (V2, T2, P2, S2) respectively.  Without loss of generality, assume that V1 and V2 are disjoint.

Construct a new CFG G = (V, T, P, S) where:
*   V = V1 ∪ V2 ∪ {S}
*   T = T1 ∪ T2
*   P = P1 ∪ P2 ∪ {S -> S1S2}

The grammar G generates L1L2.  Any string derived from G will have the form "w1w2", where w1 is derived from S1 (and thus belongs to L1) and w2 is derived from S2 (and thus belongs to L2).  Therefore, L(G) = L1L2.

**Example:**

L1 = {a^n b^n | n >= 0}
L2 = {c^m d^m | m >= 0}

G1: S1 -> aS1b | ε
G2: S2 -> cS2d | ε

G:  S -> S1S2
    S1 -> aS1b | ε
    S2 -> cS2d | ε

L(G) = {a^n b^n c^m d^m | n >= 0, m >= 0}

### 2.3 Kleene Star (Closure)

**Theorem:** CFLs are closed under Kleene star.

**Proof:**
Let L be a CFL generated by CFG G = (V, T, P, S).

Construct a new CFG G' = (V', T', P', S') where:
*   V' = V ∪ {S'}
*   T' = T
*   P' = P ∪ {S' -> ε | S'S}

The grammar G' generates L*.  The production S' -> ε generates the empty string, which is always in L*.  The production S' -> S'S allows us to generate any number of strings from L concatenated together.  Therefore, L(G') = L*.

**Example:**

L = {a^n b^n | n >= 0}

G:  S -> aSb | ε

G': S' -> ε | S'S
     S -> aSb | ε

### 2.4 Reversal

**Theorem:** CFLs are closed under reversal.

**Proof:**
Let L be a CFL generated by CFG G = (V, T, P, S).  Construct a new CFG G' = (V, T, P', S) where P' is obtained from P by reversing the right-hand side of each production.

Formally, if A -> X1X2...Xn is a production in P, then A -> XnXn-1...X1 is a production in P'.

It can be shown by induction that L(G') = L(G)^R (the reversal of L(G)).

**Example:**

G: S -> aSb | ε

G': S -> bSa | ε

If G generates "aabb", then G' generates "bbaa".

### 2.5 Homomorphism

**Theorem:** CFLs are closed under homomorphism.

**Proof:**
Let L be a CFL generated by CFG G = (V, T, P, S), and let h be a homomorphism from T to T'*, where T' is another alphabet.

Construct a new CFG G' = (V, T', P', S) where P' is obtained from P by replacing each terminal a in the right-hand side of each production rule with h(a).

If A -> X1X2...Xn is a production in P, then the corresponding production in P' is A -> h(X1)h(X2)...h(Xn), where if Xi is a terminal, h(Xi) is the string it maps to; if Xi is a non-terminal, h(Xi) = Xi.

Then, L(G') = h(L).

**Example:**

L = {a^n b^n | n >= 0} generated by S -> aSb | ε
h(a) = c
h(b) = d

G': S -> cSd | ε
L(G') = {c^n d^n | n >= 0}

### 2.6 Inverse Homomorphism

**Theorem:** CFLs are closed under inverse homomorphism.

**Proof:**
Let L be a CFL and h be a homomorphism. We want to show h<sup>-1</sup>(L) is a CFL.
Let M be a PDA that accepts L. We construct a new PDA M' that accepts h<sup>-1</sup>(L).

M' simulates M.  Whenever M reads a symbol 'a' from the input, M' reads h(a) from *its* input.  This is accomplished by buffering h(a) using the finite state control of M'.  If, after reading h(a), M would have transitioned to a certain state and manipulated its stack, M' does the same.
Therefore, if w is in h<sup>-1</sup>(L), then h(w) is in L, and M accepts h(w). M' will simulate M and accept w.  Thus, M' accepts h<sup>-1</sup>(L).

### 2.7 Intersection with Regular Languages

**Theorem:** CFLs are closed under intersection with regular languages.

**Proof:**
Let L be a CFL accepted by a PDA P = (Qp, Σ, Γ, δp, q0p, Z0, Fp), and R be a regular language accepted by a DFA D = (Qd, Σ, δd, q0d, Fd).

We construct a new PDA P' = (Q', Σ, Γ, δ', q0, Z0, F') that accepts L ∩ R.

*   Q' = Qp x Qd (The states of P' are pairs of states from P and D)
*   q0 = (q0p, q0d) (The initial state of P' is a pair of the initial states of P and D)
*   F' = Fp x Fd (The accepting states of P' are pairs of accepting states from P and D)
*   δ'((q, r), a, X) = {((q', r'), Y) | (q', Y) ∈ δp(q, a, X) and r' = δd(r, a)}  for a ∈ Σ
*   δ'((q, r), ε, X) = {((q', r), Y) | (q', Y) ∈ δp(q, ε, X)}

P' simulates P and D in parallel.  For each input symbol, P' performs a transition according to the PDA P and the DFA D.  P' accepts only if both P and D accept the input. Therefore, P' accepts L ∩ R.

**Example:**

Let L = {a^n b^n | n >= 0} and R = {a*b*}

L ∩ R = {a^n b^n | n >= 0}

### 2.8 Non-Closure Under Intersection

**Theorem:** CFLs are not closed under intersection.

**Proof:** (Proof by counterexample)
Let L1 = {a^n b^n c^m | n, m >= 0} and L2 = {a^m b^n c^n | n, m >= 0}. Both L1 and L2 are CFLs.

L1 ∩ L2 = {a^n b^n c^n | n >= 0}, which is *not* a CFL.  Therefore, CFLs are not closed under intersection.

### 2.9 Non-Closure Under Complementation

**Theorem:** CFLs are not closed under complementation.

**Proof:**
Assume, for the sake of contradiction, that CFLs are closed under complementation.  Then, for any CFL L, its complement L' would also be a CFL.

We know that L1 ∩ L2 = (L1' ∪ L2')'.  If CFLs were closed under complementation, then L1' and L2' would be CFLs.  Since CFLs *are* closed under union, L1' ∪ L2' would be a CFL.  And, if CFLs were closed under complementation, (L1' ∪ L2')' would also be a CFL.  This would mean that L1 ∩ L2 would always be a CFL.

However, we have already shown that CFLs are *not* closed under intersection.  Therefore, our assumption that CFLs are closed under complementation must be false.

## 3. Decision Properties of CFLs

A decision problem is decidable if an algorithm exists that, given any instance of the problem, will always halt and produce a correct "yes" or "no" answer.

### 3.1 Decidable Problems

*   **Membership:** Given a CFL L and a string w, is w ∈ L? **(Decidable)**
*   **Emptiness:** Given a CFL L, is L = ∅? **(Decidable)**
*   **Finiteness:** Given a CFL L, is L finite? **(Decidable)**

### 3.2 Undecidable Problems

*   **Universality:** Given a CFL L, is L = Σ*?  **(Undecidable)**
*   **Equivalence:** Given two CFLs L1 and L2, is L1 = L2?  **(Undecidable)**
*   **Inclusion:** Given two CFLs L1 and L2, is L1 ⊆ L2? **(Undecidable)**
*   **Ambiguity:** Given a CFG G, is G ambiguous? **(Undecidable)**

### 3.3 Decidability of Membership

**Algorithm:**

1.  Convert the CFG G for L into Chomsky Normal Form (CNF).  This is possible because any CFG can be converted to an equivalent CFG in CNF.
2.  Let w be the input string with length n.
3.  Use the CYK (Cocke-Younger-Kasami) algorithm to determine if w can be derived from the start symbol S of G.

**CYK Algorithm:**  The CYK algorithm is a dynamic programming algorithm that determines if a string w can be generated by a CFG in CNF.  It builds a table of all possible substrings of w and determines which non-terminals can derive each substring.

### 3.4 Decidability of Emptiness

**Algorithm:**

1.  Given a CFG G = (V, T, P, S), remove all unproductive symbols (non-terminals that cannot derive a string of terminals).
2.  Check if the start symbol S is still in the grammar.  If S has been removed, then L(G) = ∅.  Otherwise, L(G) is not empty.

### 3.5 Decidability of Finiteness

**Algorithm:**

1.  Given a CFG G, remove all unproductive and unreachable symbols.
2.  Check for cycles involving useful symbols: A derivation A =>* αAβ. A cycle in a useful derivation means the language is infinite.  Construct a dependency graph of the non-terminals.
3.  If such a cycle exists, then the language is infinite.  Otherwise, the language is finite.

## 4. Examples and Exercises

**Example 1:  Closure under Intersection with Regular Language**

Let L = {a^n b^n | n >= 0} and R = a*

*   L is a CFL generated by: S -> aSb | ε
*   R is a regular language accepted by a DFA.

L ∩ R = {a^n | n >= 0} ∩ {a^n b^n | n >= 0} = {a^n b^n : n=0} = { ε } which is a regular language.

**Exercise 1:**

Let L1 = {a^n b^m | n, m >= 0} and L2 = {a^p c^q | p, q >= 0}.  What is L1 ∩ L2? Is it a CFL?

**Answer:**

L1 ∩ L2 = {a^n | n >= 0}. This is a regular language, and therefore also a CFL.

**Exercise 2:**

Prove that the union of a CFL and a regular language is a CFL.

**Answer:**

Since regular languages are also CFLs, and CFLs are closed under union, the union of a CFL and a regular language is a CFL.

**Exercise 3:**

Is the language {ww | w ∈ {a, b}*} a CFL?

**Answer:** No.  This language is not context-free. While you can't *directly* prove it using pumping lemma, you can show that the intersection of {ww | w ∈ {a, b}*} with the regular language a*b*a*b* would result in {a<sup>n</sup>b<sup>m</sup>a<sup>n</sup>b<sup>m</sup>} which can be proven not to be a CFL using the pumping lemma.  Since CFLs are closed under intersection with regular languages, if {ww | w ∈ {a, b}*} *were* a CFL, {a<sup>n</sup>b<sup>m</sup>a<sup>n</sup>b<sup>m</sup>} would also have to be a CFL, which is a contradiction.

## 5. Important Points to Remember

*   Closure properties are crucial for manipulating and simplifying languages.
*   The decidability/undecidability results determine the limits of what can be algorithmically computed for CFLs.
*   Understanding the proofs of closure properties and decision problems provides insights into the nature of CFLs and their computational complexity.
*   Always remember that intersection and complementation are *not* closure properties of CFLs.
*   The CYK algorithm provides a practical method for determining membership in a CFL.
