# ECONOMICS FOR ENGINEERS - MODULE 4: VALUE ANALYSIS AND VALUE ENGINEERING - TOPIC: VALUE ENGINEERING PROCEDURE

## Introduction

This module focuses on Value Analysis (VA) and Value Engineering (VE), powerful techniques used to improve the value of products, processes, and services. This topic will delve into the systematic procedure of Value Engineering, equipping engineers with the tools to optimize cost and performance.

## Learning Outcomes

By the end of this module, you will be able to:

1.  Understand the structured procedure involved in Value Engineering.
2.  Identify and describe each phase of the VE process.
3.  Apply the VE procedure to real-world engineering problems.
4.  Evaluate the benefits of using the VE procedure.

## 1. Understanding the Value Engineering Procedure

Value Engineering (VE) is a systematic, function-oriented, and creative approach aimed at improving the value of a product, system, or service.  It focuses on identifying unnecessary costs without sacrificing essential function or performance.  The VE procedure is a structured problem-solving process.

**Key Definition:**

*   **Value:**  The ratio of function to cost.  Value = Function / Cost.  Improving value can involve either improving function for the same cost, maintaining function while reducing cost, or a combination of both.

**Important Points to Remember:**

*   VE is not just cost-cutting; it is about optimizing value.
*   VE focuses on function, not just the product or service itself.
*   VE is a team-based activity, leveraging diverse perspectives.

## 2. The Phases of the Value Engineering Process

The VE procedure typically consists of the following phases:

*   **A. Information Phase**
*   **B. Function Analysis Phase**
*   **C. Creative Phase**
*   **D. Evaluation Phase**
*   **E. Development Phase**
*   **F. Presentation Phase**
*   **G. Implementation Phase**

Let's examine each phase in detail:

### A. Information Phase

*   **Purpose:**  Gather comprehensive information about the product, process, or service being analyzed.  Understand its current state, costs, performance, and user requirements.

*   **Activities:**
    *   Define the problem or opportunity clearly.
    *   Gather data on:
        *   Cost (material, labor, overhead, etc.)
        *   Performance (reliability, efficiency, capacity, etc.)
        *   Function (what it does)
        *   User needs and expectations
        *   Production processes
        *   Marketing data
    *   Document all data meticulously.
    *   Benchmark against competitors or similar products/services.

*   **Deliverables:**  A well-documented understanding of the subject, its costs, performance, and requirements.

*   **Example:**  Analyzing a manufacturing process for a steel component. The information phase would involve collecting data on the cost of raw materials, labor hours, machine time, scrap rates, and the component's performance characteristics (strength, durability).

### B. Function Analysis Phase

*   **Purpose:**  Identify and define the essential functions of the product, process, or service. This phase is crucial for understanding what *must* be done, regardless of how it's currently being done.

*   **Activities:**
    *   Identify all functions performed.
    *   Define each function using a verb-noun pair (e.g., "Supports Load," "Transmits Power").
    *   Classify functions as basic (essential) or secondary (supporting).
    *   Determine the cost associated with each function.
    *   Develop a Function Analysis System Technique (FAST) diagram to visually represent the relationship between functions.

*   **Key Concepts:**
    *   **Basic Function:**  The primary reason the product or service exists.  If the basic function is not performed, the product is useless.
    *   **Secondary Function:**  Functions that support the basic function or are desirable but not essential.

*   **Example (Steel Component):**
    *   **Basic Function:** Supports Load
    *   **Secondary Functions:** Resists Corrosion, Reduces Vibration

### C. Creative Phase

*   **Purpose:**  Generate a wide range of alternative ideas for performing the required functions.  This is a brainstorming phase where quantity is more important than quality.

*   **Activities:**
    *   Brainstorming:  Encourage free-flowing ideas without criticism.
    *   Checklisting:  Use predefined checklists to stimulate ideas.
    *   Morphological Analysis:  Combine different solutions to create new ones.
    *   Nominal Group Technique:  A structured brainstorming process.

*   **Important Points to Remember:**
    *   Encourage "blue sky" thinking.  Don't be afraid to suggest unconventional ideas.
    *   Focus on the function, not the current design.

*   **Example (Steel Component):** Ideas for "Supports Load" function: Different material (aluminum, composite), different shape (hollow, reinforced), different manufacturing process (casting, forging).

### D. Evaluation Phase

*   **Purpose:**  Evaluate the ideas generated in the creative phase based on feasibility, cost, and potential impact on value.

*   **Activities:**
    *   Develop evaluation criteria (e.g., cost savings, performance improvement, ease of implementation, risk).
    *   Screen ideas against the criteria.
    *   Rank the most promising ideas.
    *   Conduct preliminary cost estimates for each idea.

*   **Key Concepts:**
    *   **Life Cycle Costing (LCC):**  Consider the total cost of ownership, including initial cost, operating costs, maintenance costs, and disposal costs.

*   **Example (Steel Component):**  Evaluating the idea of using an aluminum alloy.  Consider the cost of aluminum, its strength-to-weight ratio, corrosion resistance, and manufacturing costs.

### E. Development Phase

*   **Purpose:**  Develop the most promising ideas from the evaluation phase into detailed proposals.

*   **Activities:**
    *   Develop detailed designs and specifications.
    *   Obtain firm cost estimates.
    *   Conduct testing and analysis to verify performance.
    *   Prepare a comprehensive proposal outlining the proposed changes, their benefits, and their costs.
    *   Address potential risks and challenges.

*   **Deliverables:**  A well-documented proposal with detailed drawings, specifications, cost estimates, and performance data.

*   **Example (Steel Component):**  Developing a detailed design for the aluminum alloy component, including dimensions, material specifications, manufacturing processes, and test results.

### F. Presentation Phase

*   **Purpose:**  Present the VE proposal to decision-makers (management, stakeholders).

*   **Activities:**
    *   Prepare a clear and concise presentation summarizing the proposal, its benefits, and its costs.
    *   Highlight the potential for value improvement.
    *   Address any concerns or questions from the audience.

*   **Important Points to Remember:**
    *   Use visual aids to effectively communicate the proposal.
    *   Be prepared to answer detailed questions about the technical aspects and cost analysis.

*   **Example (Steel Component):** Presenting the proposal to management, showing the cost savings, weight reduction, and improved performance of the aluminum alloy component.

### G. Implementation Phase

*   **Purpose:**  Implement the approved VE proposal.

*   **Activities:**
    *   Update drawings and specifications.
    *   Procure materials and equipment.
    *   Train personnel.
    *   Implement the changes in production or operation.
    *   Monitor performance and track results.
    *   Document lessons learned for future VE projects.

*   **Important Points to Remember:**
    *   Effective implementation is crucial for realizing the benefits of the VE study.
    *   Continuous monitoring and feedback are essential for ensuring success.

*   **Example (Steel Component):**  Implementing the production of the aluminum alloy component, monitoring its performance in the field, and tracking cost savings.

## 3. Applying the VE Procedure to Real-World Engineering Problems

The VE procedure can be applied to a wide range of engineering problems, including:

*   Product design and manufacturing
*   Process optimization
*   Construction projects
*   Service delivery
*   Software development

**Example: Value Engineering a Bridge Design**

1.  **Information Phase:** Gather data on the bridge's function (carrying traffic), cost (materials, labor, construction), performance (load capacity, durability).
2.  **Function Analysis:** Define the basic function ("Supports Load") and secondary functions ("Resists Corrosion," "Provides Clearance").
3.  **Creative Phase:** Brainstorm alternative designs (suspension bridge, cable-stayed bridge, arch bridge), materials (steel, concrete, composite), and construction techniques.
4.  **Evaluation Phase:** Evaluate the ideas based on cost, performance, safety, and environmental impact.
5.  **Development Phase:** Develop detailed designs for the most promising alternatives.
6.  **Presentation Phase:** Present the VE proposal to the bridge owner and stakeholders.
7.  **Implementation Phase:** Construct the bridge according to the approved design.

## 4. Evaluating the Benefits of Using the VE Procedure

The benefits of using the VE procedure include:

*   **Reduced costs:** By identifying and eliminating unnecessary costs.
*   **Improved performance:** By optimizing the design and function of the product or service.
*   **Enhanced quality:** By focusing on essential functions and eliminating defects.
*   **Increased efficiency:** By streamlining processes and reducing waste.
*   **Enhanced innovation:** By encouraging creative thinking and problem-solving.
*   **Improved customer satisfaction:** By delivering products and services that meet customer needs at a lower cost.

## Practice Questions/Exercises

**Question 1:** Explain the primary goal of the Value Engineering process.

**Answer:** The primary goal of Value Engineering is to improve the value of a product, service, or process by optimizing its function and cost.  This means either improving the function for the same cost, maintaining the function while reducing the cost, or a combination of both.

**Question 2:** What is the difference between a basic function and a secondary function in the Function Analysis phase? Give examples related to a pen.

**Answer:** A basic function is the essential function that a product or service must perform. A secondary function supports the basic function or is desirable but not essential.

*   **Pen Example:**
    *   **Basic Function:** "Creates Marks"
    *   **Secondary Functions:** "Provides Grip," "Protects Ink," "Indicates Ink Level"

**Question 3:** Briefly describe the Creative phase of the VE process.

**Answer:** The Creative Phase involves generating a wide range of alternative ideas for performing the required functions of the product or service. The focus is on quantity and encouraging "blue sky" thinking. Techniques used include brainstorming, checklisting, and morphological analysis.

**Question 4:** In what phase of the VE procedure are detailed designs and specifications created?

**Answer:** Development Phase

**Question 5:** Why is the Information Phase important?

**Answer:** The Information Phase is crucial because it provides the foundation for the entire VE process.  It ensures a comprehensive understanding of the product, its costs, performance, and user requirements.  Without accurate and complete information, the VE team cannot effectively identify areas for improvement.

## Conclusion

The Value Engineering procedure is a powerful tool for engineers to optimize the value of products, processes, and services. By systematically analyzing function and cost, VE can lead to significant improvements in performance, efficiency, and customer satisfaction.  Understanding and applying the VE phases is critical for engineers seeking to drive innovation and deliver superior value. Remember that value is Function/Cost, and the goal is to maximize that ratio!
