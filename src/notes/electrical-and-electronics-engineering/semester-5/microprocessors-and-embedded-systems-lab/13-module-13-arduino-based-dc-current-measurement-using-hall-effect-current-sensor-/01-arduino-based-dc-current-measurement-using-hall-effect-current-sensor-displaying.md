# MICROPROCESSORS AND EMBEDDED SYSTEMS LAB - Module 13

## Arduino based DC Current Measurement using Hall Effect Current Sensor and I2C LCD Module

This module focuses on designing and implementing a system to measure DC current using a Hall effect sensor and display the readings on an I2C LCD. This practical application bridges the gap between theoretical knowledge of microcontrollers and real-world embedded system design.

---

### **1. Introduction to DC Current Measurement**

**1.1 Importance of Current Measurement:**
*   **System Monitoring:** Understanding current consumption is crucial for monitoring the performance and power usage of electronic devices.
*   **Fault Detection:** Deviations from expected current levels can indicate malfunctions or short circuits.
*   **Battery Management:** In battery-powered systems, current measurement is vital for estimating remaining capacity and optimizing power consumption.
*   **System Control:** Current measurements can be used as feedback for control loops, such as motor speed control or battery charging.

**1.2 Challenges in Measuring DC Current:**
*   **Direct Measurement:** Directly measuring current using a multimeter in series requires breaking the circuit, which can be inconvenient and potentially disruptive.
*   **Shunt Resistors:** While common, shunt resistors introduce voltage drop and power loss, especially for high currents, and require amplification for small voltage drops.
*   **Non-Contact Measurement:** For safety and convenience, non-contact methods are preferred, especially for high currents or in hazardous environments.

### **2. Hall Effect Current Sensor**

**2.1 Principle of Operation:**
*   **Hall Effect:** Discovered by Edwin Hall, this phenomenon states that when a current-carrying conductor is placed in a magnetic field, a voltage (Hall voltage) is produced across the conductor, perpendicular to both the current and the magnetic field.
*   **Hall Effect Current Sensor:** These sensors utilize a Hall element (a semiconductor material) positioned within a magnetic field. The magnetic field is generated by the current flowing through a conductor. The Hall voltage produced is proportional to the magnetic field strength, which in turn is proportional to the current being measured.

**2.2 Types of Hall Effect Current Sensors:**
*   **Linear Hall Effect Sensors:** These sensors provide an analog output voltage that is directly proportional to the magnetic field strength (and thus the current). This is the type commonly used for current measurement.
*   **Digital Hall Effect Sensors:** These sensors provide a digital output (high/low) indicating the presence or absence of a magnetic field above a certain threshold, typically used for proximity sensing.

**2.3 Common Hall Effect Current Sensor Modules for Arduino:**
*   **ACS712:** This is a very popular and versatile Hall effect current sensor module. It offers different ranges (e.g., 5A, 20A, 30A) and outputs an analog voltage proportional to the current.
    *   **Output Voltage:** Typically, the output voltage is centered around Vcc/2 when no current flows. For positive current, the voltage increases, and for negative current, it decreases.
    *   **Sensitivity:** The sensitivity varies with the specific ACS712 variant (e.g., 185 mV/A for the 5A version).
*   **Other Sensors:** Modules based on Allegro ACS758, ACS770, etc., also exist with different features and current ranges.

### **3. Interfacing with Arduino**

**3.1 Arduino Uno Board Overview:**
*   **Microcontroller:** ATmega328P
*   **Analog Input Pins (ADC):** Used to read the analog voltage output from the Hall effect sensor. These pins are typically labeled A0, A1, A2, etc.
*   **Digital Output Pins:** Used to communicate with the I2C LCD module.

**3.2 Connecting the Hall Effect Current Sensor (e.g., ACS712):**
*   **Power Supply:**
    *   VCC: Connect to Arduino's 5V pin.
    *   GND: Connect to Arduino's GND pin.
*   **Signal Output:**
    *   OUT (Analog Output): Connect to an Arduino analog input pin (e.g., A0).
*   **Current Path:**
    *   The conductor carrying the DC current to be measured must pass through the designated terminals of the ACS712 module. Ensure correct polarity for positive current flow if needed.

**3.3 Connecting the I2C LCD Module:**
*   **I2C Protocol:** A two-wire serial communication protocol that allows multiple devices to be connected to a microcontroller. It uses SDA (Serial Data) and SCL (Serial Clock) lines.
*   **Connections:**
    *   VCC: Connect to Arduino's 5V pin.
    *   GND: Connect to Arduino's GND pin.
    *   SDA: Connect to Arduino's SDA pin (A4 on Arduino Uno).
    *   SCL: Connect to Arduino's SCL pin (A5 on Arduino Uno).
*   **I2C Address:** Most I2C LCD modules have a default address (e.g., 0x27 or 0x3F). It's important to know this address for communication. You can use an I2C scanner sketch to find the address if unsure.

### **4. Arduino Programming for Current Measurement**

**4.1 Reading Analog Values from Hall Effect Sensor:**
*   **`analogRead()` function:** This Arduino function reads the voltage on a specified analog pin and returns an integer value between 0 and 1023. This value represents the analog-to-digital converter (ADC) reading.
*   **Mapping ADC to Voltage:** The ADC reading corresponds to a voltage between 0V and the Arduino's reference voltage (typically 5V for Arduino Uno).
    *   `voltage = (adc_reading / 1023.0) * 5.0;`
*   **Mapping Voltage to Current:** The output voltage from the Hall effect sensor is linearly related to the current. We need to use the sensor's sensitivity to convert the measured voltage to current.
    *   `current = (measured_voltage - zero_current_voltage) / sensitivity;`
    *   **Zero Current Voltage:** This is the voltage output by the sensor when no current flows. For ACS712, it's typically Vcc/2 (2.5V).
    *   **Sensitivity:** This is provided in the sensor's datasheet (e.g., 185 mV/A or 0.185 V/A for the 5A ACS712).

**4.2 Using the I2C LCD Library:**
*   **`LiquidCrystal_I2C` Library:** This is a commonly used library for interfacing with I2C LCD modules. You'll need to install it in your Arduino IDE.
*   **Initialization:**
    *   Include the library: `#include <LiquidCrystal_I2C.h>`
    *   Create an LCD object: `LiquidCrystal_I2C lcd(0x27, 16, 2);` (assuming address 0x27, 16 columns, 2 rows)
    *   Initialize the LCD in `setup()`: `lcd.init();`
    *   Turn on the backlight: `lcd.backlight();`
*   **Displaying Text and Values:**
    *   `lcd.setCursor(column, row);`
    *   `lcd.print("Text");`
    *   `lcd.print(variable);`

**4.3 Arduino Sketch Structure:**

```c++
#include <Wire.h> // Required for I2C communication
#include <LiquidCrystal_I2C.h> // Include the I2C LCD library

// Define pins
const int hallSensorPin = A0; // Analog pin connected to the Hall effect sensor output

// LCD setup
// Replace 0x27 with your LCD's I2C address. 16, 2 are columns and rows.
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Hall Effect Sensor Calibration (example for ACS712-05B)
const float mVperAmp = 185.0; // Sensitivity in mV/A
const float voltageOffset = 2.5; // Expected voltage at zero current (VCC/2)

void setup() {
  // Initialize Serial communication for debugging
  Serial.begin(9600);

  // Initialize the LCD
  lcd.init();
  lcd.backlight(); // Turn on the backlight
  lcd.setCursor(0, 0);
  lcd.print("DC Current:");
}

void loop() {
  // 1. Read analog value from Hall effect sensor
  int adcValue = analogRead(hallSensorPin);

  // 2. Convert ADC value to voltage
  // Arduino Uno has 10-bit ADC (0-1023) and 5V reference voltage
  float voltage = (adcValue / 1023.0) * 5.0;

  // 3. Convert voltage to current
  // Subtract the offset voltage and then divide by sensitivity
  // Convert mV/A to V/A for consistency with voltage calculation
  float current = (voltage - voltageOffset) / (mVperAmp / 1000.0);

  // Display on Serial Monitor for debugging
  Serial.print("ADC: ");
  Serial.print(adcValue);
  Serial.print(", Voltage: ");
  Serial.print(voltage);
  Serial.print("V, Current: ");
  Serial.print(current);
  Serial.println("A");

  // 4. Display current on LCD
  lcd.setCursor(0, 1); // Move cursor to the second line
  lcd.print("                "); // Clear the previous reading
  lcd.setCursor(0, 1);
  lcd.print(current, 2); // Print current with 2 decimal places
  lcd.print(" A");

  delay(500); // Update every 0.5 seconds
}
```

### **5. Practicing and Verifying the System**

**5.1 Testing with Different Loads:**
*   Connect a variable DC load (e.g., a resistor with a switch, a power resistor, or a motor).
*   Observe the current readings on the LCD as you change the load.
*   Compare the readings with a calibrated multimeter (connected in series) for accuracy.

**5.2 Understanding Calibration and Accuracy:**
*   **Zero Offset:** Ensure the `voltageOffset` is set correctly. You can measure the output voltage of the sensor when no current is flowing and use that value.
*   **Sensitivity:** Verify the `mVperAmp` value from the sensor's datasheet for your specific module.
*   **Environmental Factors:** Temperature can slightly affect Hall effect sensor readings.
*   **Arduino ADC Resolution:** The 10-bit ADC limits the precision of the measurement.
*   **Noise:** Electrical noise can affect analog readings. Techniques like averaging multiple readings can improve stability.

**5.3 Addressing Potential Issues:**
*   **Incorrect I2C Address:** If the LCD doesn't display anything, try common addresses (0x27, 0x3F) or use an I2C scanner sketch.
*   **Incorrect Wiring:** Double-check all connections.
*   **Sensor Sensitivity:** Ensure the `mVperAmp` value is correct for your specific sensor model.
*   **Zero Offset Mismatch:** Adjust the `voltageOffset` if the sensor reads a non-zero current when no current is flowing.
*   **LCD Backlight:** If the display is dim, ensure the backlight jumper (if present) is correctly configured.

### **9. Practice Questions and Exercises**

**Question 1:**
What is the principle behind the operation of a Hall effect current sensor?
*   **Answer:** Hall effect sensors utilize the Hall effect phenomenon, where a voltage (Hall voltage) is generated across a conductor carrying current when placed in a magnetic field. This Hall voltage is proportional to the magnetic field strength, which in turn is proportional to the current flowing through the conductor.

**Question 2:**
If an ACS712-05B sensor (sensitivity 185 mV/A) is used, and the Arduino reads an analog value of 512 for the Hall effect sensor's output, what is the measured DC current? Assume Vcc = 5V and the zero-current voltage offset is Vcc/2.
*   **Answer:**
    *   ADC value = 512
    *   Voltage = (512 / 1023.0) * 5.0V ≈ 2.502V
    *   Zero current voltage offset = 5.0V / 2 = 2.5V
    *   Sensitivity = 185 mV/A = 0.185 V/A
    *   Current = (Voltage - Zero Current Voltage) / Sensitivity
    *   Current = (2.502V - 2.5V) / 0.185 V/A
    *   Current = 0.002V / 0.185 V/A ≈ 0.0108A ≈ 10.8 mA

**Question 3:**
List the pins required for I2C communication between an Arduino and an LCD module.
*   **Answer:** The pins required for I2C communication are SDA (Serial Data) and SCL (Serial Clock). On an Arduino Uno, these are typically A4 (SDA) and A5 (SCL).
