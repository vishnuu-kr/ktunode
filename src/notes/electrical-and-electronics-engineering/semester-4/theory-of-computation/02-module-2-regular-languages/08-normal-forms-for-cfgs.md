This section delves into the concept of transforming Context-Free Grammars (CFGs) into specific forms, known as normal forms. ### 1. Introduction to Normal Forms

Normal forms for CFGs are standardized representations that simplify the structure of the grammar rules. This simplification is vital for:

*   **Algorithmic proofs:** Many proofs about CFLs and algorithms for CFLs rely on the grammar being in a specific normal form.
*   **Parsing techniques:** Certain parsing algorithms are designed to work with grammars in specific normal forms, like CNF.
*   **Proving properties:** Properties like membership in a CFL can be more easily demonstrated or disproven with grammars in normal forms.

**Key Concept:** A *normal form* is a standardized way of writing the rules of a grammar that makes it easier to analyze and manipulate.

---

### 2. Chomsky Normal Form (CNF)

**Definition:** A CFG is in Chomsky Normal Form (CNF) if all its production rules are of one of the following three forms:

1.  $A \rightarrow BC$ (where $A, B, C$ are non-terminals)
2.  $A \rightarrow a$ (where $A$ is a non-terminal and $a$ is a terminal)
3.  $S \rightarrow \epsilon$ (where $S$ is the start symbol and $\epsilon$ is the empty string), *but only if the language generated by the grammar contains the empty string*. If the language does not contain $\epsilon$, this rule is not allowed.

**Important Constraints for CNF:**

*   No rule of the form $A \rightarrow \epsilon$, unless $A=S$ and $S$ is the start symbol and $L(G)$ contains $\epsilon$.
*   No rule of the form $A \rightarrow B$ (unit productions).
*   No rule of the form $A \rightarrow u$, where $u$ is a string of terminals of length 2 or more.
*   No rule of the form $A \rightarrow X_1 X_2 \dots X_k$, where $k > 2$ and $X_i$ are non-terminals.

**Theorem:** Every context-free language (except for the language containing only the empty string, $\{\epsilon\}$) can be generated by a CFG in Chomsky Normal Form.

**Textbook Reference:**

*   **Kozen, "Automata and Computability"**: Chapter 4 discusses CFGs and their properties, including normal forms.
*   **Hopcroft, Motwani, Ullman, "Introduction to Automata Theory, Languages, and Computation"**: Chapter 5 covers CFGs and their transformations, including CNF.
*   **Sipser, "Introduction To Theory of Computation"**: Chapter 5 deals with CFLs and the conversion of CFGs to Chomsky Normal Form.

#### 2.1. Procedure for Converting a CFG to CNF

Let's outline the steps to convert an arbitrary CFG $G$ into an equivalent CFG $G'$ in CNF.

**Step 1: Eliminate $\epsilon$-productions.**

*   Identify all non-terminals that can derive $\epsilon$. Let's call this set $N_\epsilon$.
*   For every rule $A \rightarrow \epsilon$, if $A \neq S$, remove it.
*   If $S \rightarrow \epsilon$ is in the grammar, we need to handle it carefully. If $L(G)$ contains $\epsilon$, we introduce a new start symbol $S'$ and add the rule $S' \rightarrow S$ and $S' \rightarrow \epsilon$. The original start symbol $S$ can then be used in other rules. If $L(G)$ does not contain $\epsilon$, and $S \rightarrow \epsilon$ is the only way to derive $\epsilon$, it can be removed.
*   For any rule $B \rightarrow X_1 \dots X_k$ where some $X_i \in N_\epsilon$, introduce new rules. For each subset of $N_\epsilon$ that can appear on the RHS of a rule, add corresponding productions.
    *   Example: If $A \rightarrow BCD$ and $B, D \in N_\epsilon$, then we add $A \rightarrow CD$, $A \rightarrow C$, and $A \rightarrow D$ (if $B$ and $D$ can derive $\epsilon$).
    *   This step can introduce a large number of new rules.

**Step 2: Eliminate unit productions.**

*   Identify all unit productions ($A \rightarrow B$, where $A, B$ are non-terminals).
*   For each unit production $A \rightarrow B$, replace it by all rules $A \rightarrow \alpha$ from the original grammar where $B \rightarrow \alpha$ is a production, and $\alpha$ is not $\epsilon$ or a unit production.
*   If there's a cycle of unit productions (e.g., $A \rightarrow B, B \rightarrow C, C \rightarrow A$), remove $A \rightarrow B$, $B \rightarrow C$, $C \rightarrow A$. If $A \rightarrow \epsilon$ is allowed, and $A \rightarrow B \rightarrow \dots \rightarrow A$, then $A$ can derive $\epsilon$.

**Step 3: Convert remaining productions to the required forms.**

*   For any rule of the form $A \rightarrow X_1 X_2 \dots X_k$ where $k > 2$:
    *   Introduce new non-terminals. Replace $A \rightarrow X_1 X_2 \dots X_k$ with $A \rightarrow X_1 Y_1$, $Y_1 \rightarrow X_2 Y_2$, ..., $Y_{k-2} \rightarrow X_{k-1} X_k$. $Y_i$ are new non-terminals.
*   For any rule of the form $A \rightarrow a$ where $a$ is a terminal:
    *   If $a$ is a terminal, it's fine.
*   For any rule of the form $A \rightarrow w$, where $w$ is a string of terminals of length $|w| \ge 2$:
    *   Introduce new non-terminals for each terminal. Replace $A \rightarrow a_1 a_2 \dots a_k$ with $A \rightarrow T_1 T_2$, $T_1 \rightarrow a_1 T'_1$, $T'_1 \rightarrow a_2 \dots$, $T_k \rightarrow a_k$. This is a bit tricky; it's usually handled by converting terminal strings into binary sequences of new non-terminals. A simpler approach:
        *   Create new non-terminals $T_a$ for each terminal $a$. If $A \rightarrow aX$, then add $A \rightarrow T_a X$. If $A \rightarrow Xa$, then add $A \rightarrow X T_a$. If $A \rightarrow aa$, then add $A \rightarrow T_{a1} T_{a2}$.
        *   A more systematic way: For a rule $A \rightarrow a_1 a_2 \dots a_k$, introduce new non-terminals $Z_1, \dots, Z_k$ such that $Z_i \rightarrow a_i$. Then replace $A \rightarrow a_1 a_2 \dots a_k$ with $A \rightarrow Z_1 Z_2 \dots Z_k$. Now apply the rule for $k > 2$.

*   Ensure all rules are of the form $A \rightarrow BC$ or $A \rightarrow a$. The special case for $\epsilon$ is already handled.

**Important Point:** The conversion process might increase the number of non-terminals and production rules significantly.

### 3. Greibach Normal Form (GNF)

**Definition:** A CFG is in Greibach Normal Form (GNF) if all its production rules are of the form:

$A \rightarrow a X_1 X_2 \dots X_k$

where:
*   $A$ is a non-terminal.
*   $a$ is a terminal.
*   $X_1, X_2, \dots, X_k$ are non-terminals.
*   $k \ge 0$. This means rules can be of the form $A \rightarrow a$ ($k=0$) or $A \rightarrow a B$ ($k=1$) or $A \rightarrow a BC$ ($k=2$), etc.

**Crucial Characteristic of GNF:** Every sentential form (except the start symbol itself) *must* begin with a terminal symbol. This property is very useful for inductive proofs and for designing pushdown automata.

**Theorem:** Every context-free language (except $\{\epsilon\}$) can be generated by a CFG in Greibach Normal Form.

**Textbook Reference:**

*   **Kozen, "Automata and Computability"**: Section 4.6 discusses GNF and its conversion.
*   **Hopcroft, Motwani, Ullman, "Introduction to Automata Theory, Languages, and Computation"**: Section 5.8 covers GNF and the conversion process.
*   **Sipser, "Introduction To Theory of Computation"**: While Sipser focuses more on CNF, the principles of elimination of $\epsilon$, unit productions, and restricted rule forms are relevant. The conversion to GNF is often achieved by first converting to CNF and then to GNF.

---

#### 3.1. Procedure for Converting a CFG to GNF

The conversion to GNF is generally more complex than to CNF. A common strategy involves these high-level steps:

**Step 1: Eliminate $\epsilon$-productions and unit productions.**
*   This is the same as the initial steps for CNF conversion. It's often easier to first convert the grammar to CNF and then convert the CNF grammar to GNF.

**Step 2: Eliminate rules of the form $A \rightarrow B$.**
*   If $A \rightarrow B$ is a rule and $B \rightarrow \alpha$ is a rule, then add $A \rightarrow \alpha$.

**Step 3: Eliminate rules of the form $A \rightarrow X_1 X_2 \dots X_k$ where $k > 1$.**
*   Convert the grammar to CNF first. This ensures all rules are either $A \rightarrow BC$ or $A \rightarrow a$.

**Step 4: Eliminate rules of the form $A \rightarrow BC$ where $B$ is a non-terminal that derives $\epsilon$.**
*   This is tricky. If $B$ can derive $\epsilon$, we might need to eliminate it.

**Step 5: Eliminate "left recursion".**
*   Left recursion refers to rules of the form $A \rightarrow A \alpha$. For example, $A \rightarrow AX$ or $A \rightarrow AXB$.
*   To eliminate $A \rightarrow A \alpha_1 | A \alpha_2 | \dots | \beta_1 | \beta_2 | \dots$ (where $\beta_i$ do not start with $A$):
    *   Introduce new non-terminals $A'$:
        $A \rightarrow \beta_1 A'$
        $A \rightarrow \beta_2 A'$
        ...
        $A' \rightarrow \alpha_1 A'$
        $A' \rightarrow \alpha_2 A'$
        ...
        $A' \rightarrow \epsilon$

**Step 6: Rearrange remaining productions to match GNF.**
*   After eliminating left recursion, all productions will be of the form $A \rightarrow \alpha$, where $\alpha$ is a string of terminals and non-terminals.
*   If a rule is of the form $A \rightarrow a_1 \dots a_k X_1 \dots X_m$, where $a_i$ are terminals and $X_j$ are non-terminals:
    *   Introduce new non-terminals to ensure the RHS starts with a terminal.
    *   If $A \rightarrow \beta$, where $\beta$ does not start with a terminal.
        *   If $\beta = X_1 \dots X_m$, then introduce $A \rightarrow a Y_1$, $Y_1 \rightarrow X_1 Y_2$, etc., where $a$ is some terminal. This is where the problem gets hard.

A more standard approach to convert from CNF to GNF:

**Conversion from CNF to GNF:**

Let $G = (V, \Sigma, P, S)$ be a CFG in CNF.

1.  **Introduce new start symbol $S_0$**: If $S$ is not already the start symbol and $L(G)$ contains $\epsilon$, add $S_0 \rightarrow S$. If $L(G)$ does not contain $\epsilon$, add $S_0 \rightarrow S$. The new start symbol is $S_0$.
2.  **Handle productions with terminals**: For every rule $A \rightarrow a$ where $a$ is a terminal:
    *   If $A=S_0$, leave it as $S_0 \rightarrow a$.
    *   If $A \neq S_0$, replace $A \rightarrow a$ with $A \rightarrow T_a$, where $T_a \rightarrow a$. (This is slightly incorrect; it should be $A \rightarrow a$).
    *   The correct way is to transform $A \rightarrow a$ where $A \neq S_0$ to $A \rightarrow a S'$ and add $S' \rightarrow \epsilon$. This can lead to $\epsilon$ productions.

    Let's use the textbook method.

    **Algorithm by Hopcroft, Motwani, Ullman (H-M-U) for CNF to GNF conversion:**

    Given a CFG $G$ in CNF, to obtain an equivalent CFG $G'$ in GNF:

    1.  **Add a new start symbol $S_0$**: If $S$ is the original start symbol, add production $S_0 \rightarrow S$. If the original grammar $G$ produced $\epsilon$, then add $S_0 \rightarrow \epsilon$. This is the tricky part about $\epsilon$. If $L(G)$ does not contain $\epsilon$, this step is simpler.
        *   Let's assume $L(G)$ does not contain $\epsilon$ for now, to simplify. $S_0 \rightarrow S$.

    2.  **Modify rules of the form $A \rightarrow BC$**: For every rule $A \rightarrow BC$:
        *   If $B$ is the start symbol $S$ (and $A \neq S$), then replace $A \rightarrow SC$ with $A \rightarrow T_S C$ and add a new rule $T_S \rightarrow S$, where $T_S$ is a new non-terminal. (This is still not right for GNF).

    Let's use the strategy of eliminating problematic productions systematically.

    **Steps to convert a CFG $G$ to GNF:**

    1.  **Get rid of $\epsilon$-productions**: If $S \rightarrow \epsilon$, add $S_0 \rightarrow S$ and $S_0 \rightarrow \epsilon$. Rename $S$ to $S_0$.
    2.  **Get rid of unit productions**: $A \rightarrow B$.
    3.  **Get rid of rules $A \rightarrow w$ where $|w| \geq 2$**: Convert to CNF.
    4.  **Eliminate left recursion**: Convert rules of the form $A \rightarrow A \alpha$ to $A \rightarrow \beta A'$ and $A' \rightarrow \alpha A' | \epsilon$.
    5.  **Rearrange productions to start with terminals**: For any rule $A \rightarrow X_1 X_2 \dots X_k$:
        *   If $X_1$ is a terminal, it's fine.
        *   If $X_1$ is a non-terminal, say $B$, and $B \rightarrow a Y_1 Y_2 \dots Y_m$ are the rules for $B$. Then we can replace $A \rightarrow B X_2 \dots X_k$ with $A \rightarrow a Y_1 Y_2 \dots Y_m X_2 \dots X_k$. This is repeated for all such non-terminals at the start of RHS.

    **Example Conversion to GNF (from CNF):**

    Let's take the CNF grammar we derived earlier:
    $G_{CNF}$:
    $S \rightarrow AX_1$
    $S \rightarrow BA$
    $S \rightarrow AB$
    $S \rightarrow b$
    $A \rightarrow T_a A$
    $B \rightarrow b$
    $X_1 \rightarrow BA$
    $T_a \rightarrow a$

    The issue is $S \rightarrow AX_1$, $S \rightarrow BA$, $S \rightarrow AB$, $A \rightarrow T_a A$. The RHS doesn't start with a terminal.

    **Convert $S \rightarrow AX_1$**:
    *   $A$ is a non-terminal. Rules for $A$ are $A \rightarrow T_a A$.
    *   Replace $S \rightarrow AX_1$ with $S \rightarrow T_a A X_1$.
    *   Now, $S \rightarrow T_a A X_1$ has a terminal $T_a$ at the start, but we need to replace $T_a$ with its rule $T_a \rightarrow a$.
    *   This needs a systematic way to substitute.

    Let's use the method described in Hopcroft, Motwani, Ullman (H-M-U) for converting from CNF to GNF (Section 5.8).

    **Algorithm (H-M-U for CNF to GNF):**

    Let $G = (V, \Sigma, P, S)$ be a CFG in CNF.
    Assume $L(G) \neq \{\epsilon\}$.

    1.  **Add a new start symbol $S_0$**: If the original grammar $G$ does not generate $\epsilon$, add $S_0 \rightarrow S$. If $G$ generates $\epsilon$, add $S_0 \rightarrow S$ and $S_0 \rightarrow \epsilon$. For our example, $G_{CNF}$ does not generate $\epsilon$. So, add $S_0 \rightarrow S$.
        New start symbol: $S_0$.
        Grammar:

### 4. Why Normal Forms are Important (Revisiting)

*   **Algorithmic Efficiency:** Many algorithms for CFGs (like CYK for recognition, or parsing algorithms) are simpler or guaranteed to work when the grammar is in a specific normal form.
*   **Theoretical Properties:** Proving properties about CFLs (e.g., closure properties, decidability of certain problems) often relies on being able to convert any CFG to a simpler, standardized form.
*   **Equivalence:** Normal forms preserve the language generated by the grammar, so they are essential for proving that different grammars can generate the same language.

---

### 5. Summary and Key Takeaways

*   **Chomsky Normal Form (CNF):** Rules are $A \rightarrow BC$ or $A \rightarrow a$ (with a special case for $S \rightarrow \epsilon$). It simplifies the structure of derivations by ensuring that each step introduces at most one new non-terminal on the right-hand side.
*   **Greibach Normal Form (GNF):** Rules are $A \rightarrow a X_1 \dots X_k$. Every RHS starts with a terminal. This form is crucial for constructing equivalent pushdown automata and for inductive proofs on derivations.
*   **Conversion Process:** Converting to normal forms involves systematic elimination of $\epsilon$-productions, unit productions, left recursion, and then restructuring the remaining rules. The process can be complex and often increases the number of rules and non-terminals.
*   **Importance:** Normal forms are fundamental tools for understanding and manipulating context-free grammars and languages.

**Answer 4: Why GNF is useful for PDAs**

Greibach Normal Form (GNF) is useful for constructing equivalent Pushdown Automata (PDAs) because every production rule in GNF starts with a terminal symbol. This means that for any state in the PDA, a transition can be directly triggered by a terminal symbol read from the input tape. The structure $A \rightarrow a X_1 \dots X_k$ allows a direct mapping to PDA transitions: when the PDA is in a state corresponding to $A$, it can read the terminal $a$ from the input and push $X_1, \dots, X_k$ onto the stack. This systematic structure simplifies the design and analysis of PDAs that recognize CFLs generated by GNF grammars. It ensures that the PDA always makes progress by consuming input and manipulating the stack in a predictable manner.
