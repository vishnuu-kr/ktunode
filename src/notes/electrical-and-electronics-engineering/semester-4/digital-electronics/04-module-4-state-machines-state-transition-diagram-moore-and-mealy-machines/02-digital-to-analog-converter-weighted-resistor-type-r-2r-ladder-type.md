## Module 4: State Machines – State Transition Diagram – Moore and Mealy Machines

**Course Outcome Alignment:** CO3 (Design sequential logic circuits - K3)

### 1. Introduction to State Machines

*   **Definition:** A state machine is a mathematical model of computation that describes the behavior of a system. It consists of a finite number of states, transitions between these states, and inputs that trigger these transitions.
*   **Purpose:** State machines are used to design and analyze sequential logic circuits, which have memory and whose output depends not only on the current input but also on the past sequence of inputs.
*   **Key Components:**
    *   **States:** Distinct conditions or modes of operation of the system.
    *   **Inputs:** Signals that cause transitions between states.
    *   **Outputs:** Signals generated by the system, which can be dependent on the current state or the current state and input.
    *   **Transitions:** The movement from one state to another, triggered by specific inputs.

**Important Point:** Sequential circuits are characterized by the presence of memory elements (flip-flops) that store the past history of the circuit.

### 2. State Transition Diagram (STD)

*   **Definition:** A state transition diagram is a graphical representation of a finite state machine. It visually depicts the states, the possible transitions between them, and the inputs/outputs associated with these transitions.
*   **Elements of a State Transition Diagram:**
    *   **States:** Represented by circles or nodes.
    *   **Transitions:** Represented by directed arrows connecting states.
    *   **Labels on Transitions:** Usually indicate the input that causes the transition and the output generated during that transition.
*   **Purpose:** Provides a clear and intuitive way to understand the behavior of a sequential circuit. It's a crucial step before implementing the circuit using logic gates and flip-flops.

**Example:** Consider a simple traffic light controller.
*   **States:** Red, Yellow, Green.
*   **Inputs:** Timer signals (e.g., "change to yellow," "change to green").
*   **Transitions:**
    *   From Green to Yellow when timer expires.
    *   From Yellow to Red when timer expires.
    *   From Red to Green when timer expires.
*   **Outputs:** Lights (Red, Yellow, Green).

**Textbook Reference:** Floyd, T.L. (2017), Chapter 12, "Sequential Logic Circuits".

### 3. Moore Machines

*   **Definition:** In a Moore machine, the output depends *only* on the current state of the machine.
*   **Characteristics:**
    *   Outputs are associated with states.
    *   The state transition diagram shows outputs within the state circles.
    *   Often simpler to design and analyze for certain applications.
    *   Might require more states than a Mealy machine for the same functionality.
*   **State Transition Diagram Representation:** The output is typically written inside the state circle, often separated by a slash (e.g., `State_Name / Output`).

**Example:** A Moore machine that outputs '1' when it has seen an even number of '1's in its input sequence, and '0' otherwise.
*   **States:** `EVEN` (even number of 1s), `ODD` (odd number of 1s).
*   **Input:** Binary digit (0 or 1).
*   **Output:** 1 (even), 0 (odd).
*   **Transitions:**
    *   From `EVEN` with input '0' -> `EVEN` (output 1).
    *   From `EVEN` with input '1' -> `ODD` (output 1).
    *   From `ODD` with input '0' -> `ODD` (output 0).
    *   From `ODD` with input '1' -> `EVEN` (output 0).

**Circuit Implementation:** Flip-flops store the state, and combinational logic generates the outputs based solely on the flip-flop outputs (which represent the current state).

**Textbook Reference:** Malvino, A.P. & Leach, D.P. (2018), Chapter 13, "Sequential Logic".

### 4. Mealy Machines

*   **Definition:** In a Mealy machine, the output depends on *both* the current state and the current input.
*   **Characteristics:**
    *   Outputs are associated with transitions.
    *   The state transition diagram shows outputs on the transition arrows.
    *   Often more efficient in terms of the number of states required compared to a Moore machine.
    *   The output can change immediately upon the arrival of an input, even before the state changes (level-sensitive or edge-sensitive depending on the flip-flops used).
*   **State Transition Diagram Representation:** The transition label is typically in the format `Input / Output`.

**Example:** A Mealy machine that outputs '1' only when it detects a sequence of "10" in its input.
*   **States:** `IDLE` (waiting for '1'), `GOT_ONE` (just received '1').
*   **Input:** Binary digit (0 or 1).
*   **Output:** 1 (for "10" sequence), 0 (otherwise).
*   **Transitions:**
    *   From `IDLE` with input '0' -> `IDLE` (output 0).
    *   From `IDLE` with input '1' -> `GOT_ONE` (output 0).
    *   From `GOT_ONE` with input '0' -> `IDLE` (output 1 - sequence "10" detected).
    *   From `GOT_ONE` with input '1' -> `GOT_ONE` (output 0).

**Circuit Implementation:** Flip-flops store the state. Combinational logic generates the outputs based on both the flip-flop outputs (current state) and the primary inputs.

**Textbook Reference:** Mano, M.M. & Ciletti, M.D. (2018), Chapter 8, "Sequential Logic Design".

### 5. Comparison: Moore vs. Mealy Machines

| Feature           | Moore Machine                                  | Mealy Machine                                      |
| :---------------- | :--------------------------------------------- | :------------------------------------------------- |
| **Output Dependency** | Only on the current state.                     | On current state and current input.                |
| **Output Location** | Associated with states (inside state circles). | Associated with transitions (on transition arrows). |
| **Response Time** | Output changes only when the state changes.    | Output can change immediately upon input change.   |
| **Number of States** | May require more states.                       | Often requires fewer states for same functionality. |
| **Design Complexity** | Generally simpler to design and verify.        | Can be more complex due to output dependency.      |
| **Hazard Issues** | Less prone to output glitches.                 | More prone to output glitches if not designed carefully. |

**Important Point:** Both Moore and Mealy machines are equivalent in terms of their computational power, meaning any Moore machine can be converted into an equivalent Mealy machine and vice versa.

### 6. Designing State Machines

The general steps for designing a state machine include:

1.  **Understand the Problem:** Clearly define the desired behavior, inputs, and outputs.
2.  **Create a State Transition Diagram (STD):** This is the most crucial step.
    *   Define states and assign meanings.
    *   Determine transitions based on inputs.
    *   Specify outputs for each state (Moore) or transition (Mealy).
3.  **Create a State Table:** A tabular representation of the STD, listing current state, inputs, next state, and outputs.
4.  **Assign State Assignments (Binary Encoding):** Assign unique binary codes to each state. This is often done to minimize the number of flip-flops and the complexity of the excitation logic.
5.  **Create Excitation Table:** Based on state assignments, create a table showing flip-flop inputs required for each transition.
6.  **Derive Boolean Expressions:** Use Karnaugh maps or other simplification techniques to derive Boolean expressions for flip-flop inputs and circuit outputs.
7.  **Implement the Circuit:** Realize the circuit using flip-flops and logic gates.

**Textbook Reference:** Taub, H. & Schilling, D. (2017), Chapter 10, "State Machines".

## Digital to Analog Converter (DAC)

**Course Outcome Alignment:** CO4 (Describe the operation of various analog to digital and digital to analog conversion circuits - K2)

### 1. Introduction to Digital-to-Analog Converters (DACs)

*   **Definition:** A Digital-to-Analog Converter (DAC) is a device that converts a digital signal (a sequence of binary bits) into an analog signal (a continuously varying voltage or current).
*   **Purpose:** DACs are essential components in systems where digital information needs to be translated into a form that can interact with the physical world or be processed by analog circuits. Examples include audio playback, motor control, and display drivers.
*   **Key Characteristics:**
    *   **Resolution:** The number of discrete analog output levels the DAC can produce, determined by the number of input bits. Higher resolution means finer steps in the analog output.
    *   **Accuracy:** How closely the actual analog output matches the ideal output.
    *   **Monotonicity:** The property that the analog output never decreases as the digital input increases.
    *   **Settling Time:** The time it takes for the DAC's output to settle to its final value after a change in the digital input.
*   **Input:** A digital word (e.g., an N-bit binary number).
*   **Output:** An analog voltage or current proportional to the digital input value.

**Important Point:** The output of a DAC is typically a staircase-like approximation of a true analog signal. The resolution determines how "smooth" this staircase appears.

**Textbook Reference:** Floyd, T.L. (2017), Chapter 15, "Digital-to-Analog and Analog-to-Digital Converters".

### 2. Weighted Resistor Type DAC

*   **Principle:** This DAC uses a summing amplifier (usually an operational amplifier) with multiple input resistors. Each resistor is "weighted" according to its corresponding bit position in the digital input word. The value of each resistor is inversely proportional to the weight of its bit.
*   **How it Works:**
    *   The digital input bits ($D_n D_{n-1} \dots D_1 D_0$) control analog switches.
    *   For each '1' in the digital input, the corresponding weighted resistor is connected to a reference voltage ($V_{ref}$). For each '0', the resistor is connected to ground.
    *   The summing amplifier sums the currents flowing through these weighted resistors.
    *   The output voltage is proportional to the sum of these currents.
*   **Resistor Values:** If $D_0$ is the LSB (Least Significant Bit) and $D_{n-1}$ is the MSB (Most Significant Bit), the resistors are typically $R$, $2R$, $4R$, $8R$, ..., $2^{n-1}R$. The MSB corresponds to the smallest resistor ($R$), and the LSB corresponds to the largest resistor ($2^{n-1}R$).
*   **Output Voltage Formula:**
    $V_{out} = -V_{ref} \times \frac{1}{R_{ref}} \times (D_{n-1} \cdot 2^{n-1} + D_{n-2} \cdot 2^{n-2} + \dots + D_0 \cdot 2^0)$
    Where $R_{ref}$ is the resistor connected to the MSB. A common implementation uses $R$ for the MSB and $2R, 4R, \dots, 2^{n-1}R$ for subsequent bits.

**Example (3-bit Weighted Resistor DAC):**
Let $V_{ref} = 5V$. Digital input: `101` ($D_2=1, D_1=0, D_0=1$).
Resistors: $R$ for $D_2$, $2R$ for $D_1$, $4R$ for $D_0$.
Let $R = 10k\Omega$. Then $2R = 20k\Omega$, $4R = 40k\Omega$.
The output voltage will be:
$V_{out} = -V_{ref} \times (\frac{D_2}{R} + \frac{D_1}{2R} + \frac{D_0}{4R})$
$V_{out} = -5V \times (\frac{1}{10k\Omega} + \frac{0}{20k\Omega} + \frac{1}{40k\Omega})$
$V_{out} = -5V \times (\frac{1}{10000} + 0 + \frac{1}{40000})$
$V_{out} = -5V \times (0.0001 + 0.000025) = -5V \times 0.000125 = -0.625V$
The ideal output for `101` (which is 5 in decimal) would be $V_{ref} \times \frac{5}{2^3} = 5V \times \frac{5}{8} = 3.125V$. The negative sign indicates inversion by the op-amp. The magnitude is what we are interested in for proportionality.

**Advantages:**
*   Simple to understand and implement.
*   Fast settling time.

**Disadvantages:**
*   **Wide range of resistor values:** For an N-bit DAC, the resistors range from $R$ to $2^{N-1}R$. This wide range makes it difficult to manufacture precision resistors with the required accuracy, especially for higher resolutions. For a 10-bit DAC, the ratio can be up to $2^9 = 512:1$.
*   **Loading effect:** The output impedance of the switches can affect the currents.
*   **Accuracy limitations:** Difficult to achieve high accuracy due to resistor tolerance and matching.

**Reference Book:** Taub, H. & Schilling, D. (2017), Chapter 14, "Digital-to-Analog Converters".

### 3. R-2R Ladder Type DAC

*   **Principle:** This DAC uses only two resistor values: $R$ and $2R$. It's a more practical implementation for higher resolution DACs compared to the weighted resistor type.
*   **How it Works:**
    *   The digital input bits control analog switches.
    *   Each bit position is connected to a ladder network made of precisely matched $R$ and $2R$ resistors.
    *   The ladder network is designed such that each bit contributes a current that is half of the contribution of the bit to its left (more significant bit).
    *   A summing amplifier aggregates these currents to produce the analog output.
*   **Ladder Network Structure:**
    *   Each bit position (from MSB to LSB) is connected to a switch.
    *   When a bit is '1', its corresponding switch connects the ladder junction to $V_{ref}$. When it's '0', it connects to ground.
    *   The network is structured such that the equivalent resistance seen from any junction looking towards the LSB end is always $2R$.
*   **Output Voltage Formula:**
    $V_{out} = -V_{ref} \times \frac{1}{R} \times (D_{n-1} \cdot 2^{n-1} + D_{n-2} \cdot 2^{n-2} + \dots + D_0 \cdot 2^0)$
    However, the contribution of each bit is scaled differently by the ladder. A more accurate representation of the output in terms of bit weights is:
    $V_{out} = -V_{ref} \times \frac{1}{2R} \times (D_{n-1} \cdot 2^{n-1} + D_{n-2} \cdot 2^{n-2} + \dots + D_0 \cdot 2^0)$
    This formula highlights that the MSB ($D_{n-1}$) contributes $V_{ref}/2$, the next bit ($D_{n-2}$) contributes $V_{ref}/4$, and so on, down to the LSB ($D_0$) contributing $V_{ref}/2^n$.

**Example (3-bit R-2R Ladder DAC):**
Let $V_{ref} = 5V$, $R = 10k\Omega$, $2R = 20k\Omega$. Digital input: `101` ($D_2=1, D_1=0, D_0=1$).
The network is structured so that:
*   $D_2$ (MSB) contributes $V_{ref}/2$.
*   $D_1$ contributes $V_{ref}/4$.
*   $D_0$ (LSB) contributes $V_{ref}/8$.

The output voltage (ignoring the op-amp inversion for proportionality):
$V_{out\_magnitude} = V_{ref} \times (\frac{D_2}{2} + \frac{D_1}{4} + \frac{D_0}{8})$
$V_{out\_magnitude} = 5V \times (\frac{1}{2} + \frac{0}{4} + \frac{1}{8})$
$V_{out\_magnitude} = 5V \times (\frac{4+1}{8}) = 5V \times \frac{5}{8} = 3.125V$

**Advantages:**
*   **Limited resistor values:** Uses only two precision resistor values ($R$ and $2R$), which are easier to manufacture and match compared to the wide range in weighted resistor DACs.
*   **Better accuracy for higher resolutions:** Due to the limited resistor ratios.
*   **Good speed:** Can achieve relatively high conversion speeds.

**Disadvantages:**
*   **Switch resistance effect:** The ON resistance of the switches directly affects the accuracy and can cause errors, especially for the less significant bits.
*   **Complexity of ladder:** Requires precise matching of the $R$ and $2R$ values.

**Textbook Reference:** Malvino, A.P. & Leach, D.P. (2018), Chapter 14, "Digital-to-Analog Converters".
**Reference Book:** Anand Kumar, A. (2023), Chapter 10, "Digital to Analog Converters".

## Practice Questions

**Part 1: State Machines**

1.  **What is the fundamental difference between a Moore machine and a Mealy machine in terms of their output generation?**
    *   **Answer:** In a Moore machine, the output depends solely on the current state. In a Mealy machine, the output depends on both the current state and the current input.

2.  **Sketch a state transition diagram for a Mealy machine that detects the sequence "110". The output should be '1' when the sequence is detected, and '0' otherwise.**
    *   **Solution Sketch:**
        *   States: S0 (initial), S1 (got 1), S2 (got 11).
        *   Transitions:
            *   S0 --(0/0)--> S0
            *   S0 --(1/0)--> S1
            *   S1 --(0/0)--> S0
            *   S1 --(1/0)--> S2
            *   S2 --(0/1)--> S0  (Sequence 110 detected)
            *   S2 --(1/0)--> S2

3.  **Which type of state machine is generally considered less prone to output glitches and why?**
    *   **Answer:** Moore machines are generally less prone to output glitches because their outputs are tied to the state transitions (clock edges), whereas Mealy machine outputs can change immediately upon input changes, potentially causing glitches if not carefully designed.

**Part 2: Digital-to-Analog Converters**

4.  **Explain the main disadvantage of the weighted resistor type DAC.**
    *   **Answer:** The main disadvantage is the requirement for a wide range of resistor values, making it difficult to achieve high accuracy for higher resolutions due to manufacturing tolerances.

5.  **In an R-2R ladder DAC, what are the two resistor values used, and why is this advantageous compared to the weighted resistor DAC?**
    *   **Answer:** The R-2R ladder DAC uses only two resistor values: R and 2R. This is advantageous because it's easier to manufacture and match only two resistor values with high precision, leading to better accuracy for higher-resolution DACs.

6.  **A 4-bit weighted resistor DAC has $R=10k\Omega$ for its MSB and $V_{ref} = 8V$. What is the analog output voltage for the digital input `1011`?**
    *   **Solution:**
        *   Digital input `1011` means $D_3=1$ (MSB), $D_2=0$, $D_1=1$, $D_0=1$ (LSB).
        *   Resistor values: $R$ ($D_3$), $2R$ ($D_2$), $4R$ ($D_1$), $8R$ ($D_0$).
        *   Resistor for $D_3$: $10k\Omega$.
        *   Resistor for $D_2$: $20k\Omega$.
        *   Resistor for $D_1$: $40k\Omega$.
        *   Resistor for $D_0$: $80k\Omega$.
        *   $V_{out} = -V_{ref} \times (\frac{D_3}{R} + \frac{D_2}{2R} + \frac{D_1}{4R} + \frac{D_0}{8R})$
        *   $V_{out} = -8V \times (\frac{1}{10k\Omega} + \frac{0}{20k\Omega} + \frac{1}{40k\Omega} + \frac{1}{80k\Omega})$
        *   $V_{out} = -8V \times (\frac{1}{10000} + 0 + \frac{1}{40000} + \frac{1}{80000})$
        *   $V_{out} = -8V \times (0.0001 + 0.000025 + 0.0000125)$
        *   $V_{out} = -8V \times 0.0001375 = -0.0011V$
        *   Therefore, the analog output voltage is **-1.1V**.

7.  **Calculate the analog output voltage for a 3-bit R-2R ladder DAC with $V_{ref} = 10V$, $R=10k\Omega$ and digital input `011`.**
    *   **Solution:**
        *   Digital input `011` means $D_2=0$ (MSB), $D_1=1$, $D_0=1$ (LSB).
        *   In an R-2R DAC, the contribution of each bit is $V_{ref}/2^k$ where $k$ is the bit position starting from 1 for MSB.
        *   $D_2$ (MSB, k=1): Contribution is $10V/2^1 = 5V$.
        *   $D_1$ (k=2): Contribution is $10V/2^2 = 2.5V$.
        *   $D_0$ (LSB, k=3): Contribution is $10V/2^3 = 1.25V$.
        *   $V_{out\_magnitude} = D_2 \times (V_{ref}/2) + D_1 \times (V_{ref}/4) + D_0 \times (V_{ref}/8)$
        *   $V_{out\_magnitude} = 0 \times (5V) + 1 \times (2.5V) + 1 \times (1.25V)$
        *   $V_{out\_magnitude} = 0 + 2.5V + 1.25V = 3.75V$.
        *   The analog output voltage is **3.75V** (assuming non-inverting configuration for magnitude calculation or the absolute value).

**Important Points to Remember:**

*   **State Machines:** Crucial for sequential logic. State transition diagrams are key design tools. Moore outputs depend on state, Mealy outputs depend on state and input.
*   **DACs:** Convert digital to analog. Resolution determines the number of output steps.
*   **Weighted Resistor DAC:** Simple but suffers from large resistor value spread.
*   **R-2R Ladder DAC:** More practical for higher resolutions due to using only two resistor values, but sensitive to switch resistance.
