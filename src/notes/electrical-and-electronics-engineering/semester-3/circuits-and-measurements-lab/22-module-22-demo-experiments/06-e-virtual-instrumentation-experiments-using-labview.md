### 1. Introduction to Virtual Instrumentation and LABVIEW

Virtual Instrumentation (VI) refers to the use of general-purpose computer hardware and software to create instrumentation systems that perform the functions of traditional instruments. LABVIEW (Laboratory Virtual Instrument Engineering Workbench) is a graphical programming environment developed by National Instruments (NI) for creating VIs. It uses a dataflow programming paradigm, where graphical blocks represent operations, and wires connect these blocks to define the execution flow.

**Key Concepts:**

*   **Virtual Instrument (VI):** A software program that emulates the functionality of a physical instrument.
*   **Front Panel:** The user interface of a VI, where controls (inputs) and indicators (outputs) are placed.
*   **Block Diagram:** The underlying code of a VI, where the graphical programming elements are wired together to define the VI's logic.
*   **Dataflow Programming:** Execution is determined by the data dependencies between nodes, not by a sequential flow like in text-based languages.
*   **Hardware Integration:** LABVIEW can interface with various hardware devices (Data Acquisition - DAQ devices, GPIB, VXI, PXI, etc.) to acquire and control real-world signals.

**Reference:**

*   **Kalsi H. S. (Electronic Instrumentation):** Discusses the evolution of instrumentation and the role of computers in modern measurement systems, which forms the foundation for VI. While not directly focusing on LABVIEW, it provides the context for why VI is important.
*   **Sawhney A. K. & Gupta J. B. (Electrical & Electronic Measurement & Instrumentation):** These texts provide a strong theoretical background on how traditional instruments work (e.g., measurement of voltage, current, power, impedance). Understanding these principles is crucial for designing effective virtual instruments.

### 2. Components of a LABVIEW VI

A LABVIEW VI is broadly divided into two main parts:

#### 2.1 Front Panel

This is the graphical user interface (GUI) of your VI. It's what the user interacts with.

*   **Controls:** Input elements that allow the user to provide data to the VI.
    *   Examples: Knobs, sliders, numeric input, buttons, switches, waveform charts, graphs.
*   **Indicators:** Output elements that display data generated by the VI.
    *   Examples: Numeric indicators, LEDs, waveform charts, graphs, text displays.

#### 2.2 Block Diagram

This is the "code" of the VI, where you connect functions and built-in VIs to create the desired functionality.

*   **Front Panel Objects:** Controls and indicators from the Front Panel appear as terminals on the Block Diagram.
*   **Functions & VIs (Virtual Instruments):** Pre-built code modules that perform specific operations (e.g., arithmetic, logic, file I/O, instrument control).
*   **Wires:** Connect terminals of controls, indicators, and functions to define data flow and execution sequence.
*   **Structures:** Control the flow of execution.
    *   **While Loop:** Executes a block of code repeatedly as long as a condition is true.
    *   **For Loop:** Executes a block of code a specified number of times.
    *   **Case Structure:** Executes one of several code blocks based on a condition.
    *   **Sequence Structure:** Executes code blocks in a specific order.

**Important Point:** The connection between a Front Panel object and its corresponding terminal on the Block Diagram is fundamental.

### 3. Virtual Instrumentation Experiments in LABVIEW

This section will cover how LABVIEW can be used to implement experiments traditionally done in the Circuits and Measurements Lab. These experiments aim to achieve the course outcomes by simulating or directly interacting with hardware.

#### 3.1 Experiment: Voltage and Current Measurement (Relating to CO1)

**Objective:** To simulate or measure voltage and current in an RLC circuit using LABVIEW and visualize their relationship.

**Traditional Method (as per Sawhney, Gupta, Kalsi):** Using oscilloscopes, multimeters, and AC bridges.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Resistor value (Numeric Control)
        *   Inductor value (Numeric Control)
        *   Capacitor value (Numeric Control)
        *   Voltage source amplitude (Numeric Control)
        *   Voltage source frequency (Numeric Control)
        *   Start/Stop Button
    *   **Indicators:**
        *   Voltage waveform (Waveform Chart)
        *   Current waveform (Waveform Chart)
        *   Voltage phasor (Graph)
        *   Current phasor (Graph)
        *   Magnitude and Phase of voltage and current (Numeric Indicators)

2.  **Block Diagram Implementation:**
    *   **Simulating the Circuit:**
        *   Generate a sinusoidal voltage signal based on the input amplitude and frequency.
        *   Calculate the impedance of the resistor ($Z_R = R$), inductor ($Z_L = j\omega L$), and capacitor ($Z_C = 1/(j\omega C)$).
        *   Calculate the total impedance of the series RLC circuit: $Z_{total} = R + j(\omega L - 1/(\omega C))$.
        *   Calculate the current using Ohm's Law: $I = V/Z_{total}$.
        *   Calculate the voltage drops across R, L, and C.
    *   **Waveform Generation:** Use LABVIEW's signal generation VIs (e.g., `Simulate Signal.vi`) to create time-domain voltage and current waveforms.
    *   **Phasor Representation:**
        *   Convert the time-domain voltage and current to their phasor representations (magnitude and phase). This can be done by finding the RMS value and the phase angle from the generated waveforms.
        *   Use the `XY Graph` to plot the voltage and current phasors. The x-axis can represent the real part and the y-axis the imaginary part.
    *   **Data Acquisition (if using hardware):** If a DAQ device is available, use DAQ VIs to acquire actual voltage and current signals from the physical circuit.
    *   **Looping:** Use a `While Loop` to continuously update the measurements and displays as long as the "Start" button is active.
    *   **Stop Button:** Wire the stop button to the loop condition.

**Example:** For a series RLC circuit, the current phasor can be calculated from the voltage phasor ($V$) and the total impedance ($Z_{total}$) as $I = V / Z_{total}$. The magnitude of the current is $|I| = |V| / |Z_{total}|$ and the phase difference is $\phi = \angle V - \angle Z_{total}$.

**Highlight:** LABVIEW's strength lies in its ability to visualize dynamic behavior (waveforms) and static representation (phasors) simultaneously, aiding in understanding phasor relationships (CO1).

#### 3.2 Experiment: Verification of DC Network Theorems (Relating to CO2)

**Objective:** To verify theorems like Ohm's Law, Kirchhoff's Voltage Law (KVL), Kirchhoff's Current Law (KCL), Superposition, and Thevenin's Theorem using LABVIEW.

**Traditional Method:** Using multimeters to measure voltages and currents in a physical circuit and applying the theorems manually.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Resistor values (Numeric Controls for each resistor in the circuit).
        *   DC Voltage source values (Numeric Controls).
        *   Switch elements to enable/disable sources for superposition.
        *   Load resistance (Numeric Control) for Thevenin's theorem.
        *   Start/Stop Button.
    *   **Indicators:**
        *   Measured voltage across specific components (Numeric Indicators).
        *   Measured current through specific branches (Numeric Indicators).
        *   Results of theorem verification (e.g., "KVL satisfied" Boolean indicator).

2.  **Block Diagram Implementation:**
    *   **Circuit Simulation:**
        *   **Ohm's Law:** Calculate $V = IR$ and $I = V/R$ for individual components.
        *   **KVL:** Sum voltage drops around a closed loop; should equal the sum of voltage sources in that loop.
        *   **KCL:** Sum of currents entering a node equals the sum of currents leaving the node.
        *   **Superposition:** For each source, disable others, calculate the contribution of that source to a specific voltage or current, and sum them up.
        *   **Thevenin's Theorem:**
            *   Calculate Thevenin's equivalent voltage ($V_{th}$) by finding the open-circuit voltage across the terminals.
            *   Calculate Thevenin's equivalent resistance ($R_{th}$) by turning off voltage sources and calculating the equivalent resistance seen from the terminals.
            *   Connect a load resistance and calculate the current through it using $I_L = V_{th} / (R_{th} + R_L)$.
    *   **Data Acquisition (if using hardware):** Connect a physical circuit to a DAQ device and read voltage and current values from the probes.
    *   **Calculation and Verification:** Perform the calculations for each theorem within LABVIEW and compare the simulated/measured values with the theoretically expected values. Display the results clearly.

**Example:** For KVL in a simple series circuit with a voltage source $V_s$ and resistors $R_1, R_2$, the theorem states $V_s = V_{R1} + V_{R2}$. In LABVIEW, you would acquire $V_s, V_{R1}, V_{R2}$ and check if $V_s \approx V_{R1} + V_{R2}$.

**Highlight:** LABVIEW allows for quick modification of circuit parameters and immediate observation of the effects, facilitating a deeper understanding and verification of network theorems (CO2).

#### 3.3 Experiment: Power Measurement in AC Circuits (Relating to CO3)

**Objective:** To measure real power, reactive power, and apparent power in single-phase and possibly three-phase circuits using LABVIEW.

**Traditional Method:** Using wattmeters, power factor meters, and voltmeters/ammeters with phase angle measurement.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Voltage source parameters (Amplitude, Frequency, Phase).
        *   Load parameters (Resistance, Inductance, Capacitance for AC circuit).
        *   Start/Stop Button.
    *   **Indicators:**
        *   Voltage waveform (Waveform Chart).
        *   Current waveform (Waveform Chart).
        *   Real Power (Numeric Indicator).
        *   Reactive Power (Numeric Indicator).
        *   Apparent Power (Numeric Indicator).
        *   Power Factor (Numeric Indicator).
        *   Phasor Diagrams (Graph).

2.  **Block Diagram Implementation:**
    *   **Signal Generation/Acquisition:** Generate or acquire voltage and current waveforms.
    *   **Power Calculation:**
        *   **Real Power (P):** $P = V_{rms} I_{rms} \cos(\theta)$, where $\theta$ is the phase difference between voltage and current. In LABVIEW, this can be calculated by multiplying the RMS values of voltage and current by their cosine of the phase difference. Alternatively, it can be calculated as the average of the instantaneous power ($p(t) = v(t) \times i(t)$) over a cycle.
        *   **Reactive Power (Q):** $Q = V_{rms} I_{rms} \sin(\theta)$. Calculated by multiplying RMS values by the sine of the phase difference.
        *   **Apparent Power (S):** $S = V_{rms} I_{rms}$.
        *   **Power Factor (PF):** $PF = P/S = \cos(\theta)$.
    *   **RMS Value Calculation:** Use the `RMS` VI to calculate the RMS values of voltage and current.
    *   **Phase Difference Calculation:** Use the `Phase Difference` VI or other signal processing VIs to determine the phase angle between the voltage and current signals.
    *   **Visualization:** Display the calculated power values and the power factor. Plotting phasor diagrams helps in understanding the concept of power triangle.
    *   **Three-Phase Power:** For three-phase circuits, the approach would involve acquiring all three phase voltages and currents and applying appropriate calculations for balanced or unbalanced systems (e.g., using the two-wattmeter method principles within LABVIEW).

**Reference:** **Sawhney A. K. & Gupta J. B.** provide detailed explanations of power measurement techniques. LABVIEW allows implementing these methods virtually, allowing for real-time calculations and visualization.

**Highlight:** LABVIEW's ability to perform complex calculations on time-domain signals in real-time makes power measurement and analysis intuitive (CO3).

#### 3.4 Experiment: Calibration Characteristics of Meters (Relating to CO4)

**Objective:** To determine the calibration characteristics (e.g., linearity, accuracy) of measuring instruments virtually.

**Traditional Method:** Comparing readings of the instrument under test with a standard calibrated instrument.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Input value (simulated or from DAQ input, e.g., a known voltage or current).
        *   Calibration adjustments (e.g., gain, offset – if simulating a meter with adjustable parameters).
        *   Start/Stop Button.
    *   **Indicators:**
        *   "True" input value (known standard value).
        *   "Measured" value by the virtual meter.
        *   Error (Difference between true and measured).
        *   Calibration Curve (Scatter Plot or XY Graph showing True vs. Measured).
        *   Linearity indicator (Boolean).

2.  **Block Diagram Implementation:**
    *   **Simulating a Meter:** Create a VI that simulates a measuring instrument. This could involve a simple multiplication (for gain) and addition (for offset) to a standard input signal, or a more complex non-linear characteristic.
    *   **Generating Input Data:** Sweep through a range of known input values (e.g., 0V to 10V in steps of 1V).
    *   **Acquiring Readings:** For each input value, simulate or acquire the reading from the virtual meter.
    *   **Calculating Error:** Calculate the absolute error ($Error = |Measured Value - True Value|$) and percentage error ($%Error = (|Measured Value - True Value| / True Value) \times 100$).
    *   **Plotting Calibration Curve:** Use an `XY Graph` to plot the "True Input Value" on the x-axis and the "Measured Value" on the y-axis.
    *   **Analyzing Linearity:** A linear characteristic would result in points lying on a straight line. You can implement checks for deviations from linearity.
    *   **DAQ Integration:** If calibrating a physical meter, use a DAQ to provide a known, accurate input and read the output of the meter under test (if the meter has a digital output or can be interfaced).

**Reference:** **Kalsi H. S.** provides comprehensive details on calibration procedures and error analysis for various instruments. LABVIEW automates these tedious processes.

**Highlight:** LABVIEW enables the creation of automated calibration routines, significantly reducing time and improving the accuracy of calibration characteristic determination (CO4).

#### 3.5 Experiment: Magnetic Characteristics of Electrical Devices (Relating to CO5)

**Objective:** To simulate or measure magnetic characteristics like B-H curves and hysteresis loops for materials or devices.

**Traditional Method:** Using a setup with a DC or AC source, a solenoid, the material sample, and a fluxmeter or Hall effect sensor, along with an ammeter and voltmeter.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Current through coil (controlled by voltage source).
        *   Number of turns in the coil.
        *   Geometry of the material sample (e.g., core dimensions).
        *   Material properties (e.g., permeability).
        *   Start/Stop Button.
    *   **Indicators:**
        *   Magnetic Field Strength (H) (calculated from current and coil parameters).
        *   Magnetic Flux Density (B) (measured by fluxmeter or Hall sensor via DAQ).
        *   B-H Curve / Hysteresis Loop (XY Graph).

2.  **Block Diagram Implementation:**
    *   **Calculating H:** Magnetic field strength $H = NI/l$, where $N$ is the number of turns, $I$ is the current, and $l$ is the length of the magnetic path.
    *   **Measuring B:**
        *   **Simulation:** If simulating, use known material properties to calculate B for a given H.
        *   **Acquisition:** If using a fluxmeter or Hall effect sensor connected to a DAQ, acquire the voltage output and convert it to flux density (B) using the sensor's calibration.
    *   **Plotting:** Use an `XY Graph` to plot B on the y-axis and H on the x-axis to generate the hysteresis loop or B-H curve.
    *   **AC Excitation:** For AC excitation, the waveforms of H and B will be sinusoidal or distorted, and the hysteresis loop will be visible. This requires generating/acquiring AC signals.

**Reference:** **Sawhney A. K. & Gupta J. B.** extensively cover magnetic circuits and hysteresis. LABVIEW can directly implement the measurement and plotting of these characteristics.

**Highlight:** LABVIEW provides a visual and interactive way to understand the complex magnetic behavior of materials, making it easier to analyze hysteresis loss and permeability (CO5).

#### 3.6 Experiment: Characteristics of Transducer Systems (Relating to CO6)

**Objective:** To analyze the input-output characteristics of various transducers (e.g., thermocouples, strain gauges, LVDTs).

**Traditional Method:** Applying known physical stimuli (temperature, force, displacement) to the transducer and recording its electrical output using a suitable meter.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Input stimulus (e.g., temperature setpoint, applied force, displacement).
        *   Transducer type selection.
        *   Start/Stop Button.
    *   **Indicators:**
        *   Input Stimulus Value (e.g., temperature, force, displacement).
        *   Transducer Output Signal (e.g., voltage, resistance, capacitance, frequency).
        *   Transducer Characteristic Plot (XY Graph: Input Stimulus vs. Output Signal).
        *   Linearity/Sensitivity indicators.

2.  **Block Diagram Implementation:**
    *   **Stimulus Generation/Control:** If controlling a physical setup (e.g., a heater for a thermocouple), LABVIEW can control the stimulus. Otherwise, simulate the input stimulus.
    *   **Transducer Interfacing:** Connect the transducer to a DAQ device.
        *   **Thermocouple:** Requires a cold-junction compensation and often a pre-amplifier. The DAQ acquires the millivolt output.
        *   **Strain Gauge:** Typically requires a bridge circuit. The DAQ measures the bridge output voltage.
        *   **LVDT:** Requires an AC excitation signal and a demodulator circuit. The DAQ measures the demodulated DC output voltage.
    *   **Data Acquisition:** Use appropriate DAQ VIs to acquire the transducer's output signal.
    *   **Signal Conditioning (if needed):** Apply filtering or amplification within LABVIEW if not done by external hardware.
    *   **Characteristic Plotting:** Plot the acquired transducer output against the applied stimulus. This will reveal the transducer's linearity, sensitivity, and operating range.

**Reference:** **Kalsi H. S.** provides excellent insights into the working principles of various transducers. LABVIEW allows for direct acquisition and analysis of their characteristics.

**Highlight:** LABVIEW enables precise control of stimuli and simultaneous acquisition of transducer output, facilitating a detailed analysis of their performance and the development of calibration models (CO6).

#### 3.7 Experiment: Determination of Electrical Parameters Using Bridges (Relating to CO7)

**Objective:** To measure unknown resistance, capacitance, and inductance using simulated or actual bridge circuits.

**Traditional Method:** Using Wheatstone bridge, Maxwell bridge, De Sauty bridge, Schering bridge, etc., and balancing them.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Unknown component values (simulated).
        *   Known component values in the bridge arms (adjustable).
        *   Source frequency (for AC bridges).
        *   Balance/Unbalance indicator.
        *   Start/Stop Button.
    *   **Indicators:**
        *   Measured parameter value (Resistance, Capacitance, Inductance).
        *   Bridge output voltage (Graph or Indicator).
        *   Balance condition (e.g., null indicator).

2.  **Block Diagram Implementation:**
    *   **Bridge Circuit Simulation:** Model the bridge circuit equations. For example, in a Wheatstone bridge with a DC source, the balance condition is $R_1/R_2 = R_3/R_4$.
    *   **AC Bridge Simulation:** For AC bridges (e.g., Maxwell bridge for inductance), the balance condition involves impedances: $Z_1 Z_3 = Z_2 Z_4$. The goal is to adjust known components (e.g., variable resistance and capacitance) to make the voltage across the detector zero.
    *   **DAQ Integration:**
        *   Apply excitation (DC or AC) to the bridge using a function generator (controlled by LABVIEW or external).
        *   Acquire the voltage across the detector terminals using a DAQ device.
    *   **Balance Algorithm:**
        *   **Manual Adjustment:** Allow the user to adjust component values on the Front Panel and observe the detector output.
        *   **Automated Balancing:** Implement a search algorithm (e.g., gradient descent, bisection method) to automatically adjust the known components until the detector output is minimized (null condition).
    *   **Parameter Calculation:** Once the bridge is balanced, calculate the unknown parameter using the balance conditions and the values of the known components.

**Reference:** **Sawhney A. K. & Gupta J. B.** provide detailed derivations and circuit diagrams for various bridges. LABVIEW can automate the balancing process and calculations.

**Highlight:** LABVIEW's ability to automate the null detection and component adjustment process significantly speeds up bridge measurements and improves accuracy, especially for AC bridges (CO7).

#### 3.8 Experiment: Developing Simulation Models (Relating to CO8)

**Objective:** To create simulation models of electric circuits using LABVIEW.

**Traditional Method:** Using circuit simulation software like SPICE, Multisim, or manual calculations.

**Virtual Instrumentation Approach:**

1.  **Front Panel Setup:**
    *   **Controls:**
        *   Circuit topology definition (e.g., selecting components and their interconnections).
        *   Component values (R, L, C, voltage/current sources).
        *   Simulation parameters (e.g., time step, simulation duration).
        *   Start Simulation Button.
    *   **Indicators:**
        *   Voltage/Current waveforms at various nodes/branches (Waveform Charts).
        *   Node voltages and branch currents (Numeric Indicators).
        *   Frequency domain analysis (Bode plots, FFT) (Graphs).

2.  **Block Diagram Implementation:**
    *   **Circuit Representation:** Use data structures to represent the circuit (e.g., an adjacency matrix or a list of components and connections).
    *   **Numerical Methods:** Implement numerical integration techniques (e.g., Euler, Runge-Kutta) for solving differential equations that describe the circuit behavior.
    *   **Component Models:** Create VI's for each component (resistor, inductor, capacitor, voltage source, current source) that define their voltage-current relationships.
    *   **System of Equations:** Assemble the circuit equations (e.g., nodal analysis, mesh analysis) and solve them iteratively over time.
    *   **Input Signals:** Generate or acquire input signals to drive the simulation.
    *   **Output Display:** Use LABVIEW's plotting and display VIs to visualize the simulation results.

**Example:** To simulate a simple series RC circuit with a step voltage input:
*   The circuit equation is $v_s(t) = i(t)R + v_c(t)$, and $i(t) = C \frac{dv_c(t)}{dt}$.
*   This can be written as a first-order differential equation: $\frac{dv_c(t)}{dt} = \frac{1}{RC} (v_s(t) - v_c(t))$.
*   LABVIEW can be used to numerically solve this equation over time, plotting $v_c(t)$ and $i(t)$.

**Reference:** This directly addresses CO8. While the textbooks might not detail LABVIEW simulation, they provide the fundamental circuit analysis techniques (nodal, mesh) that underpin these simulation models.

**Highlight:** LABVIEW's graphical environment is well-suited for building intuitive circuit simulators, allowing users to experiment with different circuit designs and analyze their behavior without physical hardware (CO8).

### 4. Important Points to Remember

*   **Dataflow Execution:** Understand that LABVIEW executes based on data availability, not a top-to-bottom sequential flow.
*   **Error Handling:** Implement robust error handling in your VIs to manage unexpected situations during acquisition or processing.
*   **Timing and Synchronization:** For real-time experiments, carefully manage loop timing, sampling rates, and synchronization between different operations.
*   **DAQ Device Configuration:** Ensure your DAQ hardware is correctly installed and configured in NI-MAX (Measurement & Automation Explorer) before using it in LABVIEW.
*   **VI Reusability:** Develop modular VIs that can be reused in different projects.
*   **Front Panel Design:** Create user-friendly and informative Front Panels.
*   **Documentation:** Add comments and descriptions to your Block Diagrams for clarity.

### 5. Practice Questions and Answers

**Question 1:** In LABVIEW, what is the primary difference between a Control and an Indicator on the Front Panel?

**Answer:**
*   **Control:** A control is an input device that allows the user to provide data or set parameters to the VI. Examples: knobs, sliders, numeric input.
*   **Indicator:** An indicator is an output device that displays data generated by the VI to the user. Examples: numeric displays, charts, graphs.

**Question 2:** Describe how you would simulate a series RLC circuit in LABVIEW and visualize its voltage and current waveforms. (Relates to CO1 and CO8)

**Answer:**
1.  **Front Panel:** Add numeric controls for R, L, C values, voltage source amplitude, and frequency. Add two Waveform Charts to display voltage and current.
2.  **Block Diagram:**
    *   Use `Simulate Signal.vi` to generate a sinusoidal voltage waveform based on control inputs.
    *   Calculate the impedance of R, L, and C at the given frequency.
    *   Calculate the total impedance for a series RLC circuit: $Z_{total} = R + j(\omega L - 1/(\omega C))$.
    *   Calculate the current waveform using Ohm's Law: $I = V/Z_{total}$.
    *   Wire the voltage and current waveforms to the respective Waveform Charts.
    *   Use a `While Loop` and a `Wait (ms)` function to control the update rate.

**Question 3:** How can LABVIEW be used to verify KVL in a simple DC circuit? (Relates to CO2)

**Answer:**
1.  **Front Panel:** Set up a circuit with a voltage source and at least two resistors in series. Add numeric indicators for the voltage across the source and each resistor.
2.  **Block Diagram:**
    *   Simulate the circuit by calculating the voltage drops based on Ohm's Law ($V=IR$) and KCL for current distribution.
    *   Alternatively, if using a DAQ, acquire the actual voltage readings across the source and resistors.
    *   In the Block Diagram, sum the voltage drops across the resistors ($V_{R1} + V_{R2}$).
    *   Compare this sum with the voltage source reading. Display a Boolean indicator showing if $V_s \approx V_{R1} + V_{R2}$.

**Question 4:** What is the fundamental calculation for real power ($P$) in an AC circuit using RMS values and phase difference ($\theta$)? How would you implement this in LABVIEW? (Relates to CO3)

**Answer:**
*   **Calculation:** $P = V_{rms} \times I_{rms} \times \cos(\theta)$
*   **LABVIEW Implementation:**
    1.  Acquire or generate voltage and current waveforms.
    2.  Use the `RMS` VI to find $V_{rms}$ and $I_{rms}$.
    3.  Use the `Phase Difference` VI to find the phase angle $\theta$.
    4.  Use a `Multiply` VI to multiply $V_{rms}$, $I_{rms}$, and the output of a `Cosine` VI (which takes $\theta$ as input).
    5.  Display the result in a numeric indicator.
