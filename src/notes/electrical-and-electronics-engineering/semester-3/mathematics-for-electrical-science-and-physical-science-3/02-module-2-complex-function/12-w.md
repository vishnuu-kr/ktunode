# Mathematics for Electrical Science and Physical Science – 3

## Module 2: Complex Functions

### Topic: The Exponential Function $w = e^z$

This topic explores the properties and behavior of the complex exponential function, a fundamental building block in complex analysis with significant applications in electrical and physical sciences.

---

### 1. Introduction to the Complex Exponential Function

The complex exponential function is defined for a complex number $z = x + iy$ as:

$w = e^z = e^{x+iy}$

Using Euler's formula, $e^{iy} = \cos(y) + i \sin(y)$, we can express $e^z$ in rectangular form:

$w = e^x e^{iy} = e^x (\cos(y) + i \sin(y))$

Here:
*   $e^x$ is the real exponential function, representing the **magnitude** of $w$.
*   $\cos(y) + i \sin(y)$ is a complex number with magnitude 1 and argument $y$, representing the **argument** of $w$.

**Key Concepts & Definitions:**

*   **Rectangular Form:** $w = u(x,y) + iv(x,y)$, where $u(x,y) = e^x \cos(y)$ and $v(x,y) = e^x \sin(y)$.
*   **Polar Form:** $w = r e^{i\theta}$, where $r = |w| = e^x$ and $\theta = \arg(w) = y + 2k\pi$ for any integer $k$.

---

### 2. Properties of the Complex Exponential Function

The complex exponential function shares many properties with its real counterpart.

**Key Properties:**

*   **Additivity:** $e^{z_1 + z_2} = e^{z_1} e^{z_2}$
    *   **Proof:** $e^{z_1+z_2} = e^{(x_1+x_2) + i(y_1+y_2)} = e^{x_1+x_2} e^{i(y_1+y_2)} = e^{x_1}e^{x_2} (\cos(y_1+y_2) + i\sin(y_1+y_2))$
        $= e^{x_1}e^{x_2} (\cos(y_1)\cos(y_2) - \sin(y_1)\sin(y_2) + i(\sin(y_1)\cos(y_2) + \cos(y_1)\sin(y_2)))$
        $= (e^{x_1}\cos(y_1) + ie^{x_1}\sin(y_1))(e^{x_2}\cos(y_2) + ie^{x_2}\sin(y_2))$
        $= e^{x_1}e^{iy_1} e^{x_2}e^{iy_2} = e^{z_1}e^{z_2}$
*   **Periodicity:** $e^{z + 2\pi i k} = e^z$ for any integer $k$.
    *   **Proof:** $e^{z + 2\pi i k} = e^z e^{2\pi i k} = e^z (\cos(2\pi k) + i \sin(2\pi k)) = e^z (1 + i \cdot 0) = e^z$.
    *   **Implication:** The exponential function is periodic with period $2\pi i$. This means that different complex numbers can map to the same value under $e^z$.
*   **Magnitude and Argument:**
    *   $|e^z| = |e^{x+iy}| = |e^x e^{iy}| = |e^x| |e^{iy}| = e^x \cdot 1 = e^x$.
    *   $\arg(e^z) = \arg(e^x e^{iy}) = \arg(e^{iy}) = y + 2k\pi$ (where $k$ is an integer).
*   **Relationship to Hyperbolic Functions:**
    *   $\cosh(z) = \frac{e^z + e^{-z}}{2}$
    *   $\sinh(z) = \frac{e^z - e^{-z}}{2}$
*   **Relationship to Trigonometric Functions (Euler's Formula):**
    *   $\cos(z) = \frac{e^{iz} + e^{-iz}}{2}$
    *   $\sin(z) = \frac{e^{iz} - e^{-iz}}{2i}$

**Important Points to Remember:**

*   The exponential function $e^z$ is never zero. This is because $|e^z| = e^x$, and $e^x$ is always positive for real $x$.
*   The periodicity of $e^z$ means that the mapping $w = e^z$ is not one-to-one.

---

### 3. Mapping Properties of $w = e^z$

The exponential function maps horizontal lines to rays from the origin and vertical lines to circles centered at the origin. This is crucial for understanding conformal mappings (CO2).

**Mapping of Lines:**

*   **Horizontal Line:** $z = t + iy_0$, where $t \in (-\infty, \infty)$ and $y_0$ is a constant.
    *   $w = e^{t+iy_0} = e^t (\cos(y_0) + i \sin(y_0))$.
    *   The magnitude is $r = e^t$, which varies from 0 to $\infty$ as $t$ varies.
    *   The argument is $\theta = y_0$.
    *   **Result:** A horizontal line $y = y_0$ in the $z$-plane is mapped to a ray emanating from the origin in the $w$-plane with argument $y_0$. The ray starts from the origin (as $t \to -\infty$, $e^t \to 0$) and extends to infinity (as $t \to \infty$, $e^t \to \infty$).
    *   **Example:** The line $y = \pi/2$ maps to the positive imaginary axis in the $w$-plane. The line $y = \pi$ maps to the negative real axis.

*   **Vertical Line:** $z = x_0 + iy$, where $x_0$ is a constant and $y \in (-\infty, \infty)$.
    *   $w = e^{x_0+iy} = e^{x_0} (\cos(y) + i \sin(y))$.
    *   The magnitude is $r = e^{x_0}$, which is a constant.
    *   The argument is $\theta = y + 2k\pi$. As $y$ varies from $-\infty$ to $\infty$, the argument sweeps through all possible values ($0$ to $2\pi$, $2\pi$ to $4\pi$, etc.).
    *   **Result:** A vertical line $x = x_0$ in the $z$-plane is mapped to a circle centered at the origin in the $w$-plane with radius $r = e^{x_0}$. Since the argument sweeps through all values, the circle is traced infinitely many times.
    *   **Example:** The line $x = 0$ maps to the unit circle $|w| = e^0 = 1$. The line $x = \ln(2)$ maps to the circle $|w| = e^{\ln(2)} = 2$.

**Mapping of Rectangles:**

*   A rectangle defined by $x_1 \le x \le x_2$ and $y_1 \le y \le y_2$ is mapped to a region bounded by two rays and two circular arcs in the $w$-plane.
    *   The vertical sides $x = x_1$ and $x = x_2$ map to circles $|w| = e^{x_1}$ and $|w| = e^{x_2}$.
    *   The horizontal sides $y = y_1$ and $y = y_2$ map to rays $\arg(w) = y_1$ and $\arg(w) = y_2$.
    *   **Result:** A rectangle in the $z$-plane is mapped to a "sector of an annulus" in the $w$-plane.

**Analyticity and Conformal Mapping (CO2):**

The function $w = e^z$ is analytic everywhere in the complex plane. Its derivative is $\frac{dw}{dz} = e^z$.
*   The derivative $e^z$ is never zero.
*   **Therefore, $w = e^z$ is a conformal mapping everywhere.** This means that it preserves angles between intersecting curves at each point.

### 4. Inverse of the Exponential Function: The Complex Logarithm

The inverse of $w = e^z$ is the complex logarithm, $z = \log(w)$. Since $e^z$ is periodic, its inverse is multi-valued.

**Definition:**
If $w = e^z$, then $z = \log(w)$.
Let $w = r e^{i\theta}$ in polar form. We have:
$r e^{i\theta} = e^z = e^{x+iy} = e^x e^{iy}$

Equating magnitudes and arguments:
*   $r = e^x \implies x = \ln(r)$ (where $\ln$ is the natural logarithm of a positive real number).
*   $\theta = y + 2k\pi$ for any integer $k$.

Therefore, $z = x + iy = \ln(r) + i(\theta + 2k\pi)$.

**Key Concepts & Definitions:**

*   **Principal Value of the Logarithm:** To define a single-valued logarithm, we restrict the argument $\theta$ to the principal range $(-\pi, \pi]$. This is denoted by $\text{Log}(w)$.
    *   $z = \text{Log}(w) = \ln|w| + i \text{Arg}(w)$, where $\text{Arg}(w)$ is the principal argument of $w$.
    *   **Example:** For $w = -1$, $|w|=1$ and $\text{Arg}(w) = \pi$. So, $\text{Log}(-1) = \ln(1) + i\pi = i\pi$.
    *   However, $\log(-1)$ can be $i\pi, i3\pi, -i\pi$, etc.

*   **Logarithm Properties:**
    *   $\log(z_1 z_2) = \log(z_1) + \log(z_2)$ (holds up to an additive multiple of $2\pi i$)
    *   $\log(z^n) = n \log(z)$ (holds up to an additive multiple of $2\pi i$)
    *   $\log(e^z) = z$ (holds up to an additive multiple of $2\pi i$)
    *   $e^{\log(w)} = w$ (holds for the principal value and all values)

**Reference:** Kreyszig, 10th ed., Chapter 13 (Complex Analytic Functions), Section 13.6 (The Exponential Function and Its Relatives). This section details the properties and mappings of $e^z$ and introduces the complex logarithm. Zill & Shanahan, 3rd ed., Chapter 4 (Complex Functions), Section 4.3 (The Exponential and Logarithmic Functions), also provides a thorough treatment.

### 5. Applications in Electrical Science and Physical Science

The exponential function is fundamental in representing oscillations, decaying or growing signals, and solutions to differential equations in various scientific fields.

**Examples:**

*   **AC Circuits:** The voltage and current in AC circuits are often represented using complex exponentials. For example, a sinusoidal voltage $V(t) = V_0 \cos(\omega t)$ can be written as the real part of $V_0 e^{i\omega t}$. This simplifies circuit analysis using phasors.
*   **Wave Phenomena:** Solutions to wave equations and phenomena involving propagation often involve $e^{i(kx - \omega t)}$ or similar forms, representing waves traveling in space and time.
*   **Fourier Transforms (CO1):** The Fourier transform inherently uses the complex exponential $e^{-i\omega t}$ (or $e^{-i\xi x}$). Understanding $e^z$ is a prerequisite for grasping how Fourier transforms relate functions in the time or spatial domain to their frequency components.
    *   The inverse Fourier transform relates back to the original function, often involving integration over complex frequencies (though typically the integral is over the real axis in the basic FT).
*   **Differential Equations:** Solutions to linear, constant-coefficient ordinary differential equations with complex roots in the characteristic equation often involve terms like $e^{az} \cos(bz)$ and $e^{az} \sin(bz)$.

**Connection to Course Outcomes:**

*   **CO2 (Analyticity and Conformal Mapping):** The discussion on how $w=e^z$ maps lines and shapes, and its property of being conformal (since $dw/dz \neq 0$), directly addresses this outcome.
*   **CO1 (Fourier Transforms):** While not directly computing Fourier transforms here, the foundational understanding of complex exponentials is vital for applying them in Fourier analysis. The $e^{iy}$ part is central to the oscillatory nature captured by Fourier transforms.

### 6. Practice Questions and Exercises

**Question 1:**
Find the magnitude and principal argument of $w = e^{1 + i\pi/4}$.

**Answer:**
$w = e^{1 + i\pi/4} = e^1 e^{i\pi/4} = e(\cos(\pi/4) + i\sin(\pi/4)) = e(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2})$.
Magnitude: $|w| = e^1 = e$.
Principal Argument: $\text{Arg}(w) = \pi/4$.

**Question 2:**
What is the image of the vertical line segment $x = 1$, $0 \le y \le \pi$ under the mapping $w = e^z$?

**Answer:**
For $z = 1 + iy$, $w = e^{1+iy} = e^1 e^{iy} = e(\cos y + i \sin y)$.
The magnitude is $|w| = e$.
The argument is $\arg(w) = y$. As $y$ varies from $0$ to $\pi$, the argument varies from $0$ to $\pi$.
So, the image is a semi-circular arc of radius $e$ in the upper half of the $w$-plane, starting at $w = e$ (when $y=0$) and ending at $w = -e$ (when $y=\pi$).

**Question 3:**
Solve the equation $e^z = 1 + i$ for $z$.

**Answer:**
Let $z = x + iy$. We need to solve $e^{x+iy} = 1+i$.
In polar form, $1+i = \sqrt{1^2+1^2} e^{i \arctan(1/1)} = \sqrt{2} e^{i\pi/4}$.
So, $e^x e^{iy} = \sqrt{2} e^{i(\pi/4 + 2k\pi)}$ for integer $k$.
Equating magnitudes: $e^x = \sqrt{2} \implies x = \ln(\sqrt{2}) = \frac{1}{2}\ln(2)$.
Equating arguments: $y = \frac{\pi}{4} + 2k\pi$.
Therefore, $z = \frac{1}{2}\ln(2) + i(\frac{\pi}{4} + 2k\pi)$, for $k \in \mathbb{Z}$.

**Question 4:**
Show that $|\cos z|^2 + |\sin z|^2 = \cosh^2 x - \sinh^2 x = 1$ is not generally true for complex $z = x+iy$. Instead, find an expression for $|\cos z|^2 + |\sin z|^2$.

**Answer:**
$\cos z = \cos(x+iy) = \cos x \cos(iy) - \sin x \sin(iy)$.
Using $\cos(iy) = \cosh y$ and $\sin(iy) = i \sinh y$:
$\cos z = \cos x \cosh y - i \sin x \sinh y$.
$|\cos z|^2 = (\cos x \cosh y)^2 + (-\sin x \sinh y)^2 = \cos^2 x \cosh^2 y + \sin^2 x \sinh^2 y$.

$\sin z = \sin(x+iy) = \sin x \cos(iy) + \cos x \sin(iy)$.
$\sin z = \sin x \cosh y + i \cos x \sinh y$.
$|\sin z|^2 = (\sin x \cosh y)^2 + (\cos x \sinh y)^2 = \sin^2 x \cosh^2 y + \cos^2 x \sinh^2 y$.

$|\cos z|^2 + |\sin z|^2 = (\cos^2 x \cosh^2 y + \sin^2 x \sinh^2 y) + (\sin^2 x \cosh^2 y + \cos^2 x \sinh^2 y)$
$= (\cos^2 x + \sin^2 x) \cosh^2 y + (\sin^2 x + \cos^2 x) \sinh^2 y$
$= 1 \cdot \cosh^2 y + 1 \cdot \sinh^2 y$
$= \cosh^2 y + \sinh^2 y$.

Using the identity $\cosh^2 y - \sinh^2 y = 1$, we have $\cosh^2 y = 1 + \sinh^2 y$.
So, $|\cos z|^2 + |\sin z|^2 = (1 + \sinh^2 y) + \sinh^2 y = 1 + 2\sinh^2 y$.

This shows that $|\cos z|^2 + |\sin z|^2 = 1$ only when $y=0$ (i.e., for real $z$).

### 7. Summary and Key Takeaways

*   The complex exponential $e^z = e^x(\cos y + i \sin y)$ has magnitude $e^x$ and argument $y$.
*   It is periodic with period $2\pi i$, meaning $e^{z+2\pi ik} = e^z$.
*   $e^z$ is never zero.
*   The function $w = e^z$ maps horizontal lines to rays and vertical lines to circles.
*   $w = e^z$ is analytic and conformal everywhere in the complex plane as its derivative $e^z$ is never zero.
*   The inverse of $e^z$ is the multi-valued complex logarithm, $\log w = \ln |w| + i (\arg w + 2k\pi)$. The principal value $\text{Log } w$ uses the principal argument.
*   The exponential function is crucial for modeling oscillations, decay, and growth in various scientific and engineering applications.
