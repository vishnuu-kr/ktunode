# Module 2: Discretization - Iterative Convergence, Condition for Convergence, Rate of Convergence

## Introduction

Computational Fluid Dynamics (CFD) involves solving complex partial differential equations (PDEs) that govern fluid flow and heat transfer. Since analytical solutions are rarely possible for real-world problems, we resort to numerical methods that discretize the continuous domain and equations into a finite number of algebraic equations. These algebraic systems are often solved iteratively. This module focuses on understanding the principles of iterative convergence, the conditions required for a successful iterative solution, and how to assess the speed at which a solution is reached.

**Course Outcomes Alignment:**
*   **CO1 (K2):** Understanding governing equations is foundational to appreciating why numerical methods are necessary and how discretization impacts the solution.
*   **CO2 (K3) & CO3 (K3):** The techniques for iterative convergence are directly applicable when solving discretized equations using finite difference and finite volume methods.
*   **CO4 (K2):** Solution techniques for convection-diffusion equations often rely on iterative methods, making this topic crucial.
*   **CO5 (K3):** Interpreting graphical results from CFD simulations often involves evaluating convergence plots.

## 1. Iterative Convergence

### 1.1 What is Iterative Convergence?

Iterative convergence refers to the process where a sequence of approximate solutions generated by an iterative numerical method approaches the true solution of the algebraic system within a specified tolerance. In essence, as we perform more iterations, the calculated values get progressively closer to the actual values that satisfy the discretized equations.

**Key Concept:** An iterative method starts with an initial guess for the solution and refines it in successive steps (iterations) until the change between successive approximations is sufficiently small.

### 1.2 Why Use Iterative Methods?

For many CFD problems, the discretized equations result in large systems of linear or non-linear algebraic equations.

*   **Large Systems:** The number of grid points in a CFD simulation can be very high, leading to millions of unknowns. Direct solvers (like Gaussian elimination) become computationally prohibitive in terms of memory and time for such large systems.
*   **Non-linearity:** Many fluid flow phenomena (e.g., turbulence, convection) introduce non-linearity into the governing equations. Iterative methods are often more robust and efficient in handling these non-linearities.
*   **Sparse Matrices:** The discretized equations often result in sparse matrices (matrices with many zero entries), which are well-suited for iterative solution techniques.

**Reference:** Anderson Jr., Chapter 8, discusses the need for iterative methods when dealing with large, sparse systems arising from discretized PDEs.

### 1.3 Iterative Solution Process

An iterative solver typically follows these steps:

1.  **Initialization:** Start with an initial guess for the solution vector (e.g., all zeros, uniform values, or results from a coarser grid).
2.  **Iteration:** Use a specific algorithm (e.g., Jacobi, Gauss-Seidel, SOR, Conjugate Gradient, SIMPLE) to update the solution vector based on the current approximation.
3.  **Check Convergence:** Evaluate a convergence criterion to determine if the solution has reached the desired accuracy.
4.  **Update:** If convergence is not achieved, repeat step 2 with the updated solution.

### 1.4 Convergence Criteria

The decision to stop an iterative process is based on a convergence criterion, which measures how "close" the current solution is to the true solution. Common criteria include:

*   **Residual Norm:** The residual ($R$) is the difference between the left-hand side and right-hand side of the discretized equation when the current approximate solution is substituted.
    *   For a system $Ax = b$, the residual is $R = b - Ax$.
    *   The residual norm (e.g., L2-norm: $\sqrt{\sum (b_i - (Ax)_i)^2}$) quantifies the overall error in satisfying the equations.
    *   Convergence is achieved when $\|R^{(k)}\| \le \epsilon_{res}$, where $\epsilon_{res}$ is a small tolerance.
    *   **Normalized Residual:** Often, the residual is normalized by the norm of the source term ($b$) or the initial residual to account for variations in problem scale.
        $\|R^{(k)}\| / \|b\| \le \epsilon_{res}$ or $\|R^{(k)}\| / \|R^{(0)}\| \le \epsilon_{res}$

*   **Change in Solution Norm:** This criterion checks how much the solution vector changes between successive iterations.
    *   Convergence is achieved when $\|x^{(k+1)} - x^{(k)}\| \le \epsilon_{change}$, where $\epsilon_{change}$ is a small tolerance.
    *   This can also be normalized: $\|x^{(k+1)} - x^{(k)}\| / \|x^{(k+1)}\| \le \epsilon_{change}$.

**Important Note:** The residual norm is generally preferred as it directly measures how well the equations are satisfied, whereas the change in solution norm might indicate convergence even if the equations are not well-satisfied (especially for ill-conditioned systems).

**Example:** Consider a simple linear system from a discretized 1D convection-diffusion problem:
$a_P \phi_P = \sum_{nb} a_{nb} \phi_{nb} + b$
If we rearrange this to $a_P \phi_P - \sum_{nb} a_{nb} \phi_{nb} = b$, the residual for grid point P in iteration $k$ is:
$R_P^{(k)} = b - (a_P \phi_P^{(k)} - \sum_{nb} a_{nb} \phi_{nb}^{(k)})$

We then compute a norm of $R_P^{(k)}$ over all grid points.

### 1.5 Stopping Criteria

In practice, we set a maximum number of iterations allowed. If convergence is not achieved by then, the simulation is terminated. This prevents infinite loops and provides an indication of potential problems.

## 2. Condition for Convergence

### 2.1 What Guarantees Convergence?

The convergence of an iterative method is not always guaranteed. It depends on several factors:

*   **The Algebraic System:** The properties of the matrix representing the discretized equations.
*   **The Iterative Algorithm:** The specific method used for updating the solution.
*   **The Initial Guess:** A good initial guess can accelerate convergence.

### 2.2 Properties of the Algebraic System

For a linear system $Ax = b$:

*   **Diagonally Dominance:** A matrix $A$ is **strictly diagonally dominant** if for every row $i$, the absolute value of the diagonal element $|a_{ii}|$ is greater than the sum of the absolute values of the off-diagonal elements in that row:
    $|a_{ii}| > \sum_{j \ne i} |a_{ij}|$
    If $A$ is strictly diagonally dominant, iterative methods like Jacobi and Gauss-Seidel are guaranteed to converge.

*   **Symmetric Positive Definite (SPD):** If the matrix $A$ is SPD, then iterative methods like Conjugate Gradient are guaranteed to converge.

**Reference:** Sastry, Chapter on Numerical Solution of Linear Equations, often covers conditions like diagonal dominance and properties of matrices for convergence. Patankar, Chapter 5, discusses the properties of coefficient matrices arising from finite difference/volume methods and their implications for convergence.

### 2.3 Discretization and Diagonal Dominance

The discretization schemes employed in CFD play a crucial role in ensuring diagonal dominance.

*   **Upwind Differencing Scheme (UDS):** For convection-dominated problems, UDS leads to strongly diagonally dominant matrices, ensuring convergence. This is a major reason for its popularity despite its numerical diffusion.
*   **Central Differencing Scheme (CDS):** For diffusion-dominated problems, CDS also leads to diagonally dominant matrices. However, for convection-dominated problems, CDS can lead to oscillatory solutions and divergence if the Courant number is too high.
*   **Hybrid Schemes & Power Law Scheme:** These schemes attempt to balance accuracy and stability. The Power Law Scheme, in particular, ensures diagonal dominance for all Peclet numbers, guaranteeing convergence.

**Key Concept:** The physical problem (e.g., high convection vs. high diffusion) and the chosen discretization scheme directly influence the properties of the resulting algebraic system and thus its convergence behavior.

**Example:** Consider the 1D convection-diffusion equation discretization:
$\alpha \frac{\partial \phi}{\partial x} - \beta \frac{\partial^2 \phi}{\partial x^2} = 0$
Using UDS for convection and CDS for diffusion on a grid:
$\alpha \frac{\phi_P - \phi_W}{ \Delta x} - \beta \frac{\phi_E - 2\phi_P + \phi_W}{(\Delta x)^2} = 0$
Multiplying by $(\Delta x)^2$ and rearranging for $\phi_P$:
$a_P \phi_P = a_W \phi_W + a_E \phi_E$
The coefficients $a_P, a_W, a_E$ depend on the chosen scheme. With UDS, the coefficient associated with the upwind neighbor ($\phi_W$ in this case if flow is from left to right) becomes larger, enhancing diagonal dominance.

**Anderson Jr.** discusses how discretization choices directly impact the matrix properties and hence convergence. For instance, the upwind scheme's artificial diffusion helps stabilize the solution and leads to diagonally dominant matrices.

### 2.4 Impact of Non-linearity

For non-linear systems, convergence is more complex. Iterative methods often linearize the equations within each iteration (e.g., using Newton's method or Picard iteration). The convergence then depends on the Jacobian matrix of the non-linear system and the step size used in the iteration.

**Reference:** Anderson Jr., Chapter 8, might touch upon iterative methods for non-linear systems.

### 2.5 Iterative Solvers and Convergence

Different iterative solvers have different convergence properties:

*   **Jacobi Method:** Each new value of $\phi_P$ is calculated using values from the *previous* iteration for all neighbors. It's simple but often slow.
*   **Gauss-Seidel Method:** Uses the most recently computed values for neighbors within the *current* iteration. Generally converges faster than Jacobi.
*   **Successive Over-Relaxation (SOR):** An extension of Gauss-Seidel that uses a relaxation parameter ($\omega$) to accelerate convergence.
*   **Conjugate Gradient (CG):** Highly effective for SPD systems, often converging much faster than Jacobi or Gauss-Seidel.
*   **Multigrid Methods:** Very efficient for certain types of PDEs, as they can accelerate convergence by working on different grid levels.

**Key Point:** The choice of solver significantly impacts convergence speed and stability, especially for convection-dominated flows.

**Patankar**, in his discussion on solvers, emphasizes that for convection-diffusion problems, efficient solvers like the ADI (Alternating Direction Implicit) method or multigrid techniques are often employed to overcome slow convergence.

## 3. Rate of Convergence

### 3.1 What is the Rate of Convergence?

The rate of convergence describes how quickly an iterative method approaches the true solution. It's a measure of efficiency. A faster rate means fewer iterations are needed to achieve a certain level of accuracy.

### 3.2 Measuring the Rate of Convergence

The rate of convergence is typically defined by the factor by which the error is reduced in each iteration.

*   **Linear Convergence:** The error at iteration $k+1$ is a constant fraction of the error at iteration $k$.
    $E_{k+1} \approx r E_k$, where $0 < r < 1$.
    The rate of convergence is defined as $r$. A smaller $r$ means faster convergence.
    The number of iterations ($k$) required to reduce the error from $E_0$ to $\epsilon$ is roughly proportional to $1/r$.

*   **Superlinear Convergence:** The error ratio $E_{k+1}/E_k \to 0$ as $k \to \infty$. The error decreases faster than linearly.
*   **Quadratic Convergence:** The error at iteration $k+1$ is proportional to the square of the error at iteration $k$.
    $E_{k+1} \approx C E_k^2$, where $C$ is a constant.
    This means the number of correct digits roughly doubles in each iteration. Newton's method often exhibits quadratic convergence.

**Key Concept:** For most iterative methods used in CFD for linear systems (like Jacobi, Gauss-Seidel, SOR), the convergence is linear.

### 3.3 Convergence Factor (r)

For a linear iterative method $x^{(k+1)} = T x^{(k)} + c$, the error $e^{(k)} = x - x^{(k)}$ satisfies $e^{(k+1)} = T e^{(k)}$.
The convergence factor $r$ is related to the spectral radius of the iteration matrix $T$:
$r = \rho(T) = \max |\lambda_i|$, where $\lambda_i$ are the eigenvalues of $T$.
For linear convergence, $0 \le r < 1$.

**Important:** A smaller spectral radius means a faster convergence rate.

### 3.4 Factors Affecting the Rate of Convergence

1.  **Discretization Scheme:** As discussed, UDS for convection-dominated flows leads to better diagonal dominance and thus often better convergence rates for iterative solvers compared to CDS without stabilization.
2.  **Iterative Solver Algorithm:**
    *   Gauss-Seidel is generally faster than Jacobi.
    *   SOR can significantly improve the rate by choosing an optimal $\omega$.
    *   Conjugate Gradient methods are typically much faster for SPD systems.
3.  **Problem Parameters:**
    *   **Peclet Number ($Pe = \frac{U L}{\Gamma}$):** For convection-diffusion equations, high Peclet numbers (convection-dominated) can lead to slower convergence rates for some iterative methods if not handled carefully by the discretization or solver.
    *   **Reynolds Number ($Re = \frac{\rho U L}{\mu}$):** For Navier-Stokes equations, high Reynolds numbers (turbulent flows) lead to more complex phenomena and can pose significant challenges for convergence speed and stability.
4.  **Grid Resolution and Refinement:** A finer grid generally leads to a larger system, which might require more iterations. However, the *overall* computational cost depends on both the number of iterations and the cost per iteration. Sometimes, multigrid methods leverage grid hierarchy to achieve faster convergence.
5.  **Initial Guess:** A good initial guess closer to the true solution can significantly reduce the number of iterations.

**Example:** Consider solving the discretized Poisson equation. For a simple grid with Jacobi iteration, the convergence rate might be slow. With Gauss-Seidel, it's faster. With SOR, it can be even faster if $\omega$ is chosen appropriately. Using a Multigrid solver can dramatically reduce the number of iterations.

**Anderson Jr.** (Chapter 8) provides a good overview of the spectral radius and its relation to the convergence rate of various iterative methods. **Versteeg & Malalasekera** (Chapter 5, particularly on iterative solutions for linear systems in FVM) will also detail how discretization choices impact the convergence of the resulting linear systems and often discuss acceleration techniques.

### 3.5 Acceleration Techniques

To improve the rate of convergence for slow iterative methods, several techniques are employed:

*   **Relaxation:** As seen in SOR, using a relaxation parameter can speed up convergence.
*   **Multigrid Methods:** Solve the problem on a sequence of grids of increasing resolution, transferring information between grids to accelerate convergence.
*   **Preconditioning:** Transforming the linear system into an equivalent one that is easier to solve iteratively.
*   **GMRES (Generalized Minimum Residual):** An iterative method often used for non-symmetric or indefinite matrices, which can be more robust than CG.

**Key Point:** For convection-dominated flows, especially at high Reynolds or Peclet numbers, special care is needed with discretization and solver choice to achieve acceptable convergence rates.

## Practice Questions

1.  **Definition:** What is the residual of a discretized equation, and why is it important for determining convergence?
    *   **Answer:** The residual ($R$) is the difference between the left-hand side and right-hand side of a discretized algebraic equation when the current approximate solution is substituted. It measures how well the current approximation satisfies the equation. A small residual indicates that the solution is close to satisfying the discretized equations.

2.  **Condition:** What is strict diagonal dominance, and how does it relate to the convergence of iterative methods like Jacobi and Gauss-Seidel?
    *   **Answer:** A matrix is strictly diagonally dominant if, for every row, the absolute value of the diagonal element is greater than the sum of the absolute values of all other elements in that row. This property guarantees that iterative methods like Jacobi and Gauss-Seidel will converge.

3.  **Rate:** If the error in an iterative solution is reduced by a factor of 0.5 in each iteration, what type of convergence is this, and how does the error change over 3 iterations starting from an initial error $E_0$?
    *   **Answer:** This is linear convergence with a convergence factor $r = 0.5$.
        *   After 1 iteration: Error is $0.5 E_0$.
        *   After 2 iterations: Error is $0.5 \times (0.5 E_0) = 0.25 E_0$.
        *   After 3 iterations: Error is $0.5 \times (0.25 E_0) = 0.125 E_0$.

4.  **Application:** For a convection-dominated flow ($\text{Pe} \gg 1$), which discretization scheme would you generally expect to provide better convergence characteristics for iterative solvers, and why?
    *   **Answer:** The Upwind Differencing Scheme (UDS) is generally expected to provide better convergence characteristics for convection-dominated flows. This is because UDS introduces artificial diffusion which stabilizes the solution and typically leads to a more diagonally dominant coefficient matrix, a condition favorable for iterative methods.

5.  **Comparison:** Compare the typical convergence behavior of the Jacobi and Gauss-Seidel methods.
    *   **Answer:** Gauss-Seidel typically converges faster than the Jacobi method because it uses the most recently computed values of variables within the same iteration, effectively incorporating updates more quickly.

## Important Points to Remember

*   **Iterative methods are essential for solving large, sparse systems arising from CFD discretizations.**
*   **Convergence means the approximate solution gets closer to the true solution.**
*   **Convergence is judged using criteria like residual norms or changes in the solution vector.**
*   **Diagonal dominance of the coefficient matrix is a key condition that guarantees convergence for many iterative solvers.**
*   **Discretization schemes heavily influence matrix properties and thus convergence.** UDS is good for convection, CDS for diffusion.
*   **Rate of convergence measures how quickly the error decreases.** Linear convergence ($E_{k+1} \approx r E_k$) is common in CFD.
*   **Lower spectral radius of the iteration matrix leads to faster convergence.**
*   **Factors affecting convergence rate include the solver, discretization, grid, and problem physics (e.g., Peclet number).**
*   **Acceleration techniques (like SOR, multigrid) are often necessary to achieve practical convergence rates.**
*   **Always check convergence plots to ensure the solution is reliable.**
