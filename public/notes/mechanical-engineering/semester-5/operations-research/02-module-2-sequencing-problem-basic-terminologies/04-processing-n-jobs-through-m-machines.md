# Operations Research: Module 2 - Sequencing Problem: Basic Terminologies

## Topic: Processing n Jobs, through m Machines

This module introduces the fundamental concepts of sequencing problems, focusing on optimizing the order in which jobs are processed through a series of machines to minimize the total time taken (makespan) or other relevant objectives. This topic specifically addresses the scenario where we have multiple jobs that need to be processed on multiple machines, with each job requiring processing on each machine in a specific order.

---

### Learning Outcomes:

Upon successful completion of this topic, you will be able to:

*   Understand the basic terminology associated with sequencing problems.
*   Define and explain the components of a sequencing problem (jobs, machines, processing times, sequence).
*   Identify different types of sequencing problems based on the number of jobs and machines.
