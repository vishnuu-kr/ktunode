### Topic: Use Value

### 1. Introduction to Use Value

**Concept:** Use value is a fundamental concept in Value Analysis (VA) and Value Engineering (VE). It refers to the inherent ability of a product, component, or service to perform a specific function or satisfy a particular need. It is essentially about what the item *does*, rather than what it *is*.

**Importance in VA/VE:** The primary goal of VA/VE is to improve the value of a product or service, which is often achieved by optimizing its use value. This means finding ways to perform the required functions more effectively, efficiently, or at a lower cost.

**Alignment with Course Outcomes:**

*   **CO1 (K2):** Understanding the fundamentals of economic issues, including how products and services are designed to meet needs. Use value directly relates to the "purpose" or "functionality" aspect of a product.
*   **CO4 (K3):** Making use of possibilities of value analysis and engineering. Understanding use value is the first step in analyzing and improving value.

**Reference:**
*   **Paneerselvam (2012):** Emphasizes that value is a function of both function and cost, and use value is directly linked to the functional aspect.
*   **Thuesen & Fabrycky (1966):** While an older text, it lays the groundwork for understanding the functional performance of engineering designs, which is the essence of use value.

---

### 2. Defining Use Value

**Key Concepts:**

*   **Function:** The action or purpose a product, component, or service performs. For example, the function of a screw is to fasten two parts. The function of a pen is to write.
*   **Performance:** The quality and efficiency with which a function is carried out. For instance, how smoothly a pen writes, or how strongly a screw holds.
*   **Utility:** The satisfaction or benefit a user derives from the product's function. This is subjective and depends on the user's needs and preferences.

**Formal Definition:**
Use Value = Function / Cost of performing that function.
*However, in the context of VA/VE, it's more nuanced. We often consider:
**Value = Function / Cost**

And Use Value is primarily concerned with the **Function** component.

**Examples:**

*   **A Screwdriver:**
    *   **Primary Use Value:** To tighten or loosen screws.
    *   **Secondary Use Value (related to performance/design):** Ergonomic handle for comfort, magnetic tip to hold the screw.
*   **A Car Headlight:**
    *   **Primary Use Value:** To illuminate the road ahead at night.
    *   **Secondary Use Value:** Durability, resistance to weather, energy efficiency.
*   **A Software Function:**
    *   **Primary Use Value:** To process data, to allow user interaction.
    *   **Secondary Use Value:** Speed of processing, user-friendliness of the interface.

---

### 3. Types of Use Value

**Categorization:** Use values can be broadly categorized to better understand and analyze them.

*   **Primary Use Value (or Basic Function):** This is the essential purpose for which the product or component was designed. It addresses the fundamental need.
    *   **Example:** The primary use value of a chair is to provide a place to sit.
*   **Secondary Use Value (or Aesthetic/Secondary Functions):** These are additional functions or attributes that enhance the product's appeal, usability, or performance but are not strictly essential for its primary purpose.
    *   **Example:** For a chair, secondary use values could include:
        *   Comfort (cushioning)
        *   Appearance (style, color)
        *   Portability (lightweight, foldable)
        *   Durability (strength of materials)

**Importance of Distinction:** Identifying and separating primary from secondary use values is crucial in VA/VE. The focus is often on optimizing the primary use value and questioning the necessity and cost-effectiveness of secondary use values.

**Reference:**
*   **Park (2001):** Often distinguishes between basic functions (primary use value) and secondary functions (secondary use value) when discussing product improvement.

---

### 4. Assessing and Quantifying Use Value

**Challenges:** Quantifying "use value" can be subjective as it often involves user perception and satisfaction. However, in engineering contexts, we try to quantify it through performance metrics.

**Methods of Assessment:**

*   **Performance Metrics:** Defining measurable parameters that indicate how well a function is performed.
    *   **Example:** For a drill bit:
        *   Drilling speed (meters per minute)
        *   Number of holes drilled before dulling
        *   Tolerance of the hole diameter
*   **User Surveys and Feedback:** Gathering input from actual users about their satisfaction with a product's functionality.
    *   **Example:** Asking users to rate the ease of use of a software interface.
*   **Benchmarking:** Comparing the performance of a product's functions against competitors or industry standards.
*   **Functional Analysis:** Breaking down a product into its constituent functions and analyzing each one. This is a core VA/VE technique.

**Quantification Example (Simplified):**

Consider two types of light bulbs:
*   **Bulb A (LED):** 10 Watt, lasts 15,000 hours, costs $5.
*   **Bulb B (Incandescent):** 60 Watt, lasts 1,000 hours, costs $1.

*   **Function:** Provide light.
*   **Performance Metric:** Light output (lumens), Energy consumption (Watts), Lifespan (hours).

Let's simplify by considering "useful life" as a proxy for use value for a given task.

*   **Bulb A:** Offers 15,000 hours of light for $5.
*   **Bulb B:** Offers 1,000 hours of light for $1. To get 15,000 hours, you'd need 15 Bulb Bs, costing $15.

In terms of providing a certain amount of "light-hours" (a measure of its use value for illumination), Bulb A is more cost-effective and provides a better use value.

**Reference:**
*   **Blank & Tarquin (7th Edition):** Discusses performance metrics and evaluation criteria in engineering economics, which are directly applicable to assessing use value.

### 5. Role of Use Value in Value Analysis and Value Engineering

**Core Principle:** Value is maximized when the functions (Use Value) are performed with the least cost.

**How Use Value is Addressed:**

*   **Identifying Essential Functions:** VA/VE begins by clearly defining the basic functions of a product and distinguishing them from secondary functions.
*   **Improving Performance of Functions:** Finding ways to make functions work better, last longer, or be more efficient.
*   **Eliminating Unnecessary Functions:** Questioning the need for certain secondary functions or components that do not contribute significantly to the primary use value.
*   **Achieving Functions with Lower Cost:** Seeking alternative materials, manufacturing processes, or designs that can deliver the same or better use value at a reduced cost.

**The Value Equation:**

**Value = Function / Cost**

*   **To increase Value:**
    1.  Increase Function (Use Value) while keeping Cost constant.
    2.  Decrease Cost while keeping Function (Use Value) constant.
    3.  Increase Function (Use Value) and decrease Cost proportionally more.

**VA/VE Process Steps (where Use Value is paramount):**

1.  **Information Phase:** Understand the product, its functions, costs, and customer needs. This involves detailed analysis of use values.
2.  **Functional Analysis Phase:** Define and categorize all functions, prioritizing basic (use) functions.
3.  **Creative Phase:** Brainstorm alternative ways to achieve the required use values.
4.  **Evaluation Phase:** Analyze the feasibility, cost, and potential value improvement of the brainstormed ideas.
5.  **Development Phase:** Refine the selected ideas into concrete proposals.
6.  **Presentation Phase:** Present the recommendations.
7.  **Implementation Phase:** Put the approved changes into practice.

**Alignment with Course Outcomes:**

*   **CO4 (K3):** This entire section directly addresses how VA/VE utilizes the concept of use value to solve business problems by improving product efficiency and cost-effectiveness.

**Reference:**
*   **Geetika, Ghosh, & Chodhury (2015):** Likely discusses the fundamental principles of VA/VE, including the value equation and the importance of analyzing functions (use value) to reduce costs.
*   **Khan (2011):** While focused on financial systems, it provides the business context for why improving value (through use value optimization) is critical for profitability and competitiveness.

### 6. Examples of Use Value Improvement

**Scenario 1: A Plastic Pen Cap**

*   **Original Design:** A simple cylindrical cap that fits snugly over the pen tip.
    *   **Primary Use Value:** Protects the pen tip from drying out and smudging.
    *   **Secondary Use Value:** Prevents ink from marking clothing if the pen is in a pocket (via a clip).
    *   **Cost:** Standard plastic molding.
*   **Value Analysis Idea:**
    *   **Problem:** The clip breaks easily.
    *   **Alternative Idea:** Redesign the clip to be more robust, perhaps using a slightly more flexible plastic or a different attachment mechanism. This maintains or slightly improves the secondary use value (protection against smudging on clothes) without significantly increasing cost.
    *   **Another Idea:** Eliminate the clip altogether if market research shows most users don't use it or if the cost savings outweigh the loss of the secondary function. This focuses solely on the primary use value (tip protection).

**Scenario 2: A Circuit Board**

*   **Original Design:** A complex circuit board with many discrete components soldered individually.
    *   **Primary Use Value:** Performs the electronic functions required by the device.
    *   **Secondary Use Value:** Reliability, signal integrity.
    *   **Cost:** High labor cost for assembly, potential for soldering defects.
*   **Value Engineering Idea:**
    *   **Alternative Idea:** Replace multiple discrete components with a single integrated circuit (IC) or a surface-mount technology (SMT) assembly.
    *   **Impact on Use Value:** The primary function is still performed, potentially with improved reliability and smaller size.
    *   **Impact on Cost:** Significantly reduces assembly labor and potential for defects, leading to lower overall manufacturing cost for the same or better use value.

**Scenario 3: Packaging Material**

*   **Original Design:** Thick, multi-layered cardboard box with excessive foam inserts.
    *   **Primary Use Value:** Protect the product during transit.
    *   **Secondary Use Value:** Brand presentation, ease of opening.
    *   **Cost:** High material and shipping costs due to weight and volume.
*   **Value Analysis Idea:**
    *   **Alternative Idea:** Analyze the drop-test requirements. Redesign the internal supports using minimal, strategically placed cardboard inserts or molded pulp instead of foam.
    *   **Impact on Use Value:** The product is still adequately protected (primary use value maintained).
    *   **Impact on Cost:** Reduces material cost, shipping cost (due to lighter weight and smaller volume), and potentially waste disposal cost for the customer.

---

### 7. Key Points to Remember

*   **Use Value is about Function:** What does it do? This is the core of use value.
*   **Primary vs. Secondary:** Always differentiate between essential functions and desirable extras. Focus on the primary.
*   **Quantifiable Performance:** Where possible, measure performance metrics to objectively assess use value.
*   **Customer Focus:** Use value is ultimately about meeting customer needs and expectations.
*   **Cost-Benefit:** VA/VE seeks to improve use value *without* proportionally increasing cost, or ideally, by achieving the same use value at a lower cost.
*   **Continuous Improvement:** Understanding use value is a driver for ongoing product and process enhancement.

### 8. Practice Questions and Exercises

**Question 1:**
A company manufactures a handheld electric drill. Identify the primary and secondary use values of this product. What are some potential ways to improve its use value through Value Engineering?

**Answer:**
*   **Primary Use Value:** To create holes in materials (wood, metal, plastic) using a rotating bit.
*   **Secondary Use Values:**
    *   User comfort (ergonomic grip, low vibration).
    *   Durability and longevity of the motor and casing.
    *   Safety features (e.g., safety clutch, double insulation).
    *   Portability and ease of handling (weight, cord length).
    *   Variable speed control for different materials.
*   **VE Improvement Ideas:**
    *   **Improve Primary Function:** Develop a more efficient motor or gear system for faster drilling or less power consumption.
    *   **Enhance Secondary Function (Comfort):** Use advanced ergonomic materials for the grip, or incorporate vibration-dampening technology.
    *   **Reduce Cost for Same Use Value:** Source lighter but equally durable materials for the casing. Redesign the internal cooling system for better efficiency, allowing for a smaller motor that still performs the primary function.
    *   **Eliminate Unnecessary Function:** If a specific variable speed setting is rarely used by the target market, it might be removed to simplify design and reduce cost.

**Question 2:**
Consider a standard coffee mug.
a) What is its primary use value?
b) List three secondary use values.
c) If the cost of manufacturing a mug increases due to a rise in ceramic prices, how could a manufacturer maintain or improve its overall *value* by focusing on its use values?

**Answer:**
a) **Primary Use Value:** To hold and serve a hot beverage (like coffee or tea) to a user.
b) **Secondary Use Values:**
    *   Thermal insulation (keeping the beverage hot for longer).
    *   Comfortable grip (handle design).
    *   Aesthetics (design, color, decoration).
    *   Durability (resistance to chipping or breaking).
    *   Microwave/dishwasher safety.
c) To maintain or improve value (Value = Function/Cost) when ceramic costs rise (Cost increases):
    *   **Focus on Enhancing Primary Use Value:** Develop a mug with superior thermal insulation properties (e.g., double-walled construction, better ceramic formulation) so it holds heat much longer. This enhances the core function, justifying a potential price increase or maintaining perceived value.
    *   **Optimize Secondary Use Values:**
        *   Improve the handle design for significantly better ergonomics and comfort, making it a more pleasant user experience.
        *   Introduce a highly durable glaze that resists chipping and scratching, increasing the mug's lifespan and perceived quality.
        *   Offer unique, artist-designed patterns that appeal to a specific market segment, increasing perceived aesthetic value.
    *   **Cost Reduction Strategies (Without Sacrificing Essential Use Value):**
        *   Streamline the manufacturing process to reduce waste.
        *   Use slightly smaller, but still functional, handles if ergonomic studies show this doesn't significantly impact comfort for the majority of users.
        *   Source components (like lids, if applicable) from lower-cost suppliers without compromising quality.

**Question 3:**
In Value Analysis, what is the significance of the "Use Value" in relation to the "Cost Value"? Explain using the value equation.

**Answer:**
The significance of "Use Value" in relation to "Cost Value" is central to the concept of Value Analysis. The core objective of Value Analysis is to maximize **Value**, which is fundamentally defined by the relationship between the functions a product performs (Use Value) and the resources expended to perform those functions (Cost Value).

The common value equation used in VA is:

**Value = Use Value / Cost Value**

Or more broadly:

**Value = Function / Cost**

*   **Use Value (Function):** Represents the utility, performance, and benefit derived from a product or service. It answers the question: "What does it do?" and "How well does it do it?"
*   **Cost Value:** Represents the total cost incurred in producing or delivering that function, including materials, labor, overhead, etc.

**Significance:**

1.  **Focus on Functionality:** The equation highlights that the primary driver of value is the **function** or **use value**. A product with high functionality but also high cost might have poor value. Conversely, a product with simple functionality but very low cost might also have poor value if it doesn't meet the user's needs.
2.  **Cost Reduction Target:** Value Analysis aims to achieve the same or better **Use Value** at a **lower Cost Value**. This means engineers and analysts scrutinize every aspect of the product's design and manufacturing to find cost savings without compromising the essential functions.
3.  **Identifying Opportunities:** By dissecting the product into its functions and analyzing the cost associated with each function, VA can reveal areas where:
    *   Functions are over-engineered (higher cost than necessary for the use value provided).
    *   Functions are not essential and can be eliminated.
    *   Functions can be performed more efficiently or by alternative, lower-cost means.
4.  **Maximizing ROI:** Ultimately, improving the Value (by enhancing Use Value or reducing Cost Value) leads to increased profitability, customer satisfaction, and competitive advantage.

For instance, a simple screwdriver has a high use value for tightening screws. If it's made from cheap, non-ergonomic plastic and is poorly manufactured (high cost relative to its function), its overall value is low. A VE approach might find a way to use slightly better, but still cost-effective, materials and a more efficient manufacturing process to produce a more comfortable and durable screwdriver (improved use value, or same use value at lower cost), thus significantly increasing its overall value.
