# Module 4: Frequency Domain Analysis - Polar Plot

## Introduction to Control Systems

---

### **1. Overview**

This module delves into the **frequency domain analysis** of control systems, a crucial technique for understanding system behavior under sinusoidal inputs. We will explore various frequency response plots, with a focus on **Polar Plots**. These plots provide valuable insights into system stability and performance by visualizing the system's gain and phase shift as a function of frequency.

### **4. Key Concepts and Definitions**

#### **4.1. Frequency Response**

*   **Definition:** The frequency response of a linear time-invariant (LTI) system describes how the system's output sinusoidal signal varies in amplitude and phase relative to the input sinusoidal signal when subjected to a sinusoidal input.
*   **Sinusoidal Input:** Assume the input to an LTI system is $r(t) = A \sin(\omega t)$.
*   **Steady-State Output:** For a stable LTI system, the steady-state output will also be a sinusoid of the same frequency, but with a different amplitude and phase: $c(t) = B \sin(\omega t + \phi)$.
*   **Transfer Function in Frequency Domain:** If the system's transfer function is $G(s)$, its frequency response is obtained by substituting $s = j\omega$, where $\omega$ is the angular frequency. So, $G(j\omega)$ represents the frequency response.
*   **Complex Representation:** $G(j\omega)$ is a complex number, which can be expressed in polar form: $G(j\omega) = |G(j\omega)| e^{j\angle G(j\omega)}$.
    *   $|G(j\omega)|$: Magnitude of the frequency response, representing the gain.
    *   $\angle G(j\omega)$: Phase angle of the frequency response, representing the phase shift.

#### **4.2. Polar Plot**

*   **Definition:** A polar plot is a graphical representation of the frequency response of an LTI system. It is plotted on polar coordinates, where the magnitude $|G(j\omega)|$ is the radial distance from the origin, and the phase angle $\angle G(j\omega)$ is the angle with respect to the positive real axis.
*   **Plotting:** As the frequency $\omega$ varies from $0$ to $\infty$, the complex number $G(j\omega)$ traces a curve in the complex plane. This curve is the polar plot.
*   **Axes:**
    *   **Real Axis:** Represents the real part of $G(j\omega)$.
    *   **Imaginary Axis:** Represents the imaginary part of $G(j\omega)$.
    *   **Magnitude:** The distance from the origin to a point on the curve.
    *   **Phase Angle:** The angle of the line segment from the origin to the point on the curve, measured counterclockwise from the positive real axis.
*   **Parametric Representation:** The polar plot is typically generated by varying $\omega$ from $0$ to $\infty$ and plotting $|G(j\omega)|$ against $\angle G(j\omega)$.

### **5. Constructing Polar Plots**

To construct a polar plot for a given open-loop transfer function $G(j\omega)H(j\omega) = K \frac{\prod(j\omega + z_i)}{\prod(j\omega + p_j)}$, we follow these steps:

1.  **Find the Frequency Response:** Substitute $s = j\omega$ into the transfer function: $G(j\omega)H(j\omega)$.
2.  **Calculate Magnitude and Phase:**
    *   $|G(j\omega)H(j\omega)| = K \frac{\prod |j\omega + z_i|}{\prod |j\omega + p_j|}$
    *   $\angle G(j\omega)H(j\omega) = \sum \angle (j\omega + z_i) - \sum \angle (j\omega + p_j)$
    *   Recall: $|j\omega + a| = \sqrt{\omega^2 + a^2}$ and $\angle (j\omega + a) = \tan^{-1}(\omega/a)$ (for $a>0$).
3.  **Determine Key Frequencies:**
    *   **$\omega = 0$:** This usually gives the starting point of the polar plot.
    *   **$\omega = \infty$:** This usually gives the ending point of the polar plot.
    *   **Corner Frequencies:** Frequencies where poles or zeros are located (i.e., $\omega = |a|$ for terms like $(j\omega+a)$). These are important for observing changes in the slope of the plot.
    *   **Gain Crossover Frequency ($\omega_{gc}$):** The frequency at which the magnitude $|G(j\omega)H(j\omega)| = 1$.
    *   **Phase Crossover Frequency ($\omega_{pc}$):** The frequency at which the phase angle $\angle G(j\omega)H(j\omega) = -180^\circ$. This is crucial for stability analysis.
4.  **Trace the Plot:**
    *   Calculate $|G(j\omega)|$ and $\angle G(j\omega)$ for various frequencies $\omega$ from $0$ to $\infty$.
    *   Plot these magnitude-phase pairs on polar graph paper or using software.
    *   Connect the points with a smooth curve.
    *   Indicate the direction of increasing frequency on the plot with arrows.

#### **5.1. Special Cases and Behavior**

*   **Gain:** The magnitude $|G(j\omega)|$ starts at some value at $\omega=0$ and typically decreases as $\omega$ increases (for minimum phase systems with poles).
*   **Phase:** The phase angle $\angle G(j\omega)$ starts at some value at $\omega=0$ and typically becomes more negative as $\omega$ increases.
*   **Intercepts:**
    *   **Real Axis Intercept:** Occurs when the imaginary part of $G(j\omega)$ is zero.
    *   **Imaginary Axis Intercept:** Occurs when the real part of $G(j\omega)$ is zero.

#### **5.2. Example 1: $G(s)H(s) = \frac{K}{s+a}$ (with $a > 0$)**

1.  **Frequency Response:** $G(j\omega)H(j\omega) = \frac{K}{j\omega+a}$
2.  **Magnitude and Phase:**
    *   $|G(j\omega)H(j\omega)| = \frac{K}{\sqrt{\omega^2+a^2}}$
    *   $\angle G(j\omega)H(j\omega) = -\tan^{-1}(\omega/a)$
3.  **Key Frequencies:**
    *   $\omega = 0$: $|G(j0)H(j0)| = K/a$, $\angle G(j0)H(j0) = 0^\circ$.
    *   $\omega = \infty$: $|G(j\infty)H(j\infty)| = 0$, $\angle G(j\infty)H(j\infty) = -90^\circ$.
    *   Corner Frequency: $\omega = a$. At $\omega=a$, $|G(ja)H(ja)| = \frac{K}{\sqrt{a^2+a^2}} = \frac{K}{a\sqrt{2}}$, $\angle G(ja)H(ja) = -\tan^{-1}(a/a) = -45^\circ$.

**Plotting:**

*   Start at $(K/a, 0^\circ)$ on the real axis at $\omega=0$.
*   End at the origin $(0, -90^\circ)$ at $\omega=\infty$.
*   The plot is a semicircle in the fourth quadrant.

*(Refer to Nise, 5th Ed., Chapter 6 for detailed graphical methods and examples of polar plots for simple systems.)*

#### **5.3. Example 2: $G(s)H(s) = \frac{K}{(s+a)(s+b)}$ (with $a, b > 0$)**

1.  **Frequency Response:** $G(j\omega)H(j\omega) = \frac{K}{(j\omega+a)(j\omega+b)}$
2.  **Magnitude and Phase:**
    *   $|G(j\omega)H(j\omega)| = \frac{K}{\sqrt{\omega^2+a^2}\sqrt{\omega^2+b^2}}$
    *   $\angle G(j\omega)H(j\omega) = -\tan^{-1}(\omega/a) - \tan^{-1}(\omega/b)$
3.  **Key Frequencies:**
    *   $\omega = 0$: $|G(j0)H(j0)| = K/(ab)$, $\angle G(j0)H(j0) = 0^\circ$.
    *   $\omega = \infty$: $|G(j\infty)H(j\infty)| = 0$, $\angle G(j\infty)H(j\infty) = -180^\circ$.
    *   Corner Frequencies: $\omega = a$ and $\omega = b$.

**Plotting:**

*   Start at $(K/(ab), 0^\circ)$ at $\omega=0$.
*   End at the origin $(0, -180^\circ)$ at $\omega=\infty$.
*   The plot will be in the third and fourth quadrants. The shape depends on the relative values of $a$ and $b$.

*(Nagrath & Gopal, 5th Ed., Chapter 7 provides detailed derivations and graphical constructions for more complex transfer functions.)*

#### **5.4. Effect of Gain K**

*   The gain $K$ in the transfer function $G(s)H(s)$ scales the magnitude $|G(j\omega)H(j\omega)|$ at all frequencies.
*   Increasing $K$ expands the polar plot away from the origin.
*   Decreasing $K$ shrinks the polar plot towards the origin.
*   The phase angle $\angle G(j\omega)H(j\omega)$ is *unaffected* by the gain $K$.

#### **5.5. Effect of Pole-Zero Cancellation and Addition**

*   **Adding a Pole:** Generally moves the polar plot further away from the origin and introduces a further negative phase shift.
*   **Adding a Zero:** Generally pulls the polar plot closer to the origin and reduces the total negative phase shift.

### **6. Stability Analysis using Polar Plots (Nyquist Stability Criterion)**

While this module focuses on the polar plot itself, it's essential to understand its application in stability analysis, which is the foundation of the Nyquist criterion.

#### **6.1. Nyquist Criterion**

The Nyquist stability criterion relates the number of poles of the closed-loop system in the RHP to the number of encirclements of the $-1+j0$ point in the polar plot of the open-loop transfer function $G(j\omega)H(j\omega)$.

*   **The $-1+j0$ Point:** This is a critical point on the polar plot.
*   **Encirclements:** We count the number of times the polar plot encircles the $-1+j0$ point in a *counter-clockwise* direction.
*   **Nyquist Theorem:** For a system with an open-loop transfer function $G(s)H(s)$ that is rational and has $P$ poles in the RHP, the number of roots of the characteristic equation $1 + G(s)H(s) = 0$ in the RHP (i.e., the number of unstable closed-loop poles) is given by $N = P - E$, where $E$ is the number of counter-clockwise encirclements of the $-1+j0$ point by the polar plot of $G(s)H(s)$.
*   **Stability Condition:** For a stable closed-loop system, $N$ must be zero. This implies that the polar plot of $G(s)H(s)$ must not encircle the $-1+j0$ point ($N=0$, so $E=P$).

#### **6.2. Gain Margin and Phase Margin from Polar Plots**

*   **Gain Margin ($GM$):** The factor by which the open-loop gain can be increased before the closed-loop system becomes unstable.
    *   It is related to the intercept of the polar plot with the negative real axis.
    *   If the polar plot intersects the negative real axis at $-K_{pc}$ (where $K_{pc}$ is the magnitude of the real intercept), then the gain margin is $GM = 20 \log_{10} (1/K_{pc})$ dB or $GM = 1/K_{pc}$ (in ratio).
    *   If the plot does not intersect the negative real axis, the gain margin is infinite.
*   **Phase Margin ($\phi_m$):** The amount of additional phase lag that can be introduced into the system at the gain crossover frequency ($\omega_{gc}$, where $|G(j\omega_{gc})H(j\omega_{gc})| = 1$) before the closed-loop system becomes unstable.
    *   If the polar plot intersects the unit circle ($|G(j\omega)H(j\omega)| = 1$) at a phase angle of $-\theta_{gc}$, then the phase margin is $\phi_m = 180^\circ - \theta_{gc}$.

*(Nise, 5th Ed., Chapter 6 and Nagrath & Gopal, 5th Ed., Chapter 7 provide detailed explanations and graphical methods for determining GM and PM from polar plots.)*

---

### **7. Relationship with Other Frequency Domain Techniques**

*   **Bode Plot:** Bode plots (magnitude and phase vs. log frequency) and polar plots represent the same frequency response information.
    *   A point on the polar plot $(|G(j\omega)|, \angle G(j\omega))$ corresponds to a point on the Bode plot with magnitude $|G(j\omega)|$ (in dB) and phase $\angle G(j\omega)$ at frequency $\omega$.
    *   Polar plots are useful for visualizing the encirclements of the $-1+j0$ point, directly leading to Nyquist stability. Bode plots are generally easier to construct by hand using asymptotic approximations.
*   **Nyquist Plot:** The term "Nyquist plot" is often used interchangeably with "polar plot" when referring to the plot of $G(j\omega)H(j\omega)$ for the purpose of stability analysis.

*(Kuo, 9th Ed., Chapter 9 and Ogata, 5th Ed., Chapter 9 cover the comparison and conversion between these frequency domain plots.)*

### **8. Practice Questions and Exercises**

**Question 1:**
Sketch the polar plot for the open-loop transfer function $G(s)H(s) = \frac{10}{s(s+1)}$. Determine the gain and phase margins from the sketch.

**Solution:**
1.  **Frequency Response:** $G(j\omega)H(j\omega) = \frac{10}{j\omega(j\omega+1)}$
2.  **Magnitude and Phase:**
    *   $|G(j\omega)H(j\omega)| = \frac{10}{\omega\sqrt{\omega^2+1}}$
    *   $\angle G(j\omega)H(j\omega) = -90^\circ - \tan^{-1}(\omega)$
3.  **Key Points:**
    *   $\omega = 0$: $|G(j0)H(j0)| \to \infty$, $\angle G(j0)H(j0) = -90^\circ$. (Starts on the negative imaginary axis).
    *   $\omega = \infty$: $|G(j\infty)H(j\infty)| = 0$, $\angle G(j\infty)H(j\infty) = -90^\circ - 90^\circ = -180^\circ$. (Ends at the origin, approaching from the negative real axis).
    *   Corner Frequency: $\omega = 1$. At $\omega=1$, $|G(j1)H(j1)| = \frac{10}{1\sqrt{1^2+1}} = \frac{10}{\sqrt{2}} \approx 7.07$, $\angle G(j1)H(j1) = -90^\circ - \tan^{-1}(1) = -90^\circ - 45^\circ = -135^\circ$.
4.  **Plotting:**
    *   The plot starts at infinity on the negative imaginary axis and ends at the origin on the negative real axis.
    *   It will be a curve in the third and fourth quadrants.
    *   To find gain and phase margins, we need to check for intercepts with the unit circle and the negative real axis.
    *   **Phase Crossover Frequency ($\omega_{pc}$):** When phase is $-180^\circ$. For this function, the phase is always between $-90^\circ$ and $-180^\circ$. It never reaches $-180^\circ$ before $\omega \to \infty$. So $\omega_{pc} = \infty$.
    *   **Gain Crossover Frequency ($\omega_{gc}$):** When magnitude is 1.
        $\frac{10}{\omega\sqrt{\omega^2+1}} = 1$
        $100 = \omega^2(\omega^2+1)$
        Let $x = \omega^2$. $x(x+1) = 100 \implies x^2 + x - 100 = 0$.
        $x = \frac{-1 \pm \sqrt{1 - 4(1)(-100)}}{2} = \frac{-1 \pm \sqrt{401}}{2}$.
        Since $x = \omega^2 > 0$, we take the positive root: $\omega^2 = \frac{-1 + \sqrt{401}}{2} \approx \frac{-1 + 20.02}{2} \approx 9.51$.
        So, $\omega_{gc} = \sqrt{9.51} \approx 3.08$ rad/sec.
    *   **Phase Margin:** At $\omega_{gc} \approx 3.08$, phase angle is $\angle G(j3.08)H(j3.08) = -90^\circ - \tan^{-1}(3.08) \approx -90^\circ - 72^\circ = -162^\circ$.
        Phase Margin $\phi_m = 180^\circ - 162^\circ = 18^\circ$.
    *   **Gain Margin:** The plot does not intersect the negative real axis for finite $\omega$. The phase only reaches $-180^\circ$ at $\omega \to \infty$. Thus, the gain margin is infinite.

*(The sketch would show a curve starting on the negative imaginary axis, curving through a point like (-135 deg, 7.07) at $\omega=1$, and approaching the origin from the negative real axis. The point where the curve crosses the unit circle is at $\omega_{gc} \approx 3.08$. The angle at this point is $-162^\circ$. The intersection with the negative real axis for the Nyquist stability criterion would occur if the phase reached $-180^\circ$ for some finite $\omega$, which it does not.)*

**Question 2:**
For the transfer function $G(s)H(s) = \frac{1}{(s+1)(s+2)}$, determine the frequency at which the polar plot intersects the unit circle.

**Solution:**
1.  **Frequency Response:** $G(j\omega)H(j\omega) = \frac{1}{(j\omega+1)(j\omega+2)}$
2.  **Magnitude:** $|G(j\omega)H(j\omega)| = \frac{1}{\sqrt{\omega^2+1}\sqrt{\omega^2+4}}$
3.  **Intersection with Unit Circle:** Set magnitude to 1:
    $\frac{1}{\sqrt{\omega^2+1}\sqrt{\omega^2+4}} = 1$
    $\sqrt{(\omega^2+1)(\omega^2+4)} = 1$
    $(\omega^2+1)(\omega^2+4) = 1$
    $\omega^4 + 5\omega^2 + 4 = 1$
    $\omega^4 + 5\omega^2 + 3 = 0$
    Let $x = \omega^2$.
    $x^2 + 5x + 3 = 0$
    $x = \frac{-5 \pm \sqrt{5^2 - 4(1)(3)}}{2} = \frac{-5 \pm \sqrt{25 - 12}}{2} = \frac{-5 \pm \sqrt{13}}{2}$
    Since $x = \omega^2$ must be positive, we have no real solution for $\omega$. This means the polar plot for this specific transfer function never intersects the unit circle for any real frequency $\omega$.

*(Note: This result implies that the gain crossover frequency is either 0 or infinity. Let's check the limits: at $\omega=0$, magnitude is $1/(1*2)=0.5$. As $\omega \to \infty$, magnitude goes to 0. Since the magnitude starts at 0.5 and decreases to 0, it never reaches 1.)*

### **9. Important Points to Remember**

*   **Polar plots visualize $|G(j\omega)|$ vs. $\angle G(j\omega)$**.
*   **$\omega$ varies from $0$ to $\infty$**.
*   **Start and end points are critical**: $\omega=0$ and $\omega=\infty$ determine the plot's origin and termination.
*   **The $-1+j0$ point is the stability benchmark**. Encirclements indicate instability.
*   **Gain margin and phase margin** can be directly estimated from the polar plot.
*   **Systematic construction** involves calculating magnitude and phase at key frequencies.
*   **Polar plots provide a geometric interpretation of the Nyquist stability criterion**.
