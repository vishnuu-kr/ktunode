### 1. Introduction to Switch Mode DC-AC Voltage Source Inverters (VSIs)

**Definition:** A Voltage Source Inverter (VSI) is a power electronic converter that converts a DC voltage source into an AC voltage output. The DC source is assumed to be a stiff voltage source (e.g., a battery, a DC link from a rectifier). The AC output voltage is synthesized by switching power semiconductor devices (like IGBTs, MOSFETs) at high frequencies.

**Key Concept:** The AC output voltage is generated by selectively connecting and disconnecting the load to the DC source through switches. By controlling the switching instants and durations, the desired AC waveform can be achieved.

**Applications:**
*   Uninterruptible Power Supplies (UPS)
*   Variable Frequency Drives (VFDs) for AC motors
*   Renewable energy systems (solar inverters, wind turbine converters)
*   Static var compensators (SVCs)
*   AC voltage regulators

### 2. Single Phase Half-Bridge and Full-Bridge Configurations

#### 2.1 Single-Phase Half-Bridge Inverter

**Configuration:**
*   Consists of two switches (e.g., IGBTs with anti-parallel diodes) and two capacitors.
*   The DC source is split into two equal voltages by the series capacitors.
*   The output is taken from the midpoint of the DC link.

**Circuit Diagram:**

```
      + Vdc/2 ---- S1 ----
                   |
                   |
  Output ----o----
                   |
                   |
      - Vdc/2 ---- S2 ----
```

*   Where `S1` and `S2` are switching devices.
*   The capacitors (`C1`, `C2`) split the DC link. `V_C1 = V_C2 = Vdc/2`.

**Operation:**
*   **When S1 is ON and S2 is OFF:** The output voltage is connected to the positive DC link terminal. Output voltage `v_o = +Vdc/2`.
*   **When S1 is OFF and S2 is ON:** The output voltage is connected to the negative DC link terminal. Output voltage `v_o = -Vdc/2`.
*   By switching `S1` and `S2` appropriately, a bipolar square wave output voltage can be generated.

**Merits:**
*   Simpler control circuit.
*   Requires fewer switching devices.

**Demerits:**
*   **Lower output voltage:** The peak output voltage is half of the DC link voltage.
*   **Requires a split DC source:** The DC source must be able to provide equal voltages across the capacitors.
*   **Capacitor voltage balancing:** Maintaining equal voltages across capacitors can be challenging under unbalanced loads.

#### 2.2 Single-Phase Full-Bridge Inverter

**Configuration:**
*   Consists of four switches (e.g., IGBTs with anti-parallel diodes) arranged in a bridge configuration.
*   The DC source is connected across the entire DC link.
*   The output is taken across two diagonally opposite switches.

**Circuit Diagram:**

```
      + Vdc ---- S1 ----
                   |      |
                   |      |
  Output ----o-----      -----o----
                   |      |
                   |      |
      - Vdc ---- S3 ----
```

*   The complementary switch pairs are (S1, S3) and (S2, S4).
*   When S1 and S4 are ON, the load is connected across Vdc.
*   When S2 and S3 are ON, the load is connected across -Vdc.

**Operation:**
*   **Switching Pair 1 (S1 ON, S4 ON; S2 OFF, S3 OFF):** The load is connected across the DC source in one polarity. Output voltage `v_o = +Vdc`.
*   **Switching Pair 2 (S2 ON, S3 ON; S1 OFF, S4 OFF):** The load is connected across the DC source in the opposite polarity. Output voltage `v_o = -Vdc`.
*   By switching between these pairs, a bipolar square wave output voltage can be generated.

**Merits:**
*   **Higher output voltage:** The peak output voltage is equal to the DC link voltage.
*   **Does not require a split DC source:** Can be used with a single DC source.
*   Provides full utilization of the DC voltage.

**Demerits:**
*   Requires more switching devices.
*   More complex control.

**Important Point:** For generating AC waveforms using PWM, the full-bridge inverter is generally preferred due to its higher output voltage capability and simpler DC source requirement.

### 3. Sinusoidal Pulse Width Modulation (PWM)

**Concept:** Sinusoidal PWM (SPWM) is a popular technique used to synthesize AC voltage waveforms from a DC source using VSIs. It involves comparing a sinusoidal reference waveform with a high-frequency triangular carrier wave.

**How it works:**
1.  **Reference Signal:** A sinusoidal voltage signal `v_ref(t)` representing the desired output waveform (magnitude and frequency) is generated.
2.  **Carrier Signal:** A high-frequency triangular or sawtooth waveform `v_tri(t)` is generated. The frequency of this carrier wave determines the switching frequency of the inverter.
3.  **Comparison:** The reference signal is compared with the carrier signal.
4.  **Switching Pulses:**
    *   When `v_ref(t) > v_tri(t)`, the upper switches (e.g., S1, S4) are turned ON.
    *   When `v_ref(t) < v_tri(t)`, the lower switches (e.g., S3, S2) are turned ON.
    *   For a full-bridge inverter, the switching logic for one leg (e.g., S1 and S3) is determined by comparing `v_ref(t)` with `v_tri(t)`. The other leg's switching is complementary (or appropriately phased).

**Circuit for SPWM Generation (Conceptual):**

```
       Sinusoidal Reference (v_ref) ------| Comparator |------ Gate Pulse 1
                                          |            |
       Triangular Carrier (v_tri) --------|            |------ Gate Pulse 2 (Complementary)
```

**Example:**
Consider a sinusoidal reference voltage `v_ref(t) = A_ref * sin(ω_ref * t)` and a triangular carrier `v_tri(t)` with amplitude `A_tri`.
*   If `A_ref * sin(ω_ref * t) > v_tri(t)`, turn ON the switch connected to the positive DC link.
*   If `A_ref * sin(ω_ref * t) < v_tri(t)`, turn ON the switch connected to the negative DC link.

**Key Parameters:**
*   **Modulating Index (M_a):** Ratio of the amplitude of the reference voltage to the amplitude of the carrier voltage. `M_a = A_ref / A_tri`. This controls the magnitude of the fundamental output voltage.
*   **Switching Frequency (f_s):** Frequency of the carrier wave. Determines the rate at which the switches are turned ON and OFF.
*   **Output Frequency (f_o):** Frequency of the fundamental component of the output voltage. This is determined by the frequency of the reference signal.

### 4. Control of Fundamental Output Voltage

**How SPWM Controls the Fundamental Output Voltage:**
The amplitude of the fundamental component of the inverter output voltage is directly proportional to the modulating index (`M_a`).

*   **Adjusting `M_a`:** By varying the amplitude of the sinusoidal reference voltage (`A_ref`) while keeping the carrier amplitude (`A_tri`) constant, the fundamental output voltage can be controlled.
*   **Range of `M_a`:**
    *   **Linear Modulation:** For `M_a <= 1`, the fundamental output voltage is linearly proportional to `M_a`. The output waveform is a modified sine wave with high-frequency switching pulses.
    *   **Over-Modulation:** For `M_a > 1`, the sinusoidal reference voltage exceeds the carrier amplitude for a portion of the cycle. This leads to distorted output waveforms but can increase the fundamental output voltage.
    *   **Square Wave Mode:** When `M_a` is sufficiently large (effectively `M_a > 1` and the reference signal clips the carrier), the output waveform approaches a bipolar square wave, offering the maximum possible fundamental output voltage.

**Relationship between `M_a` and Fundamental Output Voltage:**
For a full-bridge inverter with DC link voltage `Vdc`:
*   In the linear region (`M_a <= 1`), the fundamental component of the output voltage is approximately `v_o1(t) ≈ (M_a * Vdc / 2) * sin(ω_ref * t)`.
*   The peak fundamental output voltage is `V_o1_peak = M_a * Vdc / 2`.
*   The RMS fundamental output voltage is `V_o1_rms = (M_a * Vdc) / (2 * sqrt(2))`.

**Important Point:** Controlling the amplitude of the sinusoidal reference voltage is the primary method for regulating the fundamental output voltage of the inverter.

### 5. Harmonic Spectrum

**Problem:** The switching process in VSIs inherently generates numerous harmonics in the output voltage and current waveforms. These harmonics can:
*   Cause increased heating in the load (e.g., motor windings).
*   Lead to electromagnetic interference (EMI).
*   Reduce the efficiency of the system.
*   Distort the desired AC waveform.

**Harmonic Spectrum in SPWM:**
*   SPWM is designed to push the harmonics to high frequencies, specifically around the switching frequency (`f_s`) and its multiples.
*   The fundamental component is at `f_o`.
*   Harmonics are also present at `f_s ± n * f_o` (where `n` is an integer) and `n * f_s`.
*   In linear modulation (`M_a <= 1`), the dominant harmonics are typically around the switching frequency. The lower-order harmonics are significantly reduced compared to simple square wave or trapezoidal modulation.

**Harmonic Reduction Techniques:**
*   **High Switching Frequency:** Increasing `f_s` shifts the dominant harmonics to higher frequencies, which are easier to filter. However, this increases switching losses.
*   **Carrier-Based PWM Variations:** Modified carrier waveforms or reference signals can be used to further reduce specific harmonics.
*   **Space Vector Modulation (SVM):** (More relevant for three-phase inverters, but conceptually applicable) A more advanced modulation technique that provides better harmonic control and utilization of the DC bus.
*   **Output Filters:** Low-pass filters (LC filters) can be placed at the output of the inverter to remove the high-frequency switching components, leaving a cleaner sinusoidal waveform.

**Important Point:** SPWM effectively shifts most of the harmonic energy to frequencies around the switching frequency, making it easier to filter and resulting in a lower total harmonic distortion (THD) compared to simpler PWM schemes.

### 6. Bipolar and Unipolar PWM

These refer to the switching patterns of the power devices, primarily in relation to the polarity of the output voltage.

#### 6.1 Bipolar PWM

**Concept:** In bipolar PWM, both switches in a leg of the inverter are switched ON and OFF to connect the output to either the positive or negative DC link terminals. The load is always connected across the entire DC link.

**Switching Pattern (Full-Bridge Example):**
*   **State 1:** S1 and S4 ON (positive voltage across load). `v_o = +Vdc`.
*   **State 2:** S2 and S3 ON (negative voltage across load). `v_o = -Vdc`.
*   The switching decisions are made by comparing the reference and carrier signals for each leg independently.

**SPWM Implementation (Bipolar):**
For a full-bridge inverter generating a single-phase output using SPWM:
*   **Leg 1 (S1, S3):** S1 is ON when `v_ref > v_tri`. S3 is ON when `v_ref < v_tri`.
*   **Leg 2 (S2, S4):** S2 is ON when `-v_ref > v_tri`. S4 is ON when `-v_ref < v_tri`. (Or, S2 and S3 are complementary to S1 and S4 respectively if the reference is applied to both legs with appropriate phasing).

A more common bipolar implementation for single phase:
*   **Leg 1 (S1, S3):** S1 is ON when `v_ref > v_tri`. S3 is ON when `v_ref < v_tri`.
*   **Leg 2 (S2, S4):** S4 is ON when `v_ref > v_tri`. S2 is ON when `v_ref < v_tri`. (This means S4 is always ON when S1 is ON, and S2 is always ON when S3 is ON).
    *   This results in the output switching between `+Vdc` and `-Vdc`.

**Merits:**
*   Simpler logic for generating switching signals.
*   Efficient use of the DC bus voltage.

**Demerits:**
*   **Higher switching losses:** Both switches in a leg are switched when the output polarity changes.
*   **Higher dv/dt across switches:** When one switch turns OFF and the other turns ON, the voltage across the output capacitor/load can change rapidly.

#### 6.2 Unipolar PWM

**Concept:** In unipolar PWM, one leg of the inverter is switched to connect the output to either the positive or negative DC link, while the other leg remains in a defined state or is switched to ensure the output polarity. The goal is to reduce switching losses by reducing the number of commutations per cycle.

**Switching Pattern (Full-Bridge Example - One common approach):**
*   **When `v_ref` is positive:**
    *   Connect the load to `+Vdc` (e.g., S1 ON, S4 ON).
    *   To create PWM, one leg is switched using SPWM (e.g., S1 ON/OFF based on `v_ref` vs `v_tri`). The other leg ensures the return path (e.g., S4 remains ON, S3 remains OFF).
*   **When `v_ref` is negative:**
    *   Connect the load to `-Vdc` (e.g., S2 ON, S3 ON).
    *   To create PWM, one leg is switched using SPWM (e.g., S3 ON/OFF based on `-v_ref` vs `v_tri`). The other leg ensures the return path (e.g., S2 remains ON, S4 remains OFF).

**A more practical Unipolar SPWM:**
*   **Positive half-cycle of `v_ref`:**
    *   Leg 1 (S1, S3): S1 ON when `v_ref > v_tri`, S3 ON when `v_ref < v_tri`.
    *   Leg 2 (S2, S4): S4 remains ON, S3 remains OFF (or complementary to S1). This results in `v_o = +Vdc` when S1 is ON and `v_o = 0` when S1 is OFF (assuming the other leg switches appropriately to return).
    *   This is a common way to achieve unipolar switching.
*   **Negative half-cycle of `v_ref`:**
    *   Leg 1 (S1, S3): S1 remains ON, S3 remains OFF.
    *   Leg 2 (S2, S4): S4 ON when `-v_ref > v_tri`, S2 ON when `-v_ref < v_tri`.
    *   This results in `v_o = -Vdc` when S4 is ON and `v_o = 0` when S4 is OFF.

**Another Common Unipolar Scheme:**
*   **When `v_ref` is positive and switching:** Leg 1 (S1, S3) switches. Leg 2 (S2, S4) is kept such that S4 is ON and S3 is OFF. So, output is `+Vdc` or `0`.
*   **When `v_ref` is negative and switching:** Leg 2 (S2, S4) switches. Leg 1 (S1, S3) is kept such that S1 is ON and S4 is OFF. So, output is `-Vdc` or `0`.

**Merits:**
*   **Reduced switching losses:** Only one switch in a leg needs to be commutated during a PWM cycle (in some schemes), reducing switching frequency for the devices.
*   **Lower EMI:** Reduced high dv/dt transitions.

**Demerits:**
*   **Requires more complex switching logic:** The switching decisions depend on the sign of the reference signal and the comparison with the carrier.
*   **Output voltage can be unipolar in some modes:** This means the output is `+Vdc`, `0`, or `-Vdc`. While this reduces harmonics, it can also introduce zero-voltage states.

**Important Point:** Unipolar PWM aims to reduce switching losses by ensuring that only one switch in each leg transitions during a PWM cycle for a significant portion of the time.

### 7. Linear, Over Modulation and Square Wave Modes

These modes describe the behavior of the VSI as the modulating index (`M_a`) is increased.

#### 7.1 Linear Mode (`M_a <= 1`)

*   **Description:** The amplitude of the sinusoidal reference voltage is less than or equal to the amplitude of the triangular carrier voltage.
*   **Output Voltage:** The output waveform is a quasi-sinusoidal waveform, where the duty cycle of the switching pulses varies sinusoidally. The fundamental component of the output voltage is directly proportional to `M_a`.
*   **Harmonics:** Harmonics are primarily concentrated around the switching frequency. Lower-order harmonics are significantly suppressed.
*   **Advantages:** Good waveform quality, predictable output voltage control.
*   **Disadvantages:** The maximum fundamental output voltage is limited to `Vdc / sqrt(2)` (RMS) or `Vdc/2` (peak) for a full bridge in a balanced bipolar operation (approximately 78.5% of the maximum possible sinusoidal voltage).

#### 7.2 Over-Modulation Mode (`M_a > 1`)

*   **Description:** The amplitude of the sinusoidal reference voltage exceeds the amplitude of the triangular carrier voltage for a portion of the cycle.
*   **Output Voltage:** The output waveform starts to become distorted. The switching pulses become wider, and the waveform approaches a trapezoidal shape. The fundamental output voltage increases beyond the linear limit.
*   **Harmonics:** The harmonic content changes. While the switching frequency harmonics are still present, new harmonics are introduced due to the distortion of the waveform. The lower-order harmonics may increase.
*   **Advantages:** Can achieve higher fundamental output voltage than linear mode.
*   **Disadvantages:** Degraded waveform quality, increased harmonic distortion.

#### 7.3 Square Wave Mode (or Maximum Linear Modulation/Third Harmonic Injection)

*   **Description:** The modulating index is very high, such that the sinusoidal reference voltage completely envelops the triangular carrier for extended periods. This results in the output waveform closely resembling a bipolar square wave. In some implementations, this is achieved by adding a third harmonic component to the sinusoidal reference to optimize the output voltage and reduce harmonic content.
*   **Output Voltage:** The output voltage is a bipolar square wave (or a modified square wave). The fundamental component is maximized.
*   **Harmonics:** For a pure bipolar square wave, the fundamental component is `4Vdc / (π * sqrt(2))` RMS, and the dominant harmonics are odd harmonics (3rd, 5th, 7th...). With third harmonic injection, the third harmonic is canceled, improving waveform quality.
*   **Advantages:** Maximizes the fundamental output voltage, can be more efficient in some cases.
*   **Disadvantages:** High harmonic content (if not using techniques like third harmonic injection), potential for EMI and increased losses.

**Important Point:** The choice of mode depends on the application's requirements for output voltage magnitude and waveform quality. Linear mode is preferred for high-quality sinusoidal output, while over-modulation and square wave modes are used when maximum voltage utilization is critical.

### 8. Merits and Demerits of SPWM VSIs

**Merits:**

*   **High Quality Output:** Can generate AC output voltages with low harmonic distortion when operated in the linear region with appropriate filtering.
*   **Variable Frequency and Voltage Control:** Easily allows for independent control of the output frequency and fundamental voltage by adjusting the reference signal.
*   **Efficient Conversion:** High switching frequencies lead to smaller passive components (inductors and capacitors) for filtering.
*   **Reduced Size and Weight:** Smaller passive components contribute to more compact and lighter inverter designs.
*   **Fast Dynamic Response:** The rapid switching of power devices allows for quick changes in output voltage and frequency.
*   **Lower Audible Noise:** When operating at high switching frequencies, the audible noise generated by the switching is less objectionable.

**Demerits:**

*   **Switching Losses:** The high-frequency switching of power devices leads to power losses, reducing overall efficiency.
*   **Harmonic Generation:** Although reduced by SPWM, harmonics are still present and may require filtering.
*   **Complexity of Control:** Requires a microcontroller or dedicated PWM generation circuitry.
*   **Electromagnetic Interference (EMI):** The fast switching can generate significant EMI, requiring proper shielding and filtering.
*   **Switching Device Stress:** High switching frequencies can stress the power devices, affecting their lifespan.
*   **Dead-time Requirement:** Essential for preventing shoot-through, adding complexity to the control.

### 9. Need for Blanking Time (Dead-Time)

**Concept:** In a VSI, power switches (like IGBTs) are typically used in series with their anti-parallel diodes. When one switch in a leg turns OFF, the corresponding diode in the other switch starts conducting until the other switch turns ON. If the turn-OFF of one switch and the turn-ON of the complementary switch overlap, a short circuit across the DC link can occur, leading to shoot-through.

**Why Blanking Time is Needed:**
*   **To Prevent Shoot-Through:** Blanking time, also known as dead-time, is a short period introduced between the turn-OFF of one switch and the turn-ON of its complementary switch in the same leg. This ensures that there is no direct path for current to flow from the positive DC rail to the negative DC rail through both switches simultaneously.

**How it's Implemented:**
When a gate pulse to turn ON a switch is to be removed, a small delay (blanking time) is inserted before the gate pulse to the complementary switch is applied.

**Example (Full-Bridge Leg S1 and S3):**
*   If S1 is ON and needs to turn OFF to allow S3 to turn ON:
    *   Remove gate pulse to S1.
    *   **Wait for blanking time (`t_d`).**
    *   Apply gate pulse to S3.

**Effect on Output Voltage:**
During the blanking time, neither switch is actively conducting in the ideal sense. This results in a momentary interruption of the current path, causing the output voltage to deviate from its ideal value. In a voltage source inverter with an inductive load, the load current continues to flow through the freewheeling diodes, creating a zero-voltage state for a short duration.

**Impact on Waveform:**
*   **Zero-Voltage States:** The presence of blanking time introduces short periods where the output voltage is zero (or momentarily undefined), even when the intention is to have a non-zero voltage.
*   **Harmonic Distortion:** These zero-voltage states can introduce additional harmonics into the output waveform, particularly if not accounted for in the modulation strategy.
*   **Control Strategy Adaptation:** PWM control strategies often need to be designed to accommodate or compensate for the effects of blanking time.

**Important Point:** Blanking time is essential for the safe operation of the VSI and must be carefully chosen. It should be long enough to prevent shoot-through but short enough to minimize the impact on the output waveform quality. The duration of blanking time depends on the switching characteristics of the power devices (turn-off time, parasitic capacitances).

### Practice Questions and Answers

**Question 1:** In a single-phase full-bridge VSI, what is the maximum fundamental output voltage RMS in linear modulation mode, if the DC link voltage is 300V?
**Answer:**
The peak fundamental output voltage is `V_o1_peak = M_a * Vdc / 2`. In linear mode, the maximum `M_a` is 1.
So, `V_o1_peak = 1 * 300V / 2 = 150V`.
The RMS fundamental output voltage is `V_o1_rms = V_o1_peak / sqrt(2) = 150V / sqrt(2) ≈ 106.07V`.

**Question 2:** Explain why unipolar PWM is preferred over bipolar PWM in applications where efficiency is critical.
**Answer:**
Unipolar PWM generally leads to reduced switching losses because only one switch in each leg needs to be commutated during a PWM cycle for a significant portion of the time. This is in contrast to bipolar PWM where both switches in a leg can change state, leading to more frequent commutations and higher switching losses. Lower switching losses directly translate to higher inverter efficiency.

**Question 3:** What is the primary purpose of blanking time in a VSI, and what is a potential consequence if it is not adequately implemented?
**Answer:**
The primary purpose of blanking time is to prevent shoot-through, a condition where both switches in a leg of the inverter are turned ON simultaneously, creating a short circuit across the DC link. If blanking time is not adequately implemented, shoot-through can occur, leading to catastrophic failure of the power devices and damage to the inverter.

**Question 4:** How does increasing the switching frequency (`f_s`) of the carrier wave in SPWM affect the harmonic spectrum of the output voltage?
**Answer:**
Increasing the switching frequency shifts the dominant harmonic components to higher frequencies. This means the low-order harmonics (which are more difficult to filter and have a greater impact on the fundamental waveform) are reduced, and the harmonic energy is pushed further away from the fundamental frequency. This results in a lower Total Harmonic Distortion (THD) for the fundamental component.

**Question 5:** Describe the difference in output voltage between linear mode and over-modulation mode for SPWM.
**Answer:**
In **linear mode** (`M_a <= 1`), the output voltage waveform is a good approximation of a sine wave, with the fundamental component directly proportional to the modulating index. The harmonics are primarily at frequencies around the switching frequency.
In **over-modulation mode** (`M_a > 1`), the sinusoidal reference voltage exceeds the carrier amplitude for part of the cycle. This leads to a distorted output waveform that starts to resemble a trapezoidal shape. While the fundamental output voltage increases, the waveform quality degrades, and harmonic distortion increases.

### Important Points to Remember

*   **VSI Function:** Convert DC to AC.
*   **Half-Bridge vs. Full-Bridge:** Half-bridge has lower output voltage and requires a split DC source; full-bridge has higher output voltage and simpler DC source requirements.
*   **SPWM Core Idea:** Compare a sinusoidal reference with a high-frequency triangular carrier to generate PWM pulses.
*   **Fundamental Voltage Control:** Achieved by adjusting the modulating index (`M_a`), which is the ratio of reference voltage amplitude to carrier voltage amplitude.
*   **Harmonics:** SPWM pushes harmonics to higher frequencies, reducing THD for the fundamental component.
*   **Bipolar vs. Unipolar:** Bipolar switches both devices in a leg to connect to +/- DC; Unipolar aims to reduce switching losses by commutating only one device in a leg at a time.
*   **Modes:** Linear (`M_a <= 1`), Over-modulation (`M_a > 1`), Square wave (max voltage, significant distortion).
*   **Blanking Time:** Crucial for preventing shoot-through by providing a safe switching transition for devices in the same leg.
