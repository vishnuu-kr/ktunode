### 1. Introduction to Formal Grammars

Before diving into Regular Grammars, let's recall the general concept of a formal grammar.

**Definition (Formal Grammar):** A formal grammar is a set of rules that defines a set of strings that can be generated by the grammar. These rules are used to derive strings in a language from a starting symbol.

A formal grammar $G$ is typically defined as a 4-tuple:
$G = (V, \Sigma, P, S)$
where:
*   $V$ is a finite set of **variables** (or non-terminal symbols). These represent syntactic categories or placeholders.
*   $\Sigma$ is a finite set of **terminals**. These are the actual symbols that form the strings of the language. $V$ and $\Sigma$ are disjoint ($V \cap \Sigma = \emptyset$).
*   $P$ is a finite set of **production rules**. Each rule is of the form $\alpha \rightarrow \beta$, where $\alpha$ and $\beta$ are strings of variables and terminals.
*   $S \in V$ is the **start symbol**. The process of generating strings begins with the start symbol.

**Derivation:** A string $w$ can be derived from a string $u$ using a grammar $G$ if there is a sequence of strings $u_0, u_1, \dots, u_n$ such that $u_0 = u$, $u_n = w$, and for each $i$ from 0 to $n-1$, $u_i \rightarrow u_{i+1}$ is a production rule in $P$. This is denoted as $u \Rightarrow^* w$.

**Language Generated by a Grammar:** The language generated by a grammar $G$, denoted by $L(G)$, is the set of all terminal strings that can be derived from the start symbol $S$.
$L(G) = \{w \in \Sigma^* \mid S \Rightarrow^* w\}$

### 2. Regular Grammars (RG)

Regular Grammars are the simplest form of formal grammars. They are directly related to **finite automata (FAs)** and **regular languages**. A language is regular if and only if it can be generated by a regular grammar.

**Definition (Regular Grammar):** A Regular Grammar is a formal grammar $G = (V, \Sigma, P, S)$ where all production rules are of one of the following three forms:

1.  **Type 1 (Right-linear):** $A \rightarrow aB$, where $A, B \in V$ and $a \in \Sigma \cup \{\epsilon\}$.
    *   The variable on the left-hand side produces a terminal followed by a variable.
    *   The $\epsilon$ (empty string) is allowed as the terminal part, meaning $A \rightarrow \epsilon$. This rule is crucial for ending derivations.

2.  **Type 2 (Right-linear):** $A \rightarrow a$, where $A \in V$ and $a \in \Sigma \cup \{\epsilon\}$.
    *   The variable on the left-hand side produces a terminal (or $\epsilon$). This rule is also crucial for ending derivations.

3.  **Type 3 (Left-linear):** $A \rightarrow Ba$, where $A, B \in V$ and $a \in \Sigma \cup \{\epsilon\}$.
    *   The variable on the left-hand side produces a variable followed by a terminal.

**Important Note:**
*   Traditionally, Regular Grammars are defined with *either* all rules being right-linear *or* all rules being left-linear. This is sometimes referred to as a "pure" or "strict" definition.
*   However, the Chomsky Hierarchy classifies grammars based on the most general form of their rules. In that context, a **Type 3 Grammar** is a grammar where all productions are of the form:
    *   $A \rightarrow \alpha B$ (left-linear form) OR
    *   $A \rightarrow B \alpha$ (right-linear form)
    where $A, B \in V$, and $\alpha \in \Sigma^*$.

For the purpose of this introductory module, we will focus on the **right-linear form** as it has a direct and intuitive mapping to Finite Automata. The definition provided above encompasses both right-linear and left-linear forms. For most practical examples and connections to NFAs, the right-linear form is more commonly used.

**Key Properties of Regular Grammars (Right-Linear Focus):**

*   **Simplicity:** They have the most restricted production rules.
*   **Equivalence to Finite Automata:** Every regular language can be generated by a regular grammar, and every language generated by a regular grammar can be accepted by a finite automaton.
*   **Relationship to Regular Expressions:** Regular languages, and thus those generated by regular grammars, can also be described by regular expressions.

### 3. Relationship between Regular Grammars and Finite Automata

This is a fundamental concept. There's a direct correspondence:

*   **From NFA to Regular Grammar:** Given an NFA $M = (Q, \Sigma, \delta, q_0, F)$, we can construct a regular grammar $G$ such that $L(M) = L(G)$.
    *   **Variables ($V$):** The variables of the grammar correspond to the states of the NFA. Each state $q \in Q$ is a variable, and we can use a symbol like $A_q$ to represent it.
    *   **Terminals ($\Sigma$):** The terminals of the grammar are the input alphabet of the NFA.
    *   **Start Symbol ($S$):** The start symbol of the grammar is the variable corresponding to the start state of the NFA, i.e., $A_{q_0}$.
    *   **Production Rules ($P$):**
        1.  For every transition $\delta(q, a) = p$ in the NFA, add a rule $A_q \rightarrow a A_p$ to $P$. (This generates strings by reading symbols and moving to new states).
        2.  If the NFA has a final state $q \in F$, and there is a transition $\delta(q, a) = p$, add a rule $A_q \rightarrow a A_p$ to $P$. (This part is standard).
        3.  If the NFA has a final state $q \in F$, and there is also a transition $\delta(q, \epsilon) = p$ (if using $\epsilon$-NFA), then add $A_q \rightarrow A_p$ to $P$. (This handles $\epsilon$-transitions).
        4.  For every final state $q \in F$, add a rule $A_q \rightarrow \epsilon$ to $P$. (This rule allows the derivation to terminate when the NFA reaches a final state).
        *   **Special Case for Start State:** If the start state $q_0$ is also a final state, we need an additional rule. If $q_0 \in F$, we can add $S \rightarrow \epsilon$ to allow the empty string to be generated.

*   **From Regular Grammar to NFA:** Given a regular grammar $G = (V, \Sigma, P, S)$, we can construct an NFA $M$ such that $L(G) = L(M)$. We will focus on right-linear grammars for this conversion.
    *   **States ($Q$):** The states of the NFA are the variables in $V$, plus a new "sink" or "dead" state $q_{dead}$ if needed. We also need a start state corresponding to $S$.
    *   **Alphabet ($\Sigma$):** The alphabet of the NFA is the set of terminals of the grammar.
    *   **Start State ($q_0$):** The start state of the NFA is the start symbol of the grammar, $S$.
    *   **Final States ($F$):** The set of final states will be constructed based on the production rules.
    *   **Transition Function ($\delta$):**
        1.  For every rule of the form $A \rightarrow aB$, add a transition $\delta(A, a) = B$.
        2.  For every rule of the form $A \rightarrow a$, where $a \in \Sigma$, let $A$ be a final state. Add a transition $\delta(A, a)$ which leads to a state that eventually generates the empty string. If $a = \epsilon$, then $A$ becomes a final state. If $a \neq \epsilon$, this rule essentially terminates the derivation, which corresponds to reaching a final state after consuming `a`.
        3.  For every rule of the form $A \rightarrow \epsilon$, $A$ is a final state.

Let's refine the conversion from RG to NFA for clarity. We aim for an NFA where states correspond to variables, and the final state is implicitly handled by rules ending in $\epsilon$.

**Conversion from Right-Linear Regular Grammar $G = (V, \Sigma, P, S)$ to NFA $M = (Q, \Sigma, \delta, q_0, F)$:**

1.  **States ($Q$):** $Q = V \cup \{q_{final}\}$, where $q_{final}$ is a new state not in $V$.
2.  **Start State ($q_0$):** $q_0 = S$.
3.  **Final States ($F$):** $F = \{q_{final}\}$.
4.  **Transition Function ($\delta$):**
    *   For each rule $A \rightarrow aB$ in $P$, add transition $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a$ in $P$ (where $a \in \Sigma$), add transition $\delta(A, a) \supseteq \{q_{final}\}$.
    *   For each rule $A \rightarrow \epsilon$ in $P$, add $A$ to the set of final states. If we stick to the $q_{final}$ approach, then $A$ transitions to $q_{final}$ on $\epsilon$, i.e., $\delta(A, \epsilon) \supseteq \{q_{final}\}$. **However, the standard conversion often simplifies this:** if $A \rightarrow \epsilon$ is a rule, the state corresponding to $A$ becomes a final state in the NFA.

Let's use the more direct mapping where states are directly the variables and a "completion" state isn't always needed.

**Revised Conversion from Right-Linear Regular Grammar $G = (V, \Sigma, P, S)$ to NFA $M = (Q, \Sigma, \delta, q_0, F)$:**

1.  **States ($Q$):** $Q = V$. (If $S \rightarrow \epsilon$ is a rule, and $S$ is the only variable, then we need to handle $\epsilon$ generation. A common way is to have the start state be final if $S \rightarrow \epsilon$ is a rule.) Let's adjust: $Q = V$.
2.  **Start State ($q_0$):** $q_0 = S$.
3.  **Final States ($F$):** $F = \{A \in V \mid \text{there is a rule } A \rightarrow \epsilon \text{ in } P\}$.
4.  **Transition Function ($\delta$):**
    *   For each rule $A \rightarrow aB$ in $P$, add transition $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a$ in $P$ (where $a \in \Sigma$), the state $A$ must transition to some "accepting" state after reading $a$. This is tricky without an explicit final state. A common way is to consider $A$ as an intermediate state. The derivation $S \Rightarrow^* a$ means $A \rightarrow a$ is the last step. This implies that if $A$ is the state reached after reading 'a', and 'a' is the last symbol, then this path should be accepted.

A more robust conversion from right-linear RG to NFA:

**Conversion from Right-Linear Regular Grammar $G = (V, \Sigma, P, S)$ to NFA $M = (Q, \Sigma, \delta, q_0, F)$:**

1.  **States ($Q$):** $Q = V$.
2.  **Alphabet ($\Sigma$):** Same as grammar.
3.  **Start State ($q_0$):** $q_0 = S$.
4.  **Final States ($F$):** $F = \{A \in V \mid \text{there is a rule } A \rightarrow \epsilon \text{ in } P\}$.
5.  **Transition Function ($\delta$):**
    *   For each rule $A \rightarrow aB$ in $P$, add transition $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a$ in $P$ (where $a \in \Sigma$), add a transition from $A$ on $a$ to a special "accepting state". Let's call this $q_{accept}$. So, $Q = V \cup \{q_{accept}\}$, $F = \{q_{accept}\}$.
        *   For each rule $A \rightarrow a$ in $P$, add transition $\delta(A, a) \supseteq \{q_{accept}\}$.
    *   For each rule $A \rightarrow \epsilon$ in $P$, add $A$ to $F$. So, $F = \{A \in V \mid A \rightarrow \epsilon \in P\} \cup \{q_{accept} \text{ if any } A \rightarrow a \text{ rule exists}\}$. This is getting complicated.

Let's use the standard textbook approach (e.g., Hopcroft, Motwani, Ullman):

**Conversion from Right-Linear Regular Grammar $G=(V, \Sigma, P, S)$ to NFA $M=(Q, \Sigma, \delta, q_0, F)$:**

1.  **States $Q$:** $Q = V$.
2.  **Start State $q_0$:** $q_0 = S$.
3.  **Final States $F$:** $F = \{A \in V \mid A \rightarrow \epsilon \in P\}$.
4.  **Transition Function $\delta$:**
    *   For each rule $A \rightarrow aB \in P$, add $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a \in P$ (where $a \in \Sigma$), add a transition from $A$ on $a$ to a new state $q_f$. Let's redefine $Q$ and $F$.
        *   Let $Q = V \cup \{q_f\}$, where $q_f$ is a new state.
        *   $F = \{q_f\}$.
        *   For each rule $A \rightarrow aB \in P$, add $\delta(A, a) \supseteq \{B\}$.
        *   For each rule $A \rightarrow a \in P$ (where $a \in \Sigma$), add $\delta(A, a) \supseteq \{q_f\}$.
        *   If $S \rightarrow \epsilon$ is a rule, then $S$ itself should be a final state. The rule $A \rightarrow \epsilon$ means state $A$ is final.

**Let's stick to the simpler, more intuitive mapping (often presented in introductory materials):**

**Conversion from Right-Linear Regular Grammar $G=(V, \Sigma, P, S)$ to NFA $M=(Q, \Sigma, \delta, q_0, F)$:**

1.  **States $Q$:** The states are the variables in $V$.
2.  **Alphabet $\Sigma$:** Same as the grammar.
3.  **Start State $q_0$:** $q_0 = S$.
4.  **Final States $F$:** For every rule $A \rightarrow \epsilon$ in $P$, the state $A$ is a final state. If the start symbol $S$ can derive $\epsilon$ (i.e., $S \rightarrow \epsilon$ is a rule), then $S$ must be a final state.
5.  **Transition Function $\delta$:**
    *   For every rule $A \rightarrow aB$ in $P$, add a transition from state $A$ on input symbol $a$ to state $B$: $\delta(A, a) \supseteq \{B\}$.
    *   For every rule $A \rightarrow a$ in $P$ (where $a \in \Sigma$), add a transition from state $A$ on input symbol $a$ to a new, unique "accepting" state $q_{accept}$. If the start symbol $S$ is also a final state (due to $S \rightarrow \epsilon$), we need to be careful.
        *   **Revised approach for `A -> a`:** This signifies the end of a string. The state $A$ should transition on `a` to a state that accepts. Let's re-use the definition of final states. If $A \rightarrow a$ is a rule, then after reading $a$, we should be in an accepting state.

**Let's use the conversion strategy from Kozen, Chapter 3, Section 3.2, which is very clear.**

**Conversion from Right-Linear Regular Grammar $G=(V, \Sigma, P, S)$ to NFA $M=(Q, \Sigma, \delta, q_0, F)$:**

1.  **States $Q$:** $Q = V$.
2.  **Start State $q_0$:** $q_0 = S$.
3.  **Final States $F$:** $F = \{A \in V \mid A \rightarrow \epsilon \in P\}$.
4.  **Transition Function $\delta$:**
    *   For each rule $A \rightarrow aB$ in $P$, add transition $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a$ in $P$, this means state $A$ on input $a$ can reach a state that signifies acceptance. If $A$ is itself a final state (i.e., $A \rightarrow \epsilon$ is also a rule), it's accepted. If not, it must transition to a final state.

This implies a slightly different structure for the NFA to perfectly mirror RG.

**Kozen's Conversion (Simplified to match RG):**

Let's use a conceptual mapping:
*   States in NFA $\leftrightarrow$ Variables in RG.
*   Transition $q \xrightarrow{a} p$ in NFA $\leftrightarrow$ Rule $A_q \rightarrow aA_p$ in RG.
*   Final state in NFA $\leftrightarrow$ Rule $A \rightarrow \epsilon$ in RG.

**From Right-Linear RG to NFA:**

$G = (V, \Sigma, P, S)$
$M = (Q, \Sigma, \delta, q_0, F)$

1.  $Q = V$
2.  $q_0 = S$
3.  $F = \{A \in V \mid A \rightarrow \epsilon \in P\}$
4.  For each rule $A \rightarrow aB \in P$, add $\delta(A, a) \supseteq \{B\}$.
5.  For each rule $A \rightarrow a \in P$: This signifies that after reading `a`, we can potentially accept. If $A$ itself is a final state (due to $A \rightarrow \epsilon$), then $a$ can be appended to an $\epsilon$-derivation. If not, we need to transition to a final state.
    *   **To handle $A \rightarrow a$ correctly without adding a new state:** If $A \rightarrow a$ is a rule, and $A \in F$ (i.e., $A \rightarrow \epsilon$ exists), then the string ending with $a$ is accepted. If $A \notin F$, then after reading $a$, we must reach a final state. This means a rule $A \rightarrow a$ effectively needs to transition to a final state.

**Let's stick to the most common and understandable mapping: states are variables, and $\epsilon$-rules make states final.**

**Conversion from Right-Linear Regular Grammar $G=(V, \Sigma, P, S)$ to NFA $M=(Q, \Sigma, \delta, q_0, F)$:**

1.  **States $Q$:** $Q = V$.
2.  **Alphabet $\Sigma$:** Same as the grammar's terminal alphabet.
3.  **Start State $q_0$:** $q_0 = S$.
4.  **Final States $F$:** $F = \{A \in V \mid A \rightarrow \epsilon \in P\}$.
5.  **Transition Function $\delta$:**
    *   For each rule $A \rightarrow aB \in P$, add $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a \in P$ (where $a \in \Sigma$): This rule indicates that after reading `a`, the string might be complete. We need to reach an accepting state. If $A$ itself is final (i.e., $A \rightarrow \epsilon \in P$), it means we can accept after reading `a`. If $A$ is not final, then this rule doesn't directly lead to acceptance unless there's a subsequent $\epsilon$-transition to a final state.

A more formal approach that handles the $A \rightarrow a$ rule properly for NFA conversion (as seen in many texts):

**Conversion from Right-Linear Regular Grammar $G=(V, \Sigma, P, S)$ to NFA $M=(Q, \Sigma, \delta, q_0, F)$:**

1.  **States $Q$:** $Q = V \cup \{q_{accept}\}$, where $q_{accept}$ is a new state not in $V$.
2.  **Alphabet $\Sigma$:** Same as the grammar's terminal alphabet.
3.  **Start State $q_0$:** $q_0 = S$.
4.  **Final States $F$:** $F = \{q_{accept}\}$.
5.  **Transition Function $\delta$:**
    *   For each rule $A \rightarrow aB \in P$, add $\delta(A, a) \supseteq \{B\}$.
    *   For each rule $A \rightarrow a \in P$ (where $a \in \Sigma$), add $\delta(A, a) \supseteq \{q_{accept}\}$.
    *   For each rule $A \rightarrow \epsilon \in P$, add $A$ to $F$. **However, if we use $q_{accept}$ as the sole final state, then $A \rightarrow \epsilon$ must transition to $q_{accept}$ on $\epsilon$.** So, $\delta(A, \epsilon) \supseteq \{q_{accept}\}$.

This last conversion is the most robust for NFA construction from RG.

### 4. Examples of Regular Grammars

Let's construct regular grammars for some simple regular languages.

**Example 1: Language $L_1 = \{a^n b \mid n \ge 0\}$**

This language consists of zero or more 'a's followed by a single 'b'.

*   **Regular Expression:** $a^*b$
*   **NFA:**
    *   States: $\{q_0, q_1\}$
    *   Alphabet: $\{a, b\}$
    *   Start State: $q_0$
    *   Final States: $\{q_1\}$
    *   Transitions: $\delta(q_0, a) = q_0$, $\delta(q_0, b) = q_1$, $\delta(q_1, a) = \emptyset$, $\delta(q_1, b) = \emptyset$.

*   **Regular Grammar (Right-Linear):**
    *   Variables $V = \{S, A\}$ (corresponds to states $q_0, q_1$)
    *   Terminals $\Sigma = \{a, b\}$
    *   Start Symbol $S$ (corresponds to $q_0$)
    *   Final State $A$ (corresponds to $q_1$)

    *   **Production Rules:**
        *   From $q_0 \xrightarrow{a} q_0$: $S \rightarrow aS$
        *   From $q_0 \xrightarrow{b} q_1$: $S \rightarrow bA$
        *   From $q_1 \xrightarrow{a} \emptyset$: No rule needed if $q_1$ is not final.
        *   From $q_1 \xrightarrow{b} \emptyset$: No rule needed.
        *   Since $q_1$ is final, we need a rule to terminate. This means from state $q_1$, we can accept the string. In grammar terms, this corresponds to a rule producing $\epsilon$.
        *   Let's re-examine the mapping. $A \rightarrow aB$ means reading $a$ moves to state $B$. $A \rightarrow a$ means reading $a$ leads to acceptance. $A \rightarrow \epsilon$ means state $A$ is final.

    *   **Revised Construction from NFA to RG (using conceptual mapping):**
        *   States $\{q_0, q_1\}$ -> Variables $\{S, A\}$
        *   Start state $q_0$ -> Start symbol $S$
        *   Final state $q_1$ -> Need a rule that can terminate. $A \rightarrow \epsilon$.

        *   Transition $q_0 \xrightarrow{a} q_0$: $S \rightarrow aS$
        *   Transition $q_0 \xrightarrow{b} q_1$: $S \rightarrow bA$
        *   Final state $q_1$: $A \rightarrow \epsilon$

    *   **Let's verify:**
        $S \Rightarrow bA$
        $S \Rightarrow b\epsilon = b$ (This is incorrect, language is $a^*b$)

    *   **Let's try a different variable assignment:**
        States $\{q_0, q_1\}$
        $q_0$ represents "haven't seen 'b' yet, can still see 'a'".
        $q_1$ represents "seen 'b', string is complete".

        *   Grammar Variables: $\{S_0, S_1\}$
        *   Start Symbol: $S_0$
        *   Final state: $S_1$ (meaning $S_1 \rightarrow \epsilon$)

        *   To stay in $q_0$ on 'a': $S_0 \rightarrow aS_0$
        *   To move from $q_0$ to $q_1$ on 'b': $S_0 \rightarrow bS_1$
        *   State $q_1$ is final: $S_1 \rightarrow \epsilon$

    *   **Derivations:**
        $S_0 \Rightarrow aS_0 \Rightarrow aaS_0 \Rightarrow aabS_1 \Rightarrow aab\epsilon = aab$ (for $n=2$)
        $S_0 \Rightarrow bS_1 \Rightarrow b\epsilon = b$ (for $n=0$)
        This grammar generates $L_1$.

**Example 2: Language $L_2 = \{ab^n \mid n \ge 1\}$**

This language consists of a single 'a' followed by one or more 'b's.

*   **Regular Expression:** $ab^+$
*   **NFA:**
    *   States: $\{q_0, q_1\}$
    *   Alphabet: $\{a, b\}$
    *   Start State: $q_0$
    *   Final States: $\{q_1\}$
    *   Transitions: $\delta(q_0, a) = q_1$, $\delta(q_1, b) = q_1$.

*   **Regular Grammar (Right-Linear):**
    *   Variables $V = \{S, A\}$
    *   Terminals $\Sigma = \{a, b\}$
    *   Start Symbol $S$ (corresponds to $q_0$)
    *   Final State $A$ (corresponds to $q_1$)

    *   **Mapping:**
        *   State $q_0$ (start) -> Variable $S$
        *   State $q_1$ (final) -> Variable $A$. Needs rule $A \rightarrow \epsilon$.

        *   Transition $q_0 \xrightarrow{a} q_1$: $S \rightarrow aA$
        *   Transition $q_1 \xrightarrow{b} q_1$: $A \rightarrow bA$
        *   Final state $q_1$: $A \rightarrow \epsilon$

    *   **Derivations:**
        $S \Rightarrow aA \Rightarrow abA \Rightarrow abbA \Rightarrow abba\epsilon = abba$ (This is for $ab^3$, $n=3$, but the language is $ab^n, n \ge 1$)

    *   **Correction for $ab^+$:** The NFA for $ab^+$ is:
        States: $q_0$ (start, not final), $q_1$ (final)
        Transitions: $\delta(q_0, a) = q_1$, $\delta(q_1, b) = q_1$.
        This means after reading 'a', we are in state $q_1$, which is final. $q_1$ can loop on 'b'.

    *   **RG mapping:**
        *   $q_0$ -> $S$
        *   $q_1$ -> $A$. Since $q_1$ is final, $A \rightarrow \epsilon$.

        *   Transition $q_0 \xrightarrow{a} q_1$: $S \rightarrow aA$
        *   Transition $q_1 \xrightarrow{b} q_1$: $A \rightarrow bA$
        *   Final state $q_1$: $A \rightarrow \epsilon$

    *   **Derivations:**
        $S \Rightarrow aA \Rightarrow abA \Rightarrow abbA \Rightarrow abba\epsilon = abba$ (This is $ab^3$)
        This seems correct for $ab^n$ where $n \ge 1$. The derivation must end with $A \rightarrow \epsilon$.

    *   What if $S$ itself could be final? If the language was $a^*b^+$, then $q_0$ could be final.

**Example 3: Language $L_3 = \{a^n b^m \mid n \ge 0, m \ge 0\}$**

This is the set of all strings containing only 'a's and 'b's. This is not a regular language in the strict sense if we interpret it as *any* sequence of 'a's and 'b's. However, if it's *any* combination of 'a's and 'b's, it can be generated. Let's consider a simpler case of regular languages.

**Example 3 (Revised): Language $L_3 = \{a^n \mid n \text{ is even}\}$**

*   **Regular Expression:** $(aa)^*$
*   **NFA:**
    *   States: $\{q_0, q_1\}$
    *   Alphabet: $\{a\}$
    *   Start State: $q_0$
    *   Final States: $\{q_0\}$
    *   Transitions: $\delta(q_0, a) = q_1$, $\delta(q_1, a) = q_0$.

*   **Regular Grammar (Right-Linear):**
    *   Variables $V = \{S, A\}$
    *   Terminals $\Sigma = \{a\}$
    *   Start Symbol $S$ (corresponds to $q_0$)
    *   Final State $S$ (corresponds to $q_0$)

    *   **Mapping:**
        *   State $q_0$ (start, final) -> Variable $S$. Needs rule $S \rightarrow \epsilon$.
        *   State $q_1$ (not final) -> Variable $A$. Needs rule $A \rightarrow \epsilon$ if $q_1$ were final.

        *   Transition $q_0 \xrightarrow{a} q_1$: $S \rightarrow aA$
        *   Transition $q_1 \xrightarrow{a} q_0$: $A \rightarrow aS$
        *   Final state $q_0$: $S \rightarrow \epsilon$

    *   **Derivations:**
        $S \Rightarrow \epsilon$ (for $n=0$)
        $S \Rightarrow aA \Rightarrow aaS \Rightarrow aaaA \Rightarrow aaaaS \Rightarrow aaaaaA \Rightarrow aaaaaa\epsilon = aaaaaa$ (for $n=6$)
        This grammar generates strings of even length.

**Example 4: Language $L_4 = \{w \in \{a,b\}^* \mid w \text{ ends with } b\}$**

*   **Regular Expression:** $(a|b)^*b$
*   **NFA:**
    *   States: $\{q_0, q_1\}$
    *   Alphabet: $\{a, b\}$
    *   Start State: $q_0$
    *   Final States: $\{q_1\}$
    *   Transitions:
        *   $\delta(q_0, a) = q_0$
        *   $\delta(q_0, b) = q_1$
        *   $\delta(q_1, a) = q_1$
        *   $\delta(q_1, b) = q_1$

*   **Regular Grammar (Right-Linear):**
    *   Variables $V = \{S, A\}$
    *   Terminals $\Sigma = \{a, b\}$
    *   Start Symbol $S$ (corresponds to $q_0$)
    *   Final State $A$ (corresponds to $q_1$)

    *   **Mapping:**
        *   $q_0$ -> $S$
        *   $q_1$ -> $A$. Needs $A \rightarrow \epsilon$.

        *   Transition $q_0 \xrightarrow{a} q_0$: $S \rightarrow aS$
        *   Transition $q_0 \xrightarrow{b} q_1$: $S \rightarrow bA$
        *   Transition $q_1 \xrightarrow{a} q_1$: $A \rightarrow aA$
        *   Transition $q_1 \xrightarrow{b} q_1$: $A \rightarrow bA$
        *   Final state $q_1$: $A \rightarrow \epsilon$

    *   **Derivations:**
        $S \Rightarrow aS \Rightarrow aaS \Rightarrow abA \Rightarrow abaA \Rightarrow ababA \Rightarrow ababbA \Rightarrow ababb\epsilon = ababb$
        This grammar correctly generates strings ending in 'b'.

### 5. Practice Questions and Exercises

**Question 1:**
Consider the regular grammar $G$ with $V=\{S, A\}$, $\Sigma=\{a, b\}$, $S$ as start symbol, and the following production rules:
$P = \{S \rightarrow aS, S \rightarrow bA, A \rightarrow bA, A \rightarrow \epsilon\}$
What language does $G$ generate?

**Answer 1:**
The grammar structure suggests:
*   $S \rightarrow aS$: Stay in state S, consume 'a'.
*   $S \rightarrow bA$: Move from state S to state A, consume 'b'.
*   $A \rightarrow bA$: Stay in state A, consume 'b'.
*   $A \rightarrow \epsilon$: State A is final.

This corresponds to an NFA with:
*   States: $\{S, A\}$
*   Start state: $S$
*   Final state: $A$
*   Transitions: $\delta(S, a)=S$, $\delta(S, b)=A$, $\delta(A, b)=A$.

The NFA accepts strings that start with any number of 'a's, then a 'b', and then any number of 'b's. The empty string $\epsilon$ is not accepted because $S$ is not final.
Let's trace:
$S \Rightarrow aS \Rightarrow aaS \Rightarrow aabA \Rightarrow aabbA \Rightarrow aabb\epsilon = aabb$.
This is $a^n b^m$ where $n \ge 0$ and $m \ge 1$. The state $S$ does not lead to a final state without consuming a 'b' and moving to $A$. The language generated is $\{a^n b^m \mid n \ge 0, m \ge 1\}$.

**Question 2:**
Construct a right-linear regular grammar for the language $L = \{w \in \{a,b\}^* \mid w \text{ starts with } a \text{ and ends with } b\}$.

**Answer 2:**
*   Regular Expression: $a(a|b)^*b$
*   NFA Construction:
    *   States: $\{q_0, q_1, q_2\}$
    *   Alphabet: $\{a, b\}$
    *   Start State: $q_0$
    *   Final States: $\{q_2\}$
    *   Transitions:
        *   $\delta(q_0, a) = q_1$ (Must start with 'a')
        *   $\delta(q_1, a) = q_1$ (Can have more 'a's)
        *   $\delta(q_1, b) = q_2$ (Can have 'b's)
        *   $\delta(q_2, a) = q_2$ (Can have more 'a's after the first 'b')
        *   $\delta(q_2, b) = q_2$ (Can have more 'b's)

*   Regular Grammar Construction (mapping states to variables):
    *   $q_0$ (start, not final) $\rightarrow S$
    *   $q_1$ (intermediate) $\rightarrow A$
    *   $q_2$ (final) $\rightarrow B$. Needs $B \rightarrow \epsilon$.

    *   Transitions to Rules:
        *   $q_0 \xrightarrow{a} q_1$: $S \rightarrow aA$
        *   $q_1 \xrightarrow{a} q_1$: $A \rightarrow aA$
        *   $q_1 \xrightarrow{b} q_2$: $A \rightarrow bB$
        *   $q_2 \xrightarrow{a} q_2$: $B \rightarrow aB$
        *   $q_2 \xrightarrow{b} q_2$: $B \rightarrow bB$
        *   Final state $q_2$: $B \rightarrow \epsilon$

*   The Regular Grammar is:
    $G = (\{S, A, B\}, \{a, b\}, P, S)$
    $P = \{S \rightarrow aA, A \rightarrow aA, A \rightarrow bB, B \rightarrow aB, B \rightarrow bB, B \rightarrow \epsilon\}$

**Question 3:**
Which of the following productions adheres to the definition of a right-linear regular grammar?
(a) $A \rightarrow aB$
(b) $A \rightarrow Ba$
(c) $A \rightarrow a$
(d) $A \rightarrow \epsilon$
(e) $A \rightarrow aBc$

**Answer 3:**
(a) $A \rightarrow aB$ - Yes, terminal followed by a variable.
(b) $A \rightarrow Ba$ - No, variable followed by terminal (left-linear form).
(c) $A \rightarrow a$ - Yes, terminal only.
(d) $A \rightarrow \epsilon$ - Yes, empty string.
(e) $A \rightarrow aBc$ - No, terminal followed by two variables and another terminal.

**Question 4:**
Can a regular grammar generate the language $L = \{a^n b^n \mid n \ge 0\}$? Justify your answer.

**Answer 4:**
No, a regular grammar cannot generate the language $L = \{a^n b^n \mid n \ge 0\}$.
**Justification:** This language requires matching the number of 'a's with the number of 'b's. For example, "aabb", "aaabbb". To do this, the grammar would need to "remember" how many 'a's have been generated and then expect the same number of 'b's. Regular grammars (and finite automata) have a finite number of states and thus a finite memory. They cannot count arbitrarily high to match counts of symbols. This language is a classic example of a context-free language.

### 6. Important Points to Remember

*   **Definition of RG:** Production rules are restricted to forms like $A \rightarrow aB$, $A \rightarrow a$, or $A \rightarrow \epsilon$ (right-linear). Left-linear forms are $A \rightarrow Ba$, $A \rightarrow a$, or $A \rightarrow \epsilon$.
*   **Equivalence:** Regular grammars generate exactly the set of regular languages.
*   **Relationship to NFAs:** There's a direct and constructive equivalence between NFAs and right-linear regular grammars.
*   **Limitations:** Regular grammars cannot handle languages that require counting or matching nested structures (like balanced parentheses or $a^n b^n$).
*   **Classification (CO1):** If a language can be generated by a regular grammar, it is a regular language. This is the simplest class in the Chomsky hierarchy.
*   **Design (CO2):** The ability to construct regular grammars is a direct application of understanding regular languages and their generative mechanisms.
