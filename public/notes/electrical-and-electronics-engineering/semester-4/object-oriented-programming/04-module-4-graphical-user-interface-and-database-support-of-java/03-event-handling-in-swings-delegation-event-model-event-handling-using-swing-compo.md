### **1. Introduction to Event Handling in Java Swing**

*   **What is an Event?**
    *   An event is an action that occurs in a GUI application. Examples include a mouse click, key press, window closing, or component being activated.
    *   Events are generated by user interactions or by the system itself.

*   **Why Event Handling?**
    *   GUI applications are inherently interactive. Event handling allows the application to respond to these user actions, making the application dynamic and user-friendly.
    *   Without event handling, a GUI would be static and unresponsive.

*   **Java Swing and Events:**
    *   Swing is a GUI toolkit in Java that provides a rich set of components for building graphical interfaces.
    *   Swing's event handling mechanism is built around the **Delegation Event Model**.

---

### **2. The Delegation Event Model**

This model is a standard and efficient way to handle events in Java GUIs. It involves three key players:

*   **Event Source:**
    *   The component that generates the event. For example, a `JButton` generates an `ActionEvent` when clicked.
    *   *Example Components:* `JFrame`, `JButton`, `JTextField`, `JLabel` (though `JLabel` is less interactive by default).

*   **Event Listener:**
    *   An object that has the capability to receive and process events.
    *   Listeners implement specific *listener interfaces* that define methods for handling particular types of events.
    *   *Key Concept:* Listeners are typically instances of classes that implement one or more listener interfaces.

*   **Event Object:**
    *   An object that encapsulates information about the event that has occurred.
    *   It contains details such as the type of event, the source of the event, and potentially other relevant data (e.g., mouse coordinates for a mouse event).
    *   Java defines a hierarchy of event classes, all inheriting from `java.util.EventObject`.

**How it works:**

1.  **Event Generation:** The Event Source detects an event (e.g., a button click).
2.  **Event Object Creation:** The Event Source creates an Event Object that describes the event.
3.  **Event Notification:** The Event Source notifies its registered Event Listeners about the event by calling the appropriate method on the listener interface, passing the Event Object as an argument.
4.  **Event Processing:** The Event Listener receives the notification and processes the event by executing the code within the listener method.

**Important Distinction:** The event source does *not* directly handle the event. It *delegates* the handling to the listener. This separation of concerns makes the code more modular and manageable.

### **3. Implementing Event Handling with Swing Components**

To handle events, you need to perform two main steps:

1.  **Create an Event Listener:** Define a class that implements the appropriate listener interface and implement the event-handling methods.
2.  **Register the Listener:** Tell the event source to notify your listener when a specific event occurs. This is done by calling the `add<EventType>Listener()` method on the event source, passing an instance of your listener.

Let's look at specific Swing components:

#### **3.1. JFrame and Window Events**

*   **JFrame:** The main window for an application.
*   **Window Events:** Events related to the state of a window, such as opening, closing, deactivating, activating, iconifying, and deiconifying.
*   **Listener Interface:** `java.awt.event.WindowListener`.
*   **Listener Methods:**
    *   `windowOpened(WindowEvent e)`
    *   `windowClosing(WindowEvent e)`: This is the most commonly used method. It's called when the user clicks the close button of the window.
    *   `windowClosed(WindowEvent e)`
    *   `windowIconified(WindowEvent e)`
    *   `windowDeiconified(WindowEvent e)`
    *   `windowActivated(WindowEvent e)`
    *   `windowDeactivated(WindowEvent e)`

*   **Adapter Class:** `java.awt.event.WindowAdapter` is a convenience class that provides default (empty) implementations for all `WindowListener` methods. You can extend `WindowAdapter` and override only the methods you need, which is often simpler than implementing the full `WindowListener` interface.

*   **Example (Closing a JFrame):**

    ```java
    import javax.swing.*;
    import java.awt.event.*;

    public class JFrameEventDemo extends JFrame {

        public JFrameEventDemo() {
            setTitle("JFrame Event Demo");
            setSize(300, 200);
            setDefaultCloseOperation(JFrame.DO_NOTHING_ON_CLOSE); // Prevent default closing

            // Add a WindowListener using WindowAdapter
            addWindowListener(new WindowAdapter() {
                @Override
                public void windowClosing(WindowEvent e) {
                    System.out.println("Window is closing. Exiting application.");
                    System.exit(0); // Terminate the application
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JFrameEventDemo();
                }
            });
        }
    }
    ```

*   **Important Point:** When you set `setDefaultCloseOperation(JFrame.DO_NOTHING_ON_CLOSE)`, you take control of what happens when the user clicks the close button. You *must* handle this in your `windowClosing` method (e.g., by calling `System.exit(0)`). If you set `setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)`, Swing handles the closing automatically, and you don't necessarily need a `WindowListener` for basic closing.

#### **3.2. JButton and Action Events**

*   **JButton:** A standard button component that triggers an action when clicked.
*   **Action Events:** Events generated by user actions like clicking a button or selecting a menu item.
*   **Listener Interface:** `java.awt.event.ActionListener`.
*   **Listener Method:**
    *   `actionPerformed(ActionEvent e)`: This method is called when the action occurs. The `ActionEvent` object contains information about the event, including which component triggered it (e.g., `e.getSource()`).

*   **Example (Clicking a JButton):**

    ```java
    import javax.swing.*;
    import java.awt.event.*;
    import java.awt.FlowLayout; // For simple layout

    public class JButtonEventDemo extends JFrame {

        private JButton clickButton;
        private JLabel statusLabel;

        public JButtonEventDemo() {
            setTitle("JButton Event Demo");
            setSize(300, 150);
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            setLayout(new FlowLayout()); // Use FlowLayout for simplicity

            // Create components
            clickButton = new JButton("Click Me!");
            statusLabel = new JLabel("Button not clicked yet.");

            // Add components to the frame
            add(clickButton);
            add(statusLabel);

            // Register an ActionListener for the button
            clickButton.addActionListener(new ActionListener() {
                @Override
                public void actionPerformed(ActionEvent e) {
                    // This code executes when the button is clicked
                    statusLabel.setText("Button was clicked!");
                    System.out.println("Button clicked!");
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JButtonEventDemo();
                }
            });
        }
    }
    ```

*   **Important Point:** Anonymous inner classes are very commonly used for creating listeners directly where they are registered, as shown in the example. This keeps the code concise for simple event handlers.

#### **3.3. JTextField and Document/Action/Focus Events**

*   **JTextField:** A single-line text input field.
*   **Key Events for JTextField:**
    *   **Action Event:** When the user presses **Enter** while the JTextField has focus. This uses the `ActionListener` interface and `actionPerformed()` method, similar to `JButton`.
    *   **Document Events:** When the content of the text field changes (characters are inserted, removed, or replaced). These are handled by the `DocumentListener` interface.
    *   **Focus Events:** When the component gains or loses keyboard focus. These use the `FocusListener` interface.

*   **Handling Action Event (Enter Key Press):**

    ```java
    import javax.swing.*;
    import java.awt.event.*;
    import java.awt.FlowLayout;

    public class JTextFieldActionEventDemo extends JFrame {

        private JTextField inputField;
        private JLabel outputLabel;

        public JTextFieldActionEventDemo() {
            setTitle("JTextField Action Event Demo");
            setSize(300, 150);
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            setLayout(new FlowLayout());

            inputField = new JTextField(20); // 20 columns wide
            outputLabel = new JLabel("Enter text and press Enter.");

            add(inputField);
            add(outputLabel);

            // Register an ActionListener for the JTextField
            inputField.addActionListener(new ActionListener() {
                @Override
                public void actionPerformed(ActionEvent e) {
                    // This code executes when the user presses Enter
                    String enteredText = inputField.getText();
                    outputLabel.setText("You entered: " + enteredText);
                    System.out.println("Enter pressed. Text: " + enteredText);
                    // Optionally clear the field after Enter
                    // inputField.setText("");
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JTextFieldActionEventDemo();
                }
            });
        }
    }
    ```

*   **Handling Document Events (Text Changes):**
    *   **Listener Interface:** `javax.swing.event.DocumentListener`.
    *   **Listener Methods:**
        *   `insertUpdate(DocumentEvent e)`: Called after text is inserted.
        *   `removeUpdate(DocumentEvent e)`: Called after text is removed.
        *   `changedUpdate(DocumentEvent e)`: Called for attribute changes (less common for plain text).
    *   **To get Document Events:** You need to get the `Document` object associated with the `JTextField` and add a `DocumentListener` to it.

    ```java
    import javax.swing.*;
    import javax.swing.event.DocumentEvent;
    import javax.swing.event.DocumentListener;
    import java.awt.event.*;
    import java.awt.FlowLayout;

    public class JTextFieldDocumentEventDemo extends JFrame {

        private JTextField inputField;
        private JLabel statusLabel;

        public JTextFieldDocumentEventDemo() {
            setTitle("JTextField Document Event Demo");
            setSize(300, 150);
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            setLayout(new FlowLayout());

            inputField = new JTextField(20);
            statusLabel = new JLabel("Type something in the text field.");

            add(inputField);
            add(statusLabel);

            // Get the Document from the JTextField
            inputField.getDocument().addDocumentListener(new DocumentListener() {
                @Override
                public void insertUpdate(DocumentEvent e) {
                    updateLabel();
                }

                @Override
                public void removeUpdate(DocumentEvent e) {
                    updateLabel();
                }

                @Override
                public void changedUpdate(DocumentEvent e) {
                    // Plain text components don't fire changed updates
                    updateLabel();
                }

                private void updateLabel() {
                    String currentText = inputField.getText();
                    statusLabel.setText("Current text: " + currentText.length() + " chars");
                    System.out.println("Text changed: " + currentText);
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JTextFieldDocumentEventDemo();
                }
            });
        }
    }
    ```

*   **Handling Focus Events:**
    *   **Listener Interface:** `java.awt.event.FocusListener`.
    *   **Listener Methods:**
        *   `focusGained(FocusEvent e)`: Called when the component gains focus.
        *   `focusLost(FocusEvent e)`: Called when the component loses focus.

    ```java
    import javax.swing.*;
    import java.awt.event.*;
    import java.awt.FlowLayout;

    public class JTextFieldFocusEventDemo extends JFrame {

        private JTextField field1, field2;

        public JTextFieldFocusEventDemo() {
            setTitle("JTextField Focus Event Demo");
            setSize(350, 150);
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            setLayout(new FlowLayout());

            field1 = new JTextField(15);
            field2 = new JTextField(15);

            add(new JLabel("Field 1:"));
            add(field1);
            add(new JLabel("Field 2:"));
            add(field2);

            // Add FocusListener to field1
            field1.addFocusListener(new FocusAdapter() { // Using FocusAdapter for convenience
                @Override
                public void focusGained(FocusEvent e) {
                    System.out.println("Focus gained by Field 1");
                    field1.setToolTipText("You are typing in Field 1!");
                }

                @Override
                public void focusLost(FocusEvent e) {
                    System.out.println("Focus lost by Field 1");
                    field1.setToolTipText(null); // Clear tooltip
                }
            });

            // Add FocusListener to field2
            field2.addFocusListener(new FocusAdapter() {
                @Override
                public void focusGained(FocusEvent e) {
                    System.out.println("Focus gained by Field 2");
                }

                @Override
                public void focusLost(FocusEvent e) {
                    System.out.println("Focus lost by Field 2");
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JTextFieldFocusEventDemo();
                }
            });
        }
    }
    ```

#### **3.4. JLabel and Event Handling (Less Common)**

*   **JLabel:** Typically used for displaying static text or images. By default, `JLabel` does not generate events.
*   **Making JLabel Interactive:** To make a `JLabel` respond to events, you need to:
    1.  **Enable Event Generation:** Call `setFocusable(true)` on the `JLabel`. This allows it to receive keyboard focus.
    2.  **Register a Listener:** Add a listener (e.g., `MouseListener` or `KeyListener`) to the `JLabel`.

*   **Example (Clicking a JLabel):**

    ```java
    import javax.swing.*;
    import java.awt.event.*;
    import java.awt.FlowLayout;

    public class JLabelEventDemo extends JFrame {

        private JLabel clickableLabel;

        public JLabelEventDemo() {
            setTitle("JLabel Event Demo");
            setSize(300, 150);
            setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            setLayout(new FlowLayout());

            clickableLabel = new JLabel("Clickable Label");
            clickableLabel.setFocusable(true); // Make it focusable

            add(clickableLabel);

            // Register a MouseListener for the JLabel
            clickableLabel.addMouseListener(new MouseAdapter() { // Using MouseAdapter
                @Override
                public void mouseClicked(MouseEvent e) {
                    System.out.println("JLabel clicked!");
                    clickableLabel.setText("You clicked me!");
                }
            });

            setVisible(true);
        }

        public static void main(String[] args) {
            SwingUtilities.invokeLater(new Runnable() {
                public void run() {
                    new JLabelEventDemo();
                }
            });
        }
    }
    ```

*   **Important Point:** `JLabel` is not typically designed for direct user interaction like buttons. If you need interactive text, consider using `JButton` with a transparent background or `JHyperlink` (from `JFC` or custom implementations) for a more appropriate look and feel.

### **4. Key Concepts and Definitions Recap**

*   **Event:** An action or occurrence that Java programs can respond to.
*   **Event Source:** The object that triggers the event.
*   **Event Listener:** An object that waits for events and reacts to them.
*   **Event Object:** Carries information about the event.
*   **Delegation Event Model:** The architectural pattern where the event source delegates event handling to a registered listener.
*   **Listener Interfaces:** Define the methods that listeners must implement (e.g., `ActionListener`, `WindowListener`, `DocumentListener`).
*   **Adapter Classes:** Provide default implementations for listener interfaces, simplifying the creation of listeners that only handle a few specific event types (e.g., `WindowAdapter`, `FocusAdapter`, `MouseAdapter`).
*   **`add<EventType>Listener()`:** The method used on event sources to register listeners.
*   **`ActionEvent`:** Triggered by buttons, menu items, and Enter key in text fields. Handled by `ActionListener`.
*   **`WindowEvent`:** Triggered by window state changes. Handled by `WindowListener`.
*   **`DocumentEvent`:** Triggered by changes in `JTextField` content. Handled by `DocumentListener`.
*   **`FocusEvent`:** Triggered by component gaining or losing focus. Handled by `FocusListener`.
*   **`SwingUtilities.invokeLater()`:** Crucial for ensuring GUI updates and event handling occur on the Event Dispatch Thread (EDT) to prevent thread-related issues.

---

### **5. Important Points to Remember**

*   **Event Dispatch Thread (EDT):** All Swing GUI updates and event handling should ideally happen on the EDT. `SwingUtilities.invokeLater()` is the standard way to submit tasks to the EDT.
*   **`setDefaultCloseOperation()`:** Understand the different options for `JFrame`'s close operation (`EXIT_ON_CLOSE`, `DISPOSE_ON_CLOSE`, `HIDE_ON_CLOSE`, `DO_NOTHING_ON_CLOSE`).
*   **Source Identification:** Inside an event handler, `e.getSource()` returns the object that fired the event, allowing you to differentiate actions if multiple components share the same listener.
*   **Component Focus:** For `JTextField` and `JLabel` to effectively participate in focus and key events, they might need to be made focusable.
*   **Layout Managers:** While not directly event handling, layout managers are essential for arranging components that will be involved in event handling.
*   **Multiple Listeners:** A single component can have multiple listeners registered for the same event type.
*   **Single Listener, Multiple Events:** A single listener object can implement multiple listener interfaces to handle different types of events from one or more components.

### **6. Practice Questions and Exercises**

**Question 1:** Explain the three main components of the Delegation Event Model in Java Swing. (K2)

**Answer:**
The three main components are:
1.  **Event Source:** The component that generates the event (e.g., a `JButton`).
2.  **Event Listener:** An object that is registered with the event source and contains methods to handle specific events.
3.  **Event Object:** An object that encapsulates the details of the event that occurred.

**Question 2:** What listener interface and method would you use to detect when a user presses the Enter key while focus is on a `JTextField`? (K2)

**Answer:**
You would use the `ActionListener` interface and its `actionPerformed(ActionEvent e)` method.

**Question 3:** Write a Java Swing program that creates a `JFrame` with a `JButton`. When the button is clicked, it should change the title of the `JFrame`. (K3)

**Solution:**

```java
import javax.swing.*;
import java.awt.event.*;

public class ButtonTitleChange extends JFrame {

    private JButton changeTitleButton;

    public ButtonTitleChange() {
        setTitle("Initial Title");
        setSize(300, 100);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(new FlowLayout()); // Simple layout

        changeTitleButton = new JButton("Change Frame Title");
        add(changeTitleButton);

        // Add ActionListener to the button
        changeTitleButton.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                setTitle("Title Changed!"); // Change the JFrame's title
            }
        });

        setVisible(true);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(new Runnable() {
            public void run() {
                new ButtonTitleChange();
            }
        });
    }
}
```

**Question 4:** Describe the purpose of the `WindowAdapter` class and why it is useful. (K2)

**Answer:**
`WindowAdapter` is a convenience adapter class for `WindowListener`. It provides empty method implementations for all the methods declared in the `WindowListener` interface. It is useful because it allows developers to extend `WindowAdapter` and override only the specific `WindowListener` methods they need to handle, rather than implementing all seven methods of the `WindowListener` interface.

**Question 5:** Create a Swing application with a `JTextField`. When the text in the `JTextField` changes (characters are added or deleted), update a `JLabel` to show the current number of characters in the text field. (K3)

**Solution:**

```java
import javax.swing.*;
import javax.swing.event.DocumentEvent;
import javax.swing.event.DocumentListener;
import java.awt.FlowLayout;

public class TextFieldCharCount extends JFrame {

    private JTextField inputField;
    private JLabel charCountLabel;

    public TextFieldCharCount() {
        setTitle("Text Field Character Count");
        setSize(350, 120);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(new FlowLayout());

        inputField = new JTextField(25);
        charCountLabel = new JLabel("Character count: 0");

        add(new JLabel("Enter text:"));
        add(inputField);
        add(charCountLabel);

        // Add DocumentListener to track text changes
        inputField.getDocument().addDocumentListener(new DocumentListener() {
            @Override
            public void insertUpdate(DocumentEvent e) {
                updateLabel();
            }

            @Override
            public void removeUpdate(DocumentEvent e) {
                updateLabel();
            }

            @Override
            public void changedUpdate(DocumentEvent e) {
                // This is for attribute changes, less relevant for plain text
                updateLabel();
            }

            private void updateLabel() {
                charCountLabel.setText("Character count: " + inputField.getText().length());
            }
        });

        setVisible(true);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(new Runnable() {
            public void run() {
                new TextFieldCharCount();
            }
        });
    }
}
```
