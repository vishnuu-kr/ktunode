# Module 3: Search Methods: One-Dimensional Optimization

## Topic: Steepest Descent/Ascent Methods

This module introduces methods for finding the minimum (or maximum) of a function that depends on a single variable. The Steepest Descent (for minimization) and Steepest Ascent (for maximization) methods are foundational iterative techniques for solving such problems.
