# Module 3: Search Methods: One-Dimensional Optimization

## Topic: Univariate Search

### 1. Introduction to One-Dimensional Optimization

*   **Objective:** To find the minimum (or maximum) of a function of a single variable, $f(x)$, within a given interval $[a, b]$.
*   **Civil Engineering Applications:**
    *   Optimizing the cross-sectional dimensions of a beam for maximum stiffness or minimum material.
    *   Finding the optimal location for a facility along a single road.
    *   Determining the optimal curing time for concrete to achieve desired strength.
    *   Minimizing the cost of a pipeline of a certain length.

### 2. Univariate Search: The Core Idea

*   **Concept:** Univariate search methods involve systematically narrowing down an interval that is known to contain the optimum of a unimodal function. A unimodal function has only one minimum (or maximum) within a given interval.
*   **Unimodal Function:** A function $f(x)$ is unimodal on an interval $[a, b]$ if there exists a point $x^*$ in $[a, b]$ such that:
