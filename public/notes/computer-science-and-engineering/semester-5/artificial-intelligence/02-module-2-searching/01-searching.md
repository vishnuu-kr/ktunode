## ARTIFICIAL INTELLIGENCE - Module 2: Searching - Topic: Searching

**Introduction:**

This module delves into the fundamental concept of searching, a cornerstone of Artificial Intelligence. Searching involves exploring a state space to find a solution that satisfies a given goal. It's a crucial technique used in problem-solving, game playing, route planning, and many other AI applications. This topic covers the basics of defining a search problem and introduces common search algorithms.

**Learning Outcomes:**

By the end of this topic, you should be able to:

*   Define a search problem and its components.
*   Understand the concepts of state space, search tree, and solution.
*   Differentiate between various search algorithms based on their properties (completeness, optimality, time complexity, space complexity).
*   Apply uninformed (blind) search algorithms to solve simple search problems (Breadth-First Search, Depth-First Search, Depth-Limited Search, Iterative Deepening Search).
*   Understand the advantages and disadvantages of each uninformed search algorithm.

**1. Defining a Search Problem:**

A search problem can be formally defined by specifying the following components:

*   **Initial State:** The state from which the search begins.  This represents the starting point of the problem.
    *   **Example:**  In a route-finding problem, the initial state might be your current location. In the 8-puzzle, it's the initial configuration of tiles.

*   **Actions:** A set of possible actions that can be taken in each state.  These actions define how the agent can move from one state to another.
    *   **Example:**  In a route-finding problem, actions might be "go north," "go south," "go east," or "go west."  In the 8-puzzle, actions might be "move the blank tile up," "move the blank tile down," "move the blank tile left," or "move the blank tile right."

*   **Transition Model:** A function that describes what happens when a specific action is executed in a specific state.  It defines the result of taking an action. This is often represented as `Result(state, action)`, which returns the new state reached by taking action `action` in state `state`.
    *   **Example:** `Result(Location A, "go north")` might return `Location B`.  In the 8-puzzle, `Result(state, "move blank up")` would return the new state of the puzzle after the blank tile has been moved up (if that move is legal).

*   **Goal Test:** A function that determines whether a given state is a goal state.  This is how the search algorithm knows when it has found a solution.
    *   **Example:**  In a route-finding problem, the goal test might check if the current location is the desired destination.  In the 8-puzzle, the goal test might check if the tiles are arranged in the correct order.

*   **Path Cost:** A function that assigns a numerical cost to each path. The search algorithm aims to find a path with the lowest cost.  The cost can be based on distance, time, resources, or any other relevant factor.
    *   **Example:**  In a route-finding problem, the path cost might be the total distance traveled.  In the 8-puzzle, the path cost might be the number of moves made to reach the goal state. Often, a *step cost* is defined which gives the cost of applying a particular action in a particular state. Then, the path cost is the sum of the step costs along the path.

**Key Concepts and Definitions:**

*   **State:** A representation of the current situation in the problem.
*   **State Space:** The set of all possible states reachable from the initial state. This can be visualized as a graph where nodes represent states and edges represent actions.
*   **Search Tree:** A tree-like representation of the state space, rooted at the initial state. Each node in the tree represents a state, and each branch represents an action. The search tree is generated by expanding nodes in the state space.
*   **Node:** A data structure used to represent a state in the search tree.  A node typically contains the state, the parent node (the node that generated it), the action that led to the current state, and the path cost from the initial state to the current state.
*   **Branching Factor (b):** The maximum number of children a node can have in the search tree.
*   **Depth (d):** The depth of the shallowest goal node.
*   **Maximum Depth (m):**  The maximum length of any path in the state space. This might be infinite if the state space contains loops.
*   **Solution:** A sequence of actions that leads from the initial state to a goal state.
*   **Optimal Solution:**  A solution with the lowest path cost.

**2. Search Algorithms and their Properties:**

Search algorithms are evaluated based on the following properties:

*   **Completeness:** Does the algorithm guarantee to find a solution if one exists?
*   **Optimality:** Does the algorithm guarantee to find the optimal solution (i.e., the solution with the lowest cost)?
*   **Time Complexity:** How long does the algorithm take to find a solution?  This is typically expressed in terms of the branching factor (b), depth (d), and maximum depth (m).
*   **Space Complexity:** How much memory does the algorithm require to store the search tree and other data?  This is also typically expressed in terms of b, d, and m.

**3. Uninformed (Blind) Search Algorithms:**

Uninformed search algorithms use only the information available in the problem definition. They do not have any knowledge about the distance to the goal or the cost of reaching the goal from a given state.

Here's a breakdown of some common uninformed search algorithms:

*   **Breadth-First Search (BFS):**
    *   **Strategy:** Expands the shallowest unexpanded node. Implemented using a FIFO queue.
    *   **Completeness:** Complete if *b* is finite.
    *   **Optimality:** Optimal if all step costs are identical.
    *   **Time Complexity:** O(b<sup>d</sup>)
    *   **Space Complexity:** O(b<sup>d</sup>) (keeps every node in memory)
    *   **Advantages:** Guarantees finding the shallowest goal node.
    *   **Disadvantages:** High space complexity, especially for large state spaces.

*   **Depth-First Search (DFS):**
    *   **Strategy:** Expands the deepest unexpanded node. Implemented using a LIFO stack (or recursion).
    *   **Completeness:** Not complete (can get stuck in infinite loops). Complete in finite state spaces with loop avoidance.
    *   **Optimality:** Not optimal.
    *   **Time Complexity:** O(b<sup>m</sup>)  (can be much larger than BFS if *m* is much larger than *d*)
    *   **Space Complexity:** O(bm) (much lower than BFS)
    *   **Advantages:** Low space complexity.
    *   **Disadvantages:** Not complete, not optimal, can explore a very long path even if a goal state is nearby.

*   **Depth-Limited Search (DLS):**
    *   **Strategy:** Performs DFS up to a specified depth limit *l*.
    *   **Completeness:** Complete if the goal is within the depth limit *l*.
    *   **Optimality:** Not optimal.
    *   **Time Complexity:** O(b<sup>l</sup>)
    *   **Space Complexity:** O(bl)
    *   **Advantages:** Avoids the infinite-loop problem of DFS.
    *   **Disadvantages:** If the depth limit *l* is less than the depth of the shallowest goal node, the algorithm will fail to find a solution. Choosing the right depth limit is crucial.

*   **Iterative Deepening Search (IDS):**
    *   **Strategy:** Repeatedly performs DLS, increasing the depth limit *l* by one in each iteration until a goal is found.
    *   **Completeness:** Complete.
    *   **Optimality:** Optimal if all step costs are identical.
    *   **Time Complexity:** O(b<sup>d</sup>) (asymptotically the same as BFS)
    *   **Space Complexity:** O(bd)  (much lower than BFS)
    *   **Advantages:** Complete, optimal (with uniform cost), and has low space complexity.
    *   **Disadvantages:**  Repeatedly generates the same states, but this overhead is often not significant.

**Example:**

Consider a simple graph where nodes represent cities, and edges represent roads connecting them. The problem is to find a route from city A to city G.

```
      A
     / \
    B   C
   / \   \
  D   E   F
       \
        G
```

*   **Initial State:** A
*   **Actions:** Move to a neighboring city (e.g., from A, the actions are to go to B or C).
*   **Transition Model:**  `Result(A, "go to B")` returns `B`.
*   **Goal Test:** Check if the current city is G.
*   **Path Cost:** The number of roads traveled.

Let's apply BFS to find a path from A to G:

1.  Start at A. Enqueue A.
2.  Dequeue A. Expand A to B and C. Enqueue B and C.
3.  Dequeue B. Expand B to D and E. Enqueue D and E.
4.  Dequeue C. Expand C to F. Enqueue F.
5.  Dequeue D. D has no children.
6.  Dequeue E. Expand E to G. Enqueue G.
7.  Dequeue F. F has no children.
8.  Dequeue G. Goal test passes.

The solution found by BFS is A -> B -> E -> G.

**Practice Questions & Exercises:**

1.  **Question:** Define the components of a search problem for finding the shortest path between two cities on a map.

    **Answer:**
    *   **Initial State:** The starting city.
    *   **Actions:** Moving from the current city to a neighboring city connected by a road.
    *   **Transition Model:** `Result(city A, "go to city B")` returns city B if there's a road from A to B.
    *   **Goal Test:** Check if the current city is the destination city.
    *   **Path Cost:** The total distance traveled (sum of the distances of the roads traveled).

2.  **Question:** Explain the difference between DFS and BFS in terms of how they explore the state space.

    **Answer:** DFS explores the state space by going as deep as possible along each branch before backtracking, while BFS explores the state space by expanding all the nodes at a given depth before moving to the next depth level.  DFS uses a stack, while BFS uses a queue.

3.  **Question:** Which uninformed search algorithm is complete and optimal when all step costs are equal?

    **Answer:** Breadth-First Search (BFS) and Iterative Deepening Search (IDS).

4.  **Exercise:** Consider the following search problem:

    *   Initial State: S
    *   Goal State: G
    *   Actions: A, B, C
    *   Transition Model: Defined by the following graph:

    ```
       S --A--> 1 --B--> G
       S --C--> 2
       1 --C--> 2
       2 --B--> G
    ```

    Show the order in which nodes are expanded using:
    *   a) Breadth-First Search
    *   b) Depth-First Search

    **Answer:**

    *   a) BFS: S, 1, 2, G (Solution: S-A-1-B-G or S-C-2-B-G)
    *   b) DFS: S, 1, G (Solution: S-A-1-B-G) (Note that DFS may find different solutions depending on the order in which actions A, B, C are considered from each state)

**Important Points to Remember:**

*   The choice of search algorithm depends on the characteristics of the problem, such as the size of the state space, the branching factor, and whether an optimal solution is required.
*   Uninformed search algorithms can be inefficient for large state spaces. Informed search algorithms (covered in later modules) use heuristics to guide the search and can be much more efficient.
*   Understanding the properties of different search algorithms is crucial for selecting the appropriate algorithm for a given task.
*   Space complexity is a significant concern for many search problems, especially those with large state spaces.
