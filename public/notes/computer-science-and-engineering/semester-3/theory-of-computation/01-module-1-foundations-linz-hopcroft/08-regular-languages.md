# THEORY OF COMPUTATION: Module 1 - Regular Languages

## Learning Outcomes:

*   Understand the definition of regular languages and regular expressions.
*   Be able to convert between regular expressions, deterministic finite automata (DFAs), and non-deterministic finite automata (NFAs).
*   Understand and apply Kleene's Theorem.
*   Apply the Pumping Lemma to prove that a language is *not* regular.
*   Perform operations on regular languages (union, concatenation, Kleene star, intersection, complement).
*   Understand closure properties of regular languages.
*   Understand the Myhill-Nerode Theorem and its applications.

## 1. Introduction to Regular Languages

*   **Definition:** A regular language is a language that can be:
    *   Recognized by a Finite Automaton (DFA or NFA).
    *   Generated by a Regular Expression.
    *   Described by a Regular Grammar.

*   **Importance:** Regular languages are a fundamental class of languages in Computer Science. They are used in:
    *   Lexical analysis in compilers.
    *   Text searching (e.g., `grep`).
    *   Pattern matching.
    *   Protocol specification.
    *   Hardware design.

## 2. Regular Expressions (REs)

*   **Definition:** A regular expression is a string that describes a pattern to be matched in a text.

*   **Basic Regular Expressions:** Let Σ be an alphabet.
    *   `∅` (empty set): Denotes the language containing no strings.
    *   `ε` (epsilon): Denotes the language containing only the empty string.
    *   `a` (where a ∈ Σ): Denotes the language containing only the string `a`.

*   **Operations on Regular Expressions:** Let `r` and `s` be regular expressions. Then:
    *   `r|s` (union): Denotes the language L(r) ∪ L(s).  Also denoted as `r+s` in some texts.
    *   `rs` (concatenation): Denotes the language L(r)L(s) = {xy | x ∈ L(r) and y ∈ L(s)}.
    *   `r*` (Kleene star): Denotes the language L(r)* = {ε, r, rr, rrr, ...} (zero or more concatenations of `r`).
    *   `r+` (Positive closure): Denotes the language L(r)+ = {r, rr, rrr, ...} (one or more concatenations of `r`).  Equivalent to `rr*`.
    *   `(r)` (parentheses): Used for grouping and precedence.

*   **Operator Precedence:**  From highest to lowest:
    1.  Kleene star (*) and positive closure (+)
    2.  Concatenation
    3.  Union (|)

*   **Examples:**
    *   `a*`:  The language {ε, a, aa, aaa, ...}
    *   `a|b`: The language {a, b}
    *   `(a|b)*`: The language containing all strings of a's and b's.
    *   `a(a|b)*b`: The language containing all strings of a's and b's that start with an 'a' and end with a 'b'.
    *   `(0|1)*00`: All strings of 0's and 1's ending in 00.
    *   `1(01*0)*1`:  All strings over {0,1} with an even number of 0's.

## 3. Finite Automata (FA)

*   **Deterministic Finite Automaton (DFA):**

    *   **Definition:** A DFA is a 5-tuple M = (Q, Σ, δ, q₀, F), where:
        *   Q is a finite set of states.
        *   Σ is a finite alphabet.
        *   δ: Q × Σ → Q is the transition function.
        *   q₀ ∈ Q is the start state.
        *   F ⊆ Q is the set of accept states.

    *   **Operation:**  A DFA starts in the start state (q₀). For each input symbol, it transitions to a new state as determined by the transition function (δ).  After processing the entire input string, if the DFA is in an accept state (F), the string is accepted. Otherwise, it is rejected.

    *   **Diagrammatic Representation:** States are represented by circles, with double circles representing accept states. Transitions are represented by arrows labeled with input symbols.  The start state has an arrow pointing to it from nowhere.

    *   **Example:**  A DFA that accepts strings ending in 'b'.
        *   Q = {q₀, q₁}
        *   Σ = {a, b}
        *   δ:
            | State | Input a | Input b |
            |---|---|---|
            | q₀ | q₀ | q₁ |
            | q₁ | q₀ | q₁ |
        *   q₀ is the start state.
        *   F = {q₁}

*   **Non-deterministic Finite Automaton (NFA):**

    *   **Definition:** An NFA is a 5-tuple M = (Q, Σ, δ, q₀, F), where:
        *   Q is a finite set of states.
        *   Σ is a finite alphabet.
        *   δ: Q × (Σ ∪ {ε}) → P(Q) is the transition function (power set of Q).  Can transition to a *set* of states, and can transition on the empty string (ε-transitions).
        *   q₀ ∈ Q is the start state.
        *   F ⊆ Q is the set of accept states.

    *   **Operation:**  An NFA can be in multiple states at the same time.  It accepts a string if *any* of its possible execution paths end in an accept state after processing the entire input string.

    *   **ε-transitions:**  NFAs can transition from one state to another without consuming any input symbol. This adds flexibility.

    *   **Example:** An NFA that accepts strings ending in 'ab'.
        *   Q = {q₀, q₁, q₂}
        *   Σ = {a, b}
        *   δ:
            | State | Input a | Input b | Input ε |
            |---|---|---|---|
            | q₀ | {q₀, q₁} | {q₀} | ∅ |
            | q₁ | ∅ | {q₂} | ∅ |
            | q₂ | ∅ | ∅ | ∅ |
        *   q₀ is the start state.
        *   F = {q₂}

*   **Important Note:** Every DFA is an NFA, but not every NFA is a DFA.  The key difference is the determinism of the transition function.

## 4. Conversion Between Regular Expressions, NFAs, and DFAs

*   **Regular Expression to NFA (Thompson's Construction):** A constructive algorithm that builds an NFA for any regular expression.  It recursively constructs NFAs for basic expressions (∅, ε, a) and then combines them using NFAs for union, concatenation, and Kleene star.

*   **NFA to DFA (Subset Construction):** An algorithm that converts an NFA to a DFA. The states of the DFA are sets of states from the NFA.  This algorithm simulates the parallel execution of the NFA by tracking the set of reachable states.

*   **DFA to Regular Expression:** Can be done using state elimination or by solving a system of equations representing the transitions between states. (See Linz or Hopcroft for detailed algorithms).  This conversion is often more complex than the other two.

## 5. Kleene's Theorem

*   **Statement:** A language is regular if and only if it can be:
    *   Described by a regular expression.
    *   Recognized by a DFA.
    *   Recognized by an NFA.

*   **Significance:**  Kleene's Theorem formally establishes the equivalence of these three representations of regular languages.  It provides a powerful tool for proving that a language is regular: simply show that it can be described by *any* of the three representations.

## 6. The Pumping Lemma for Regular Languages

*   **Purpose:** A powerful tool used to prove that a language is *not* regular.  It is a *necessary* condition for a language to be regular, but not sufficient.

*   **Statement:** If L is a regular language, then there exists a pumping length *p* (where *p* ≥ 1) such that for any string *w* in L where |*w*| ≥ *p*, *w* can be divided into three substrings, *w* = *xyz*, satisfying the following conditions:
    1.  |*y*| > 0  (the pumped portion *y* is non-empty)
    2.  |*xy*| ≤ *p*  (the pumped portion and the prefix are no longer than *p*)
    3.  For all *i* ≥ 0, *xy<sup>i</sup>z* ∈ L (pumping *y* any number of times results in a string still in L).

*   **How to use the Pumping Lemma to prove that L is not regular:**
    1.  Assume, for the sake of contradiction, that L is regular.
    2.  Therefore, the Pumping Lemma holds for L.
    3.  Let *p* be the pumping length guaranteed by the Pumping Lemma.
    4.  Choose a string *w* ∈ L such that |*w*| ≥ *p*.  (This is the *crucial* step. The choice of *w* is critical to making the proof work).
    5.  Consider all possible ways to divide *w* into *xyz* such that |*y*| > 0 and |*xy*| ≤ *p*.
    6.  For each possible division, find an *i* ≥ 0 such that *xy<sup>i</sup>z* ∉ L.
    7.  Since we have shown that for all possible divisions of *w*, there exists an *i* such that *xy<sup>i</sup>z* ∉ L, we have contradicted the Pumping Lemma.
    8.  Therefore, our initial assumption that L is regular must be false.  Hence, L is not regular.

*   **Example:**  Prove that L = {a<sup>n</sup>b<sup>n</sup> | n ≥ 0} is not regular.
    1.  Assume L is regular.
    2.  Let *p* be the pumping length.
    3.  Let *w* = a<sup>p</sup>b<sup>p</sup>.  |w| = 2p ≥ p.
    4.  Consider all possible divisions of *w* into *xyz* such that |*y*| > 0 and |*xy*| ≤ *p*. This means that *xy* can only consist of a's, and *y* consists of at least one a.  Therefore, *y* = a<sup>k</sup> for some k > 0.
    5.  Let *i* = 0.  Then *xy<sup>0</sup>z* = *xz* = a<sup>p-k</sup>b<sup>p</sup>.
    6.  Since k > 0, p-k < p. Therefore, *xz* has fewer a's than b's, so *xz* ∉ L.
    7.  We have contradicted the Pumping Lemma.
    8.  Therefore, L is not regular.

## 7. Operations on Regular Languages

*   Regular languages are closed under the following operations.  That is, if L₁ and L₂ are regular languages, then the following languages are also regular:
    *   **Union:** L₁ ∪ L₂
    *   **Concatenation:** L₁L₂
    *   **Kleene Star:** L₁*
    *   **Intersection:** L₁ ∩ L₂ (Proof: Use DeMorgan's Law and closure under complementation.)
    *   **Complementation:** ¬L₁ (The language of all strings *not* in L₁)
    *   **Reversal:** L₁<sup>R</sup> (The language consisting of the reversals of all strings in L₁)
    *   **Difference:** L₁ - L₂ (L₁ ∩ ¬L₂)

*   **Closure Properties:**  These closure properties are useful for proving that a language is regular. If you can show that a language can be constructed from regular languages using these operations, then it is also regular.

## 8. The Myhill-Nerode Theorem

*   **Concept:** The Myhill-Nerode Theorem provides a necessary and sufficient condition for a language to be regular.  It connects the concept of distinguishability of strings with the existence of a DFA that recognizes the language.

*   **Definition: Distinguishability:** Two strings *x* and *y* are distinguishable with respect to a language L if there exists a string *z* such that *xz* ∈ L and *yz* ∉ L, or *xz* ∉ L and *yz* ∈ L.  If no such *z* exists, then *x* and *y* are *indistinguishable*.

*   **Theorem (Myhill-Nerode):** The following three statements are equivalent:
    1.  L is a regular language.
    2.  There exists a DFA that recognizes L.
    3.  The equivalence relation ~<sub>L</sub> defined by x ~<sub>L</sub> y if and only if for all z, xz ∈ L if and only if yz ∈ L, has a finite number of equivalence classes. In other words, the number of pairwise distinguishable strings (with respect to L) is finite.

*   **Minimal DFA:** The Myhill-Nerode Theorem implies that for every regular language, there exists a *unique* minimal DFA (up to isomorphism) that recognizes the language. This DFA has the fewest number of states possible.  Each state in the minimal DFA corresponds to an equivalence class of indistinguishable strings.

*   **Using Myhill-Nerode to prove non-regularity:**  If you can show that a language L requires an *infinite* number of pairwise distinguishable strings, then L is not regular.

*   **Example:** Prove that L = {a<sup>n</sup>b<sup>n</sup> | n ≥ 0} is not regular using the Myhill-Nerode theorem.

    Consider the strings a<sup>0</sup>, a<sup>1</sup>, a<sup>2</sup>, a<sup>3</sup>, ....  We will show that these strings are all pairwise distinguishable with respect to L.  Let a<sup>i</sup> and a<sup>j</sup> be any two strings in this set, where i ≠ j. Then consider the string z = b<sup>i</sup>.

    *   a<sup>i</sup>z = a<sup>i</sup>b<sup>i</sup> ∈ L
    *   a<sup>j</sup>z = a<sup>j</sup>b<sup>i</sup> ∉ L (since i ≠ j)

    Therefore, for any two distinct strings a<sup>i</sup> and a<sup>j</sup>, there exists a string z such that a<sup>i</sup>z ∈ L and a<sup>j</sup>z ∉ L. This means that a<sup>i</sup> and a<sup>j</sup> are distinguishable.  Since there are an infinite number of such strings a<sup>i</sup>, the language L requires an infinite number of pairwise distinguishable strings. By the Myhill-Nerode theorem, L is not regular.

## Practice Questions & Exercises

1.  **Write regular expressions for the following languages over the alphabet Σ = {0, 1}:**

    *   a) All strings that start with '1' and end with '0'.
    *   b) All strings that contain the substring '110'.
    *   c) All strings with an even number of '1's.
    *   d) All strings with at least three '0's.
    *   e) All strings that do *not* contain the substring '111'.

    **Answers:**

    *   a) `1(0|1)*0`
    *   b) `(0|1)*110(0|1)*`
    *   c) `0*(10*10*)*` or `0*(10*1)*0*`
    *   d) `1*01*01*01*`
    *   e) This is tricky. One possible solution is to consider the strings before "111". It's easiest to handle with DFAs (see below), converting to regular expressions can be difficult. A valid expression is `(110|10|0)*(ε|1|11)`

    (Solution diagram requires a drawing tool, but the process involves constructing NFAs for `a`, `b`, `(a|b)`, `(a|b)*`, then concatenating with `a` and `b`.)

3.  **Convert the following NFA to a DFA using Subset Construction:**

    NFA: Q = {q₀, q₁, q₂}, Σ = {a, b}, q₀ = q₀, F = {q₂}, transitions:

    | State | Input a | Input b | Input ε |
    |---|---|---|---|
    | q₀ | {q₁} | ∅ | ∅ |
    | q₁ | ∅ | {q₂} | ∅ |
    | q₂ | ∅ | ∅ | ∅ |

    (Solution:  The DFA states will be sets of NFA states: {q₀}, {q₁}, {q₂}, ∅. Calculate the transitions based on the NFA transitions.  The accept states will be all states in the DFA that contain q₂.)

    (Solution: Choose w = a<sup>p</sup>ba<sup>p</sup>b.  Carefully consider all possible divisions xyz, ensuring |y| > 0 and |xy| <= p. Show that pumping *y* any number of times leads to a string not in L.)

5.  **Are regular languages closed under the reversal operation?  Prove your answer.**

    (Yes.  Proof: Given a regular language L recognized by a DFA M, we can construct an NFA M' that recognizes L<sup>R</sup> by reversing all transitions in M, making the start state an accept state, and making the accept states start states.  Since L<sup>R</sup> can be recognized by an NFA, it is regular.)

6.  **Explain the difference between a DFA and an NFA.**

    (A DFA has a single, deterministic transition for each input symbol from each state. An NFA can have multiple possible transitions for an input symbol (or an epsilon transition), and can be in multiple states at the same time.  DFAs are easier to implement, while NFAs can sometimes be more concise.)

## Important Points to Remember:

*   Kleene's Theorem connects regular expressions, DFAs, and NFAs.  Use whichever representation is easiest to work with.
*   The Pumping Lemma is used to prove that a language is *not* regular.  Choose your string *w* carefully!
*   The Myhill-Nerode Theorem gives a *necessary and sufficient* condition for regularity.  It is often harder to apply than the Pumping Lemma.
*   Understand the closure properties of regular languages.
*   Regular languages are a fundamental building block for more complex language classes.
