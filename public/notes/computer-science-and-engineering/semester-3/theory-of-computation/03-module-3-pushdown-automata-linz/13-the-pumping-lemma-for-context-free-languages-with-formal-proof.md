*   Learn the formal statement of the Pumping Lemma for CFLs.

### 1. Introduction to the Pumping Lemma for CFLs

*   **Purpose:** The Pumping Lemma for Context-Free Languages (CFLs) is a *necessary* condition that every CFL must satisfy. It's a powerful tool used to prove that certain languages are *not* context-free.  It works like this: if a language violates the Pumping Lemma, it's *not* context-free.  However, if a language *satisfies* the Pumping Lemma, we *cannot* conclude that it is context-free.
*   **Contrast with Regular Languages:**  Recall the Pumping Lemma for Regular Languages. This lemma addresses the limitations of finite automata (FAs).  The Pumping Lemma for CFLs similarly addresses the limitations of pushdown automata (PDAs), which are more powerful than FAs, but still have limitations.
*   **Intuition:** CFLs are generated by Context-Free Grammars (CFGs). If a CFG generates a sufficiently long string, its derivation tree must have a long path. This long path must repeat a variable. The repetition of a variable allows us to "pump" the string, meaning we can duplicate sections of the string while still remaining in the language.  If a language cannot be "pumped" in this way, it can't be context-free.

### 2. Formal Statement of the Pumping Lemma for CFLs

Let *L* be a context-free language. Then there exists an integer *p* ≥ 1 (the *pumping length*) such that for any string *w* in *L* with |*w*| ≥ *p*, *w* can be divided into five substrings, *w* = *uvxyz*, such that the following conditions hold:

1.  |*vxy*| ≤ *p*
2.  |*vy*| ≥ 1
3.  For all *i* ≥ 0, *uv<sup>i</sup>xy<sup>i</sup>z* ∈ *L*

**Explanation of the Components:**

*   **L:** The language we are trying to determine if it's context-free.
*   **p:** The pumping length. This is a property of the language *L*.  It represents a length such that any string in *L* longer than *p* must have the "pumpable" property.
*   **w:** Any string in *L* whose length is greater than or equal to *p*. This is the string we will attempt to "pump".
*   **u, v, x, y, z:** The five substrings that *w* must be divided into. The Pumping Lemma guarantees that such a division exists.
*   **|vxy| ≤ p:** The length of the substring *vxy* must be less than or equal to the pumping length *p*. This restriction is important for effectively using the lemma.  It confines the "pumpable" sections.
*   **|vy| ≥ 1:** The combined length of substrings *v* and *y* must be at least 1. This ensures that we are actually "pumping" something.  At least one of *v* or *y* must be non-empty.
*   **uv<sup>i</sup>xy<sup>i</sup>z ∈ L for all i ≥ 0:** This is the core of the lemma. It states that if we "pump" the substrings *v* and *y* any number of times (including zero times), the resulting string will still be in the language *L*. "Pumping" means repeating the substrings *v* and *y* *i* times.

### 3. Applying the Pumping Lemma to Prove a Language is NOT Context-Free

The Pumping Lemma is used to *disprove* that a language is context-free. Here's the typical proof structure:

1.  **Assume L is Context-Free:** Begin by assuming that the language *L* is context-free.
2.  **Assume Existence of Pumping Length p:**  By the Pumping Lemma, there exists a pumping length *p* > 0.
3.  **Choose a String w:** Choose a string *w* ∈ *L* such that |*w*| ≥ *p*.  The choice of *w* is *critical* to the success of the proof. It should be chosen carefully to exploit the limitations of context-free languages.  The string should generally have some type of dependency or relationship between parts of it that pumping will destroy.
4.  **Consider All Possible Divisions:**  For *all* possible ways to divide *w* into *uvxyz* satisfying the conditions |*vxy*| ≤ *p* and |*vy*| ≥ 1.  (This is the most challenging part).  Often, you don't need to examine *every single* division directly, but you must show that *no matter how* *w* is divided, a contradiction will arise.  You might divide cases based on where *vxy* falls within the string.
5.  **Find a Contradiction:**  For each possible division of *w* into *uvxyz*, choose a value of *i* (usually *i* = 0 or *i* = 2) and show that the resulting string *uv<sup>i</sup>xy<sup>i</sup>z* is *not* in *L*. This contradiction demonstrates that the Pumping Lemma is violated.
6.  **Conclude L is NOT Context-Free:** Since we assumed *L* was context-free and derived a contradiction by violating the Pumping Lemma, we conclude that *L* is *not* context-free.

### 4. Examples

**Example 1: L = {a<sup>n</sup>b<sup>n</sup>c<sup>n</sup> | n ≥ 0}**

Let's prove that L is *not* context-free using the Pumping Lemma.

1.  **Assume L is Context-Free:** Assume L is context-free.
2.  **Assume Existence of Pumping Length p:** There exists a pumping length *p* > 0.
3.  **Choose a String w:**  Choose *w* = a<sup>*p*</sup>b<sup>*p*</sup>c<sup>*p*</sup>.  Clearly, *w* ∈ *L* and |*w*| = 3*p* ≥ *p*.
4.  **Consider All Possible Divisions:** We need to consider all ways to divide *w* = a<sup>*p*</sup>b<sup>*p*</sup>c<sup>*p*</sup> into *uvxyz* such that |*vxy*| ≤ *p* and |*vy*| ≥ 1. We'll analyze cases based on where *vxy* falls within the string:

    *   **Case 1: *vxy* contains only 'a's:**  Then *v* and *y* consist only of 'a's. Let's pump with *i* = 2. The resulting string *uv<sup>2</sup>xy<sup>2</sup>z* will have more 'a's than 'b's or 'c's.  Therefore, *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 2: *vxy* contains only 'b's:** Similar to Case 1, pumping will unbalance the number of 'b's. *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 3: *vxy* contains only 'c's:** Similar to Cases 1 and 2, pumping will unbalance the number of 'c's. *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 4: *vxy* contains 'a's and 'b's:** Since |*vxy*| ≤ *p*, *vxy* can contain at most 'p' symbols, and thus must be contained entirely within the 'a's followed by the 'b's.  Since |*vy*| ≥ 1, at least one of *v* or *y* is not empty. When we pump, we will change the number of 'a's and 'b's, but not the number of 'c's.  Therefore, the pumped string will not have the same number of 'a's, 'b's, and 'c's, and thus *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 5: *vxy* contains 'b's and 'c's:** This case is analogous to Case 4. Pumping will change the number of 'b's and 'c's, but not the number of 'a's.  *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

5.  **Find a Contradiction:** In all possible cases, we can choose *i* such that *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*. This contradicts the Pumping Lemma.
6.  **Conclude L is NOT Context-Free:** Therefore, *L* = {a<sup>n</sup>b<sup>n</sup>c<sup>n</sup> | n ≥ 0} is not a context-free language.

**Example 2: L = {ww | w ∈ {a, b}*}**

Let's prove that L is *not* context-free. This language consists of strings that are a repetition of some string *w*. For example, "aabb" ∈ L, "abaaba" ∈ L, but "abab" ∉ L.

1.  **Assume L is Context-Free:** Assume L is context-free.
2.  **Assume Existence of Pumping Length p:** There exists a pumping length *p* > 0.
3.  **Choose a String w:** Choose *w* = a<sup>*p*</sup>b a<sup>*p*</sup>b. Clearly, *w* ∈ *L* and |*w*| = 2*p* + 2 ≥ *p*.
4.  **Consider All Possible Divisions:** Divide *w* = a<sup>*p*</sup>b a<sup>*p*</sup>b into *uvxyz* such that |*vxy*| ≤ *p* and |*vy*| ≥ 1.

    *   **Case 1: *vxy* lies entirely within the first group of *p* 'a's:** Pumping *v* and *y* will change the number of 'a's in the first group, but not in the second. Therefore, the resulting string will not be of the form ww.
        *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 2: *vxy* lies entirely within the second group of *p* 'a's:**  Similar to Case 1.
        *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*.

    *   **Case 3: *vxy* contains the 'b' between the first and second groups of 'a's and part of the first group of 'a's (but not the second 'b'):** In this case, since |*vy*| >= 1, pumping will insert at least one 'a' and/or 'b' before the first *b*. If we pump down (i=0), we will remove at least one 'a' and/or 'b' before the first *b*. Either way, the resulting string will not be of the form ww. *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*, or *uxz* ∉ *L*.

    *   **Case 4: *vxy* contains the 'b' between the first and second groups of 'a's and part of the second group of 'a's (but not the first 'b'):**  Similar to Case 3. *uv<sup>2</sup>xy<sup>2</sup>z* ∉ *L*, or *uxz* ∉ *L*.

    *   **Case 5:  *vxy* = a<sup>k</sup> for 0< k <= p. *v* and *y* consist only of 'a's and are non-empty**:  Let's choose *i*=0. The resulting string will have less 'a's on one of the sequences of 'a's. The string is not of the form *ww* and is therefore not in *L*. *uxz* ∉ *L*.

5.  **Find a Contradiction:** In all possible cases, we can choose *i* such that *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*. This contradicts the Pumping Lemma.

6.  **Conclude L is NOT Context-Free:** Therefore, *L* = {ww | w ∈ {a, b}*} is not a context-free language.

### 5. Important Points to Remember

*   **Necessary, Not Sufficient:** The Pumping Lemma is a *necessary* condition for a language to be context-free.  If a language violates the Pumping Lemma, it is *not* context-free. But, satisfying the Pumping Lemma does *not* guarantee that the language is context-free.
*   **Choosing the String w:**  The choice of *w* is critical. Choose a string that has a relationship between different parts that will be broken when you pump. Think about the "structure" of the language.
*   **All Possible Divisions:** You must consider *all* possible ways to divide *w* into *uvxyz*.  Often, this involves considering different cases based on where *vxy* lies within the string.
*   **Value of i:**  The choice of *i* is also crucial.  *i* = 0 or *i* = 2 are common choices. The goal is to pump the string in a way that makes it no longer in the language.
*   **Contradiction:**  The goal is to derive a contradiction by showing that *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L* for some value of *i*.
*   **Negative Result:** The Pumping Lemma can only be used to prove that a language is *not* context-free. It cannot be used to prove that a language *is* context-free.

### 6. Practice Questions/Exercises

**Question 1:**

Prove that the language *L* = {a<sup>n</sup>b<sup>m</sup>c<sup>k</sup> | n < m < k} is not context-free.

**Answer:**

1.  **Assume L is Context-Free:** Assume L is context-free.
2.  **Assume Existence of Pumping Length p:** There exists a pumping length *p* > 0.
3.  **Choose a String w:** Choose *w* = a<sup>*p*</sup>b<sup>*p+1*</sup>c<sup>*p+2*</sup>. Clearly, *w* ∈ *L* and |*w*| = 3*p* + 3 ≥ *p*.
4.  **Consider All Possible Divisions:** Divide *w* into *uvxyz* such that |*vxy*| ≤ *p* and |*vy*| ≥ 1.

    *   **Case 1: *vxy* contains only 'a's:**  Pumping up (i > 1) will increase the number of 'a's, possibly making n >= m or n >=k. Pumping down(i=0) will reduce the number of 'a's, again potentially making n >= m or n >=k. Either way,  *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.

    *   **Case 2: *vxy* contains only 'b's:**  Pumping up (i > 1) will increase the number of 'b's, possibly making m >= k. Pumping down(i=0) will reduce the number of 'b's, possibly making n >= m. Either way, *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.

    *   **Case 3: *vxy* contains only 'c's:**  Pumping down(i=0) will reduce the number of 'c's, possibly making m >= k.  *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.

    *   **Case 4:  *vxy* contains only 'a's and 'b's:**  Pumping can disrupt the relationship n < m < k. If *v* and *y* contain a's and b's, then pumping up increases both 'a's and 'b's. Pumping down decreases both. In either case it is possible to violate *n < m < k*.  *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.

    *   **Case 5: *vxy* contains only 'b's and 'c's:** The same as Case 4,  pumping can disrupt the relationship n < m < k. *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.

    *   **Case 6: *vxy* contains only 'a's, 'b's, and 'c's:** Since  *|vxy| ≤ p*, the strings of a's, b's and c's are tightly grouped in such a way that increasing them will mean that n >= m or m >= k.  *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*.
5.  **Find a Contradiction:** In all possible cases, we can choose *i* such that *uv<sup>i</sup>xy<sup>i</sup>z* ∉ *L*. This contradicts the Pumping Lemma.
6.  **Conclude L is NOT Context-Free:** Therefore, *L* = {a<sup>n</sup>b<sup>m</sup>c<sup>k</sup> | n < m < k} is not a context-free language.
