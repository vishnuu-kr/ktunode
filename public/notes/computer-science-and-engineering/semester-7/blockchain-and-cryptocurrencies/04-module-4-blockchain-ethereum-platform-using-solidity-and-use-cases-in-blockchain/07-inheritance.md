### Learning Outcomes:

Upon successful completion of this topic, you will be able to:

### 1. Introduction to Inheritance in Solidity

#### 1.1. What is Inheritance?

*   **Definition:** Inheritance is a fundamental principle of Object-Oriented Programming (OOP) that allows a new class (called a **derived class**, **child class**, or **subclass**) to inherit properties (state variables) and behaviors (functions) from an existing class (called a **base class**, **parent class**, or **superclass**).
*   **Core Idea:** "Is-a" relationship. A derived class *is a* type of the base class.
