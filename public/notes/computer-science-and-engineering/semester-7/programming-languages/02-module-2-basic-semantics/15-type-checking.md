# PROGRAMMING LANGUAGES: Module 2: Basic Semantics - Type Checking

## Learning Outcomes

Upon completion of this topic, you should be able to:

*   **Define** type checking and its purpose.
*   **Differentiate** between static and dynamic type checking.
*   **Explain** the concepts of type safety and type errors.
*   **Identify** common type checking strategies and their implications.
*   **Understand** the role of type inference.
*   **Discuss** the advantages and disadvantages of different type checking approaches.

## 1. What is Type Checking?

**Definition:** Type checking is the process of verifying and enforcing the constraints of types in a program. It ensures that operations performed on data are appropriate for the data's type.
