# Data Types in JavaScript: The Foundational Classification System

## 1.1 Formal Academic Definition (KTU 2024 Syllabus Aligned)

A **data type** in JavaScript is a classification that specifies which type of value a variable can hold and determines the operations that can be performed on it without causing a type error. In the context of the KTU 2024 Scheme (OECST832 – Web Programming, Module 2: Scripting Language), JavaScript is classified as a **dynamically-typed, weakly-typed** scripting language, meaning variables are not bound to a fixed type at declaration time and the interpreter implicitly converts types during runtime operations.
