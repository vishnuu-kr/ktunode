## 1. CORE CONCEPT MATRIX

| # | Topic | Core Definition | Cognitive Level | Primary Utility |
|:-:|:------|:----------------|:---------------:|:----------------|
| 1 | Cyclic Code | A linear block code C ⊆ F₂^n in which every cyclic shift of a codeword is also a codeword: $(c_0, c_1, \dots, c_{n-1}) \in C \Rightarrow (c_{n-1}, c_0, \dots, c_{n-2}) \in C$ | Understand (L2) | Foundation of code structure |
| 2 | Polynomial Representation | Each codeword $\mathbf{c} = (c_0, c_1, \dots, c_{n-1})$ ↔ polynomial $c(x) = c_0 + c_1 x + \dots + c_{n-1} x^{n-1}$ in ring $F_2[x]/(x^n - 1)$ | Apply (L3) | Maps vectors ↔ polynomials |
| 3 | Generator Polynomial $g(x)$ | Monic polynomial of **minimum degree** $n-k$ in the ideal generated by it; $g(x) \vert (x^n - 1)$ | Analyze (L4) | Encodes entire code as $\langle g(x) \rangle$ |
| 4 | Parity-Check Polynomial $h(x)$ | Defined by $g(x) h(x) = x^n - 1$; degree of $h(x) = k$ | Apply (L3) | Builds parity-check matrix |
| 5 | Generator Matrix $G$ | $G$ is $k \times n$ whose rows are cyclic shifts of $g(x)$: $G = [g(x),\ xg(x), \dots, x^{k-1}g(x)]$ | Create (L6) | Encoding (non-systematic) |
| 6 | Systematic Form | $G_{sys} = [I_k \ \vert \ P]$, $H_{sys} = [P^T \ \vert \ I_{n-k}]$ obtained by row operations on $G$, $H$ | Create (L6) | Simplifies encoding & decoding |
| 7 | Encoding – Non-Systematic | $c(x) = m(x) g(x)$ | Apply (L3) | Direct multiplication |
| 8 | Encoding – Systematic | Divide $x^{n-k} m(x)$ by $g(x)$: $x^{n-k} m(x) = q(x) g(x) + r(x)$, then $c(x) = q(x) g(x) + r(x)$ | Apply (L3) | Information bits appear in plaintext |
| 9 | Syndrome $s(x)$ | $s(x) = r(x) \bmod g(x)$ where $r(x)$ is received polynomial; degree of $s(x) < n-k$ | Analyze (L4) | Error detection / correction |
| 10 | Syndrome Decoding | Error $e(x)$ satisfies $s(x) = e(x) \bmod g(x)$ since $c(x) \equiv 0 \pmod{g(x)}$ | Apply (L3) | Locate and correct errors |
| 11 | Meggitt Decoder | Uses syndrome of received word, shifts cyclically, corrects single errors only | Apply (L3) | Practical decoder for cyclic codes |
| 12 | Cyclic Hamming Codes | $n = 2^m - 1$, $k = n-m$, $g(x)$ is a **primitive polynomial of degree m** | Create (L6) | Single-error correction, perfect code |
| 13 | Minimum Distance Bound | $d_{min} \geq \nu + 1$ where $\nu$ = number of **consecutive powers of $\alpha$** (or roots) of $g(x)$ | Evaluate (L5) | Bound on error correction |
| 14 | Shortened Cyclic Codes | Drop a fixed coordinate and shorten the message; new length $n' = n - i$, $k' = k - i$ | Create (L6) | Custom length codes from cyclic ones |

## 2. THE MASTER FORMULA SHEET

| # | Formula / Identity | Description / Parameters | Units / Domain |
|:-:|:-------------------|:-------------------------|:---------------|
| F1 | **Code structure**: $C = \langle g(x) \rangle = \{ m(x) g(x) \bmod (x^n - 1) \ \vert \ m(x) \in F_2[x], \deg m < k \}$ | All codewords are multiples of $g(x)$ modulo $x^n - 1$ | $F_2[x]$ |
| F2 | **Necessary condition**: $g(x) \vert (x^n - 1)$ | $g(x)$ must be a factor of $x^n - 1$ over $F_2$ | $F_2[x]$ |
| F3 | **Degree relation**: $\deg g(x) = n - k$ | Monic generator of degree $n-k$ | bits |
| F4 | **Parity-check polynomial**: $h(x) = (x^n - 1) / g(x)$, $\deg h(x) = k$ | Also monic, satisfies $c(x) h(x) \equiv 0 \pmod{x^n - 1}$ | $F_2[x]$ |
| F5 | **Generator matrix (poly form)**: $G(x) = \begin{bmatrix} g(x) \\ xg(x) \\ \vdots \\ x^{k-1}g(x) \end{bmatrix}$ | Each row is a polynomial of degree $< n$ | $k \times n$ |
| F6 | **Encoding (non-systematic)**: $c(x) = m(x) \cdot g(x)$ | $m(x) = m_0 + m_1 x + \dots + m_{k-1} x^{k-1}$ | $F_2[x]$ |
| F7 | **Encoding (systematic)**: $c(x) = x^{n-k} m(x) + r(x)$ where $r(x) = x^{n-k} m(x) \bmod g(x)$ | Last $n-k$ coefficients of $c$ = $r(x)$ | $F_2[x]$ |
| F8 | **Codeword property**: $c(x) \equiv 0 \pmod{g(x)}$ | All codewords are multiples of $g(x)$ | Modulo identity |
| F9 | **Syndrome**: $s(x) \equiv r(x) \pmod{g(x)}$, with $0 \leq \deg s(x) < n-k$ | $r(x)$ received; syndrome = remainder by $g(x)$ | Polynomial bits |
| F10 | **Syndrome of error**: $s(x) = e(x) \bmod g(x)$ | Since $r(x) = c(x) + e(x)$ and $g(x) \vert c(x)$ | Detection |
| F11 | **Cyclic shift of syndrome**: $s^{(i)}(x) \equiv x^i s(x) \pmod{g(x)}$ | Equivalence used in Meggitt decoder | Shifted form |
| F12 | **Single error at position i**: $e(x) = x^i$, $s(x) = x^i \bmod g(x)$ | Syndrome identifies error location | Position $i$ |
| F13 | **Hamming code parameters**: $n = 2^m - 1$, $k = n - m$, $d_{min} = 3$ | For $m \geq 2$ | bits |
| F14 | **Hamming generator polynomial**: $g(x)$ = primitive polynomial of degree $m$ over $F_2$ | $g(x)$ has $\alpha, \alpha^2, \alpha^4$ as roots | $F_2[x]$ |
| F15 | **Hamming syndrome table**: $s_i = x^i \bmod g(x)$ for $i = 0, 1, \dots, n-1$ | One-to-one with non-zero syndromes; used for decoding | Look-up |
| F16 | **Bose-Chaudhuri bound**: $d_{min} \geq d^*$ where $d^*$ = smallest index such that $x^{d^*} \equiv 1 \pmod{g(x), x^n-1}$ (BCH bound) | $d^* - 1$ = consecutive roots count | Bound |
| F17 | **Shortened code parameters**: $n' = n - s$, $k' = k - s$ | Shorten $s$ info + parity positions; new $g'(x) = g(x)$ | New length |
| F18 | **Cyclic Hamming rate**: $R = k / n = (n - m)/n$ | Efficiency of Hamming code | Dimensionless |
| F19 | **Sphere-packing bound (Hamming)**: $\sum_{i=0}^{t} \binom{n}{i} \leq 2^{n-k}$, $t = \lfloor (d_{min}-1)/2 \rfloor$ | Hamming codes meet this with equality → **perfect** | $F_2^n$ |
| F20 | **Weight enumerator (cyclic)**: $A(z) = \sum_{i=0}^{n} A_i z^i$ | $A_i$ = # of codewords of weight $i$ | Polynomial |

## 3. HIGH-YIELD EXAM CHECKPOINTS

### A. Construction of $g(x)$ and $h(x)$ from $x^n - 1$
- Factor $x^n - 1$ over $F_2$.
- $g(x)$ = monic factor of degree $n - k$ that has the **desired roots** (powers of primitive element $\alpha$).
- Verify $g(x) h(x) = x^n - 1$.

### B. Systematic Encoding Procedure (Always Tested)
1. Given $m(x)$ of degree $\leq k-1$.
2. Compute $x^{n-k} m(x)$ (shift left by $n-k$).
3. Divide $x^{n-k} m(x)$ by $g(x)$ → get remainder $r(x)$, $\deg r < n-k$.
4. Form $c(x) = x^{n-k} m(x) + r(x)$.
5. **Coefficients of $r(x)$ are the appended parity bits** (last $n-k$ positions).

### C. Syndrome Computation — Fastest Method
- Perform **polynomial long division** of $r(x)$ by $g(x)$.
- The remainder is the syndrome $s(x)$.
- Convert $s(x)$ to an $(n-k)$-bit syndrome vector $\mathbf{s} = (s_0, s_1, \dots, s_{n-k-1})$.

### D. Decoding Cyclic Codes
- If $s(x) = 0$ → no detectable error (or undetectable error).
- For **single-error correction** in cyclic Hamming code: find $i$ such that $s(x) \equiv x^i \pmod{g(x)}$; error is at position $i$.
- Use **Meggitt decoder** for general cyclic codes (single-error correcting).

### E. Cyclic Hamming Code Construction (n, k) for small m
| m | n = $2^m - 1$ | k = n − m | Primitive $g(x)$ |
|:-:|:--:|:--:|:--|
| 2 | 3 | 1 | $x^2 + x + 1$ |
| 3 | 7 | 4 | $x^3 + x + 1$ |
| 4 | 15 | 11 | $x^4 + x + 1$ |
| 5 | 31 | 26 | $x^5 + x^2 + 1$ |

### F. Generator Matrix in Systematic Form — Standard Method
1. Compute $g(x)$ and form $G$ with rows $g(x), xg(x), \dots, x^{k-1}g(x)$.
2. Perform **row reduction** (mod 2) to bring $G$ to $[I_k \ \vert \ P]$.
3. **Shortcut**: If $g(x) = g_0 + g_1 x + \dots + g_{n-k} x^{n-k}$ with $g_0 = 1$, then $P$ has $j$-th row = $(g_{n-k}, g_{n-k-1}, \dots, g_1)$ placed in appropriate columns.

### G. Shortened Cyclic Codes
- To shorten by $s$ positions: take the subcode of $C$ with $s$ fixed (zero) coordinates, then delete them.
- New parameters: $(n' = n - s, k' = k - s)$, $d'_{min} \geq d_{min}$.
- The **same generator polynomial $g(x)$** still generates the shortened code (after re-encoding).

### H. Minimum Distance from Roots (BCH-style)
- If $g(x)$ has roots $\alpha^b, \alpha^{b+1}, \dots, \alpha^{b+\delta-2}$ (consecutive), then $d_{min} \geq \delta$.

## 4. EXAMINER'S WARNING GUIDE (Valuation Insights)

| # | Mistake | Correct Approach | Mark Loss Risk |
|:-:|:--------|:-----------------|:--------------:|
| 1 | Writing $g(x) \vert (x^n + 1)$ | Must be $g(x) \vert (x^n - 1)$ over $F_2$ (note: $-1 = +1$ in $F_2$, but write **explicitly** $x^n - 1$) | High |
| 2 | Forgetting to make $g(x)$ **monic** | Always normalize leading coefficient to 1 | Medium |
| 3 | Conflating $\deg g(x) = n - k$ with $\deg g(x) = k$ | $\deg g(x) = n - k$ (parity bits count) | High |
| 4 | Syndrome: dividing $r(x)$ by $h(x)$ instead of $g(x)$ | **Always divide by $g(x)$** for syndrome, not $h(x)$ | High |
| 5 | In systematic encoding, writing $c(x) = m(x) + r(x)$ instead of $c(x) = x^{n-k}m(x) + r(x)$ | Shift first, then add remainder | High |
| 6 | Mismatch in degree: $r(x)$ must satisfy $\deg r(x) < n-k$ | Always check this | Low |
| 7 | Using $h(x)$ to build $G$ (wrong) | $g(x)$ builds $G$; $h(x)$ builds $H$ | High |
| 8 | Confusing polynomial $G(x)$ with matrix $G$ | $G(x)$ is a list of polynomials; $G$ is the matrix of coefficients | Medium |
| 9 | For Hamming: $n = 2^m - 1$, not $2^m$ | $n = 2^m - 1$ (not $2^m$) | High |
| 10 | In shortened codes: claiming $g(x)$ changes | $g(x)$ **remains the same**; only the code substructure changes | Medium |
| 11 | Not showing working in Meggitt decoding | Always show: syndrome → shift → error pattern → correct | Medium |
| 12 | Writing $e(x) = 1$ for "error in first position" | $e(x) = x^0 = 1$ is correct, but specify position $i=0$ | Low |
| 13 | Forgetting $F_2$ arithmetic: $1 + 1 = 0$ | Show all XOR operations explicitly | Low |
| 14 | Skipping verification that $g(x) h(x) = x^n - 1$ | **Always verify** — examiners award marks for this | High |
| 15 | Mixing up $G_{sys}$ row order after row reduction | The order of rows of $I_k$ corresponds to info bits; preserve order | Medium |

**Presentation Tips:**
- ✍️ Always state $n$, $k$, and the field ($F_2$) at the start of the problem.
- ✍️ Show polynomial long division step by step (at least 2-3 lines).
- ✍️ Write final codeword as **bit vector AND polynomial** form.
- ✍️ For Hamming codes, draw the **syndrome table** clearly in tabular form.

### 🎯 Top 5 Things to Memorize Before Walking In

1. **$g(x) h(x) = x^n - 1$** and $\deg g = n - k$.
2. **Systematic encoding**: shift, divide, add remainder.
3. **Syndrome = remainder of $r(x)$ by $g(x)$**.
4. **Hamming**: $n = 2^m - 1$, $k = n - m$, $g(x)$ primitive of degree $m$.
5. **Shortened code**: $(n-s, k-s)$ with **same** $g(x)$.
