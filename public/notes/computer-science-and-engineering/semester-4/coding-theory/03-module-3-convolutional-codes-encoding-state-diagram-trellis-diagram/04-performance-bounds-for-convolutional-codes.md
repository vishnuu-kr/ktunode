## Coding Theory: Module 3 - Convolutional Codes: Performance Bounds

**Module:** Convolutional Codes
**Topic:** Performance Bounds for Convolutional Codes

**Learning Outcomes:**

*   Understand the concept of distance properties of convolutional codes, specifically the minimum free distance.
*   Learn how to calculate the distance spectrum of a convolutional code.
*   Understand how the distance spectrum relates to performance bounds (e.g., union bound) on the probability of error.
*   Apply these concepts to estimate the performance of convolutional codes in various channel conditions (e.g., AWGN).

---

### 1. Key Concepts and Definitions

*   **Convolutional Code:**  A type of error-correcting code where the encoder has memory. The output at any given time depends not only on the current input but also on previous inputs.  Represented as (n, k, K) where:
    *   n: Number of output bits per input bit.
    *   k: Number of input bits.
    *   K: Constraint length (memory order + 1). Memory order, 'm', represents the number of previous input bits influencing the current output. K = m + 1. The higher K is, the more powerful the code (generally) but the more complex the decoder.
*   **Minimum Free Distance (d<sub>free</sub>):**  The minimum Hamming distance between any two distinct code sequences generated by the encoder.  A crucial parameter for determining the error-correcting capability of a convolutional code. It's the minimum weight of all non-zero codewords corresponding to paths through the trellis diagram that start and end in the all-zero state.
*   **Hamming Distance:** The number of positions at which two code sequences differ.  Mathematically, for sequences *x* and *y*, the Hamming distance d(x, y) = Σ  I(x<sub>i</sub> ≠ y<sub>i</sub>), where I(.) is the indicator function (1 if true, 0 if false).
*   **Code Weight:**  The number of non-zero symbols in a codeword.  For binary codes, it's simply the number of '1's in the codeword.
*   **Distance Spectrum:** A list of the number of codewords (paths) at each Hamming distance from the all-zero codeword, starting at distance d<sub>free</sub>. Denoted as {A<sub>d</sub>}, where A<sub>d</sub> is the number of codewords with Hamming weight *d*.
*   **Error Event:** An event in which the decoder makes a mistake by choosing an incorrect path through the trellis diagram.
*   **Transfer Function (T(D)) of the Trellis Diagram:**  A generating function that describes the distance spectrum of a convolutional code.  It's a powerful tool for analyzing and understanding the code's performance.  T(D) =  Σ A<sub>d</sub> * D<sup>d</sup>
*   **Union Bound:** An upper bound on the probability of error, based on the distance spectrum and the pairwise error probability between the correct codeword and other possible codewords.
*   **Pairwise Error Probability (PEP):** The probability that the decoder chooses an incorrect codeword, *v*, given that the correct codeword, *u*, was transmitted. This depends on the distance between *u* and *v*, and the channel characteristics.

### 2. Calculating the Minimum Free Distance (d<sub>free</sub>)

The minimum free distance, d<sub>free</sub>, is the key parameter that determines the error-correcting capability of a convolutional code. Here's how to find it:

1.  **Draw the State Diagram or Trellis Diagram:** This visually represents all possible transitions and outputs of the convolutional encoder.

2.  **Identify Paths Diverging and Re-merging with the All-Zero State:** Start at the all-zero state (usually state 'a' or '00') and find all paths that diverge from the all-zero state and eventually re-merge back into the all-zero state for the first time.

3.  **Calculate the Weight of Each Path:**  Calculate the Hamming weight (number of '1's) of the output sequence (codeword) corresponding to each of these paths.  Exclude the initial and final all-zero state transitions (these contribute zero weight).

4.  **Determine the Minimum:**  The minimum free distance, d<sub>free</sub>, is the *smallest* weight found among all the paths identified in step 3.

**Example:**

Consider a (2, 1, 3) convolutional code with generator polynomials g1(D) = 1 + D + D<sup>2</sup> and g2(D) = 1 + D<sup>2</sup>.

*   To find d<sub>free</sub>, we analyze paths starting and ending at the all-zero state (00).
*   One possible path: 00 -> 10 -> 01 -> 00 (corresponding input sequence 1, 0, 1)
*   The output sequence (excluding initial and final zeros): 11, 10, 01. The Hamming weight of this sequence is 4.
*   Another path: 00 -> 10 -> 11 -> 01 -> 00 (corresponding input sequence 1, 1, 0, 1)
*   Output sequence: 11, 01, 10, 11.  Hamming Weight = 6
*   By examining all such paths, we would find that the minimum weight is 5 (corresponding to the input sequence 1, 0, 0, 0, 0...). Therefore, d<sub>free</sub> = 5.

### 3. Calculating the Distance Spectrum

The distance spectrum {A<sub>d</sub>} lists the number of codewords at each Hamming distance *d* from the all-zero codeword, starting with d<sub>free</sub>. To calculate it:

1.  **Draw the Trellis Diagram:** Again, the trellis diagram is crucial.

2.  **Enumerate Error Events:**  Systematically examine all possible error events (paths diverging from and re-merging with the all-zero state).  Focus on error events of increasing length.

3.  **Calculate Weights and Count:** For each error event, calculate the Hamming weight of the corresponding output sequence. Keep track of how many error events have a particular weight.

4.  **Form the Distance Spectrum:**  A<sub>d</sub> represents the number of paths with Hamming weight *d*.  So, you'll have:
    *   A<sub>d<sub>free</sub></sub> = Number of paths with weight d<sub>free</sub>
    *   A<sub>d<sub>free+1</sub></sub> = Number of paths with weight d<sub>free+1</sub>
    *   ...and so on.

5.  **Alternatively - Use the Transfer Function:** A more systematic way to find the distance spectrum is to determine the Transfer Function of the trellis diagram. This involves solving a set of linear equations based on the state diagram. The transfer function T(D) =  Σ A<sub>d</sub> * D<sup>d</sup> will directly give you the distance spectrum.

**Example (Continuing from the previous example):**

Let's say, after analyzing several error events, we find the following:

*   1 path with weight 5 (d<sub>free</sub>)
*   2 paths with weight 6
*   3 paths with weight 7
*   5 paths with weight 8

Then, the distance spectrum would be:

*   A<sub>5</sub> = 1
*   A<sub>6</sub> = 2
*   A<sub>7</sub> = 3
*   A<sub>8</sub> = 5
*   ...and so on

The transfer function would be T(D) = D<sup>5</sup> + 2D<sup>6</sup> + 3D<sup>7</sup> + 5D<sup>8</sup> + ...

### 4. Performance Bounds (Union Bound)

The distance spectrum allows us to estimate the performance of the convolutional code using the union bound.  The union bound gives an *upper bound* on the probability of bit error or codeword error.

**a) Probability of Codeword Error (P<sub>e</sub>):**

The union bound on the probability of codeword error is given by:

P<sub>e</sub> ≤  Σ A<sub>d</sub> * P<sub>2</sub>(d)   where the sum is taken over all *d* from d<sub>free</sub> to infinity, and P<sub>2</sub>(d) is the pairwise error probability.

*   **P<sub>2</sub>(d): Pairwise Error Probability.** This is the probability that the decoder chooses an incorrect codeword *v* that differs from the transmitted codeword *u* by a Hamming distance *d*.  The specific formula for P<sub>2</sub>(d) depends on the channel.

    *   **For an AWGN channel (with BPSK modulation):**
        P<sub>2</sub>(d) = Q(√(d * 2 * E<sub>b</sub> / N<sub>0</sub>))

        Where:
            *   Q(x) is the Q-function (the tail probability of the standard normal distribution).  Q(x) = (1/√(2π)) ∫<sub>x</sub><sup>∞</sup> exp(-t<sup>2</sup>/2) dt
            *   E<sub>b</sub> is the energy per bit.
            *   N<sub>0</sub> is the noise power spectral density.
            *   E<sub>b</sub>/N<sub>0</sub> is the signal-to-noise ratio (SNR).

**b) Probability of Bit Error (P<sub>b</sub>):**

A tighter bound on the probability of bit error can be obtained by incorporating the number of bit errors associated with each error event. Let B<sub>d</sub> be the number of bit errors associated with codewords at distance *d*.

P<sub>b</sub> ≤  Σ (B<sub>d</sub> / k) * P<sub>2</sub>(d)  where k is the number of input bits per block (usually 1 for rate 1/n codes).  Estimating the B<sub>d</sub> is difficult without simulations or more complex analysis. In practice the probability of codeword error is commonly used.

**Explanation:**

The Union Bound essentially sums the probabilities of all possible error events. It overestimates the actual error probability because it doesn't account for the fact that some error events are mutually exclusive (i.e., the decoder can't choose both codeword *v* and codeword *w* simultaneously). However, it's a useful tool for *estimating* the performance of convolutional codes and comparing different code designs.

**Key Factors Influencing Performance:**

*   **d<sub>free</sub>:**  The larger d<sub>free</sub>, the better the performance. This is because a larger d<sub>free</sub> means that the codewords are more separated in Hamming space, making it harder for the decoder to make a mistake.
*   **Distance Spectrum:** The fewer codewords at distances close to d<sub>free</sub>, the better the performance.  A code with a "good" distance spectrum has A<sub>d</sub> values that increase slowly as d increases.
*   **SNR (E<sub>b</sub>/N<sub>0</sub>):** As SNR increases, the error probability decreases.

### 5. Example Calculation of the Union Bound

Let's continue with our previous example (2, 1, 3) convolutional code with d<sub>free</sub> = 5 and the following distance spectrum (simplified):

*   A<sub>5</sub> = 1
*   A<sub>6</sub> = 2
*   A<sub>7</sub> = 3

Assume we are using BPSK modulation over an AWGN channel with E<sub>b</sub>/N<sub>0</sub> = 4 dB (which is approximately 2.51 in linear scale).

1.  **Calculate P<sub>2</sub>(d) for each distance:**

    *   P<sub>2</sub>(5) = Q(√(5 * 2 * 2.51)) = Q(√25.1) ≈ Q(5.01) ≈ 2.87 x 10<sup>-7</sup>
    *   P<sub>2</sub>(6) = Q(√(6 * 2 * 2.51)) = Q(√30.12) ≈ Q(5.49) ≈ 2.07 x 10<sup>-8</sup>
    *   P<sub>2</sub>(7) = Q(√(7 * 2 * 2.51)) = Q(√35.14) ≈ Q(5.93) ≈ 1.31 x 10<sup>-9</sup>

2.  **Apply the Union Bound:**

    P<sub>e</sub> ≤ A<sub>5</sub> * P<sub>2</sub>(5) + A<sub>6</sub> * P<sub>2</sub>(6) + A<sub>7</sub> * P<sub>2</sub>(7)
    P<sub>e</sub> ≤ (1 * 2.87 x 10<sup>-7</sup>) + (2 * 2.07 x 10<sup>-8</sup>) + (3 * 1.31 x 10<sup>-9</sup>)
    P<sub>e</sub> ≤ 2.87 x 10<sup>-7</sup> + 4.14 x 10<sup>-8</sup> + 3.93 x 10<sup>-9</sup>
    P<sub>e</sub> ≤ 3.32 x 10<sup>-7</sup>

Therefore, the union bound estimates the probability of codeword error to be approximately 3.32 x 10<sup>-7</sup> at an SNR of 4 dB.

**Important Note:** This is an *upper bound*. The actual performance will likely be better.  Also, only considering the first few terms of the distance spectrum is an approximation.  For more accurate results, more terms should be included.

### 6. Practice Questions/Exercises

1.  **Consider a (2, 1, 2) convolutional code with generator polynomials g1(D) = 1 + D and g2(D) = 1 + D<sup>2</sup>.  Draw the state diagram and trellis diagram.  Find the minimum free distance (d<sub>free</sub>).**

    *   **Answer:** d<sub>free</sub> = 3

2.  **For the same code in question 1, find the first few terms of the distance spectrum (A<sub>3</sub>, A<sub>4</sub>, A<sub>5</sub>).**

    *   **Answer:** A<sub>3</sub> = 1, A<sub>4</sub> = 2, A<sub>5</sub> = 4  (These values might vary slightly depending on how you traverse the trellis.)

3.  **Using the d<sub>free</sub> you found in question 1, and assuming an AWGN channel with BPSK modulation and E<sub>b</sub>/N<sub>0</sub> = 6 dB (approximately 3.98 in linear scale), calculate the first term of the union bound on the probability of codeword error.**

    *   **Answer:**  P<sub>e</sub> ≈ A<sub>3</sub> * Q(√(3 * 2 * 3.98)) = Q(√23.88) ≈ Q(4.89) ≈ 5.02 x 10<sup>-7</sup>

4.  **Why is the minimum free distance an important parameter for evaluating convolutional codes?**

    *   **Answer:** The minimum free distance, d<sub>free</sub>, determines the error-correcting capability of the code. A larger d<sub>free</sub> implies better error-correcting performance, as the code has greater separation between codewords in Hamming space.

5.  **What is the main limitation of the Union Bound as a performance evaluation tool for convolutional codes?**

    *   **Answer:** The Union Bound is an *upper bound*. It overestimates the actual probability of error because it doesn't account for the statistical dependency among different error events.  In other words it is not a tight bound.

### 7. Important Points to Remember

*   The minimum free distance (d<sub>free</sub>) is the most important parameter for characterizing the error-correcting capability of a convolutional code.
*   A higher d<sub>free</sub> generally leads to better performance (lower error probability).
*   The distance spectrum provides a more complete picture of the code's performance than just d<sub>free</sub> alone.
*   The union bound is an upper bound on the probability of error and can be used to estimate the performance of a convolutional code in various channel conditions.
*   The transfer function of the trellis diagram is a powerful method for finding the distance spectrum.
*   The performance of convolutional codes is significantly affected by the channel characteristics (e.g., AWGN, fading).
*   Decoding algorithms (like Viterbi) aim to find the most likely path through the trellis diagram. The performance bounds give an indication of how well these decoders will perform.
