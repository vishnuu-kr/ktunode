# Module 2: Complex Function - Topic $w = \sin z$

## Introduction

The sine function, a fundamental concept in real analysis, is extended to the complex plane in this module. Understanding $w = \sin z$ is crucial for analyzing various physical phenomena, particularly in wave mechanics, signal processing, and electrical circuits where sinusoidal behavior is prevalent. This topic builds upon the basic definitions of complex numbers and functions and will be instrumental in understanding concepts like conformal mapping and solving differential equations.

**Knowledge Level:** K3 (Applying knowledge) - We will apply the definition of $\sin z$ to solve problems and understand its properties.

## 1. Definition of $w = \sin z$

The complex sine function is defined using its relationship with the complex exponential function, similar to its real counterpart.

**Key Concept:** Euler's Formula for complex exponentials: $e^{iz} = \cos z + i \sin z$.

From Euler's formula, we can derive the definition of $\sin z$ and $\cos z$ for complex arguments:
*   $e^{iz} = \cos z + i \sin z$
*   $e^{-iz} = \cos(-z) + i \sin(-z) = \cos z - i \sin z$ (since $\cos(-z) = \cos z$ and $\sin(-z) = -\sin z$)

Subtracting the second equation from the first:
$e^{iz} - e^{-iz} = (\cos z + i \sin z) - (\cos z - i \sin z) = 2i \sin z$

Therefore, the definition of $\sin z$ for a complex number $z = x + iy$ is:
$$w = \sin z = \frac{e^{iz} - e^{-iz}}{2i}$$

**Reference:** This definition is standard in complex analysis and can be found in Kreyszig (10th ed., Section 13.3), Zill & Shanahan (3rd ed., Section 6.1), and Ramana (39th ed., Chapter 27).

## 2. Properties of $w = \sin z$

Understanding the properties of $\sin z$ is vital for its application.

### 2.1. Relation to Real and Imaginary Parts

Let $z = x + iy$. We can express $\sin z$ in terms of $\sin x$, $\cos x$, $\sinh y$, and $\cosh y$.

Using the angle addition formula for sine: $\sin(A+B) = \sin A \cos B + \cos A \sin B$.
Let $A = x$ and $B = iy$:
$\sin z = \sin(x + iy) = \sin x \cos(iy) + \cos x \sin(iy)$

We need to find expressions for $\cos(iy)$ and $\sin(iy)$:
From Euler's formula and the definition of $\sin z$ and $\cos z$:
*   $\cos z = \frac{e^{iz} + e^{-iz}}{2}$
*   $\sin z = \frac{e^{iz} - e^{-iz}}{2i}$

Substitute $z = iy$:
*   $\cos(iy) = \frac{e^{i(iy)} + e^{-i(iy)}}{2} = \frac{e^{-y} + e^{y}}{2} = \cosh y$ (Hyperbolic cosine)
*   $\sin(iy) = \frac{e^{i(iy)} - e^{-i(iy)}}{2i} = \frac{e^{-y} - e^{y}}{2i} = \frac{-(e^{y} - e^{-y})}{2i} = \frac{-2 \sinh y}{2i} = \frac{-\sinh y}{i} = i \sinh y$

Now, substitute these back into the expression for $\sin z$:
$\sin z = \sin x (\cosh y) + \cos x (i \sinh y)$
$$w = \sin z = \sin x \cosh y + i \cos x \sinh y$$

This shows that if $w = u + iv$, then:
$u(x, y) = \sin x \cosh y$
$v(x, y) = \cos x \sinh y$

**Key Point:** The real part of $\sin z$ is $\sin x \cosh y$ and the imaginary part is $\cos x \sinh y$.

### 2.2. Analyticity

A complex function is analytic (or holomorphic) if it is differentiable in a region of the complex plane. We can check for analyticity using the Cauchy-Riemann equations.

Let $u(x, y) = \sin x \cosh y$ and $v(x, y) = \cos x \sinh y$.
We need to compute the partial derivatives:
*   $\frac{\partial u}{\partial x} = \frac{\partial}{\partial x}(\sin x \cosh y) = \cos x \cosh y$
*   $\frac{\partial u}{\partial y} = \frac{\partial}{\partial y}(\sin x \cosh y) = \sin x \sinh y$
*   $\frac{\partial v}{\partial x} = \frac{\partial}{\partial x}(\cos x \sinh y) = -\sin x \sinh y$
*   $\frac{\partial v}{\partial y} = \frac{\partial}{\partial y}(\cos x \sinh y) = \cos x \cosh y$

Now, check the Cauchy-Riemann equations:
1.  $\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$?
    $\cos x \cosh y = \cos x \cosh y$ (True)
2.  $\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$?
    $\sin x \sinh y = -(-\sin x \sinh y) = \sin x \sinh y$ (True)

Since the Cauchy-Riemann equations are satisfied and the partial derivatives are continuous everywhere, the function $w = \sin z$ is analytic everywhere in the complex plane. This means it is an entire function.

**Reference:** Kreyszig (10th ed., Section 13.1), Zill & Shanahan (3rd ed., Section 2.2), Ramana (39th ed., Chapter 27).

**Alignment with CO2:** This section directly addresses understanding the analyticity of complex functions.

### 2.3. Derivative of $w = \sin z$

Since $\sin z$ is analytic, its derivative exists and can be found using the Cauchy-Riemann equations or by differentiating the exponential form.

Using the exponential definition:
$w = \sin z = \frac{e^{iz} - e^{-iz}}{2i}$
$\frac{dw}{dz} = \frac{d}{dz} \left( \frac{e^{iz} - e^{-iz}}{2i} \right)$
$\frac{dw}{dz} = \frac{1}{2i} \left( \frac{d}{dz}(e^{iz}) - \frac{d}{dz}(e^{-iz}) \right)$
$\frac{dw}{dz} = \frac{1}{2i} \left( e^{iz} \cdot i - e^{-iz} \cdot (-i) \right)$
$\frac{dw}{dz} = \frac{1}{2i} (i e^{iz} + i e^{-iz})$
$\frac{dw}{dz} = \frac{i}{2i} (e^{iz} + e^{-iz})$
$\frac{dw}{dz} = \frac{e^{iz} + e^{-iz}}{2}$
$\frac{dw}{dz} = \cos z$

So, $\frac{d}{dz}(\sin z) = \cos z$, which is analogous to the real derivative.

**Reference:** Kreyszig (10th ed., Section 13.3), Zill & Shanahan (3rd ed., Section 6.1).

### 2.4. Periodicity

The complex sine function is periodic with period $2\pi$.

$\sin(z + 2\pi) = \frac{e^{i(z+2\pi)} - e^{-i(z+2\pi)}}{2i}$
$= \frac{e^{iz} e^{i2\pi} - e^{-iz} e^{-i2\pi}}{2i}$
Since $e^{i2\pi} = \cos(2\pi) + i \sin(2\pi) = 1 + i(0) = 1$ and $e^{-i2\pi} = \cos(-2\pi) + i \sin(-2\pi) = 1 + i(0) = 1$.
$\sin(z + 2\pi) = \frac{e^{iz}(1) - e^{-iz}(1)}{2i} = \frac{e^{iz} - e^{-iz}}{2i} = \sin z$.

**Important Point to Remember:** $\sin z$ is periodic with period $2\pi$, just like the real sine function.

### 2.5. Zeros of $w = \sin z$

The zeros of $\sin z$ are the values of $z$ for which $\sin z = 0$.
Using the definition: $\frac{e^{iz} - e^{-iz}}{2i} = 0$.
$e^{iz} - e^{-iz} = 0$
$e^{iz} = e^{-iz}$
$e^{2iz} = 1$

Let $2iz = \log(1)$. The general logarithm of 1 is $2k\pi i$ for $k \in \mathbb{Z}$ (integers).
$2iz = 2k\pi i$
$iz = k\pi i$
$z = k\pi$, where $k$ is an integer.

This is the same as the zeros of the real sine function.

**Important Point to Remember:** The zeros of $\sin z$ in the complex plane are $z = k\pi$, where $k \in \mathbb{Z}$.

### 2.6. Range of $w = \sin z$

The range of the real sine function is $[-1, 1]$. However, the range of the complex sine function is the entire complex plane. This is a significant difference.

To show this, we need to demonstrate that for any complex number $w_0$, there exists a $z$ such that $\sin z = w_0$.
Let $w_0 = u_0 + iv_0$. We want to solve $\sin z = w_0$ for $z$.
$\frac{e^{iz} - e^{-iz}}{2i} = w_0$
$e^{iz} - e^{-iz} = 2iw_0$

Let $Z = e^{iz}$. Then $e^{-iz} = 1/Z$.
$Z - \frac{1}{Z} = 2iw_0$
Multiply by $Z$:
$Z^2 - 1 = 2iw_0 Z$
$Z^2 - 2iw_0 Z - 1 = 0$

This is a quadratic equation in $Z$. Using the quadratic formula:
$Z = \frac{-(-2iw_0) \pm \sqrt{(-2iw_0)^2 - 4(1)(-1)}}{2(1)}$
$Z = \frac{2iw_0 \pm \sqrt{-4w_0^2 + 4}}{2}$
$Z = \frac{2iw_0 \pm 2\sqrt{1 - w_0^2}}{2}$
$Z = iw_0 \pm \sqrt{1 - w_0^2}$

Since $Z = e^{iz}$, we have:
$e^{iz} = iw_0 \pm \sqrt{1 - w_0^2}$

Let $w_0 = A + iB$. Then $iw_0 = iA - B$.
$1 - w_0^2 = 1 - (A+iB)^2 = 1 - (A^2 + 2iAB - B^2) = (1 - A^2 + B^2) - i(2AB)$.
Let $\sqrt{1 - w_0^2} = P + iQ$.

So, $e^{iz} = (-B \pm P) + i(A \pm Q)$.
Since $e^{iz}$ is generally non-zero, we can take the logarithm:
$iz = \log(iw_0 \pm \sqrt{1 - w_0^2})$
$z = \frac{1}{i} \log(iw_0 \pm \sqrt{1 - w_0^2})$
$z = -i \log(iw_0 \pm \sqrt{1 - w_0^2})$

The complex logarithm is multi-valued, so there are always solutions for $z$ for any $w_0$.

**Example:** Let's find $z$ such that $\sin z = 2$.
Here $w_0 = 2$.
$Z = i(2) \pm \sqrt{1 - 2^2} = 2i \pm \sqrt{1 - 4} = 2i \pm \sqrt{-3} = 2i \pm i\sqrt{3} = i(2 \pm \sqrt{3})$.

Case 1: $Z = i(2 + \sqrt{3})$
$e^{iz} = i(2 + \sqrt{3})$
$iz = \log(i(2 + \sqrt{3}))$
$iz = \ln|i(2 + \sqrt{3})| + i \arg(i(2 + \sqrt{3})) + 2k\pi i$
$iz = \ln(2 + \sqrt{3}) + i \frac{\pi}{2} + 2k\pi i$
$z = -i \ln(2 + \sqrt{3}) - \frac{\pi}{2} - 2k\pi$
$z = - \frac{\pi}{2} - 2k\pi - i \ln(2 + \sqrt{3})$

Case 2: $Z = i(2 - \sqrt{3})$
$e^{iz} = i(2 - \sqrt{3})$
$iz = \log(i(2 - \sqrt{3}))$
$iz = \ln|i(2 - \sqrt{3})| + i \arg(i(2 - \sqrt{3})) + 2k\pi i$
$iz = \ln(2 - \sqrt{3}) + i \frac{\pi}{2} + 2k\pi i$
$z = -i \ln(2 - \sqrt{3}) - \frac{\pi}{2} - 2k\pi$
$z = - \frac{\pi}{2} - 2k\pi - i \ln(2 - \sqrt{3})$

We know that $\ln(2 - \sqrt{3}) = \ln\left(\frac{(2-\sqrt{3})(2+\sqrt{3})}{2+\sqrt{3}}\right) = \ln\left(\frac{4-3}{2+\sqrt{3}}\right) = \ln\left(\frac{1}{2+\sqrt{3}}\right) = -\ln(2+\sqrt{3})$.
So the second set of solutions is $z = - \frac{\pi}{2} - 2k\pi + i \ln(2 + \sqrt{3})$.

Combining results for $k \in \mathbb{Z}$:
$z = - \frac{\pi}{2} - n\pi + i (-1)^{n+1} \ln(2+\sqrt{3})$ is not quite right. Let's use the general form of inverse sine.

The general solution for $\sin z = w_0$ is $z = n\pi + (-1)^n \arcsin(w_0)$, where $\arcsin(w_0)$ is the principal value.
For $w_0 = 2$, the principal value of $\arcsin(2)$ is $\frac{\pi}{2} - i \ln(2+\sqrt{3})$.
So, $z = n\pi + (-1)^n (\frac{\pi}{2} - i \ln(2+\sqrt{3}))$.

If $n$ is even, $n=2k$: $z = 2k\pi + (\frac{\pi}{2} - i \ln(2+\sqrt{3})) = (2k + \frac{1}{2})\pi - i \ln(2+\sqrt{3})$.
If $n$ is odd, $n=2k+1$: $z = (2k+1)\pi - (\frac{\pi}{2} - i \ln(2+\sqrt{3})) = (2k+1 - \frac{1}{2})\pi + i \ln(2+\sqrt{3}) = (2k + \frac{1}{2})\pi + i \ln(2+\sqrt{3})$.

This matches our earlier results (with a shift in $k$ or sign convention).

**Important Point to Remember:** The range of $\sin z$ is the entire complex plane, unlike the real sine function.

## 3. Relationship with Hyperbolic Functions

The complex sine function is intimately related to the hyperbolic sine function ($\sinh y$) and hyperbolic cosine function ($\cosh y$).

We've already seen:
*   $\sin(iy) = i \sinh y$
*   $\cos(iy) = \cosh y$

From $\sin z = \sin x \cosh y + i \cos x \sinh y$:
*   If $z = x$ is real, $\sin x = \sin x \cosh 0 + i \cos x \sinh 0 = \sin x (1) + i \cos x (0) = \sin x$.
*   If $z = iy$ is purely imaginary, $\sin(iy) = \sin 0 \cosh y + i \cos 0 \sinh y = 0 \cdot \cosh y + i \cdot 1 \cdot \sinh y = i \sinh y$.

Also, we can express $\sinh z$ and $\cosh z$ in terms of $\sin$ and $\cos$:
*   $\sinh z = \frac{e^z - e^{-z}}{2}$
    Let $z = ix$: $\sinh(ix) = \frac{e^{ix} - e^{-ix}}{2} = i \left( \frac{e^{ix} - e^{-ix}}{2i} \right) = i \sin x$.
    So, $\sin x = \frac{\sinh(ix)}{i} = -i \sinh(ix)$.
*   $\cosh z = \frac{e^z + e^{-z}}{2}$
    Let $z = ix$: $\cosh(ix) = \frac{e^{ix} + e^{-ix}}{2} = \cos x$.

Now consider $\sin z$ and $\cos z$ for $z = x+iy$:
We know $\sin z = \sin x \cosh y + i \cos x \sinh y$.
Consider $\cos z$: $\cos z = \frac{e^{iz} + e^{-iz}}{2}$. Let $z=x+iy$.
$iz = i(x+iy) = ix - y$.
$e^{iz} = e^{ix - y} = e^{-y} e^{ix} = e^{-y}(\cos x + i \sin x)$.
$e^{-iz} = e^{-(ix - y)} = e^{y} e^{-ix} = e^{y}(\cos x - i \sin x)$.

$\cos z = \frac{1}{2} [e^{-y}(\cos x + i \sin x) + e^{y}(\cos x - i \sin x)]$
$\cos z = \frac{1}{2} [\cos x (e^{-y} + e^y) + i \sin x (e^{-y} - e^y)]$
$\cos z = \frac{1}{2} [\cos x (2 \cosh y) + i \sin x (-2 \sinh y)]$
$\cos z = \cos x \cosh y - i \sin x \sinh y$.

This shows that the trigonometric functions are related to hyperbolic functions.

**Summary of Relations:**
*   $\sin(iy) = i \sinh y$
*   $\cos(iy) = \cosh y$
*   $\sinh(ix) = i \sin x$
*   $\cosh(ix) = \cos x$
*   $\sin z = \sin x \cosh y + i \cos x \sinh y$
*   $\cos z = \cos x \cosh y - i \sin x \sinh y$

**Important Point to Remember:** These identities are crucial for converting between trigonometric and hyperbolic forms, simplifying complex expressions.

**Alignment with CO2:** Understanding these relationships is part of grasping the behavior of complex analytic functions and their mapping properties.

## 4. Conformal Mapping by $w = \sin z$

A conformal mapping is a transformation that preserves angles locally, both in magnitude and orientation. For an analytic function $f(z)$, the mapping $w = f(z)$ is conformal at points where $f'(z) \neq 0$.

We know that for $w = \sin z$, the derivative is $\frac{dw}{dz} = \cos z$.
The mapping $w = \sin z$ is conformal at all points $z$ where $\cos z \neq 0$.

The zeros of $\cos z$ are found by setting $\cos z = 0$:
$\frac{e^{iz} + e^{-iz}}{2} = 0$
$e^{iz} + e^{-iz} = 0$
$e^{iz} = -e^{-iz}$
$e^{2iz} = -1$

Let $2iz = \log(-1)$. The general logarithm of $-1$ is $i(\pi + 2k\pi) = i(2k+1)\pi$ for $k \in \mathbb{Z}$.
$2iz = i(2k+1)\pi$
$iz = \frac{(2k+1)\pi}{2} i$
$z = \frac{(2k+1)\pi}{2}$, where $k \in \mathbb{Z}$.

These are the points $z = \pm \frac{\pi}{2}, \pm \frac{3\pi}{2}, \pm \frac{5\pi}{2}, \ldots$.
At these points, the mapping $w = \sin z$ is not conformal, as the angle of magnification is zero or infinite.

**How does $\sin z$ map regions?**

Consider the horizontal strip $0 < x < \pi/2$, $y > 0$.
The mapping transforms this strip into a region in the $w$-plane.

Let's analyze the mapping of the boundaries:
*   $z = x$, $0 \le x \le \pi/2$ (on the real axis):
    $w = \sin x \cosh 0 + i \cos x \sinh 0 = \sin x$.
    As $x$ goes from 0 to $\pi/2$, $w$ goes from $\sin 0 = 0$ to $\sin(\pi/2) = 1$. This is the segment $[0, 1]$ on the real axis in the $w$-plane.

*   $z = \pi/2 + iy$, $y > 0$ (vertical line):
    $w = \sin(\pi/2 + iy) + i \cos(\pi/2 + iy) \sinh y$
    Using $\sin(\pi/2 + \theta) = \cos \theta$ and $\cos(\pi/2 + \theta) = -\sin \theta$:
    $\sin(\pi/2 + iy) = \cos(iy) = \cosh y$
    $\cos(\pi/2 + iy) = -\sin(iy) = -i \sinh y$
    So, $w = \cosh y + i (-i \sinh y) = \cosh y + \sinh y$.
    Since $y > 0$, $w$ traces a ray starting from $\cosh 0 + \sinh 0 = 1$ towards infinity along the line $u = v$ (since $u = \cosh y, v = \sinh y$, and $\cosh^2 y - \sinh^2 y = 1$). More precisely, as $y$ increases, $w$ moves along the hyperbola $u^2 - v^2 = 1$. Specifically, $u=\cosh y$ and $v=\sinh y$, so $u > 1$ and $v>0$. $u$ goes from 1 to $\infty$. This is the right half of the hyperbola $u^2 - v^2 = 1$ in the first quadrant.

*   $z = iy$, $y > 0$ (imaginary axis):
    $w = \sin(iy) = i \sinh y$.
    As $y$ goes from 0 to $\infty$, $\sinh y$ goes from 0 to $\infty$. So $w$ goes from $i \cdot 0 = 0$ to $i \cdot \infty$. This is the positive imaginary axis in the $w$-plane.

The region $0 < x < \pi/2$, $y > 0$ maps to the region bounded by the positive real axis from 0 to 1, the hyperbola $u^2 - v^2 = 1$ in the first quadrant ($u > 1$), and the positive imaginary axis. This region is a part of the first quadrant.

**Reference:** Kreyszig (10th ed., Section 14.1), Zill & Shanahan (3rd ed., Section 7.1).

**Alignment with CO2:** This directly relates to applying analyticity in conformal mapping.

**Question 3:** Find all solutions to $\sin z = -i$.
**Answer:**
We want to solve $\sin z = -i$.
$z = n\pi + (-1)^n \arcsin(-i)$.
The principal value of $\arcsin(-i)$ is found by setting $\sin w = -i$.
$\frac{e^{iw} - e^{-iw}}{2i} = -i$
$e^{iw} - e^{-iw} = -2i^2 = 2$
Let $Z = e^{iw}$.
$Z - 1/Z = 2$
$Z^2 - 1 = 2Z$
$Z^2 - 2Z - 1 = 0$
$Z = \frac{2 \pm \sqrt{4 - 4(1)(-1)}}{2} = \frac{2 \pm \sqrt{8}}{2} = \frac{2 \pm 2\sqrt{2}}{2} = 1 \pm \sqrt{2}$.

Case 1: $e^{iw} = 1 + \sqrt{2}$.
$iw = \log(1+\sqrt{2}) = \ln(1+\sqrt{2}) + 2k\pi i$.
$w = -i \ln(1+\sqrt{2}) + 2k\pi$.
$w = 2k\pi - i \ln(1+\sqrt{2})$.

Case 2: $e^{iw} = 1 - \sqrt{2}$.
$iw = \log(1-\sqrt{2})$. Note that $1-\sqrt{2}$ is negative.
$iw = \ln|1-\sqrt{2}| + i \arg(1-\sqrt{2}) + 2k\pi i$.
$iw = \ln(\sqrt{2}-1) + i\pi + 2k\pi i$.
$w = -i \ln(\sqrt{2}-1) + \pi + 2k\pi$.
Since $\ln(\sqrt{2}-1) = \ln\left(\frac{(\sqrt{2}-1)(\sqrt{2}+1)}{\sqrt{2}+1}\right) = \ln\left(\frac{1}{\sqrt{2}+1}\right) = -\ln(\sqrt{2}+1)$.
$w = i \ln(\sqrt{2}+1) + (2k+1)\pi$.

The principal value of $\arcsin(-i)$ is $-\frac{\pi}{2} - i \ln(\sqrt{2}+1)$ or $-\frac{\pi}{2} + i \ln(\sqrt{2}+1)$ depending on convention. Let's use the formula $z = n\pi + (-1)^n \arcsin(w_0)$.
$\arcsin(-i) = -\frac{\pi}{2} - i \ln(\sqrt{2}+1)$ is not the principal value.
The principal value of $\arcsin w$ is $w = \frac{\pi}{2} + i \ln(2+\sqrt{3})$ for $w=2$. For $w=-i$, $\sin(z)=-i$.
Let's directly solve for $z$.
$z = x+iy$. $\sin x \cosh y + i \cos x \sinh y = -i$.
$\sin x \cosh y = 0$
$\cos x \sinh y = -1$

From $\sin x \cosh y = 0$: Since $\cosh y \ge 1$ for real $y$, we must have $\sin x = 0$.
This implies $x = n\pi$ for $n \in \mathbb{Z}$.

Now substitute $x = n\pi$ into the second equation: $\cos(n\pi) \sinh y = -1$.
$\cos(n\pi) = (-1)^n$.
So, $(-1)^n \sinh y = -1$.

Case 1: $n$ is even. $n=2k$.
$(-1)^{2k} \sinh y = 1 \cdot \sinh y = -1$.
$\sinh y = -1$.
$y = \text{arsinh}(-1) = -\text{arsinh}(1) = -\ln(1+\sqrt{1^2+1}) = -\ln(1+\sqrt{2})$.
So, $z = 2k\pi - i \ln(1+\sqrt{2})$.

Case 2: $n$ is odd. $n=2k+1$.
$(-1)^{2k+1} \sinh y = -1 \cdot \sinh y = -1$.
$\sinh y = 1$.
$y = \text{arsinh}(1) = \ln(1+\sqrt{1^2+1}) = \ln(1+\sqrt{2})$.
So, $z = (2k+1)\pi + i \ln(1+\sqrt{2})$.

Combining both cases: $z = m\pi + (-1)^{m+1} i \ln(1+\sqrt{2})$, for $m \in \mathbb{Z}$.
Or $z = m\pi + i (-1)^m \ln(\sqrt{2}+1)$ is also a way to write it.
Let's verify.
If $m=0$: $z = i \ln(\sqrt{2}+1)$. $\sin(i \ln(\sqrt{2}+1)) = i \sinh(\ln(\sqrt{2}+1)) = i (\frac{e^{\ln(\sqrt{2}+1)} - e^{-\ln(\sqrt{2}+1)}}{2}) = i (\frac{\sqrt{2}+1 - 1/(\sqrt{2}+1)}{2}) = i (\frac{\sqrt{2}+1 - (\sqrt{2}-1)}{2}) = i (\frac{2}{2}) = i$. This is $\sin z = i$, not $-i$.

Let's recheck the solution of $\sin z = -i$.
$x = n\pi$.
If $n$ is even, $n=2k$: $\sinh y = -1 \implies y = -\ln(1+\sqrt{2})$. $z = 2k\pi - i \ln(1+\sqrt{2})$.
If $n$ is odd, $n=2k+1$: $-\sinh y = -1 \implies \sinh y = 1 \implies y = \ln(1+\sqrt{2})$. $z = (2k+1)\pi + i \ln(1+\sqrt{2})$.

The solutions are $z = 2k\pi - i \ln(1+\sqrt{2})$ and $z = (2k+1)\pi + i \ln(1+\sqrt{2})$.
These can be written as $z = m\pi + i (-1)^m \ln(1+\sqrt{2})$ is incorrect.
Correct form: $z = m\pi + i(-1)^{m+1} \ln(1+\sqrt{2})$ for $m \in \mathbb{Z}$.
Let's check:
If $m=0$ (even): $z = 0 + i (-1)^1 \ln(1+\sqrt{2}) = -i \ln(1+\sqrt{2})$. This matches Case 1 with $k=0$.
If $m=1$ (odd): $z = \pi + i (-1)^2 \ln(1+\sqrt{2}) = \pi + i \ln(1+\sqrt{2})$. This matches Case 2 with $k=0$.

**Question 4:** At which points is the mapping $w = \sin z$ not conformal?
**Answer:** At points where $\frac{dw}{dz} = \cos z = 0$, which are $z = \frac{\pi}{2} + k\pi$ for $k \in \mathbb{Z}$.

**Question 5:** Find the imaginary part of $\sin(i)$.
**Answer:**
$\sin(i) = \sin(0+1i) = \sin(0)\cosh(1) + i \cos(0)\sinh(1) = 0 \cdot \cosh(1) + i \cdot 1 \cdot \sinh(1) = i \sinh(1)$.
The imaginary part is $\sinh(1) = \frac{e^1 - e^{-1}}{2} \approx \frac{2.718 - 0.368}{2} \approx 1.175$.

## 7. Important Points to Remember

*   **Definition:** $\sin z = \frac{e^{iz} - e^{-iz}}{2i}$.
*   **Real and Imaginary Parts:** $\sin z = \sin x \cosh y + i \cos x \sinh y$.
*   **Analyticity:** $\sin z$ is analytic everywhere in the complex plane (an entire function).
*   **Derivative:** $\frac{d}{dz}(\sin z) = \cos z$.
*   **Periodicity:** $\sin z$ is periodic with period $2\pi$.
*   **Zeros:** The zeros of $\sin z$ are $z = k\pi$ for $k \in \mathbb{Z}$.
*   **Range:** The range of $\sin z$ is the entire complex plane.
*   **Relations to Hyperbolic Functions:** $\sin(iy) = i \sinh y$, $\cos(iy) = \cosh y$, etc.
*   **Conformal Mapping:** $w = \sin z$ is conformal everywhere except where $\cos z = 0$, i.e., $z = \frac{\pi}{2} + k\pi$.
