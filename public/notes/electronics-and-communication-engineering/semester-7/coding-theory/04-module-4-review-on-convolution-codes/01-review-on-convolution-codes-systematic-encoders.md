## Topic: Systematic Encoders

### 1. Introduction to Convolutional Codes

Convolutional codes are a type of error-correcting code that are widely used in digital communication systems. Unlike block codes, which operate on fixed-size blocks of data independently, convolutional codes operate on a stream of data, with the encoded output at any given time depending on the current input bit and a finite number of previous input bits. This memory property is what gives convolutional codes their "convolutional" nature.

**Key Concepts:**

*   **Encoder Memory:** The number of previous input bits that influence the current output. This is often represented by the constraint length, $K$.
*   **Generator Polynomials:** Polynomials that define the structure of the convolutional encoder. For a rate $R = k/n$ code, there are $n$ generator polynomials, each of a degree related to the constraint length.
*   **Constraint Length ($K$):** The total number of bits from the shift register that affect the output. Specifically, $K = m+1$, where $m$ is the number of memory elements (shift register stages).
*   **Code Rate ($R$):** The ratio of the number of information bits to the number of transmitted bits ($k/n$).
*   **Generator Matrix ($G(D)$):** A matrix representation of the encoder's structure in the polynomial domain. For a systematic convolutional encoder, this matrix has a specific structure.

*   **Haykin:** Chapter 10 discusses convolutional codes and their applications in communication systems.
*   **Richardson & Urbanke:** Chapter 3 delves into the fundamental concepts of convolutional codes, including their representation and analysis.

### 2. Systematic Convolutional Encoders

A **systematic encoder** is a type of encoder that transmits the original information bits directly, along with parity bits that are generated from these information bits and previous ones. This means that the encoded message contains the original data, making it easier to recover the information if the decoder can only correct a limited number of errors or if the received signal is not severely corrupted.

**Why Systematic Encoders?**

*   **Easier Decoding:** For some decoding algorithms, especially those designed for block codes or certain trellis-based decoders, having the original information bits alongside parity bits can simplify the decoding process.
*   **Partial Recovery:** If the channel causes minimal errors, the decoder might be able to recover the original information bits directly without needing to decode the parity bits.
*   **Comparison with Block Codes:** Similar to systematic block codes, systematic convolutional codes aim to retain the original information in the transmitted codeword.

**Structure of a Systematic Convolutional Encoder:**

For a convolutional encoder with rate $k/n$ and constraint length $K$, a systematic encoder typically has the following characteristics:

*   The encoder has $k$ parallel input streams and $n$ output streams.
*   The encoder's state is determined by the contents of its shift register. The number of memory elements (stages) is $m = K-1$.
*   The encoder output is a linear combination of the current and previous input bits, determined by the generator polynomials.

In a systematic convolutional encoder, the first $k$ output streams are often designed to be identical to the $k$ input streams. The remaining $n-k$ output streams are the parity bits generated by the encoder.

**Example:**

Let's consider a simple systematic convolutional encoder with:
*   Rate: $R = 1/2$ ($k=1, n=2$)
*   Constraint Length: $K = 3$ ($m=2$ memory elements)

The encoder has one input stream and two output streams. The first output stream will be the direct input bit. The second output stream will be a parity bit.

Let $u(t)$ be the input bit at time $t$. The encoder's state is determined by the previous two input bits: $u(t-1)$ and $u(t-2)$.

**Encoder Diagram:**

```
      u(t) --> [ ] --+--> Output 1 (Direct Input)
               ^   |
               |   |
          [ ] ---+   |
           ^       |
           |       |
          [ ] -----+--> Parity Calculation --> Output 2 (Parity)
```

Here, `[ ]` represents a shift register stage.

Let's define the generator polynomials in the $D$-transform domain. For a rate $1/2$ code with $K=3$, we have two generator polynomials, $g_1(D)$ and $g_2(D)$.

*   $g_1(D)$ will generate the direct input: $g_1(D) = 1$. This means the first output is simply $u(t)$.
*   $g_2(D)$ will generate the parity bit. Since $K=3$, the generator polynomial can have terms up to $D^{K-1} = D^2$. A common choice for $g_2(D)$ might be $1+D+D^2$ (corresponding to $1 \oplus D \oplus D^2$).

**Encoder Equations:**

*   $y_1(t) = u(t)$
*   $y_2(t) = u(t) \oplus u(t-1) \oplus u(t-2)$

**Generator Matrix $G(D)$:**

For a systematic encoder, the generator matrix often has a specific form. For a rate $1/n$ encoder, it's a $1 \times n$ matrix:

$G(D) = [g_1(D), g_2(D), \dots, g_n(D)]$

For our example ($R=1/2$, $K=3$, $g_1(D)=1$, $g_2(D)=1+D+D^2$):

$G(D) = [1, \quad 1+D+D^2]$

The encoded output vector $Y(D)$ is given by $Y(D) = U(D) G(D)$, where $U(D)$ is the input polynomial.

$Y(D) = [y_1(D), y_2(D)]$

$y_1(D) = u(D) \cdot 1 = u(D)$
$y_2(D) = u(D) \cdot (1+D+D^2)$

This confirms that the first output is the original input.

### 3. Constructing Systematic Convolutional Encoders

The process of constructing a systematic convolutional encoder involves selecting appropriate generator polynomials such that the encoder structure naturally produces the original information bits as part of the output.

**General Procedure:**

1.  **Choose Rate ($k/n$) and Constraint Length ($K$):** These parameters define the encoder's complexity and coding performance.
2.  **Select Generator Polynomials:** For a rate $k/n$ code, we need $n$ generator polynomials, $g_{i,j}(D)$, where $i$ denotes the output stream ($1 \le i \le n$) and $j$ denotes the input stream ($1 \le j \le k$). Each polynomial $g_{i,j}(D)$ has a degree at most $K-1$.
3.  **Systematicity Condition:** To ensure systematicity, for each input stream $j$, there must be an output stream $i$ such that its corresponding generator polynomial $g_{i,j}(D)$ is equal to 1. This means that one of the output streams directly passes the $j$-th input stream.
    *   For a rate $k/n$ code, if we assume $k$ output streams directly carry the $k$ input streams, then for each $j \in \{1, \dots, k\}$, there exists an $i \in \{1, \dots, n\}$ such that $g_{i,j}(D) = 1$. Usually, we can assign the first $k$ output streams to carry the $k$ input streams, so $g_{j,j}(D) = 1$ for $j=1, \dots, k$.
4.  **Parity Polynomials:** The remaining $n-k$ outputs will be the parity bits, generated by other linear combinations of input bits. The corresponding generator polynomials for these parity outputs will be other polynomials of degree up to $K-1$.

**Generator Matrix for Systematic Convolutional Codes:**

A common form for the generator matrix $G(D)$ of a systematic convolutional encoder with rate $k/n$ is:

$G(D) = [P(D) \mid I_k]$

where:
*   $P(D)$ is a $k \times (n-k)$ matrix containing the polynomials that generate the parity bits.
*   $I_k$ is the $k \times k$ identity matrix.

**Wait, this is for systematic block codes! Let's correct this for convolutional codes.**

For a systematic convolutional encoder with $k$ inputs and $n$ outputs, the generator matrix $G(D)$ is a $k \times n$ matrix. If we assume the first $k$ output streams correspond to the $k$ input streams (systematicity), then:

$G(D) = [G_{parity}(D) \mid I_k]$

where:
*   $G_{parity}(D)$ is a $k \times (n-k)$ matrix containing the polynomials for the parity outputs.
*   $I_k$ is the $k \times k$ identity matrix.

**Correction:** The standard representation of $G(D)$ for a $k/n$ rate code is a $k \times n$ matrix where rows correspond to inputs and columns correspond to outputs. If we want the first $k$ outputs to be systematic, then the first $k$ columns should form the identity matrix.

Let's rethink this. A $k/n$ convolutional code takes $k$ input bits at a time and produces $n$ output bits. The encoder has $k$ shift registers. The state is determined by the contents of these shift registers and the previous input bits.

A more standard way to represent the generator matrix for a convolutional encoder of rate $k/n$ is a $k \times n$ matrix of polynomials in $D$. Each row corresponds to an input stream, and each column corresponds to an output stream.

For a systematic convolutional encoder, we want some outputs to be the direct input. Let's consider the common case of a rate $1/n$ systematic encoder. The input is a single stream $u(t)$. The encoder has $n$ output streams, $y_1(t), \dots, y_n(t)$. For systematicity, one of these outputs, say $y_1(t)$, should be equal to $u(t)$.

The generator matrix for a rate $1/n$ encoder is a $1 \times n$ matrix:
$G(D) = [g_1(D), g_2(D), \dots, g_n(D)]$

For systematicity, we set $g_1(D) = 1$. The remaining $g_i(D)$ for $i=2, \dots, n$ are the polynomials that generate the parity bits. The degree of each $g_i(D)$ is at most $K-1$.

**Example (Rate 1/2, K=3):**

*   $k=1$, $n=2$, $K=3$ ($m=2$ memory elements).
*   Input: $u(t)$.
*   Outputs: $y_1(t), y_2(t)$.

To make it systematic, $y_1(t) = u(t)$. This corresponds to $g_1(D) = 1$.
We need a parity polynomial $g_2(D)$ for $y_2(t)$. The degree of $g_2(D)$ can be up to $K-1 = 2$.
Let's choose $g_2(D) = 1 + D^2$.

Encoder equations:
*   $y_1(t) = u(t)$
*   $y_2(t) = u(t) \oplus u(t-2)$

Generator Matrix:
$G(D) = [1, \quad 1+D^2]$

### 4. Properties and Advantages of Systematic Convolutional Encoders

**Key Properties:**

*   **Direct Information Transmission:** The original information bits are directly transmitted as part of the coded output.
*   **Structure:** The generator matrix typically has a structure that clearly separates information and parity generation.

**Advantages:**

*   **Simplified Decoding for Certain Scenarios:**
    *   **Soft-Decision Decoding:** For soft-decision decoders (e.g., Viterbi decoder), the presence of the direct information bits can sometimes lead to a more straightforward path metric calculation.
    *   **Erasure Decoding:** If a decoder can detect erasures (unreliable bits), the systematic bits can be used directly.
*   **Graceful Degradation:** In low signal-to-noise ratio (SNR) conditions where error correction is difficult, the receiver can still potentially recover a significant portion of the information by simply using the directly transmitted systematic bits, leading to a more graceful degradation of performance.
*   **Implementation Simplicity:** In some cases, designing hardware for systematic encoders can be conceptually simpler.

**Disadvantages:**

*   **No Gain in Minimum Distance for All Codes:** While systematicity is desirable, it doesn't automatically guarantee an improvement in the code's minimum free distance (which is a primary measure of error-correcting capability). The choice of parity generator polynomials is crucial for achieving good performance.
*   **Efficiency:** For certain code structures, forcing systematicity might lead to a less optimal choice of generator polynomials compared to non-systematic codes that achieve the same minimum distance.

**Important Point to Remember:**
The systematic nature of a convolutional encoder is a property of its construction and generator polynomials, specifically ensuring that some output streams are identical to the input streams. The error-correcting capability still largely depends on the overall structure and the minimum free distance of the code, which is determined by the set of all generator polynomials.

### 6. Practice Questions and Exercises

**Question 1:**
Consider a rate $1/2$ convolutional encoder with $K=4$. If the encoder is systematic, and its generator polynomials are $g_1(D) = 1$ and $g_2(D) = 1+D+D^3$, what are the encoder output bits $y_1(t)$ and $y_2(t)$ in terms of the input bit $u(t)$ and its previous values?
    *   **Answer:**
        *   $y_1(t) = u(t)$ (due to systematicity, $g_1(D)=1$)
        *   $y_2(t) = u(t) \oplus u(t-1) \oplus u(t-3)$ (from $g_2(D) = 1+D+D^3$)

**Question 2:**
For the systematic convolutional encoder in Question 1, write down its generator matrix $G(D)$.
    *   **Answer:**
        $G(D) = [1, \quad 1+D+D^3]$

**Question 3:**
What is the main advantage of using a systematic convolutional encoder compared to a non-systematic one, particularly in scenarios with limited decoder capability or low SNR?
    *   **Answer:** The primary advantage is the direct transmission of information bits. This allows for partial recovery of information even if the parity bits are severely corrupted or if the decoder cannot fully correct all errors. This leads to a more graceful degradation of performance.

**Question 4:**
Can a rate $1/3$ convolutional encoder be systematic? If so, what would be the structure of its generator matrix $G(D)$?
    *   **Answer:** Yes, a rate $1/3$ encoder can be systematic. For it to be systematic, one of the output streams must carry the original information directly. The generator matrix $G(D)$ would be a $1 \times 3$ matrix, for example:
        $G(D) = [1, \quad g_2(D), \quad g_3(D)]$
        Here, $y_1(t) = u(t)$, and $y_2(t)$ and $y_3(t)$ are parity bits generated by polynomials $g_2(D)$ and $g_3(D)$ respectively.

**Question 5:**
Consider a rate $2/3$ systematic convolutional encoder. Assume the first output stream is identical to the first input stream ($u_1(t)$), and the second output stream is identical to the second input stream ($u_2(t)$). What would be the structure of its $2 \times 3$ generator matrix $G(D)$?
    *   **Answer:** The generator matrix $G(D)$ for a $2/3$ rate code is a $2 \times 3$ matrix. For systematicity where the first two outputs correspond to the two inputs, the structure would be:
        $G(D) = \begin{pmatrix}
        1 & 0 & g_{13}(D) \\
        0 & 1 & g_{23}(D)
        \end{pmatrix}$
        Here, the first row represents the first input $u_1(t)$ and the second row represents the second input $u_2(t)$. The first column corresponds to the first output, the second column to the second output, and the third column to the third output. The '1's on the diagonal of the first two columns ensure that the first two outputs ($y_1(t)$ and $y_2(t)$) are the original input bits ($u_1(t)$ and $u_2(t)$). $g_{13}(D)$ and $g_{23}(D)$ are the polynomials that generate the parity bits for the third output.

### 7. Important Points to Remember

*   **Systematicity means transmitting the original information bits directly.** For a rate $k/n$ code, $k$ of the $n$ output streams are identical to the $k$ input streams.
*   **The first output stream usually carries the first input stream, and so on, for systematic codes.** This is achieved by setting the corresponding generator polynomial to 1.
*   **The generator matrix of a systematic convolutional encoder has a structure that reflects this direct transmission.** For a rate $1/n$ code, $G(D) = [1, g_2(D), \dots, g_n(D)]$. For a rate $k/n$ code, the structure typically involves an identity matrix block.
*   **Systematicity aids in graceful degradation and potentially simplifies decoding in specific scenarios.** However, it does not guarantee a better minimum free distance on its own; the choice of parity polynomials is critical.
*   **The constraint length $K$ still dictates the memory of the encoder and influences the complexity and performance.**
