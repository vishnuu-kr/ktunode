### 1. Introduction to Colour Image Processing

*   **Definition:** Colour image processing is a branch of digital image processing that deals with the processing of images that contain color information. It extends the concepts of monochrome image processing to color images, requiring new techniques and considerations.
*   **Importance of Colour:** Colour provides a significant amount of information that is not present in monochrome images. It plays a crucial role in:
    *   **Human Perception:** Our visual system is highly sensitive to colour, allowing us to distinguish objects and their properties more effectively.
    *   **Object Recognition and Segmentation:** Colour features can be powerful discriminators for identifying and separating different objects within an image.
    *   **Image Analysis and Understanding:** Colour can convey semantic meaning, such as the state of an object (e.g., ripe vs. unripe fruit) or emotional cues.
*   **Relationship to Monochrome Image Processing:** Many fundamental concepts from monochrome image processing (e.g., sampling, quantization, filtering) are extended to colour image processing. However, the multi-component nature of colour images introduces complexities.

### 2. Colour Models

*   **Definition:** A colour model is a mathematical model that describes how colours can be represented as a set of numerical values. These models aim to capture the characteristics of human colour perception or the way colours are generated by physical devices.

#### 2.1. RGB Colour Model

*   **Description:** The RGB colour model is a widely used additive colour model where red (R), green (G), and blue (B) are combined in various proportions to produce a spectrum of colours.
*   **Additive Nature:** In an additive model, colours are created by adding light. When R, G, and B are combined at maximum intensity, white light is produced. When no light is present, black is produced.
*   **Components:**
    *   **Red (R):** Represents the intensity of red light.
    *   **Green (G):** Represents the intensity of green light.
    *   **Blue (B):** Represents the intensity of blue light.
*   **Representation:** A colour in the RGB model is represented by a triplet $(R, G, B)$.
*   **Colour Cube:** The RGB colour space can be visualized as a cube in a 3D Cartesian coordinate system. The axes represent the intensity of R, G, and B.
    *   The origin (0, 0, 0) represents black.
    *   The point (Max, Max, Max) represents white (where Max is the maximum intensity value).
    *   The primary colours (R, 0, 0), (0, G, 0), and (0, 0, B) lie on the axes.
    *   Secondary colours (e.g., yellow = R+G, cyan = G+B, magenta = R+B) lie on the planes.
*   **Quantization:** The intensity of each colour component is typically quantized into a finite number of discrete levels.
    *   **8-bit per channel:** Each component (R, G, B) can take values from 0 to 255. This results in $256 \times 256 \times 256 = 16,777,216$ possible colours. This is often referred to as "True Colour."
    *   **24-bit colour:** The total number of bits used to represent a pixel is 24 (8 bits for R, 8 for G, 8 for B).
*   **Applications:**
    *   **Display Devices:** Monitors, TVs, projectors, and digital cameras primarily use the RGB model to generate colours by emitting light.
    *   **Image Acquisition:** Sensors in digital cameras capture light and typically output RGB values.
*   **Textbook Reference:** Gonzalez & Woods (4th Ed.) extensively covers colour models, including RGB, in Chapter 6. They explain the additive nature and the concept of the colour cube. Jayaraman et al. also discusses RGB in its initial chapters on colour image fundamentals.

*   Magenta: (255, 0, 255) (Red + Blue)
*   Grey: (128, 128, 128) (Mid-intensity)

#### 2.2. Colour Image Representation in Memory

*   **Pixel Structure:** A colour image is represented as a collection of pixels. Each pixel in a colour image has a colour value associated with it, which is typically represented by multiple components (e.g., R, G, B).
*   **Storage Formats:**
    *   **Planar Format:** The image is stored as three separate planes, one for each colour component (R plane, G plane, B plane). Each plane is essentially a monochrome image of the same dimensions.
        *   Example: A $W \times H$ colour image would require $3 \times W \times H$ bytes of storage (if 8 bits per component).
    *   **Interleaved Format:** The colour components of each pixel are stored together. For a pixel at (x, y), its components are stored consecutively: R, G, B, R, G, B, ...
        *   Example: Pixel data for (x, y) might be stored as R-value, G-value, B-value, then the data for (x+1, y).
*   **Data Types:** The intensity values for each component are typically stored as integers (e.g., `unsigned char` for 8-bit values, `short` or `int` for higher bit depths).
*   **Textbook Reference:** Gonzalez & Woods (4th Ed.) and Jayaraman et al. both discuss how colour images are stored in memory, often illustrating the planar and interleaved formats.

### 3. Colour Perception and Human Vision

*   **Trichromatic Theory of Vision:** This theory states that human colour perception is based on the response of three different types of cone photoreceptor cells in the retina. Each type of cone is maximally sensitive to different wavelengths of light:
    *   **Short-wavelength cones (S-cones):** Sensitive to blue light.
    *   **Medium-wavelength cones (M-cones):** Sensitive to green light.
    *   **Long-wavelength cones (L-cones):** Sensitive to red light.
*   **How RGB Relates:** The RGB model is inspired by this biological mechanism. The primary colours R, G, and B correspond to the peak sensitivities of these cone types. By stimulating these cones in different proportions, we perceive a wide range of colours.
*   **Limitations of RGB for Perception:** While RGB is good for display, it's not always ideal for describing colour perception because:
    *   The perceived colour depends not only on the spectral distribution of light but also on the context and adaptation of the observer's visual system.
    *   Equal amounts of RGB light do not necessarily result in equal perceived brightness.

### 4. Advantages and Disadvantages of RGB

*   **Advantages:**
    *   **Simplicity and Universality:** It's the most common colour model for displays and digital cameras.
    *   **Hardware Compatibility:** Widely supported by hardware devices.
    *   **Directly Related to Display:** Easy to map RGB values to the colours displayed on a screen.
*   **Disadvantages:**
    *   **Lack of Perceptual Uniformity:** Changes in RGB values do not always correspond to perceptually uniform changes in colour. For example, changing R by 10 might have a different perceptual impact than changing G by 10.
    *   **Not Ideal for Image Analysis:** For tasks like segmentation or colour-based retrieval, it can be difficult to isolate colour information (like hue) from intensity information. Brightness variations can drastically alter the R, G, and B values, even if the perceived colour remains similar.
    *   **Redundancy:** RGB components are often correlated, especially in natural images.

### 5. Beyond RGB: Introduction to Other Colour Models (Briefly)

*   While this topic focuses on RGB, it's important to note that other colour models exist to address RGB's limitations or serve different purposes. These often involve separating colour information (like hue and saturation) from intensity information.
    *   **CMY/CMYK:** Cyan, Magenta, Yellow (and Key/Black) - Subtractive models used in printing.
    *   **HSV/HSL:** Hue, Saturation, Value/Lightness - Perceptually more intuitive models.
    *   **YIQ/YUV:** Luminance (Y) and Chrominance (I, Q or U, V) - Used in television broadcasting and some image compression standards to separate brightness from colour information.

### 6. Important Points to Remember

*   **RGB is an Additive Colour Model:** Colours are created by adding light.
*   **Primary Colours:** Red, Green, Blue.
*   **Colour Representation:** $(R, G, B)$ triplets.
*   **Quantization:** Commonly 8 bits per channel (0-255), leading to 24-bit colour.
*   **Applications:** Primarily for display devices and image acquisition.
*   **Perceptual Basis:** Inspired by the trichromatic theory of human vision.
*   **Limitations:** Not perceptually uniform, difficult to separate intensity and colour information for analysis.

### 8. Answers to Practice Questions

**A1. b) Red, Green, Blue**
    *Explanation: The RGB model uses Red, Green, and Blue as its primary colours, which are mixed to create other colours.*

**A2. c) $(2^8)^3$**
    *Explanation: Each component (R, G, B) can take $2^8 = 256$ values. The total number of colours is the product of the number of values each component can take, hence $256 \times 256 \times 256 = (2^8)^3 = 2^{24}$.*

**A3. Planar Format:** The image is stored as three separate 2D arrays (planes), one for each colour component (R, G, B). Each plane has the same dimensions as the original image.
    **Interleaved Format:** The colour components of each pixel are stored consecutively. For a pixel at (x, y), its R, G, and B values are stored together as R(x,y), G(x,y), B(x,y), followed by the data for the next pixel.

**A4. It is additive because colours are created by adding different intensities of light. When all three primary colours (Red, Green, Blue) are mixed at their maximum intensity, they produce white light. Absence of all light produces black.**

**A5. The RGB colour model is less suitable for tasks like colour-based segmentation or analysing specific colour attributes (like hue) because the intensity of illumination significantly affects the R, G, and B values of a pixel, even if the perceived colour (hue) remains the same. For example, a red object viewed under bright white light will have high R, G, and B values, but a red object viewed under dim light will have lower R, G, and B values. This makes it difficult to isolate colour information from brightness information. Models like HSV or YUV, which separate luminance from chrominance, are often preferred for such analysis.**
