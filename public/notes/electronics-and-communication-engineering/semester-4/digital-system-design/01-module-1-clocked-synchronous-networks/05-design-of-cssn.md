### 1. Introduction to Clocked Synchronous State Machines (CSSM)

**Definition:** A Clocked Synchronous State Machine (CSSM) is a sequential logic circuit whose state changes are synchronized to the edges of a clock signal. This synchronization ensures predictable behavior and avoids timing-related issues like race conditions common in asynchronous circuits.

**Key Components of a CSSM:**

*   **Combinational Logic:** This part of the circuit computes the next state and the output based on the current state and the primary inputs.
*   **State Register (Flip-flops):** This memory element stores the current state of the machine. Flip-flops are triggered by the clock signal.
*   **Clock Signal:** A periodic signal that synchronizes the state transitions. State changes occur only when the clock transitions (e.g., from low to high – positive edge-triggered).
*   **Primary Inputs:** External signals that influence the behavior of the machine.
*   **Outputs:** Signals generated by the machine, which can be dependent on the current state (Mealy machine) or both the current state and primary inputs (Moore machine).

**Types of State Machines:**

1.  **Mealy Machine:**
    *   Outputs depend on both the **current state** and **primary inputs**.
    *   Outputs can change as soon as the inputs change, even between clock edges.
    *   **Block Diagram:**
        ```
                +-----------------+
        Inputs -->|                 |
                | Combinational   |--> Outputs
        State --> | Logic           |
                | (Next State &   |
                |  Output Logic)  |
                +--------+--------+
                         |
                         v
                     +--------+
                     | State  |
                     | Reg.   |
                     +--------+
                         ^
                         |
                      Clock
        ```

2.  **Moore Machine:**
    *   Outputs depend only on the **current state**.
    *   Outputs change only when the state changes (i.e., on the clock edge).
    *   **Block Diagram:**
        ```
                +-----------------+
        Inputs -->|                 |
                | Combinational   |--> Next State Logic
        State --> | Logic           |
                | (Next State Logic|
                |  & Output Logic)|
                +--------+--------+
                         |
                         v
                     +--------+
                     | State  |
                     | Reg.   |
                     +--------+
                         ^
                         |
                      Clock
        ```
        *Note: In a Moore machine, the output logic is separate and driven solely by the state register.*

### 2. State Diagrams and State Tables

**State Diagram:** A graphical representation of a sequential machine that shows the states, transitions between states, and the inputs and outputs associated with each transition.

*   **States:** Represented by circles or nodes.
*   **Transitions:** Represented by directed arcs between states.
*   **Transition Labels:** Indicate the primary input conditions that cause the transition and the corresponding output(s).
    *   **Mealy:** `input / output`
    *   **Moore:** `input` (leading to the next state), with outputs indicated within the state circle.

**Example (Mealy): A simple sequence detector for "10"**

```
       +-------+      1 / 0       +-------+
       |       | -------------> |       |
       |  S0   |                |  S1   |
       | (Idle)| <------------- | (Got 1)|
       |       |      0 / 0     |       |
       +-------+ ---------------> +-------+
             0 / 0                  1 / 1
                                (Output 1 when "10" detected)
```

*   **S0:** Initial state, no part of the sequence detected.
*   **S1:** State after detecting a '1'.
*   **Transition S0 to S1 on input 1:** Output is 0.
*   **Transition S1 to S0 on input 0:** Output is 1 (sequence "10" detected).
*   **Transition S1 to S1 on input 1:** Output is 0 (still have '1', waiting for '0').
*   **Transition S0 to S0 on input 0:** Output is 0 (still idle).

**State Table:** A tabular representation of a sequential machine that lists all possible states, inputs, next states, and outputs.

*   **Columns:** Current State, Primary Inputs, Next State, Outputs.

**Example (Mealy): State Table for the "10" detector**

| Current State | Input (X) | Next State | Output (Y) |
| :------------ | :-------- | :--------- | :--------- |
| S0            | 0         | S0         | 0          |
| S0            | 1         | S1         | 0          |
| S1            | 0         | S0         | 1          |
| S1            | 1         | S1         | 0          |

**Example (Moore): A simple sequence detector for "10"**

```
       +-------+      1       +-------+
       |       | ---------> |       |
       |  S0   |            |  S1   |
       | (Idle)| <--------- | (Got 1)|
       |  Y=0  |   0        |  Y=0  |
       +-------+ ---------> +-------+
             0                1
                           (Output 1 when "10" detected)
                            +-------+
                            |  S2   |
                            | (10   |
                            | Found)|
                            |  Y=1  |
                            +-------+
```

*   **S0:** Idle, output 0.
*   **S1:** Got '1', output 0.
*   **S2:** Detected "10", output 1.

**Example (Moore): State Table for the "10" detector**

| Current State | Input (X) | Next State | Output (Y) |
| :------------ | :-------- | :--------- | :--------- |
| S0            | 0         | S0         | 0          |
| S0            | 1         | S1         | 0          |
| S1            | 0         | S2         | 0          |
| S1            | 1         | S1         | 0          |
| S2            | 0         | S0         | 1          |
| S2            | 1         | S1         | 1          |

### 3. State Minimization

**Purpose:** To reduce the number of states in a state machine without changing its external behavior. This leads to simpler hardware implementation with fewer flip-flops and gates.

**Methods:**

1.  **Implication Table Method (Karnaugh-Kopp Method):**
    *   **Concept:** Identifies equivalent states by checking if they produce the same outputs and transition to equivalent next states for all input combinations.
    *   **Steps:**
        1.  Create an implication table with pairs of states.
        2.  Mark pairs as "implied" if their outputs are different for any input.
        3.  For each pair (A, B) that is implied, mark all pairs (A', B') where A' is the next state of A and B' is the next state of B as implied, provided the next states are different for some input.
        4.  Continue this process until no new pairs are implied.
        5.  Group the remaining unimplied pairs into equivalent state sets.
        6.  Choose one state from each equivalent set to represent the minimized machine.

2.  **Equivalence Partitioning:**
    *   **Concept:** Start with a partition where each state is in its own set. Iteratively refine the partition by splitting sets if states within a set produce different outputs or transition to states in different sets for any input.

**Example (Equivalence Partitioning):**

Consider a state machine with states {S0, S1, S2, S3} and transitions based on input X.

*   **Initial Partition (P0):** {{S0}, {S1}, {S2}, {S3}}

*   **Refinement based on outputs:**
    *   Assume S0 and S2 have output 0, S1 and S3 have output 1.
    *   Partition P1: {{S0, S2}, {S1, S3}}

*   **Refinement based on next states:**
    *   Check S0 vs. S2 for input X=0 and X=1.
    *   If S0(X=0) -> S1 and S2(X=0) -> S1, then S0 and S2 are still potentially equivalent for X=0.
    *   If S0(X=1) -> S3 and S2(X=1) -> S3, then S0 and S2 are still potentially equivalent for X=1.
    *   If for any input, S0 transitions to a state in a different partition set than S2, then S0 and S2 are not equivalent.

**Example (Minimization):**

Consider the following state table:

| Current State | X=0 | X=1 | Y (Moore) |
| :------------ | :-- | :-- | :-------- |
| S0            | S1  | S0  | 0         |
| S1            | S0  | S2  | 0         |
| S2            | S1  | S0  | 0         |

*   **Initial Partition (P0):** {{S0}, {S1}, {S2}}
*   **Partition by output:** All states have output 0. No split.
*   **Consider S0 and S2:**
    *   For X=0: S0 -> S1, S2 -> S1. Same next state.
    *   For X=1: S0 -> S0, S2 -> S0. Same next state.
    *   Since their outputs are the same and their next states are the same for all inputs, S0 and S2 are equivalent.
*   **New Partition (P1):** {{S0, S2}, {S1}}
*   **Check within {S0, S2}:** Already determined to be equivalent.
*   **Check between {S0, S2} and {S1}:**
    *   Consider S0 (from {S0, S2}) and S1 (from {S1}).
    *   For X=0: S0 -> S1 (in {S1}), S1 -> S0 (in {S0, S2}). These next states are in different sets.
    *   Therefore, S0 and S1 are not equivalent.
    *   Consider S2 (from {S0, S2}) and S1 (from {S1}).
    *   For X=0: S2 -> S1 (in {S1}), S1 -> S0 (in {S0, S2}). These next states are in different sets.
    *   Therefore, S2 and S1 are not equivalent.

*   **Final Partition:** {{S0, S2}, {S1}}. This indicates that S0 and S2 are equivalent.
*   **Minimized Machine:** We can replace S0 and S2 with a single state, say S0'.
    *   The minimized state table would have states {S0', S1}.

**Important Point:** Minimization should be done **before** state assignment.

### 4. State Assignment

**Purpose:** To assign unique binary codes to each state of the minimized state machine. The choice of state assignment can significantly impact the complexity of the resulting logic circuit.

**Goals of State Assignment:**

*   **Minimize the number of flip-flops:** Determined by the number of states (N), $n = \lceil \log_2 N \rceil$.
*   **Minimize the combinational logic complexity:** This is achieved by assigning codes such that states that are often transitioned to together or have similar next-state behavior share common binary patterns in their assigned codes.

**Types of State Assignment:**

1.  **Binary (Natural) Assignment:** Assigning binary codes sequentially (000, 001, 010, ...). Simple but rarely optimal for logic minimization.

2.  **One-Hot Assignment:** Each state is assigned a unique binary code with only one '1' bit. If there are N states, N flip-flops are used. While it uses more flip-flops than necessary, it can simplify the combinational logic by making next-state logic for each flip-flop depend on only one or two states.

3.  **Heuristic Methods (e.g., Pairwise State Assignment, Row/Column Adjacency Methods):** These methods aim to group states with similar transition patterns or output behavior together in the binary code assignment to facilitate Karnaugh map simplification.

    *   **Grundy-Huffman Method:** Aims to minimize the number of product terms.
    *   **Petrick's Method:** A more systematic approach to finding an optimal assignment.

**Example (State Assignment):**

Consider a minimized machine with 3 states: {S0', S1, S2} (from the previous example).

*   **Number of flip-flops:** $n = \lceil \log_2 3 \rceil = 2$. Let the flip-flop outputs be $Q_1Q_0$.

*   **Binary Assignment:**
    *   S0' -> 00
    *   S1   -> 01
    *   S2   -> 10

*   **One-Hot Assignment:**
    *   S0' -> 00
    *   S1   -> 01
    *   S2   -> 10
    *   (This example shows identical codes, but for 3 states, we'd need 3 flip-flops in true one-hot for N states requiring N flip-flops. If we use the minimum number of flip-flops, one-hot is a strategy for assigning codes to those minimum flip-flops.)
    *   Correct One-Hot for 3 states:
        *   S0' -> 001
        *   S1   -> 010
        *   S2   -> 100
        *   (Requires 3 flip-flops, which is not optimal for 3 states. However, if we consider the encoding of the states themselves, not just the FF outputs, this is one-hot.)

*   **Heuristic Assignment (aiming for adjacency):**
    *   Assume state S0' and S1 have many common transitions or similar next states. We want their codes to differ by only one bit (adjacent).
    *   Let's try:
        *   S0' -> 00
        *   S1   -> 01
        *   S2   -> 11 (or 10)

    *   The choice depends on creating favorable Karnaugh maps for the next-state logic. This requires constructing the excitation table and K-maps for each assignment.

**Building the Excitation Table:** After state assignment, construct an excitation table mapping (Current State Code, Input) to (Next State Code, Output).

### 5. Implementation of CSSM

**Purpose:** To translate the finalized state table (after minimization and state assignment) into a hardware circuit using flip-flops and combinational logic gates.

**Steps:**

1.  **Choose Flip-flops:**
    *   **D Flip-flops:** Simplest to design with. $Q^+ = D$. Next state logic directly drives the D input.
    *   **JK Flip-flops:** Offer more flexibility. $Q^+ = J\overline{Q} + \overline{K}Q$. Can be used for optimization.
    *   **T Flip-flops:** Useful for toggling states. $Q^+ = T\overline{Q} + \overline{T}Q$.
    *   **SR Flip-flops:** Generally avoided in synchronous design due to potential race conditions if not carefully implemented with a clock.

2.  **Construct the Excitation Table:** This table shows the required input values for the chosen flip-flops (e.g., D inputs) for each transition.
    *   For D flip-flops: $D = Q^+$.

3.  **Derive Boolean Expressions:** For each flip-flop input (D, J, K, T) and each output, derive a Boolean expression as a function of the current state bits ($Q_i$) and primary inputs ($X_j$).

4.  **Simplify Boolean Expressions:** Use Karnaugh maps or Boolean algebra to minimize the derived expressions. This is where the state assignment plays a crucial role.

5.  **Draw the Logic Diagram:** Implement the simplified Boolean expressions using logic gates and the chosen flip-flops.

**Example (Implementation with D Flip-flops):**

Let's use the binary state assignment for our minimized machine:
*   States: {S0', S1, S2}
*   Assignment: S0' -> 00 ($Q_1Q_0$), S1 -> 01, S2 -> 10
*   Input: X
*   Output: Y (Moore)

**Minimized State Table with Assignment:**

| Current State ($Q_1Q_0$) | Input (X) | Next State ($Q_1^+Q_0^+$) | Output (Y) |
| :--------------------- | :-------- | :----------------------- | :--------- |
| 00 (S0')               | 0         | 01                       | 0          |
| 00 (S0')               | 1         | 00                       | 0          |
| 01 (S1)                | 0         | 00                       | 0          |
| 01 (S1)                | 1         | 10                       | 0          |
| 10 (S2)                | 0         | 01                       | 0          |
| 10 (S2)                | 1         | 00                       | 0          |

**Excitation Table (for D flip-flops):**

| Current State ($Q_1Q_0$) | Input (X) | $D_1 = Q_1^+$ | $D_0 = Q_0^+$ | Output (Y) |
| :---------------------- | :-------- | :------------ | :------------ | :--------- |
| 00                      | 0         | 0             | 1             | 0          |
| 00                      | 1         | 0             | 0             | 0          |
| 01                      | 0         | 0             | 0             | 0          |
| 01                      | 1         | 1             | 0             | 0          |
| 10                      | 0         | 0             | 1             | 0          |
| 10                      | 1         | 0             | 0             | 0          |

**Boolean Expressions using Karnaugh Maps:**

*   **For $D_1$:**
    | $Q_1Q_0$ | X=0 | X=1 |
    | :------- | :-- | :-- |
    | 00       | 0   | 0   |
    | 01       | 0   | 1   |
    | 11       | -   | -   |
    | 10       | 0   | 0   |
    *   $D_1 = Q_0 \cdot X$

*   **For $D_0$:**
    | $Q_1Q_0$ | X=0 | X=1 |
    | :------- | :-- | :-- |
    | 00       | 1   | 0   |
    | 01       | 0   | 0   |
    | 11       | -   | -   |
    | 10       | 1   | 0   |
    *   $D_0 = \overline{Q_1} \cdot \overline{X}$

*   **For Output Y:**
    | $Q_1Q_0$ | X=0 | X=1 |
    | :------- | :-- | :-- |
    | 00       | 0   | 0   |
    | 01       | 0   | 0   |
    | 11       | -   | -   |
    | 10       | 0   | 0   |
    *   $Y = 0$ (This specific example is a trivial output!)

**Logic Diagram:**
```
          +-----------------+
Inputs -- |                 |
(X)       | Combinational   |-- D1 = Q0 . X
          | Logic           |-- D0 = Q1' . X'
State --> | (Boolean Expr.) |-- Y = 0
($Q_1Q_0$) |                 |
          +--------+--------+
                   |
                   v
             +-----------+
             | D Flip-flop|-- Q1
             | ($D_1$)   |
             +-----------+
                   ^
                   | Clock
             +-----------+
             | D Flip-flop|-- Q0
             | ($D_0$)   |
             +-----------+
```
*(Note: The Y=0 output means this machine never produces a '1' output. A more illustrative example would be needed for a non-trivial output).*

### 6. Design Flow Summary for CSSM

The systematic design of a clocked synchronous state machine follows these steps:

1.  **Understand the Problem:** Clearly define the functional requirements of the sequential circuit (e.g., sequence detector, controller).
2.  **Create a State Diagram:** Represent the functionality graphically, identifying all states and transitions.
3.  **Create a State Table:** Convert the state diagram into a tabular form.
4.  **Minimize the States:** Use implication tables or equivalence partitioning to reduce the number of states.
5.  **Assign Binary Codes to States:** Choose a state assignment strategy to optimize the resulting logic.
6.  **Construct the Excitation Table:** Based on the minimized state table and chosen state assignment, determine the flip-flop inputs and outputs.
7.  **Derive and Simplify Boolean Expressions:** Use K-maps or Boolean algebra to obtain minimized logic for flip-flop inputs and outputs.
8.  **Draw the Logic Diagram:** Implement the circuit using flip-flops and logic gates.
9.  **Verify the Design:** Simulate the circuit or build a prototype to ensure it functions as intended.

**Important Point:** Each step builds upon the previous one, and errors in earlier stages can propagate through the design.

**Relationship to Course Outcomes:**

*   **CO1: Analyze asynchronous and clocked synchronous sequential circuits:** This entire flow is about designing CSSMs.

### 7. Examples and Applications

*   **Sequence Detectors:** Circuits that output a pulse when a specific input sequence is detected (e.g., serial data pattern recognition).
*   **Counters:** Circuits that increment or decrement a binary count in response to a clock.
    *   **Ripple Counters:** Asynchronous, where the output of one flip-flop clocks the next.
    *   **Synchronous Counters:** All flip-flops are clocked simultaneously by the same clock. Design involves creating logic to determine when each flip-flop should toggle.
*   **Finite State Machine Controllers:** Used in various digital systems to control the sequence of operations (e.g., traffic light controllers, vending machines, FPGAs).
*   **Data Synchronizers:** Used to interface asynchronous inputs to a synchronous system.

**Example: Design of a Synchronous 2-bit Up Counter**

*   **Requirement:** Count from 00, 01, 10, 11 and repeat.
*   **States:** S0 (00), S1 (01), S2 (10), S3 (11)
*   **State Diagram/Table:**
    | Current State | Next State |
    | :------------ | :--------- |
    | S0 (00)       | S1 (01)    |
    | S1 (01)       | S2 (10)    |
    | S2 (10)       | S3 (11)    |
    | S3 (11)       | S0 (00)    |

*   **State Assignment (Binary):**
    *   S0 -> $Q_1Q_0 = 00$
    *   S1 -> $Q_1Q_0 = 01$
    *   S2 -> $Q_1Q_0 = 10$
    *   S3 -> $Q_1Q_0 = 11$

*   **Excitation Table (using D flip-flops):**
    | Current State ($Q_1Q_0$) | $D_1 = Q_1^+$ | $D_0 = Q_0^+$ |
    | :--------------------- | :------------ | :------------ |
    | 00                     | 0             | 1             |
    | 01                     | 1             | 0             |
    | 10                     | 1             | 1             |
    | 11                     | 0             | 0             |

*   **K-maps for $D_1$ and $D_0$:**
    *   **$D_1$:**
        | $Q_1Q_0$ | 00 | 01 | 11 | 10 |
        | :------- | :-- | :-- | :-- | :-- |
        | 0        | 0   | 1   | 0   | 1   |
        *   $D_1 = Q_1 \oplus Q_0$

    *   **$D_0$:**
        | $Q_1Q_0$ | 00 | 01 | 11 | 10 |
        | :------- | :-- | :-- | :-- | :-- |
        | 0        | 1   | 0   | 0   | 1   |
        *   $D_0 = \overline{Q_1} \cdot \overline{Q_0}$ (or $D_0 = \overline{Q_1+Q_0}$)

*   **Implementation:**
    *   Use two D flip-flops, $Q_1$ and $Q_0$.
    *   $D_1$ is connected to $Q_1 \oplus Q_0$.
    *   $D_0$ is connected to $\overline{Q_1} \cdot \overline{Q_0}$.
    *   Both flip-flops are clocked by the same system clock.

### 8. Practice Questions

1.  **Question:** Differentiate between Mealy and Moore state machines, providing a block diagram and an example scenario for each.
    **Answer:**
    *   **Mealy:** Outputs depend on current state AND inputs. Changes can occur between clock edges. Block diagram shows outputs from combinational logic block. Scenario: A circuit that outputs '1' only when a specific sequence *and* an input transition occur simultaneously.
    *   **Moore:** Outputs depend ONLY on current state. Changes occur only on clock edges. Block diagram shows outputs from state register or a separate output logic block driven by the state register. Scenario: A circuit that outputs '1' when the machine is in a specific state, regardless of current inputs.

2.  **Question:** Minimise the following state table using the implication table method. Assume a Moore machine.

    | Current State | X=0 | X=1 | Output (Y) |
    | :------------ | :-- | :-- | :-------- |
    | S0            | S1  | S0  | 0         |
    | S1            | S0  | S2  | 0         |
    | S2            | S1  | S0  | 0         |
    | S3            | S2  | S3  | 0         |

    **Answer:**
    *   **Initial Partition:** {{S0}, {S1}, {S2}, {S3}}
    *   **Output-based Partition:** All outputs are 0. No split.
    *   **Implication Table:**
        *   (S0, S1): S0(X=0)->S1, S1(X=0)->S0. S0(X=1)->S0, S1(X=1)->S2. S0 and S2 are not equivalent.
        *   (S0, S2): S0(X=0)->S1, S2(X=0)->S1. S0(X=1)->S0, S2(X=1)->S0. S0 and S0 are equivalent, S1 and S1 are equivalent. Implied: (S0,S2) are equivalent.
        *   (S0, S3): S0(X=0)->S1, S3(X=0)->S2. (S1,S2) are not equivalent. Implied: (S0,S3) are not equivalent.
        *   (S1, S2): S1(X=0)->S0, S2(X=0)->S1. (S0,S1) are not equivalent. Implied: (S1,S2) are not equivalent.
        *   (S1, S3): S1(X=0)->S0, S3(X=0)->S2. (S0,S2) are equivalent. Implied: (S1,S3) are equivalent.
        *   (S2, S3): S2(X=0)->S1, S3(X=0)->S2. (S1,S2) are not equivalent. Implied: (S2,S3) are not equivalent.

    *   **Equivalence Classes:** {S0, S2}, {S1}, {S3}.
    *   **Wait!** My previous analysis of (S1, S3) implies they are equivalent IF (S0, S2) are equivalent. Let's recheck carefully.

    Let's use a more structured approach for the implication table:

    | Pair   | X=0 (Next States) | X=1 (Next States) | Implied by (Output Diff?) |
    | :----- | :---------------- | :---------------- | :------------------------ |
    | (S0,S1) | (S1,S0)           | (S0,S2)           | No                        |
    | (S0,S2) | (S1,S1)           | (S0,S0)           | Yes                       |
    | (S0,S3) | (S1,S2)           | (S0,S3)           | Yes (S1,S2 diff)          |
    | (S1,S2) | (S0,S1)           | (S2,S0)           | No                        |

3.  **Question:** Explain why state assignment is important in the design of CSSMs and mention at least two methods of state assignment.
    **Answer:** State assignment is crucial because the binary codes assigned to states directly affect the complexity of the combinational logic required for next-state and output functions. A good state assignment can simplify Karnaugh maps and reduce the number of gates, leading to a more efficient hardware implementation. Two methods are Binary Assignment and One-Hot Assignment. Heuristic methods like the Grundy-Huffman method also exist.

4.  **Question:** Design a synchronous circuit using D flip-flops that counts up when an input 'A' is 1, and stays in the same state when 'A' is 0. It should have states corresponding to binary counts 00, 01, 10, and 11.
    **Answer:** This is similar to the 2-bit up counter example, but the transitions are controlled by input 'A'.
    *   States: S0(00), S1(01), S2(10), S3(11).
    *   State Assignment: S0->00, S1->01, S2->10, S3->11.
    *   Excitation Table:
        | Current State ($Q_1Q_0$) | Input (A) | $D_1 = Q_1^+$ | $D_0 = Q_0^+$ |
        | :---------------------- | :-------- | :------------ | :------------ |
        | 00                      | 0         | 0             | 0             |
        | 00                      | 1         | 0             | 1             |
        | 01                      | 0         | 0             | 1             |
        | 01                      | 1         | 1             | 0             |
        | 10                      | 0         | 1             | 0             |
        | 10                      | 1         | 1             | 1             |
        | 11                      | 0         | 1             | 1             |
        | 11                      | 1         | 0             | 0             |
    *   K-maps:
        *   $D_1$: The '1's are at (01,1), (10,0), (10,1), (11,0), (11,1).
            *   $D_1 = Q_1 \overline{Q_0} \overline{A} + Q_1 Q_0 \overline{A} + \overline{Q_1} Q_0 A + Q_1 Q_0 A + \overline{Q_1} \overline{Q_0} A$
            *   After K-map simplification: $D_1 = Q_1 + Q_0 A$
        *   $D_0$: The '1's are at (00,1), (01,0), (10,1), (11,0).
            *   $D_0 = \overline{Q_1} \overline{Q_0} A + Q_1 \overline{Q_0} \overline{A} + \overline{Q_1} Q_0 \overline{A} + Q_1 Q_0 A$
            *   After K-map simplification: $D_0 = \overline{Q_0} A + Q_0 \overline{A} + \overline{Q_1} \overline{Q_0} A$
            *   $D_0 = Q_0 \oplus A + \overline{Q_1}\overline{Q_0}A$

    *   **Implementation:** Connect $D_1$ and $D_0$ to the respective inputs of two D flip-flops clocked by the same system clock.

### 9. Important Points to Remember

*   **Synchronous Design:** All state changes are synchronized by a clock signal, preventing race conditions.
*   **State Diagram and Table:** The fundamental tools for representing and analyzing sequential machines.
*   **Minimization:** Essential for efficient hardware implementation.
*   **State Assignment:** Impacts logic complexity; heuristic methods are often used.
*   **D Flip-flops:** Commonly used for CSSM implementation due to simpler logic derivation.
*   **Design Flow:** Follow a systematic process from problem definition to circuit implementation.
*   **Mealy vs. Moore:** Understand the difference in output behavior and their implications.
