## ECONOMICS FOR ENGINEERS - Module 4: Value Analysis and Value Engineering

### Topic: Use Value

**Introduction:**

Value analysis and value engineering are systematic methodologies employed to improve the "value" of a product, process, or service. Value, in this context, is defined as the relationship between **function** and **cost**. This module delves into the core concepts that underpin these methodologies, with a particular focus on **Use Value** as a foundational element. Understanding Use Value is crucial for engineers to identify opportunities for improvement, cost reduction, and enhanced customer satisfaction.

**Learning Outcomes Covered:**

*   **Understanding the concept of Use Value** within the framework of Value Analysis and Value Engineering.
*   **Differentiating Use Value from Esteem Value** and other value types.
*   **Analyzing the relationship between Use Value and Function.**
*   **Identifying methods to assess and enhance Use Value** in engineering projects and products.
*   **Applying the concept of Use Value to solve practical engineering problems** (indirectly through its role in VAVE).

**Course Outcomes Alignment:**

*   **CO4: Make use of the possibilities of value analysis and engineering, and solve simple business problems using break even analysis, cost benefit analysis and capital budgeting techniques. (Knowledge Level: K3)** - This topic directly contributes to CO4 by providing the foundational understanding of "value" which is essential for applying VAVE techniques, a key aspect of VAVE.

### 1. What is Value?

In the context of Value Analysis and Value Engineering (VAVE), **Value (V)** is not simply about being cheap or high quality. It's a nuanced concept that can be expressed as a ratio:

**Value (V) = Function (F) / Cost (C)**

*   **Function:** What a product, process, or service *does*. This refers to its performance, its ability to fulfill a need or requirement.
*   **Cost:** The resources (monetary, material, time, labor) required to achieve that function.

**Key Concept:** To increase value, you can either:

1.  **Increase the Function while keeping the Cost constant.**
2.  **Decrease the Cost while keeping the Function constant.**
3.  **Increase the Function while decreasing the Cost.**
4.  **Increase the Function disproportionately more than the Cost increases.**
5.  **Decrease the Cost disproportionately more than the Function decreases.**

**(Reference: Park, Contemporary Engineering Economics, Chapter on Value Engineering)**

### 2. Types of Value

While the primary focus is often on functional and cost aspects, VAVE acknowledges different types of value perception. For the purpose of VAVE, the most relevant types of value are:

#### 2.1. Use Value

**Definition:** **Use Value** represents the **functional utility** or the **performance** of a product, process, or service. It answers the question: "What does it *do*?"

*   **Focus:** The actual performance, the intrinsic capabilities, and the fundamental purpose it serves.
*   **Attributes:** It's about the tangible benefits and the essential operations.
*   **Examples:**
    *   A chair's Use Value is its ability to support a person's weight and provide a place to sit.
    *   A screwdriver's Use Value is its ability to turn screws.
    *   A software program's Use Value is its ability to process data or perform specific calculations.
    *   A bridge's Use Value is its ability to carry traffic across an obstacle.

**Key Concept:** Use Value is objective and measurable through performance metrics.

**(Reference: Thuesen, Fabrycky, Engineering Economy, Chapter on Value Engineering – While not explicitly defining "Use Value" as a separate term in great detail, the emphasis on performance and functionality aligns with this concept.)**

---

#### 2.2. Esteem Value

**Definition:** **Esteem Value** is the subjective or psychological value a customer associates with a product, process, or service. It answers the question: "What does it *mean* to me?" or "How does it make me *feel*?"

*   **Focus:** Prestige, brand recognition, aesthetics, emotional appeal, status, tradition, convenience, or personal preference.
*   **Attributes:** It's often intangible and influenced by marketing, brand image, and customer perception.
*   **Examples:**
    *   A luxury car's Esteem Value might come from its brand name, status symbol, or perceived prestige, even if its basic Use Value (transportation) is similar to a less expensive car.
    *   A designer handbag's Esteem Value is often tied to its brand, craftsmanship, and fashion statement, rather than its utility as a bag.
    *   A product with a unique or aesthetically pleasing design can have higher Esteem Value.
    *   The "convenience" factor of a pre-packaged meal can add to its Esteem Value, even if its nutritional Use Value is comparable to a home-cooked meal.

**Key Concept:** Esteem Value is subjective and can vary significantly among individuals.

**(Reference: Park, Contemporary Engineering Economics, highlights the importance of understanding customer perceptions which directly relates to Esteem Value.)**

---

#### 2.3. Other Value Types (Briefly Mentioned for Context)

*   **Cost Value:** The cost incurred to produce a product or service.
*   **Exchange Value:** The price at which a product or service can be sold in the market.

While these are important in economic analysis, for VAVE, the core focus is on the interplay between **Use Value (Function)** and **Cost**.

---

### 3. The Relationship Between Use Value and Function

**Use Value is synonymous with Function** in many VAVE discussions. The core of VAVE is to understand *what* a product or service is supposed to do (its functions) and then explore ways to achieve those functions at the lowest possible cost without compromising essential performance.

*   **Function Identification:** The first step in VAVE is to break down a product or system into its basic functions. This involves asking "Why?" repeatedly to get to the fundamental purpose.
*   **Primary vs. Secondary Functions:**
    *   **Primary Functions:** The essential, core functions without which the product/service would not fulfill its basic purpose. (e.g., A drill's primary function is to make holes).
    *   **Secondary Functions:** Supporting functions that enhance usability, safety, or aesthetics but are not strictly essential to the primary purpose. (e.g., A drill's secondary function might be its ergonomic grip or its variable speed control).
*   **Quantifying Function:** Functions can be quantified using performance metrics. For example, the Use Value of a light bulb can be measured in lumens (brightness) and lifespan (hours). The Use Value of a motor can be measured in horsepower or torque.

**(Reference: Geetika, Ghosh, Chodhury, Managerial Economics, discusses concepts of utility and performance which are directly linked to Use Value and Function.)**

---

### 4. Importance of Use Value in Value Analysis and Value Engineering

Understanding and maximizing Use Value is paramount in VAVE because it directly addresses the "Function" component of the Value equation.

*   **Focus on Core Needs:** VAVE aims to eliminate unnecessary costs associated with features or materials that do not contribute to the essential Use Value.
*   **Function-Oriented Approach:** By prioritizing Use Value, VAVE encourages engineers to think critically about what a product *must* do. This prevents over-engineering or adding features that customers don't actually need or value.
*   **Cost Reduction without Performance Degradation:** The goal is often to achieve the same or better Use Value at a lower cost. This might involve finding alternative materials, simplifying designs, or improving manufacturing processes.
*   **Customer Satisfaction:** By ensuring that essential functions are met efficiently and effectively, VAVE ultimately contributes to customer satisfaction. Customers want products that perform their intended tasks reliably.

**(Reference: Park, Contemporary Engineering Economics, strongly emphasizes that VAVE is about improving value by analyzing and improving functions and reducing costs.)**

### 5. Assessing and Enhancing Use Value

Engineers utilize several techniques to assess and enhance Use Value:

#### 5.1. Function Analysis

*   **Definition:** The systematic process of identifying, defining, and understanding the functions performed by a product, system, or process.
*   **Methodology:** Often involves the use of **FAST (Function Analysis System Technique)** diagrams, which graphically represent the relationships between functions.
*   **Steps:**
    1.  **Identify All Functions:** List all actions the product/system performs.
    2.  **Define Functions Concisely:** Use verb-noun pairs (e.g., "Transmit Force," "Support Weight," "Conduct Electricity").
    3.  **Categorize Functions:** Primary, Secondary, or Support functions.
    4.  **Analyze Function Relationships:** How do functions depend on each other? (Using FAST diagrams).
    5.  **Evaluate Functions:** Are all functions necessary? Can they be achieved at lower cost?

#### 5.2. Cost Analysis of Functions

*   **Definition:** Assigning costs to each identified function.
*   **Methodology:**
    *   Determine the cost of each component or process step.
    *   Allocate these costs to the functions they support.
*   **Outcome:** Helps identify which functions are the most expensive and thus represent opportunities for cost reduction without impacting essential Use Value.

#### 5.3. Brainstorming and Creative Solutions

*   **Definition:** Generating alternative ways to achieve the identified functions.
*   **Methodology:**
    *   Encourage unconventional thinking.
    *   Involve a multidisciplinary team.
    *   Focus on "what if" scenarios.
*   **Examples of Enhancements:**
    *   **Material Substitution:** Replacing a high-cost material with a lower-cost material that performs the same function. (e.g., using plastic instead of metal for a non-load-bearing component).
    *   **Design Simplification:** Reducing the number of parts or complexity of assembly.
    *   **Standardization:** Using standard parts rather than custom-made ones.
    *   **Manufacturing Process Improvement:** Finding more efficient ways to produce the product.
    *   **Eliminating Unnecessary Features:** Removing features that don't contribute to essential Use Value or customer needs.

#### 5.4. Benchmarking

*   **Definition:** Comparing the product's performance and cost with that of competitors or industry best practices.
*   **Purpose:** To identify areas where Use Value can be improved or costs reduced.

**(Reference: Paneerselvam, Engineering Economics, discusses cost-benefit analysis and project evaluation which involves assessing the utility or benefit (Use Value) against costs.)**

### 6. Practice Questions and Exercises

**Question 1:**
A manufacturer of office chairs wants to reduce costs without sacrificing the primary function of sitting comfortably. They are considering two options:
a) Using a less expensive fabric for the seat.
b) Reducing the thickness of the foam padding.

Which of these options is more likely to preserve the **Use Value** of the chair, and why?

**Answer:**
Option (a), using a less expensive fabric, is more likely to preserve the Use Value. The primary Use Value of a chair is to support a person comfortably. The fabric's primary function is to cover the padding and provide a surface to sit on. While different fabrics have different textures and appearances (Esteem Value), a less expensive, durable fabric can still fulfill this function effectively.

Option (b), reducing the thickness of the foam padding, directly impacts the comfort and support (Use Value) provided by the chair. If the padding is too thin, the chair will become uncomfortable, thus degrading its Use Value.

---

**Question 2:**
Identify the primary and secondary functions of a smartphone. How could a company aim to increase its Use Value while potentially reducing its cost?

**Answer:**
*   **Primary Functions:**
    *   Communication (making calls, sending messages)
    *   Accessing information (internet browsing, apps)
    *   Information processing (calculations, note-taking)
*   **Secondary Functions:**
    *   Photography and videography
    *   Entertainment (gaming, music playback)
    *   Navigation (GPS)
    *   Personal organization (calendar, contacts)
    *   Aesthetics and brand prestige (Esteem Value)

**To increase Use Value while potentially reducing cost:**

*   **Focus on Core Communication & Information Access:** Ensure these functions are robust, reliable, and efficient. This might involve optimizing the operating system for faster data retrieval or improving call clarity.
*   **Material Substitution:** If a specific component contributes to Esteem Value (e.g., a premium metal casing) but not to core Use Value, consider a more cost-effective material that still offers good durability and grip.
*   **Software Optimization:** Improve the efficiency of the software to deliver faster performance without requiring more powerful (and expensive) hardware for the primary functions.
*   **Modular Design:** If certain secondary functions (like a specialized camera sensor) are very expensive, explore making them optional or upgradable modules, thus reducing the base cost for users who primarily need the core Use Value.

---

### 7. Important Points to Remember

*   **Value = Function / Cost:** This is the fundamental equation in VAVE.
*   **Use Value is about Functionality:** It's the objective performance and utility.
*   **Esteem Value is about Perception:** It's subjective and tied to emotions, brand, and aesthetics.
*   **VAVE aims to maximize Value:** This is achieved by improving functions or reducing costs, with a strong emphasis on preserving or enhancing Use Value.
*   **Function Analysis is key:** Understanding *what* something does is the first step to improving its value.
*   **Don't confuse Esteem Value with Use Value:** While both are important, VAVE primarily targets improving the cost-effectiveness of Use Value.

---

### Conclusion

Understanding Use Value is foundational to the successful application of Value Analysis and Value Engineering. By dissecting the functions of a product or process and critically evaluating the costs associated with achieving those functions, engineers can identify opportunities to create more value for their organizations and customers. The focus remains on delivering the required performance efficiently and cost-effectively, ensuring that essential utilities are met without unnecessary expenditure.
