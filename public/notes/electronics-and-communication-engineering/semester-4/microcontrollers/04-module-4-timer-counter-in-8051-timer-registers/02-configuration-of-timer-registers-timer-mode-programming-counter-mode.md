## 1. Introduction to 8051 Timer/Counter Modules

The 8051 microcontroller features two built-in, 16-bit timer/counter modules, often referred to as Timer 0 and Timer 1. These modules are versatile and can be configured to perform two primary functions:

*   **Timer:** Generate time delays by counting internal machine cycles.
*   **Counter:** Count external events occurring on specific input pins.

*(Refer to Mazidi et al., Chapter 6, "Timer/Counters"; Ayala & Gadre, Chapter 7, "Timers/Counters")*

---

## 2. Timer Registers

The operation of the 8051 timers is controlled by a set of special function registers (SFRs).

### 2.1. Timer Mode Control Register (TMOD)

The **TMOD** register is an 8-bit register used to configure the operating modes of Timer 0 and Timer 1. It is a bit-addressable register.

*   **Structure of TMOD:**

    ```
    | GATE | C/T | M1 | M0 | GATE | C/T | M1 | M0 |
    |------|-----|----|----|------|-----|----|----|
    | Timer 1 | Timer 1 | Timer 1 | Timer 1 | Timer 0 | Timer 0 | Timer 0 | Timer 0 |
    ```

*   **Bit Definitions:**

    | Bit | Symbol | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
    |-----|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    | 7   | GATE   | **Gate Control:** <br> - **1:** Timer/Counter is controlled by hardware. The timer/counter will only run when the corresponding INTx pin (INT0 for Timer 0, INT1 for Timer 1) is HIGH **AND** the TRx bit in the TCON register is SET. <br> - **0:** Timer/Counter is controlled by software. The timer/counter runs when the TRx bit in the TCON register is SET, regardless of the state of the INTx pin.                                                                      |
    | 6   | C/T    | **Counter/Timer Select:** <br> - **1:** The module functions as a **Counter**. It counts external pulses applied to the corresponding pin (T0 for Timer 0, T1 for Timer 1). The external pulses are detected on the falling edge. <br> - **0:** The module functions as a **Timer**. It counts internal machine cycles.                                                                                                                                                           |
    | 5, 4 | M1, M0 | **Mode Select Bits:** These two bits determine the operating mode of the timer/counter. There are four possible modes (0, 1, 2, 3).                                                                                                                                                                                                                                                                                                                                  |
    | 3   | GATE   | Same as Bit 7, but for Timer 0.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
    | 2   | C/T    | Same as Bit 6, but for Timer 0.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
    | 1, 0 | M1, M0 | Same as Bits 5, 4, but for Timer 0.                                                                                                                                                                                                                                                                                                                                                                                                                                  |

*(Refer to Mazidi et al., "TMOD register"; Ayala & Gadre, "TMOD control register")*

---

### 2.2. Timer Registers (TLx and THx)

Each timer/counter module uses two 8-bit registers to form a 16-bit register.

*   **Timer 0:**
    *   **TL0:** Lower 8 bits of Timer 0.
    *   **TH0:** Higher 8 bits of Timer 0.
*   **Timer 1:**
    *   **TL1:** Lower 8 bits of Timer 1.
    *   **TH1:** Higher 8 bits of Timer 1.

These registers are collectively referred to as **T**imer **L**ow and **T**imer **H**igh.

*   **How they work:**
    *   When the timer/counter is running, these registers are incremented (or decremented in some modes, though less common in 8051) on each machine cycle (for timer mode) or external pulse (for counter mode).
    *   When the timer rolls over from its maximum value to 0, it sets the corresponding timer flag (TFx) in the TCON register.
    *   The 16-bit value is formed by concatenating THx and TLx: `16-bit Timer Value = (THx << 8) | TLx`.

*(Refer to Mazidi et al., "Timer Registers TLx and THx"; Ayala & Gadre, "Timer registers TLx and THx")*

---

### 2.3. Timer Control Register (TCON)

The **TCON** register is an 8-bit register that controls the start, stop, and interrupt status of the timer/counter modules. It is also bit-addressable.

*   **Structure of TCON:**

    ```
    | TF1 | TR1 | TF0 | TR0 | IE1 | IT1 | IE0 | IT0 |
    |-----|-----|-----|-----|-----|-----|-----|-----|
    ```

*   **Bit Definitions:**

    | Bit | Symbol | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
    |-----|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    | 7   | TF1    | **Timer 1 Overflow Flag:** <br> - Set by hardware when Timer 1 overflows from its maximum value (FFFFh) to 0. <br> - Cleared by hardware when the processor vectored to the Timer 1 interrupt service routine (ISR). <br> - Can be cleared by software. <br> - Used to signal that Timer 1 has completed its count.                                                                                                                                                                                                |
    | 6   | TR1    | **Timer 1 Run Control:** <br> - **1:** Starts Timer 1. <br> - **0:** Stops Timer 1.                                                                                                                                                                                                                                                                                                                                                                                                                        |
    | 5   | TF0    | **Timer 0 Overflow Flag:** <br> - Set by hardware when Timer 0 overflows from its maximum value (FFFFh) to 0. <br> - Cleared by hardware when the processor vectored to the Timer 0 interrupt service routine (ISR). <br> - Can be cleared by software. <br> - Used to signal that Timer 0 has completed its count.                                                                                                                                                                                                |
    | 4   | TR0    | **Timer 0 Run Control:** <br> - **1:** Starts Timer 0. <br> - **0:** Stops Timer 0.                                                                                                                                                                                                                                                                                                                                                                                                                        |
    | 3   | IE1    | **External Interrupt 1 Edge Flag:** <br> - Set by hardware when an external interrupt signal (INT1) occurs. <br> - Cleared by hardware when the processor is vectored to the External Interrupt 1 ISR. <br> - Can be cleared by software. <br> - When configured for edge triggering (IT1=1), this bit is set by a falling edge on the INT1 pin. <br> - When configured for level triggering (IT1=0), this bit is set if INT1 is HIGH and cleared when INT1 goes LOW.                                              |
    | 2   | IT1    | **External Interrupt 1 Type Control:** <br> - **1:** External Interrupt 1 is **edge triggered**. <br> - **0:** External Interrupt 1 is **level triggered**.                                                                                                                                                                                                                                                                                                                                                |
    | 1   | IE0    | **External Interrupt 0 Edge Flag:** <br> - Set by hardware when an external interrupt signal (INT0) occurs. <br> - Cleared by hardware when the processor is vectored to the External Interrupt 0 ISR. <br> - Can be cleared by software. <br> - When configured for edge triggering (IT0=1), this bit is set by a falling edge on the INT0 pin. <br> - When configured for level triggering (IT0=0), this bit is set if INT0 is HIGH and cleared when INT0 goes LOW.                                              |
    | 0   | IT0    | **External Interrupt 0 Type Control:** <br> - **1:** External Interrupt 0 is **edge triggered**. <br> - **0:** External Interrupt 0 is **level triggered**.                                                                                                                                                                                                                                                                                                                                                |

*(Note: The IE1, IT1, IE0, IT0 bits are related to external interrupts but are part of the TCON register. For timer operation, we primarily focus on TFx and TRx bits.)*

*(Refer to Mazidi et al., "TCON Register"; Ayala & Gadre, "TCON Control Register")*

## 3. Timer Mode Programming

The timer/counter modules can be configured into four distinct modes by setting the M1 and M0 bits in the TMOD register.

### 3.1. Timer Modes Overview

| Mode | M1 | M0 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Registers Used | Max Count Value | Timer Width |
|------|----|----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------|-----------------|-------------|
| 0    | 0  | 0  | **13-bit Timer Mode:** <br> In this mode, Timer 0 uses TL0 and TH0. TL0 acts as the lower 5 bits and TH0 acts as the upper 8 bits, forming a 13-bit timer. The TL0 lower 3 bits are unused. This mode is rarely used in modern applications.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | TL0, TH0       | 8191 (1FFFh)    | 13-bit      |
| 1    | 0  | 1  | **16-bit Timer Mode:** <br> In this mode, Timer 0 uses TL0 and TH0 as a 16-bit register. Both TL0 and TH0 contribute 8 bits each, forming a full 16-bit timer. This is the most commonly used mode for generating time delays. When the timer overflows from FFFFh to 0000h, the TFx flag is set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | TL0, TH0       | 65535 (FFFFh)   | 16-bit      |

## 4. Counter Mode

When the `C/T` bit in the TMOD register is set to '1', the respective timer module operates as a counter.

*   **Counter Operation:**
    *   The counter counts external pulses applied to the specific pin associated with the timer.
        *   **Timer 0:** Counts pulses on the **P3.4 (T0)** pin.
        *   **Timer 1:** Counts pulses on the **P3.5 (T1)** pin.
    *   The counter increments on the **falling edge** of the signal on the respective pin.
    *   The `GATE` bit in TMOD still controls whether the counting is enabled by software (GATE=0) or by a combination of software (TRx bit) and the external interrupt pin (INTx).
        *   If `GATE=0`, the counter increments whenever the TRx bit is set and a falling edge occurs on the count input pin.
        *   If `GATE=1`, the counter increments only when TRx is set **AND** the corresponding INTx pin is HIGH, and a falling edge occurs on the count input pin.

*(Refer to Mazidi et al., "Counter Operation"; Ayala & Gadre, "Counter Functionality")*

### 4.1. Counter Mode Example

Let's say we want to count pulses arriving on the T0 pin (P3.4). We can configure Timer 0 in Mode 1 (16-bit counter).

*   **Configuration:**
    *   `C/T` for Timer 0 = 1 (Counter)
    *   `GATE` for Timer 0 = 0 (Software controlled)
    *   `M1` for Timer 0 = 0
    *   `M0` for Timer 0 = 1
    *   This means TMOD for Timer 0 should be `0000 0001b` which is `01h`.

*   **Programming Steps (C):**

    1.  **Configure TMOD:** Set the bits for Timer 0 to select Mode 1 and Counter function.
    2.  **Initialize TL0/TH0:** Load the initial count value (often 0000h for counting from zero).
    3.  **Enable Timer/Counter:** Set the TR0 bit in TCON to '1' to start counting.
    4.  **Monitor TF0:** The TF0 flag will be set when the counter overflows (from FFFFh to 0000h).
    5.  **Read the Count:** The current count can be read from TL0 and TH0 at any time.

    ```c
    #include <reg51.h>

    sbit T0_PIN = P3^4; // For external observation, not directly used in code for counting

    void main() {
        // Configure Timer 0 as a 16-bit counter (Mode 1)
        TMOD = TMOD & 0xF0; // Clear bits for Timer 0
        TMOD = TMOD | 0x01; // Set Timer 0 to Mode 1 (0001) and Counter (C/T=1)

        // Initialize the counter (optional, starts from 0 if not loaded)
        TH0 = 0x00;
        TL0 = 0x00;

        // Start the counter
        TR0 = 1;

        // Application logic:
        // The counter will now increment on falling edges of P3.4
        // We can read TH0:TL0 at any time to get the count.
        // For example, to count 10 pulses, we would monitor the count.

        while (1) {
            // Example: Blink an LED after a certain number of pulses are counted.
            // This requires reading the counter and comparing.
            // For a simple demonstration, we'll just let it count.

            // To demonstrate reading the count:
            // unsigned int current_count = (TH0 << 8) | TL0;
            // Add logic to use 'current_count'
        }
    }
    ```

*   **Programming Steps (Assembly):**

    ```assembly
    ORG 0000H
    JMP MAIN

    ORG 000BH ; Timer 0 Interrupt Vector (if used)

    MAIN:
        MOV TMOD, #01H   ; Timer 0, Mode 1, Counter
        MOV TH0, #00H    ; Initialize high byte of counter
        MOV TL0, #00H    ; Initialize low byte of counter
        SETB TR0         ; Start Timer 0

    LOOP:
        ; The counter is running. We can read TH0:TL0 to get the current count.
        ; For example, to check if 100 pulses have arrived:
        MOV A, TH0
        MOV R0, A        ; Store current TH0 in R0
        MOV A, TL0
        MOV R1, A        ; Store current TL0 in R1

        ; Convert R0:R1 to a 16-bit value and compare with 100 (64h)

        ; For demonstration, we just loop.
        JMP LOOP

    END
    ```

*(Refer to Intel Corporation, "8051 Hardware Description Datasheet"; Das, "Microprocessors and Microcontrollers")*

## 5. Important Points to Remember

*   **TMOD Configuration:** Always configure `TMOD` first to set the desired mode and timer/counter function for Timer 0 and Timer 1.
*   **TRx Control:** Use the `TRx` bits in `TCON` to start and stop the timer/counter. Setting `TRx` to '1' starts, and '0' stops.
*   **TFx Flags:** The `TFx` flags (TF0, TF1) in `TCON` are set by hardware upon overflow. They are used to generate interrupts or to signal the completion of a count. You must clear these flags in software if you are not using interrupts.
*   **Timer Clock:** In timer mode, the clock source is the system clock divided by 12 (i.e., machine cycles).
*   **Counter Input:** In counter mode, the input is from the dedicated pins P3.4 (T0) and P3.5 (T1) on the falling edge.
*   **GATE Bit:** The `GATE` bit provides hardware-level control, useful for specific applications where the timer/counter should only run under certain external conditions.
*   **Auto-Reload (Mode 2):** This mode is crucial for generating periodic events or signals. Ensure the reload value is placed in `THx` (for Timer 0, TH0; for Timer 1, TH1).
*   **13-bit Mode (Mode 0):** This mode is rarely used and offers a shorter counting range.

## 6. Practice Questions

**Question 1:** Explain the purpose of the TMOD register and describe its bit fields. (Relates to CO1)

**Answer 1:** The TMOD register is an 8-bit Special Function Register (SFR) used to configure the operating modes of the two timer/counter modules (Timer 0 and Timer 1) in the 8051 microcontroller. Its bit fields include:
*   **GATE:** Controls whether the timer/counter is enabled by software (TRx bit) or by a combination of software and an external interrupt pin (INTx).
*   **C/T:** Selects whether the module operates as a Timer (counts machine cycles) or a Counter (counts external pulses).
*   **M1, M0:** Mode selection bits that define the operational mode of the timer/counter (Mode 0, 1, 2, or 3).

**Question 2:** You need to generate a delay of approximately 10 milliseconds using Timer 0 in Mode 1. The 8051 microcontroller is operating with a crystal frequency of 12 MHz. If the timer is loaded with an initial value, how many machine cycles will it take to overflow? Calculate the initial value to be loaded into TH0 and TL0. (Relates to CO2, CO4)

**Hint:**
*   Machine cycle frequency = Crystal Frequency / 12
*   Each machine cycle increments the timer.
*   16-bit timer counts from an initial value up to FFFFh. The number of counts = FFFFh - Initial Value + 1.
*   Desired delay = (Number of counts) * (Machine cycle period).

**Answer 2:**
*   Crystal Frequency = 12 MHz
*   Machine Cycle Frequency = 12 MHz / 12 = 1 MHz
*   Machine Cycle Period = 1 / 1 MHz = 1 microsecond (µs)
*   Desired Delay = 10 ms = 10,000 µs
*   Number of counts required = Desired Delay / Machine Cycle Period = 10,000 µs / 1 µs = 10,000 counts.

Since Timer 0 in Mode 1 counts up to 65536 (FFFFh + 1), we need to find an initial value such that:
65536 - Initial Value = 10,000
Initial Value = 65536 - 10,000 = 55536

Convert 55536 to hexadecimal:
55536 / 256 = 217 with a remainder of 16
217 / 256 = 0 with a remainder of 217

So, 55536 in decimal is `0xDD00` in hexadecimal.
*   TH0 = 0xDD
*   TL0 = 0x00

*   **C Code Snippet:**
    ```c
    TMOD = 0x01; // Timer 0, Mode 1
    TH0 = 0xDD;
    TL0 = 0x00;
    TR0 = 1; // Start Timer 0
    // ... wait for TF0 to be set (or use polling/interrupt)
    ```
*   **Assembly Code Snippet:**
    ```assembly
    MOV TMOD, #01H   ; Timer 0, Mode 1
    MOV TH0, #0DDH
    MOV TL0, #00H
    SETB TR0         ; Start Timer 0
    ```

**Question 3:** What is the purpose of the `TF0` flag in the TCON register? How is it cleared? (Relates to CO1)

**Answer 3:** The `TF0` flag is the Timer 0 Overflow Flag. It is a read-only bit set by hardware when Timer 0 (or Timer 0 in counter mode) overflows from its maximum count value (FFFFh for Mode 1, 1FFFh for Mode 0, FFh for Mode 2) to 0000h.
*   If Timer 0 interrupts are enabled, `TF0` is automatically cleared by hardware when the processor jumps to the Timer 0 interrupt service routine (ISR).
*   If Timer 0 interrupts are disabled, or if you are polling the flag instead of using interrupts, `TF0` must be cleared manually by software (e.g., `CLR TF0` in assembly or `TF0 = 0;` in C).

**Question 4:** Describe how to configure Timer 1 to count pulses on the P3.5 pin. Which mode is suitable and why? (Relates to CO2)

**Answer 4:** To configure Timer 1 to count pulses on the P3.5 pin (which is the T1 input), you would set the `C/T` bit for Timer 1 in the TMOD register to '1'.
*   **Suitable Mode:** Mode 1 (16-bit counter) is generally suitable as it offers the largest counting range (65536 counts). This allows you to count a significant number of external events before an overflow occurs.
*   **Configuration:**
    *   In TMOD, for Timer 1: `C/T` = 1, `M1` = 0, `M0` = 1. This corresponds to `0101_xxxx` in TMOD.
    *   If Timer 0 is not being used or is in Mode 0, TMOD could be `0100 0000b` (40h). If Timer 0 is in Mode 1, TMOD would be `0100 0001b` (41h).
*   **Operation:** With `TR1` set to '1' (and `GATE` set to '0' for software control), Timer 1 will increment its TH1:TL1 register on the falling edge of the signal on P3.5.
