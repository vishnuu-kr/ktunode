### Key Concepts and Definitions:

*   **Output Stream:** A sequence of data that is written to a destination, such as a file or the console.
*   **Character Stream:** An output stream that deals with characters (e.g., `char`, `String`).
*   **Buffered Output:** Data is temporarily stored in a buffer before being written to the destination. This improves performance by reducing the number of direct write operations.
*   **Formatted Output:** The ability to control the presentation of data, such as specifying decimal places for numbers or aligning text.
*   **`java.io.PrintWriter`:** A character-output stream that provides methods for writing formatted data and convenient methods for printing various data types. It wraps an existing `Writer` object.

---

### Introduction to PrintWriter Class

The `PrintWriter` class in Java is a powerful tool for writing formatted text to various output destinations. It's a convenient wrapper around other `Writer` classes, simplifying the process of writing primitive data types and formatted strings.

**Core Functionality:**

*   **Formatted Printing:** Allows you to print data of different types (integers, floats, strings, objects) in a formatted way.
*   **Convenient Methods:** Provides methods like `print()`, `println()`, `printf()`, and `format()` for easy output.
*   **Exception Handling:** Supports automatic flushing on certain conditions, and you can configure it to throw exceptions for errors.
