# Module 3: Statistical Detection Theory I - Classical Approach

## Introduction to Statistical Detection

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:**
*   Understand the fundamental problem of statistical detection.
*   Define the two basic hypotheses in classical detection.
*   Explain the role of prior probabilities and likelihood functions in the detection process.
*   Introduce the likelihood ratio test (LRT) as a foundational tool.

### 1. The Fundamental Problem of Statistical Detection

Statistical detection theory deals with the problem of deciding which of two or more hypotheses about a signal or system is true, given observed data. This is a ubiquitous problem in many engineering disciplines, such as:

*   **Communication Systems:** Deciding if a signal is present or absent, or which symbol was transmitted. (Kay, Vol II, Chapter 1)
*   **Radar and Sonar:** Detecting the presence of a target in noise. (Van Trees, Chapter 2)
*   **Image Processing:** Identifying objects or features in an image.
*   **Biomedical Engineering:** Detecting abnormal patterns in physiological signals.

**Key Concept:** The core idea is to use observed data to make an informed decision about an underlying state of the world.

### 2. The Two Basic Hypotheses

In the simplest form of detection, we consider two mutually exclusive and exhaustive possibilities, known as hypotheses:

*   **Hypothesis H₀ (Null Hypothesis):** Represents the "absence" of a signal or a particular condition. Often, this implies the presence of only noise.
*   **Hypothesis H₁ (Alternative Hypothesis):** Represents the "presence" of a signal or a different condition.

**Example:** In a radar system, H₀ might be "no target is present," and H₁ might be "a target is present."

### 3. Observed Data and Underlying Model

We observe data, typically a sequence of measurements, denoted by a vector $\mathbf{y}$. This observed data is assumed to be generated by a probabilistic model that depends on which hypothesis is true.

Let the probability density function (PDF) of the observed data $\mathbf{y}$ be:
*   $f(\mathbf{y} | H_0)$: The PDF of $\mathbf{y}$ given that $H_0$ is true.
*   $f(\mathbf{y} | H_1)$: The PDF of $\mathbf{y}$ given that $H_1$ is true.

**Important Note:** The choice of PDF is crucial and depends on the specific problem. For example, if the noise is additive Gaussian, the PDFs will be Gaussian.

### 4. Prior Probabilities

Before observing any data, we might have some prior knowledge about the likelihood of each hypothesis being true. These are represented by prior probabilities:

*   $P(H_0)$: The prior probability that $H_0$ is true.
*   $P(H_1)$: The prior probability that $H_1$ is true.

We know that $P(H_0) + P(H_1) = 1$.

**Example:** In a communication system, if a signal is transmitted infrequently, $P(H_1)$ would be low.

### 5. Posterior Probabilities and Bayes' Rule

Once we observe the data $\mathbf{y}$, we can update our belief about the hypotheses using Bayes' rule to obtain posterior probabilities:

*   $P(H_0 | \mathbf{y})$: The posterior probability that $H_0$ is true given the observed data $\mathbf{y}$.
*   $P(H_1 | \mathbf{y})$: The posterior probability that $H_1$ is true given the observed data $\mathbf{y}$.

Bayes' Rule states:
$P(H_i | \mathbf{y}) = \frac{f(\mathbf{y} | H_i) P(H_i)}{f(\mathbf{y})}$

where $f(\mathbf{y})$ is the marginal PDF of $\mathbf{y}$, which can be calculated as:
$f(\mathbf{y}) = f(\mathbf{y} | H_0) P(H_0) + f(\mathbf{y} | H_1) P(H_1)$

So, the posterior probabilities are:
$P(H_0 | \mathbf{y}) = \frac{f(\mathbf{y} | H_0) P(H_0)}{f(\mathbf{y} | H_0) P(H_0) + f(\mathbf{y} | H_1) P(H_1)}$
$P(H_1 | \mathbf{y}) = \frac{f(\mathbf{y} | H_1) P(H_1)}{f(\mathbf{y} | H_0) P(H_0) + f(\mathbf{y} | H_1) P(H_1)}$

The goal of detection is to decide between $H_0$ and $H_1$ by comparing these posterior probabilities.

### 6. The Likelihood Ratio Test (LRT)

A fundamental approach to making the decision is the Likelihood Ratio Test (LRT). The likelihood ratio (LR) is defined as:

$LR(\mathbf{y}) = \frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)}$

To decide between $H_0$ and $H_1$, we compare the likelihood ratio to a threshold $\eta$.

**Decision Rule:**
*   If $LR(\mathbf{y}) > \eta$, decide $H_1$.
*   If $LR(\mathbf{y}) < \eta$, decide $H_0$.
*   If $LR(\mathbf{y}) = \eta$, the decision can be made arbitrarily or based on a secondary criterion.

(Kay, Vol II, Section 1.2.2)

**Relationship to Posterior Probabilities:**
The LRT can be derived by comparing posterior probabilities:
Decide $H_1$ if $P(H_1 | \mathbf{y}) > P(H_0 | \mathbf{y})$
$\frac{f(\mathbf{y} | H_1) P(H_1)}{f(\mathbf{y})} > \frac{f(\mathbf{y} | H_0) P(H_0)}{f(\mathbf{y})}$
$f(\mathbf{y} | H_1) P(H_1) > f(\mathbf{y} | H_0) P(H_0)$
$\frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} > \frac{P(H_0)}{P(H_1)}$

Thus, the threshold $\eta$ is related to the prior probabilities: $\eta = \frac{P(H_0)}{P(H_1)}$.

**Important Point to Remember:** The LRT provides a framework for making decisions based on observed data and prior knowledge, balancing the probability of correct detection against the probability of false alarms.

## Types of Errors in Detection

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:**
*   Define and understand the types of errors in a binary detection problem.
*   Introduce the concepts of Probability of Detection and Probability of False Alarm.
*   Understand the trade-off between these errors.

When making a decision between $H_0$ and $H_1$, there are four possible outcomes:

| Decision       | True State | Outcome                       | Type of Error |
| :------------- | :--------- | :---------------------------- | :------------ |
| Decide $H_0$   | $H_0$      | Correct Decision (True Negative) | -             |
| Decide $H_0$   | $H_1$      | **False Negative (Miss)**     | Type II Error |
| Decide $H_1$   | $H_0$      | **False Positive (False Alarm)** | Type I Error  |
| Decide $H_1$   | $H_1$      | Correct Decision (True Positive) | -             |

### 1. Type I Error (False Alarm)

*   **Definition:** Deciding that $H_1$ is true when in reality $H_0$ is true.
*   **Probability:** $P_{FA} = P(\text{Decide } H_1 | H_0) = \int_{\mathcal{W}} f(\mathbf{y} | H_0) d\mathbf{y}$, where $\mathcal{W}$ is the region of the observation space where we decide $H_1$.

(Kay, Vol II, Section 1.2.1)

### 2. Type II Error (Miss)

*   **Definition:** Deciding that $H_0$ is true when in reality $H_1$ is true.
*   **Probability:** $P_M = P(\text{Decide } H_0 | H_1) = \int_{\mathcal{R}} f(\mathbf{y} | H_1) d\mathbf{y}$, where $\mathcal{R}$ is the region of the observation space where we decide $H_0$.

(Kay, Vol II, Section 1.2.1)

### 3. Performance Measures

*   **Probability of Detection (PD) / True Positive Rate (TPR):** The probability of correctly deciding $H_1$ when $H_1$ is true.
    $P_D = P(\text{Decide } H_1 | H_1) = \int_{\mathcal{W}} f(\mathbf{y} | H_1) d\mathbf{y}$
    Note that $P_D = 1 - P_M$.

*   **Probability of False Alarm (PFA) / False Positive Rate (FPR):** The probability of incorrectly deciding $H_1$ when $H_0$ is true.
    $P_{FA} = P(\text{Decide } H_1 | H_0) = \int_{\mathcal{W}} f(\mathbf{y} | H_0) d\mathbf{y}$

(Kay, Vol II, Section 1.2.1)

### 4. The Trade-off Between Errors

The LRT threshold $\eta$ controls the trade-off between $P_D$ and $P_{FA}$.

*   **Increasing $\eta$:** Makes it harder to decide $H_1$, thus decreasing $P_{FA}$ but also decreasing $P_D$.
*   **Decreasing $\eta$:** Makes it easier to decide $H_1$, thus increasing $P_{FA}$ and also increasing $P_D$.

This relationship can be visualized using the Receiver Operating Characteristic (ROC) curve, which plots $P_D$ versus $P_{FA}$ for varying thresholds $\eta$. (Kay, Vol II, Section 1.2.1)

**Important Point to Remember:** There is an inherent trade-off between detecting the signal when it's present ($P_D$) and avoiding false alarms when it's absent ($P_{FA}$). The choice of threshold depends on the relative costs or importance of these errors.

## The Optimal Detector: Neyman-Pearson Criterion

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:**
*   Understand the Neyman-Pearson criterion for designing optimal detectors.
*   Derive the Neyman-Pearson test for a given problem.
*   Explain the concept of a constant Probability of False Alarm (PFA).

The Neyman-Pearson criterion aims to maximize the Probability of Detection ($P_D$) for a fixed, acceptable Probability of False Alarm ($P_{FA}$). This is particularly useful when the costs of Type I and Type II errors are not precisely known or when a specific level of false alarm rate is mandated.

### 1. The Criterion

**Maximize** $P_D = P(\text{Decide } H_1 | H_1)$
**Subject to** $P_{FA} = P(\text{Decide } H_1 | H_0) \le \alpha$, where $\alpha$ is a small, fixed probability (e.g., 0.01).

(Kay, Vol II, Section 1.2.2)

### 2. Derivation of the Neyman-Pearson Test

The Neyman-Pearson test is derived using the LRT. We set the threshold $\eta$ such that the resulting $P_{FA}$ is exactly equal to the specified level $\alpha$.

The decision rule is:
*   If $\frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} > \eta_0$, decide $H_1$.
*   If $\frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} < \eta_0$, decide $H_0$.
*   If $\frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} = \eta_0$, decide $H_1$ with probability $p$, and $H_0$ with probability $1-p$, to achieve the target $P_{FA}$.

Here, $\eta_0$ is chosen such that $P(\frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} > \eta_0 | H_0) = \alpha$.

**Example:**
Consider a simple case where we observe a single data point $y$.
Let $f(y | H_0) = e^{-y}$ for $y \ge 0$, and $f(y | H_1) = 2e^{-2y}$ for $y \ge 0$.
We want to find a threshold $\eta_0$ such that $P(2e^{-2y} / e^{-y} > \eta_0 | H_0) = \alpha$.
The likelihood ratio is $LR(y) = 2e^{-y}$.
We want $P(2e^{-y} > \eta_0 | H_0) = \alpha$.
This means $P(e^{-y} > \eta_0/2 | H_0) = \alpha$.
$P(-y > \ln(\eta_0/2) | H_0) = \alpha$.
$P(y < -\ln(\eta_0/2) | H_0) = \alpha$.
Since $y \sim \text{Exponential}(1)$ under $H_0$, its CDF is $F_Y(y) = 1 - e^{-y}$.
So, $1 - e^{-[-\ln(\eta_0/2)]} = \alpha$.
$1 - (\eta_0/2) = \alpha$, which gives $\eta_0 = 2(1 - \alpha)$.

The decision rule is:
*   If $2e^{-y} > 2(1 - \alpha)$, i.e., $e^{-y} > 1 - \alpha$, or $y < -\ln(1 - \alpha)$, decide $H_1$.
*   Otherwise, decide $H_0$.

The $P_{FA}$ is $P(y < -\ln(1 - \alpha) | H_0) = 1 - e^{-[-\ln(1 - \alpha)]} = 1 - (1 - \alpha) = \alpha$. This matches our requirement.

(Kay, Vol II, Section 1.2.2, Example 1.2.1)

### 3. The Likelihood Ratio Test as the Neyman-Pearson Test

The LRT is inherently the Neyman-Pearson test when the threshold $\eta$ is chosen appropriately to satisfy the $P_{FA}$ constraint. The "classical approach" in detection theory often refers to the LRT, which, when optimized under the Neyman-Pearson criterion, becomes the most powerful test for a given $P_{FA}$.

(Van Trees, Chapter 2)

**Important Point to Remember:** The Neyman-Pearson criterion provides a principled way to design detectors by prioritizing the detection of the signal while controlling the rate of false alarms. The LRT forms the mathematical basis for this optimal test.

## The Uniformly Most Powerful (UMP) Detector

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:**
*   Define the concept of a Uniformly Most Powerful (UMP) detector.
*   Understand when UMP detectors exist.
*   Relate UMP detectors to the LRT.

### 1. Definition of UMP Detector

A detector is Uniformly Most Powerful (UMP) if it achieves the highest Probability of Detection ($P_D$) among *all* possible tests that satisfy a given constraint on the Probability of False Alarm ($P_{FA}$), for *all* possible values of the unknown parameters (if any).

In a simple binary detection problem where the signal parameters are completely known (i.e., the PDFs $f(\mathbf{y}|H_0)$ and $f(\mathbf{y}|H_1)$ are fully specified), the Neyman-Pearson test for a given $\alpha$ is indeed the UMP test.

(Kay, Vol II, Section 1.2.3)

### 2. Existence of UMP Detectors

*   **Known Signal Parameters:** When the distributions under $H_0$ and $H_1$ are completely known, the LRT is the UMP test. This is the most common scenario in the "classical approach."
*   **Unknown Signal Parameters:** In more complex scenarios where some parameters are unknown, the existence of a UMP detector is not guaranteed. If a UMP detector exists, it is typically derived from the LRT by considering the "worst-case" scenario for the unknown parameters.

(Kay, Vol II, Section 1.2.3)

### 3. UMP Detectors and the LRT

When the signal parameters are known, the LRT is the UMP detector. This means that the LRT, by setting the threshold $\eta$ to achieve a desired $P_{FA}$, automatically provides the highest possible $P_D$ for that $P_{FA}$, regardless of the specific data observed.

**Why the LRT is UMP (when parameters are known):**
The LRT maximizes the ratio of probabilities. By setting the threshold to achieve a target $P_{FA} = \alpha$, the LRT effectively finds the region $\mathcal{W}$ that contains the highest likelihood values under $H_1$ relative to $H_0$, subject to the constraint that the integral of $f(\mathbf{y}|H_0)$ over $\mathcal{W}$ is $\alpha$. This inherently makes it the most powerful test.

(Kay, Vol II, Section 1.2.3)

**Example:** Consider detecting a known signal $s$ in additive white Gaussian noise (AWGN).
$H_0$: $\mathbf{y} = \mathbf{n}$
$H_1$: $\mathbf{y} = s + \mathbf{n}$
where $\mathbf{n} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$.

The PDFs are:
$f(\mathbf{y} | H_0) = \frac{1}{(2\pi\sigma^2)^{N/2}} e^{-\frac{1}{2\sigma^2} ||\mathbf{y}||^2}$
$f(\mathbf{y} | H_1) = \frac{1}{(2\pi\sigma^2)^{N/2}} e^{-\frac{1}{2\sigma^2} ||\mathbf{y}-s||^2}$

The likelihood ratio is:
$LR(\mathbf{y}) = \frac{e^{-\frac{1}{2\sigma^2} ||\mathbf{y}-s||^2}}{e^{-\frac{1}{2\sigma^2} ||\mathbf{y}||^2}} = e^{\frac{1}{2\sigma^2} [||\mathbf{y}||^2 - ||\mathbf{y}-s||^2]}$
$||\mathbf{y}-s||^2 = (\mathbf{y}-s)^T(\mathbf{y}-s) = \mathbf{y}^T\mathbf{y} - 2\mathbf{y}^T s + s^T s = ||\mathbf{y}||^2 - 2\mathbf{y}^T s + ||s||^2$
$LR(\mathbf{y}) = e^{\frac{1}{2\sigma^2} [||\mathbf{y}||^2 - (||\mathbf{y}||^2 - 2\mathbf{y}^T s + ||s||^2)]} = e^{\frac{1}{2\sigma^2} [2\mathbf{y}^T s - ||s||^2]}$
$LR(\mathbf{y}) = e^{\frac{s^T \mathbf{y}}{\sigma^2}} e^{-\frac{||s||^2}{2\sigma^2}}$

The LRT decides $H_1$ if $LR(\mathbf{y}) > \eta$.
$e^{\frac{s^T \mathbf{y}}{\sigma^2}} e^{-\frac{||s||^2}{2\sigma^2}} > \eta$
Taking the natural logarithm:
$\frac{s^T \mathbf{y}}{\sigma^2} - \frac{||s||^2}{2\sigma^2} > \ln(\eta)$
$s^T \mathbf{y} > \sigma^2 \ln(\eta) + \frac{||s||^2}{2}$

This is a linear test of the form $w^T \mathbf{y} > \gamma$, where $w = s$ and $\gamma = \sigma^2 \ln(\eta) + \frac{||s||^2}{2}$.
The threshold $\gamma$ is chosen to satisfy the $P_{FA}$ constraint. Under $H_0$, $\mathbf{y} = \mathbf{n}$, so $s^T \mathbf{y} = s^T \mathbf{n}$. Since $\mathbf{n} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$, $s^T \mathbf{n}$ is a Gaussian random variable with mean 0 and variance $\sigma^2 ||s||^2$.

This specific LRT is the UMP test for detecting a known signal in AWGN.

(Kay, Vol II, Section 1.2.3, Example 1.2.2)

**Important Point to Remember:** When the signal parameters are known, the LRT provides the UMP test, meaning it is the most powerful detector for any given level of false alarm rate. This makes it a cornerstone of classical detection theory.

## Maximum Likelihood Detection

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:**
*   Understand the Maximum Likelihood (ML) detection rule.
*   Relate ML detection to the LRT and Bayes' decision rule.
*   Discuss the conditions under which ML detection is optimal.

### 1. The Maximum Likelihood (ML) Detection Rule

Maximum Likelihood detection is a decision rule that selects the hypothesis that is *most likely* to have generated the observed data. It does this by choosing the hypothesis that maximizes the likelihood function $f(\mathbf{y} | H_i)$.

**Decision Rule:**
*   If $f(\mathbf{y} | H_1) > f(\mathbf{y} | H_0)$, decide $H_1$.
*   If $f(\mathbf{y} | H_1) < f(\mathbf{y} | H_0)$, decide $H_0$.
*   If $f(\mathbf{y} | H_1) = f(\mathbf{y} | H_0)$, the decision can be made arbitrarily.

(Kay, Vol II, Section 1.2.1)

### 2. Relationship to LRT and Bayes' Decision Rule

*   **Relationship to LRT:** ML detection is equivalent to the LRT when the prior probabilities are equal, i.e., $P(H_0) = P(H_1) = 0.5$. In this case, the threshold $\eta = P(H_0)/P(H_1) = 1$.
    $LR(\mathbf{y}) = \frac{f(\mathbf{y} | H_1)}{f(\mathbf{y} | H_0)} > 1 \iff f(\mathbf{y} | H_1) > f(\mathbf{y} | H_0)$.

*   **Relationship to Bayes' Decision Rule:** The general Bayes' decision rule minimizes the average probability of error (or a weighted probability of error if costs are involved).
    The Bayes' decision rule is: Decide $H_1$ if $P(H_1 | \mathbf{y}) > P(H_0 | \mathbf{y})$.
    This is equivalent to $f(\mathbf{y} | H_1) P(H_1) > f(\mathbf{y} | H_0) P(H_0)$.

    ML detection does not directly consider prior probabilities. It assumes all hypotheses are equally likely *a priori*, or it implicitly prioritizes likelihood over prior beliefs.

(Kay, Vol II, Section 1.2.1)

### 3. When ML Detection is Optimal

ML detection is optimal in the sense of minimizing probability of error *only* when the prior probabilities of the hypotheses are equal ($P(H_0) = P(H_1) = 0.5$). In this specific scenario, ML detection is identical to the Bayes' detector minimizing the probability of error.

**However, ML detection is *not* generally optimal when:**
*   **Prior probabilities are unequal:** ML ignores prior information, which can lead to suboptimal performance if one hypothesis is much more likely than another.
*   **Costs of errors are different:** ML implicitly assigns equal costs to both types of errors.

**Example:** Suppose we are looking for a rare signal.
$H_0$: No signal (occurs 99% of the time)
$H_1$: Signal present (occurs 1% of the time)

If $f(\mathbf{y}|H_1)$ is only slightly larger than $f(\mathbf{y}|H_0)$ for some observed $\mathbf{y}$, an ML detector might decide $H_1$. However, due to the very low prior probability of $H_1$, the posterior probability $P(H_1|\mathbf{y})$ might still be much lower than $P(H_0|\mathbf{y})$. A Bayes' detector would correctly account for this prior probability and likely decide $H_0$.

(Kay, Vol II, Section 1.2.1)

**Important Point to Remember:** Maximum Likelihood detection is a simple and intuitive rule that is optimal when prior probabilities are equal. However, for a truly optimal detector that accounts for different prior probabilities or error costs, one must use the Bayes' decision rule or the Neyman-Pearson criterion.

## Problems and Practice Questions

**Course Outcomes Addressed:** CO3 (K2), CO4 (K3)

**Learning Outcomes Covered:** All learning outcomes for this section.

**Practice Question 1:**
Suppose we observe a single data point $y$. The probability densities under two hypotheses are given by:
$f(y | H_0) = \frac{1}{\sqrt{2\pi}} e^{-y^2/2}$ (Standard Normal)
$f(y | H_1) = \frac{1}{\sqrt{2\pi}} e^{-(y-1)^2/2}$ (Normal with mean 1)

Assume equal prior probabilities, $P(H_0) = P(H_1) = 0.5$.
Derive the Likelihood Ratio Test and determine the threshold for deciding $H_1$. What is the nature of this test (e.g., ML, Bayes)?

**Answer 1:**
The likelihood ratio is:
$LR(y) = \frac{f(y | H_1)}{f(y | H_0)} = \frac{\frac{1}{\sqrt{2\pi}} e^{-(y-1)^2/2}}{\frac{1}{\sqrt{2\pi}} e^{-y^2/2}} = e^{-(y-1)^2/2 + y^2/2}$
$LR(y) = e^{-(y^2 - 2y + 1)/2 + y^2/2} = e^{-y^2/2 + y - 1/2 + y^2/2} = e^{y - 1/2}$

For equal prior probabilities, the LRT threshold $\eta = P(H_0)/P(H_1) = 0.5/0.5 = 1$.
The decision rule is to decide $H_1$ if $LR(y) > 1$:
$e^{y - 1/2} > 1$
$y - 1/2 > \ln(1) = 0$
$y > 1/2$

This is a Maximum Likelihood (ML) test because the prior probabilities are equal. It is also a Bayes' test in this specific case (equal priors).

**Practice Question 2:**
Consider the same scenario as Practice Question 1, but now assume that the signal is very rare, so $P(H_0) = 0.99$ and $P(H_1) = 0.01$.
Derive the threshold for the LRT and determine the decision rule. Is this test ML?

**Answer 2:**
The likelihood ratio is the same: $LR(y) = e^{y - 1/2}$.
The LRT threshold is $\eta = \frac{P(H_0)}{P(H_1)} = \frac{0.99}{0.01} = 99$.
The decision rule is to decide $H_1$ if $LR(y) > 99$:
$e^{y - 1/2} > 99$
$y - 1/2 > \ln(99)$
$y > 1/2 + \ln(99) \approx 0.5 + 4.595 = 5.095$

This test is a Bayes' test. It is *not* an ML test because the prior probabilities are not equal. If it were an ML test, the threshold would be 1, and we would decide $H_1$ for $y > 0.5$. With the unequal priors, we require a much larger observation ($y > 5.095$) to decide $H_1$, correctly accounting for the rarity of the signal.

**Practice Question 3:**
A radar system detects a target. Under $H_0$ (no target), the signal received is just noise, modeled as a Rayleigh distribution $f(y|H_0) = y e^{-y^2/2}$ for $y \ge 0$. Under $H_1$ (target present), the signal has a Rice distribution $f(y|H_1) = y e^{-(y^2+A^2)/2} I_0(Ay)$ for $y \ge 0$, where $A$ is a positive constant and $I_0$ is the modified Bessel function of the first kind of order zero.
If we want to design a detector with $P_{FA} = 0.05$, what is the form of the Neyman-Pearson test? (You don't need to solve for the threshold analytically, but describe the test).

**Answer 3:**
The Neyman-Pearson test will be based on the likelihood ratio:
$LR(y) = \frac{f(y | H_1)}{f(y | H_0)} = \frac{y e^{-(y^2+A^2)/2} I_0(Ay)}{y e^{-y^2/2}} = e^{-A^2/2} I_0(Ay)$

The decision rule will be to decide $H_1$ if $LR(y) > \eta_0$, where $\eta_0$ is chosen such that $P(LR(y) > \eta_0 | H_0) = 0.05$.
$P(e^{-A^2/2} I_0(Ay) > \eta_0 | H_0) = 0.05$
Since $I_0(x)$ is an increasing function of $x$ for $x \ge 0$, and $A > 0$, $I_0(Ay)$ is an increasing function of $y$.
Thus, the test will be of the form:
Decide $H_1$ if $I_0(Ay) > \eta'$, where $\eta' = \eta_0 e^{A^2/2}$ is chosen such that $P(I_0(Ay) > \eta' | H_0) = 0.05$.
This means we decide $H_1$ if $y$ is greater than some threshold $y_0$, where $y_0$ is determined by the $P_{FA}$ constraint. The test essentially looks for high values of $y$ (and hence high values of $I_0(Ay)$) when the signal is present.

(This relates to the concept of a "non-randomized" test where if the threshold results in equality, the decision is made deterministically, not probabilistically, as long as it meets the $P_{FA}$ constraint. In practice, such a threshold is often found.)

## Important Points to Remember

*   **Hypotheses:** The fundamental problem is deciding between $H_0$ (absence) and $H_1$ (presence).
*   **Observed Data:** Decisions are made based on observed data $\mathbf{y}$ and their probability distributions under each hypothesis ($f(\mathbf{y}|H_0)$ and $f(\mathbf{y}|H_1)$).
*   **Prior Probabilities:** $P(H_0)$ and $P(H_1)$ represent our belief before observing data and are crucial for optimal decisions.
*   **Likelihood Ratio (LR):** $LR(\mathbf{y}) = f(\mathbf{y}|H_1)/f(\mathbf{y}|H_0)$ is the core of many detection tests.
*   **LRT:** Deciding $H_1$ if $LR(\mathbf{y}) > \eta$. The threshold $\eta$ determines the trade-off between $P_D$ and $P_{FA}$.
*   **Errors:** Type I (False Alarm) and Type II (Miss) are inherent. $P_D = 1 - P_M$.
*   **Neyman-Pearson:** Maximizes $P_D$ for a fixed $P_{FA}$ ($\alpha$). The LRT with $\eta$ set to meet the $P_{FA}$ constraint is the NP test.
*   **UMP:** Uniformly Most Powerful means the test is the best for *all* possible data outcomes, given the $P_{FA}$ constraint. The LRT is UMP for known signal parameters.
*   **ML:** Maximizes the likelihood function $f(\mathbf{y}|H_i)$. Optimal only when prior probabilities are equal ($P(H_0)=P(H_1)=0.5$).
*   **Bayes' Detector:** Minimizes average probability of error (or expected cost) by considering both likelihoods and prior probabilities. Equivalent to LRT with $\eta = P(H_0)/P(H_1)$.

This module lays the foundation for understanding how to make statistically optimal decisions in the presence of uncertainty, a critical skill in signal processing and many other engineering fields.
